<Exercise

  title="Escolher controlos de store"

  answer={{

      'Ativei MemWrite e ALUSrc.',

      'Usei o segundo registo como dado, não como endereço.',
    ],
  }}
>
  <div>
    Indica os sinais principais para sw t1, 20(a0) e explica origem do
    endereço/dado.
  </div>
  <div slot="hint">O imediato serve para calcular endereço.</div>
  <div slot="solution">
    ALUSrc 1, ALUOp 00, MemWrite 1, MemRead 0, RegWrite 0, Branch 0; MemtoReg
    indiferente, porque o endereço é a0+20 e a palavra guardada vem de t1.
  </div>
  <div slot="mistakes">Ativar RegWrite ou usar t1 como base do endereço.</div>
</Exercise>

<Exercise
  id="ac-control-rd"
  revision={2}
  title="Diagnosticar uma escrita no destino errado"
  explanation="/cadeiras/ac/percurso-dados/#o-que-atravessa-uma-pipeline"
  answer={{
    kind: 'self',
    checklist: [
      'Identifiquei x7 como destino do load.',
      'Mostrei por que usar x8 da instrução em ID corrompe o estado.',
      'Transportei rd, RegWrite e a seleção do dado até WB.',
    ],
  }}
>
  <div>
    Um <code>lw x7,0(x10)</code> chega a WB com dado 9. Nesse ciclo, ID
    descodifica <code>add x8,x11,x12</code>. O circuito usa o rd de ID para
    escrever o dado de WB. Que registo altera indevidamente? Que informação tem
    de atravessar os registos da pipeline para corrigir o circuito?
  </div>

  <div slot="solution">
    Escreve 9 em x8, embora o load devesse escrever em x7. O destino x7 pertence
    ao load e deve passar por ID/EX, EX/MEM e MEM/WB. RegWrite e a seleção do
    dado de memória acompanham-no; usar os controlos de ID também aplicaria os
    efeitos de uma instrução diferente.
  </div>
</Exercise>

<Exercise
  id="ac-multicycle-cpi"
  revision={1}
  title="Comparar organizações"
  explanation="/cadeiras/ac/percurso-dados/#uma-máquina-multiciclo"
  answer={{ kind: 'number', value: 1050, tolerance: 0, unit: 'ps' }}
>
  <div>
    Máquina multiciclo: R 4, load 5, store 4, branch 3 ciclos; mistura 40%, 30%,
    20%, 10%; período 250 ps. Calcula tempo médio por instrução.
  </div>
  <div slot="hint">Pondera ciclos e multiplica pelo período.</div>
  <div slot="solution">
    CPI=0,4×4+0,3×5+0,2×4+0,1×3=4,2. Cada ciclo custa 250 ps, logo o tempo médio
    é 4,2×250=1050 ps. Uma organização de ciclo único com 800 ps por instrução
    seria mais rápida para esta mistura.
  </div>
  <div slot="mistakes">
    Concluir que relógio mais rápido implica menor tempo de execução.
  </div>
</Exercise>
