<Exercise
  id="ac-control-store"
  revision={1}
  title="Escolher controlos de store"
  explanation="/cadeiras/ac/percurso-dados/#sinais-de-controlo"
  answer={{
    kind: 'self',
    checklist: [
      'Ativei MemWrite e ALUSrc.',
      'Desativei RegWrite e MemRead.',
      'Usei o segundo registo como dado, não como endereço.',
    ],
  }}
>
  <div>
    Indica os sinais principais para sw t1, 20(a0) e explica origem do
    endereço/dado.
  </div>
  <div slot="hint">O imediato serve para calcular endereço.</div>
  <div slot="hint-more">ALU soma a0+20; o valor de t1 vai para memória.</div>
  <div slot="solution">
    ALUSrc 1, ALUOp 00, MemWrite 1, MemRead 0, RegWrite 0, Branch 0; MemtoReg
    indiferente. O endereço é a0+20 e a palavra guardada vem de t1.
  </div>
  <div slot="mistakes">Ativar RegWrite ou usar t1 como base do endereço.</div>
</Exercise>

      {

      },
      {

        correct: false,

      },
      {
        text: 'Usar rs1 do load como destino',
        correct: false,
        explanation: 'rs1 é a base do endereço, não o destino.',
      },
    ],
  }}
>
  <p>Como deve WB escolher o registo de destino de um load em uma pipeline?</p>
  <div slot="hint">Várias instruções ocupam fases diferentes.</div>
  <div slot="hint-more">A instrução em ID não é o load que está em WB.</div>
  <div slot="solution">
    O rd deve atravessar ID/EX, EX/MEM e MEM/WB, com RegWrite e seleção do dado.
  </div>
  <div slot="mistakes">
    Guardar apenas dados e deixar o destino ligado à instrução atualmente
    descodificada.
  </div>
</Exercise>

<Exercise

>
  <div>
    Máquina multiciclo: R 4, load 5, store 4, branch 3 ciclos; mistura 40%, 30%,
    20%, 10%; período 250 ps. Calcula tempo médio por instrução.
  </div>
  <div slot="hint">Pondera ciclos e multiplica pelo período.</div>
  <div slot="hint-more">CPI=4,2.</div>
  <div slot="solution">
    Tmedio=4,2×250=1050 ps. Ciclo único 800 ps seria mais rápido para esta
    mistura.
  </div>
  <div slot="mistakes">
    Concluir que relógio mais rápido implica menor tempo de execução.
  </div>
</Exercise>
