<Exercise
  id="ac-pipe-load-use"
  revision={1}
  title="Localizar a paragem"
  explanation="/cadeiras/ac/pipeline/#load-use-com-uma-bolha"
  answer={{ kind: 'number', value: 7, tolerance: 0 }}
>
  <div>
    lw t0, 0(a0); add t1, t0, t2. Pipeline 5 fases, forwarding completo para EX,
    WB-primeiro/ID-depois. Quantos ciclos até WB do add?
  </div>
  <div slot="hint">Duas instruções sem conflito levariam 6 ciclos.</div>
  <div slot="solution">
    7 ciclos, porque lw: IF 1, ID 2, EX 3, MEM 4, WB 5; add: IF 2, ID 3, ID 4,
    EX 5, MEM 6, WB 7.
  </div>
  <div slot="mistakes">
    Encaminhar de EX/MEM o endereço do load como se fosse o dado.
  </div>
</Exercise>

<Exercise

  answer={{ kind: 'number', value: 8, tolerance: 0 }}
>
  <div>
    lw t0, 0(a0); add t1, t0, t2. Pipeline de 5 fases, sem atalhos; WB na
    primeira metade e ID na segunda. Quantos ciclos até WB do add?
  </div>
  <div slot="hint">O add pode ler o valor no ciclo WB do load.</div>
  <div slot="solution">
    8 ciclos. Duas paragens levam o add até WB 8, porque a leitura no mesmo
    ciclo WB 5 evita uma terceira paragem.
  </div>
  <div slot="mistakes">
    Presumir uma terceira paragem sem alterar o contrato temporal do banco.
  </div>
</Exercise>

<Exercise
  id="ac-pipe-store"
  revision={1}
  title="Distinguir dado e endereço"
  explanation="/cadeiras/ac/pipeline/#o-operando-de-um-store"
  answer={{
    kind: 'self',
    checklist: [
      'Identifiquei t0 como dado usado em MEM.',
      'Indiquei o atalho de MEM/WB para MEM.',
      'Não confundi esse caso com t0 usado como base em EX.',
    ],
  }}
>
  <p>Explica quando lw t0, 0(a0); sw t0, 0(a1) pode executar sem paragem.</p>
  <div slot="hint">O store só precisa de guardar o dado em MEM.</div>
  <div slot="solution">
    Com atalho que leva o dado carregado de MEM/WB para a entrada de escrita em
    MEM 5, não há paragem. Se t0 fosse base do endereço do store, seria
    necessário em EX 4, mais cedo; se o atalho de store não existe, segue as
    regras do modelo.
  </div>
  <div slot="mistakes">
    Aplicar uma regra universal para load seguido de store sem conferir o
    caminho de hardware.
  </div>
</Exercise>

<Exercise
  id="ac-pipe-schedule"
  revision={2}
  title="Reordenar preservando o resultado"
  explanation="/cadeiras/ac/pipeline/#contar-e-reduzir-paragens"
  answer={{
    kind: 'self',
    checklist: [
      'Intercalei uma instrução independente.',
      'Conservei dependências de registos e memória.',
      'Expliquei qual valor fica pronto no EX do consumidor.',
    ],
  }}
>
  <div>
    Propõe uma ordem sem paragem load-use para lw t0, 0(a0); add t1, t0, t2;
    addi a1, a1, 4. a1 não participa nos restantes operandos. Usa a pipeline de
    5 fases com atalhos completos para EX e memórias I/D separadas, sem exceções
    ou efeitos externos.
  </div>
  <div slot="hint">A atualização de a1 é independente do load/add.</div>
  <div slot="solution">
    lw t0, 0(a0); addi a1, a1, 4; add t1, t0, t2. O add chega a EX quando o dado
    do load já pode ser encaminhado. A mudança é válida nas condições dadas
    porque a1 não interfere com os acessos ou resultados.
  </div>
  <div slot="mistakes">
    Intercalar uma operação que altera a0 antes do load ou que muda um operando
    do add.
  </div>
</Exercise>

<Exercise
  id="ac-pipe-duas-iteracoes"
  revision={1}
  title="Traçar duas iterações sem confundir finito com regime"
  explanation="/cadeiras/ac/pipeline/#contar-e-reduzir-paragens"
  answer={{ kind: 'number', value: 9, tolerance: 0 }}
>
  <div>
    Traça add a0,t0,a1; lw t0,0(a0) por duas iterações (add1, lw1, add2, lw2),
    pipeline de 5 fases com forwarding completo para EX. Conta as bolhas dentro
    da janela e os ciclos até WB de lw2. Depois indica o CPI limite em regime.
  </div>
  <div slot="hint">
    Dentro de cada iteração não há espera; só há uma aresta lw para add dentro
    da janela.
  </div>
  <div slot="solution">
    Só lw1 para add2 impõe bolha; lw2 para um add3 fora da janela não conta. Com
    B=1, são 9 ciclos até WB de lw2 e CPI finito 9/4=2,25. Em regime, cada 2
    instruções pagam 1 paragem, logo o CPI tende para 3/2=1,5. O erro é contar 2
    paragens no traço finito ou ler 1,5 como 9/4.
  </div>
  <div slot="mistakes">
    Contar a aresta de fecho fora da janela ou confundir o CPI finito com o
    limite em regime.
  </div>
</Exercise>
