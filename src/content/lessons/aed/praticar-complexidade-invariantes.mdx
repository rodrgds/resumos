<Exercise
  id="aed-triangular"
  title="Contar um ciclo triangular"
  explanation="/cadeiras/aed/complexidade-invariantes/#contar-operações"
  answer={{ kind: 'number', value: 66, tolerance: 0 }}
>
  <p>
    Um ciclo exterior usa i=1..12; o interior usa j=1..i-1 e faz uma comparação
    por iteração. Quantas comparações são feitas?
  </p>
  <div slot="hint">
    <p>Escreve os comprimentos dos primeiros ciclos interiores.</p>
  </div>
  <div slot="hint-more">
    <p>A soma é 0+1+...+11.</p>
  </div>
  <div slot="solution">
    <p>
      São 12×11/2=66 comparações. Para dimensão n, n(n-1)/2 é Θ(n²). O ciclo com
      i=1 não executa o corpo interior.
    </p>
  </div>
  <div slot="mistakes">
    <p>Não uses n² como contagem exata; não incluas j=i.</p>
  </div>
</Exercise>

<Exercise
  id="aed-primeiro-maximo"
  title="Provar uma política de empate"
  explanation="/cadeiras/aed/complexidade-invariantes/#contrato-e-invariante"
  answer={{
    kind: 'self',
    checklist: [
      'Indiquei a posição 1.',
      'Mostrei inicialização, manutenção e conclusão com a política de empate.',
      'Justifiquei terminação e o contrato não vazio.',
    ],
  }}
>
  <p>
    O máximo do vetor [6,9,9,2] é procurado atualizando a posição só quando o
    novo valor é estritamente maior. Dá a posição com índices a partir de zero e
    prova que é a primeira ocorrência.
  </p>
  <div slot="work">
    <p>
      Este programa usa uma comparação que viola a política da primeira
      ocorrência. Corrige-a e confirma que cada resultado obtido coincide com o
      esperado. No vazio, a posição devolvida é o tamanho, sem aceder ao vetor.
    </p>
    <CodePlayground
      language="cpp"
      title="Corrigir o empate do máximo"
      code={
        '#include <iostream>\n#include <vector>\nstd::size_t primeiraPosicao(const std::vector<int>& a) {\n    if (a.empty()) return a.size();\n    std::size_t melhor = 0;\n    for (std::size_t i = 1; i < a.size(); ++i)\n        if (a[i] >= a[melhor]) melhor = i;\n    return melhor;\n}\nint main() {\n    const std::vector<std::vector<int>> casos{{6,9,9,2},{4,4,4},{-2},{1,3,5},{}};\n    const std::vector<std::size_t> esperado{1,0,0,2,0};\n    for (std::size_t i = 0; i < casos.size(); ++i)\n        std::cout << "obtido=" << primeiraPosicao(casos[i])\n                  << "; esperado=" << esperado[i] << \'\\n\';\n}\n'
      }
    />
  </div>
  <div slot="hint">
    <p>
      A propriedade tem de referir o prefixo já examinado e a escolha entre
      iguais.
    </p>
  </div>
  <div slot="hint-more">
    <p>
      Antes da iteração i, a resposta é a primeira posição do máximo em [0,i).
    </p>
  </div>
  <div slot="solution">
    <p>
      A posição é 1. Inicialmente o prefixo tem só a posição 0. Uma chave maior
      substitui o máximo; uma chave igual não troca a posição mais antiga. Ao
      terminar, o prefixo é todo o vetor. n-i diminui até zero, provando
      terminação. Uma entrada vazia exige outro contrato.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Provar só que o valor é máximo não justifica a primeira posição; usar
      &gt;= mudaria a resposta para 2.
    </p>
  </div>
</Exercise>

<Exercise
  id="aed-kadane"
  title="Distinguir o intervalo vazio"
  explanation="/cadeiras/aed/complexidade-invariantes/#melhor-soma-contígua"
  answer={{ kind: 'number', value: 8, tolerance: 0 }}
>
  <p>
    Qual é a maior soma de um intervalo contíguo não vazio de [-2,4,-6,3,5,-1]?
    Traça atual e melhor para justificar a resposta.
  </p>
  <div slot="hint">
    <p>
      Em cada posição, compara começar aí com prolongar o melhor intervalo que
      acabava antes.
    </p>
  </div>
  <div slot="hint-more">
    <p>
      Os valores de atual começam por -2, 4 e -2; o valor 3 inicia um intervalo
      novo.
    </p>
  </div>
  <div slot="solution">
    <p>
      Os valores de atual são -2,4,-2,3,8,7. Os de melhor são -2,4,4,4,8,8. A
      soma máxima é 8, do intervalo [3,5]. Há apenas trabalho constante por
      posição, dando O(n). Numa entrada só de negativos, a inicialização no
      primeiro elemento conserva o contrato não vazio.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Não escolhas valores separados: 4+3+5 ignora o -6 entre eles. Inicializar
      a resposta em zero devolveria um intervalo vazio quando todos os valores
      fossem negativos.
    </p>
  </div>
</Exercise>
