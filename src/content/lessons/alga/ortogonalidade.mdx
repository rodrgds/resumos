Depois de medir ângulos e comprimentos com o produto escalar, esta página responde à pergunta seguinte: como escolher bases em que as coordenadas saem sem resolver um sistema novo para cada vetor?

Uma base descreve cada vetor com coordenadas. Uma base **ortogonal** facilita essas contas, porque cada direção fica perpendicular às restantes. Por isso, obténs as coordenadas com produtos escalares, sem resolver um sistema novo para cada vetor.

## Ortogonal não significa ortonormado

Uma família $(u_1,\ldots,u_k)$ é ortogonal quando $u_i\cdot u_j=0$ para $i\ne j$. Se todos os vetores forem não nulos, são independentes. Para ver porquê, toma uma combinação nula e faz o produto escalar com $u_j$:

$$
\sum_i a_i u_i=0
\quad\Longrightarrow\quad a_j\|u_j\|^2=0
\quad\Longrightarrow\quad a_j=0.
$$

Uma família **ortonormada** é ortogonal e cada vetor tem norma 1. Normaliza cada vetor por $q_i=u_i/\|u_i\|$. O vetor zero é perpendicular a todos, mas não pode fazer parte de uma base nem ser normalizado.

## Gram-Schmidt passo a passo

O processo de Gram-Schmidt recebe vetores independentes $(v_1,\ldots,v_k)$ e produz uma base ortogonal do mesmo subespaço. A cada vetor, retira as componentes nas direções já obtidas:

$$
u_1=v_1,\qquad
u_j=v_j-\sum_{i=1}^{j-1}\frac{v_j\cdot u_i}{u_i\cdot u_i}u_i.
$$

Os denominadores são normas ao quadrado. Não são apenas normas. Os vetores usados nas projeções são os $u_i$ já ortogonalizados.

Parte de $v_1=(1,1,0)$, $v_2=(1,0,1)$ e $v_3=(0,1,1)$.

1. Mantemos $u_1=(1,1,0)$.
2. Como $v_2\cdot u_1=1$ e $u_1\cdot u_1=2$,

$$
u_2=(1,0,1)-\frac12(1,1,0)=(1/2,-1/2,1).
$$

3. Para $v_3$, retiramos as duas projeções:

$$
u_3=(0,1,1)-\frac12(1,1,0)-\frac13(1/2,-1/2,1)
=(-2/3,2/3,2/3).
$$

Aqui $v_3\cdot u_2=1/2$ e $u_2\cdot u_2=3/2$, por isso o segundo coeficiente é $1/3$.

Podes multiplicar cada vetor não nulo por um escalar para evitar frações. A base ortogonal fica

$$
(w_1,w_2,w_3)=((1,1,0),(1,-1,2),(-1,1,1)).
$$

Os três produtos escalares entre vetores distintos são zero. As normas são $\sqrt2,\sqrt6,\sqrt3$, logo a base ortonormada é $(w_1/\sqrt2,w_2/\sqrt6,w_3/\sqrt3)$.

Se um passo produzir o vetor zero, o vetor de entrada já estava no espaço gerado pelos anteriores. Não o normalizes. Retira-o e continua, se o objetivo for obter uma base a partir de geradores dependentes.

## Coordenadas numa base ortogonal

Se $v$ pertence ao espaço gerado por uma base ortogonal $(u_1,\ldots,u_k)$, as suas coordenadas são

$$
a_i=\frac{v\cdot u_i}{u_i\cdot u_i}.
$$

Numa base ortonormada, os denominadores são 1 e $a_i=v\cdot q_i$. Esta simplificação exige ortogonalidade: fazer produtos escalares com uma base qualquer não dá, em geral, as coordenadas. Por exemplo, com $v=(2,1,0)$ na base ortogonal $((1,1,0),(1,-1,2))$, as coordenadas são $(v\cdot u_1)/(u_1\cdot u_1)=3/2$ e $(v\cdot u_2)/(u_2\cdot u_2)=1/6$.

## Projeção num subespaço

Para $W=\operatorname{span}(u_1,\ldots,u_k)$, com base ortogonal,

$$
\operatorname{proj}_W v=\sum_{i=1}^k
\frac{v\cdot u_i}{u_i\cdot u_i}u_i.
$$

O vetor projetado pertence a $W$. O erro $v-\operatorname{proj}_Wv$ é perpendicular a todos os vetores de $W$.

Considera $W=\operatorname{span}((1,1,0),(1,-1,2))$ e $v=(2,1,0)$. Como os dois geradores são ortogonais,

$$
p=\frac32(1,1,0)+\frac16(1,-1,2)=(5/3,4/3,1/3).
$$

O erro é $e=v-p=(1/3,-1/3,-1/3)$. Os produtos $e\cdot(1,1,0)$ e $e\cdot(1,-1,2)$ são zero. A distância de $v$ ao plano $W$ é $\|e\|=1/\sqrt3$.

Porque é $p$ o ponto mais próximo? Para qualquer $w\in W$, escrevemos $v-w=e+(p-w)$. As duas parcelas são perpendiculares, logo

$$
\|v-w\|^2=\|e\|^2+\|p-w\|^2\geq\|e\|^2.
$$

A igualdade só acontece quando $w=p$. A projeção não é apenas um ponto do plano, é o único que minimiza a distância.

## Reflexão num subespaço

Decompõe $v=p+e$, com $p=\operatorname{proj}_W v$ e $e$ perpendicular a $W$. O vetor refletido em relação a $W$ é $R_W(v)=2p-v$: o ponto médio de $v$ e $R_W(v)$ é $p$ e a diferença $v-R_W(v)=2e$ é perpendicular a $W$. Com $W=\operatorname{span}((1,1,0),(1,-1,2))$ e $v=(2,1,0)$, temos $p=(5/3,4/3,1/3)$ e $R_W(v)=(4/3,5/3,2/3)$. Confirma: o ponto médio é $p$ e $v-R_W(v)=(2/3,-2/3,-2/3)$ tem produto escalar zero com os dois geradores.

## Complemento ortogonal

O **complemento ortogonal** de $W$ é

$$
W^\perp=\{x:x\cdot w=0\text{ para todo }w\in W\}.
$$

Para o obter, basta exigir produto escalar nulo com os vetores de uma base de $W$. No exemplo,

$$
x+y=0,\qquad x-y+2z=0
\quad\Longrightarrow\quad
W^\perp=\operatorname{span}((-1,1,1)).
$$

Em $\mathbb R^n$, $\dim W+\dim W^\perp=n$ e $\mathbb R^n=W\oplus W^\perp$. A decomposição $v=p+e$ acima é precisamente essa soma direta.

## O que costuma correr mal

- Normalizar o vetor zero ou confundir norma 1 com ortogonalidade.
- Projetar sobre os vetores originais em cada passo de Gram-Schmidt.
- Somar projeções sobre uma base que não é ortogonal.
- Entregar uma base ortogonal quando o pedido exige uma base ortonormada.
