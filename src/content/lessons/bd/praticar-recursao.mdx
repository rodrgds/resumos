<Exercise
  id="recursao-limite-seis"
  title="O limite usa o valor anterior"
  explanation="/cadeiras/bd/sql-recursao/#parte-inicial-e-passo-recursivo"
  answer={{ kind: 'number', value: 6, tolerance: 0 }}
>
  <div>
    A CTE começa com <code>{'SELECT'}</code> 1 e usa <code>{'UNION ALL'}</code>{' '}
    <code>{'SELECT'}</code> n+1 FROM Numero <code>{'WHERE'}</code>
    n&lt;=5. Qual o maior número produzido?
  </div>
  <div slot="hint">O predicado testa n antes de somar um.</div>
  <div slot="solution">
    O maior é 6. A sequência é 1,2,3,4,5,6. Ao processar 6, a condição é falsa e
    não produz 7. Para terminar em 5, usa n&lt;5 no passo, com a mesma parte
    inicial.
  </div>
</Exercise>

<Exercise
  id="recursao-union-profundidade"
  title="UNION num ciclo não basta sempre"
  explanation="/cadeiras/bd/sql-recursao/#grafos-e-ciclos"
  answer={{
    kind: 'self',
    checklist: [
      'Expliquei a comparação do tuplo completo.',
      'Propus uma estratégia adequada à pergunta.',
    ],
  }}
>
  <div>
    Num grafo 1→2→1, uma CTE recursiva guarda (id,profundidade), começa em (1,0)
    e incrementa profundidade. UNION impede por si só o ciclo?
  </div>
  <div slot="hint">UNION compara o tuplo completo.</div>
  <div slot="solution">
    Não. Produz (1,0),(2,1),(1,2),(2,3) e assim sucessivamente. Cada retorno tem
    outra profundidade, por isso não é um duplicado do tuplo anterior. Para
    alcançabilidade sem distâncias, guarda apenas id e usa UNION. Para caminhos
    ou profundidade, aplica outra estratégia que impeça repetir nós no caminho
    ou imponha uma condição de exploração coerente com a pergunta.
  </div>
  <div slot="mistakes">
    Um limite arbitrário de profundidade pode terminar a consulta mas cortar
    respostas válidas. Distingue terminação de correção.
  </div>
</Exercise>

<Exercise
  id="dhondt-divisores-recursivos"
  revision={2}
  title="Só os divisores precisam de recursão"
  explanation="/cadeiras/bd/sql-recursao/#divisores-e-distribuição-de-mandatos"
  answer={{
    kind: 'self',
    checklist: [
      'Gerei os divisores 1 a 4 com a CTE recursiva.',
      'Cruzei votos com divisores e escolhi os 4 maiores quocientes.',
      'Obtive A com 2, B com 1 e C com 1, com desempate explícito.',
    ],
  }}
>
  <div>
    Três listas têm 100, 60 e 40 votos e há 4 mandatos. Escreve a consulta de
    D'Hondt que gera os divisores recursivamente e distribui os mandatos. Para este problema, desempata quocientes pelo nome da lista, em ordem crescente. A
    execução apresenta o resultado; confere cada quociente do top 4.
  </div>
  <div slot="work">
    <p>
      Os quocientes candidatos são 100, 60, 50 e 40. A resposta deve ser A com
      2, B com 1 e C com 1.
    </p>
    <CodePlayground
      autoRun={false}
      language="sqlite"
      title="Completar a distribuição de D'Hondt"
      code={`WITH Voto(lista, votos) AS (
  VALUES ('A', 100), ('B', 60), ('C', 40)
)
-- Acrescenta divisores, quocientes e seleção dos lugares.
SELECT * FROM Voto ORDER BY lista;`}
    />
  </div>
  <div slot="hint">
    Cada lista compete com votos/1, votos/2, votos/3 e votos/4.
  </div>
  <div slot="solution">

```sql
WITH RECURSIVE Divisor(k) AS (
  SELECT 1
  UNION ALL
  SELECT k + 1 FROM Divisor WHERE k < 4
),
Voto(lista, votos) AS (
  VALUES ('A', 100), ('B', 60), ('C', 40)
),
Quociente AS (
  SELECT v.lista, v.votos / (d.k * 1.0) AS q
  FROM Voto AS v CROSS JOIN Divisor AS d
),
Top AS (
  SELECT lista FROM Quociente
  ORDER BY q DESC, lista LIMIT 4
)
SELECT lista, COUNT(*) AS mandatos
FROM Top GROUP BY lista ORDER BY lista;
```

    O top 4 é 100 de A, 60 de B, 50 de A e 40 de C, por isso A fica com 2, B com
    1 e C com 1. Só a CTE Divisor é recursiva; quocientes, seleção e contagem
    são operações comuns. O segundo critério de ordenação resolve empates de
    quociente de forma explícita. Sem ele, a escolha entre empatados ficaria
    indefinida.

  </div>
  <div slot="mistakes">
    Não tornes a agregação recursiva. Não contes votos quando a pergunta pede
    lugares nos maiores quocientes.
  </div>
</Exercise>
