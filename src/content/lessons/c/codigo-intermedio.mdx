A árvore sintática ainda está longe das instruções da máquina. Entre as duas há um nível intermédio: uma representação que explicita operações e controlo para as otimizações e a geração de código. A forma clássica é o **código de três endereços**: uma atribuição típica tem a forma `destino = operando1 op operando2`. Os três endereços são o destino e os dois operandos, que podem ser nomes ou constantes. Cópias, saltos, chamadas e retornos usam outras formas e nem sempre definem um temporário.

## Níveis de representação

Uma representação de alto nível pode conservar operações como acesso a vetor ou chamada de método. Ao baixar o nível, explicitamos endereços, deslocamentos e operações simples. Por exemplo, num vetor de inteiros de 4 bytes sem cabeçalho, o endereço de `v[i]` é `base + 4 * i`. O tamanho do elemento e a disposição do vetor são hipóteses do alvo, não constantes universais.

## Traduzir expressões e controlo

A tradução desfaz as expressões aninhadas em passos elementares com temporários frescos (`t1`, `t2`, ...). O controlo traduz-se com **rótulos** e **saltos**: cada construção gera o teste, os saltos para os ramos e os rótulos de junção, com os nomes gerados de forma única.

## Exemplo: `while` com condição composta

```java
while (a < b && c != 0) {
  a = a + 1;
}
```

Tradução para três endereços, com a condição composta partida em testes encadeados. Há curto-circuito: se `a < b` for falso, salta logo para fora sem avaliar o resto.

```
L_topo:
  t1 = a < b
  if_false t1 goto L_fora
  t2 = c != 0
  if_false t2 goto L_fora
  t3 = a + 1
  a = t3
  goto L_topo
L_fora:
```


Cada teste decide logo: se `a < b` for falso, o segundo teste nunca corre. É o comportamento que o programador espera de `&&`.

```
t1 = a < b
t2 = c != 0
t3 = t1 && t2
if_false t3 goto L_fora
```

Os dois lados avaliam-se sempre e o `&&` vira uma operação sobre booleanos. Mais simples de gerar, mas avalia `c != 0` mesmo quando `a < b` já falhou, o que muda o significado se o segundo teste tiver efeitos ou puder falhar, como `d != 0 && n / d > 2` quando `d` vale zero.

Os temporários `t1` e `t2` guardam resultados booleanos intermédios que na árvore estavam escondidos dentro da condição.

## Blocos básicos e grafo de fluxo

Um **bloco básico** é uma sequência de instruções que se executa sempre do início ao fim: entra-se só pela primeira instrução e sai-se só pela última. Para partir o código em blocos, marcam-se os **líderes**: a primeira instrução, cada destino de salto e cada instrução logo a seguir a um salto. Cada bloco vai de um líder até antes do líder seguinte.

Numeramos os rótulos juntamente com as operações para este exemplo. Um rótulo final representa a saída, sem instrução executável. Instruções numeradas: 1 `t1 = a < b`, 2 `if_false t1 goto L_fora`, 3 `t2 = c != 0`, 4 `if_false t2 goto L_fora`, 5 `t3 = a + 1`, 6 `a = t3`, 7 `goto L_topo`, 8 `L_fora:`. Líderes: 1 (primeira), 3 (segue-se a um salto condicional), 5 (segue-se a um salto condicional), 8 (destino de salto). Blocos: B1 = {1, 2}, B2 = {3, 4}, B3 = {5, 6, 7}, B4 = {8}. O **grafo de fluxo** liga-os pelas arestas possíveis: B1 para B2 (condição verdadeira) e para B4 (saída), B2 para B3 e para B4, B3 de volta para B1.

Cada caminho do grafo descreve uma execução possível do `while`, com zero, uma ou várias iterações.

O programa abaixo aplica a regra dos líderes às mesmas oito instruções.

<CodePlayground
  language="python"
  title="Líderes e blocos"
  code={
    'instrucoes = [\n    "L_topo: t1 = a < b",\n    "if_false t1 goto L_fora",\n    "t2 = c != 0",\n    "if_false t2 goto L_fora",\n    "t3 = a + 1",\n    "a = t3",\n    "goto L_topo",\n    "L_fora:",\n]\nrotulos = {}\nfor n, inst in enumerate(instrucoes):\n    if ":" in inst:\n        rotulo, _ = inst.split(":", 1)\n        rotulos[rotulo] = n\nlideres = {0}\nfor n, inst in enumerate(instrucoes):\n    operacao = inst.split(":", 1)[-1].strip().split()\n    if operacao and operacao[0] in {"if_false", "goto"}:\n        lideres.add(rotulos[operacao[-1]])\n        if n + 1 < len(instrucoes):\n            lideres.add(n + 1)\ninicio = sorted(lideres)\nfor b, a in enumerate(inicio):\n    fim = inicio[b + 1] if b + 1 < len(inicio) else len(instrucoes)\n    print(f"B{b + 1} = {list(range(a + 1, fim + 1))}")'
  }
/>

:::tip[Como partir sem errar]
Sublinha primeiro todos os rótulos destino e todos os saltos. Cada líder é mecânico: primeira linha, destino, depois de salto. Só depois agrupa, porque o erro típico é pôr um destino de salto a meio de um bloco.
:::
