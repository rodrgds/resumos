Uma **condição** é uma pergunta com resposta sim ou não que escolhe um caminho. Um **ciclo** repete instruções enquanto a resposta for sim. Para prever a saída, segue os valores das variáveis e identifica o momento em que a condição é avaliada.

## Escolher um ramo

```python
if nota >= 18:
    classificacao = "excelente"
elif nota >= 10:
    classificacao = "aprovado"
else:
    classificacao = "reprovado"
```

Python testa os ramos por ordem e executa apenas o primeiro verdadeiro. Para `nota = 19`, não volta a executar o ramo de aprovação. Dois `if` independentes seriam duas decisões, que podem executar ambas.

A indentação define o bloco. Usa quatro espaços e alinha as instruções que pertencem à mesma decisão. Uma instrução sem indentação depois do bloco executa independentemente do ramo escolhido.

`<`, `<=`, `>`, `>=`, `==` e `!=` comparam valores. `and`, `or` e `not` combinam condições. Em `divisor != 0 and numerador / divisor > 2`, Python só divide quando a primeira condição é verdadeira. Isto chama-se **avaliação em curto-circuito**.

`0`, strings vazias, coleções vazias e `None` são falsos numa condição. Uma string `"False"` é verdadeira porque não está vazia. Usa `is None` para testar ausência e `==` para comparar valores.

## Repetir enquanto uma condição vale

Num `while`, a condição é testada antes de cada iteração. Pode não haver nenhuma iteração. Vamos somar 1, 2 e 3:

<CodePlayground
  language="python"
  title={'Seguir um while'}
  code={
    'k = 1\ntotal = 0\nwhile k <= 3:\n    total += k\n    k += 1\nprint(total)'
  }
/>

| Teste antes da iteração | `k` | `total` antes | `total` depois |
| ----------------------- | --- | ------------- | -------------- |
| `1 <= 3`                | 1   | 0             | 1              |
| `2 <= 3`                | 2   | 1             | 3              |
| `3 <= 3`                | 3   | 3             | 6              |
| `4 <= 3`                | 4   | 6             | Não executa    |

O ciclo termina porque `k` aumenta e acaba por ultrapassar 3. Se retirares `k += 1`, a condição continua verdadeira e o ciclo não termina.

  source={

  }

## Percorrer valores com for

`for` recebe um iterável e percorre os seus elementos. Não precisas de controlar o avanço manualmente.

```python
for quantidade in [2, 4, 6]:
    print(quantidade)
```

`range(inicio, fim, passo)` produz inteiros. Inclui o início e exclui o fim. O passo por defeito é 1 e não pode ser zero.

| Expressão         | Valores    |
| ----------------- | ---------- |
| `range(4)`        | 0, 1, 2, 3 |
| `range(1, 4)`     | 1, 2, 3    |
| `range(2, 8, 2)`  | 2, 4, 6    |
| `range(5, 0, -2)` | 5, 3, 1    |
| `range(3, 3)`     | Nenhum     |

Para somar de 1 até `n` inclusive, escreve `range(1, n + 1)`. Se o início já está além do fim na direção do passo, o intervalo é vazio.

## Acumular, contar e procurar

O estado inicial depende da operação: uma soma começa em zero, um produto em um. Uma contagem começa em zero e aumenta apenas quando a condição se verifica.

<CodePlayground
  language="python"
  title={'Média dos valores positivos'}
  code={
    'valores = [3, -1, 4, 0, 2]\ntotal = 0\ncontagem = 0\nfor valor in valores:\n    if valor > 0:\n        total += valor\n        contagem += 1\nprint(total, contagem)\nprint(total / contagem)'
  }
/>

A média usa três observações, não o comprimento da lista inteira. Se não houver positivos, a contagem é zero e a divisão precisa de um ramo que trate esse caso.

`break` termina o ciclo mais próximo. `continue` passa ao próximo teste ou próximo elemento. Um `else` de um ciclo executa quando o ciclo acaba normalmente, sem `break`, e não significa que a última condição de um `if` foi falsa.

## Procurar sem confundir ausência com zero

Para encontrar o máximo de uma sequência não vazia, começa pelo primeiro valor, não por zero. Se todos os valores forem negativos, zero seria um máximo inventado. Ao procurar também a posição, decide como tratar empates:

<CodePlayground
  language="python"
  title="Guardar o primeiro máximo"
  code={
    'valores = [-5, -2, -2, -8]\nif not valores:\n    raise ValueError("Não há máximo sem valores")\nmaximo = valores[0]\nposicao = 0\nfor i in range(1, len(valores)):\n    if valores[i] > maximo:\n        maximo = valores[i]\n        posicao = i\nprint(maximo, posicao)'
  }
/>

Usar `>` conserva a primeira ocorrência do máximo −2 na posição 1; usar `>=` guardaria a última, posição 2. O estado do ciclo tem dois nomes: o maior valor visto até agora e a posição em que o encontrámos.

## Procurar um divisor com for e else

Um inteiro é primo se for pelo menos 2 e os seus únicos divisores positivos forem 1 e ele próprio. Para 9, encontrar o divisor 3 é suficiente para concluir que não é primo. Para 13, nenhum dos inteiros de 2 até 12 divide exatamente.

<CodePlayground
  language="python"
  title="Parar quando aparece um divisor"
  code={
    'n = 9\nif n < 2:\n    print("Não é primo")\nelse:\n    for divisor in range(2, n):\n        if n % divisor == 0:\n            print("Não é primo; divisor:", divisor)\n            break\n    else:\n        print("É primo")'
  }
/>

O `else` está alinhado com o `for`. Só executa se não houve `break`. O teste `n < 2` trata 0, 1 e negativos; para 2, o intervalo é vazio e a conclusão é primo. Não uses o último valor do ciclo para decidir se encontraste um divisor: um ciclo vazio nem sequer atribui esse nome.

## Ciclos dentro de ciclos

Para uma tabela com duas linhas e três colunas, o ciclo exterior escolhe a linha e o interior percorre as suas colunas. Há seis visitas a células. Se `break` estiver no ciclo interior, sai apenas desse ciclo. Não alteres a coleção que estás a percorrer sem compreender como isso muda os elementos que o iterador ainda vai visitar.
