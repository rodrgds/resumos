Uma nota de 19 satisfaz tanto `nota >= 18` como `nota >= 10`. Para lhe atribuir uma única classificação, a ordem dos testes e a escolha entre `if` independentes ou uma cadeia `if`/`elif` fazem diferença.

## if, elif e else

```python
if nota >= 18:
    classificacao = "excelente"
elif nota >= 10:
    classificacao = "aprovado"
else:
    classificacao = "reprovado"
```

Python testa os ramos por ordem e executa apenas o primeiro verdadeiro, por isso para `nota = 19` não volta a executar o ramo de aprovação. Dois `if` independentes seriam duas decisões, que podem executar ambas.

A indentação define o bloco. Usa quatro espaços e alinha as instruções que pertencem à mesma decisão, pois uma instrução sem indentação depois do bloco executa independentemente do ramo escolhido.

`<`, `<=`, `>`, `>=`, `==` e `!=` comparam valores, enquanto `and`, `or` e `not` combinam condições. Em `divisor != 0 and numerador / divisor > 2`, Python só divide quando a primeira condição é verdadeira, o que se chama **avaliação em curto-circuito**.

`0`, strings vazias, coleções vazias e `None` são falsos numa condição, mas uma string `"False"` é verdadeira porque não está vazia. Usa `is None` para testar ausência e `==` para comparar valores.

## Raízes reais de uma equação quadrática

No problema 4.03 da folha de 2022, a escolha do ramo depende de existirem raízes reais. Para $ax^2 + bx + c = 0$, com $a \ne 0$, o **discriminante** é $\Delta = b^2 - 4ac$. A raiz quadrada real só existe quando $\Delta \ge 0$:

$$
x = \frac{-b \pm \sqrt{\Delta}}{2a}.
$$

Com coeficientes inteiros pequenos, o discriminante é calculado exatamente como inteiro em Python. Para `a = 1`, `b = -3` e `c = 2`, dá `9 - 8 = 1`, por isso há duas raízes: `(3 - 1)/2 = 1` e `(3 + 1)/2 = 2`.

```python
from math import sqrt

a, b, c = 1, -3, 2
if a == 0:
    raise ValueError("A equação não é quadrática")
discriminante = b * b - 4 * a * c
if discriminante > 0:
    raiz = sqrt(discriminante)
    print((-b - raiz) / (2 * a), (-b + raiz) / (2 * a))
elif discriminante == 0:
    print(-b / (2 * a))
else:
    print("Sem raízes reais")
```

O programa escreve `1.0 2.0`. Se $\Delta = 0$, os dois sinais da fórmula dão a mesma raiz, que escrevemos uma vez. Se $\Delta < 0$, não calculamos `sqrt(discriminante)`: esse cálculo causaria `ValueError` antes de conseguirmos apresentar a conclusão.

O teste inicial evita a divisão por zero, mas também verifica a hipótese da fórmula: com `a = 0`, a equação deixa de ser quadrática. Não a classificamos automaticamente como uma equação sem raízes. Para coeficientes reais aproximados perto de um discriminante nulo, a decisão exige uma política numérica adequada; o exemplo usa inteiros pequenos para separar essa questão da escolha dos ramos.

## Ciclo while

Num `while`, a condição é testada antes de cada iteração, pelo que pode não haver nenhuma iteração. Para somar 1, 2 e 3:

<CodePlayground
  language="python"
  title={'Seguir um while'}
  code={
    'k = 1\ntotal = 0\nwhile k <= 3:\n    total += k\n    k += 1\nprint(total)'
  }
/>

| Teste antes da iteração | `k` | `total` antes | `total` depois |
| ----------------------- | --- | ------------- | -------------- |
| `1 <= 3`                | 1   | 0             | 1              |
| `2 <= 3`                | 2   | 1             | 3              |
| `3 <= 3`                | 3   | 3             | 6              |
| `4 <= 3`                | 4   | 6             | Não executa    |

O ciclo termina porque `k` aumenta e acaba por ultrapassar 3. Se retirares `k += 1`, a condição continua verdadeira e o ciclo não termina.

## Ciclo for e range

`for` recebe um iterável e percorre os seus elementos, sem precisares de controlar o avanço manualmente.

```python
for quantidade in [2, 4, 6]:
    print(quantidade)
```

`range(inicio, fim, passo)` produz inteiros. Inclui o início e exclui o fim, com passo 1 por defeito, que não pode ser zero.

| Expressão         | Valores    |
| ----------------- | ---------- |
| `range(4)`        | 0, 1, 2, 3 |
| `range(1, 4)`     | 1, 2, 3    |
| `range(2, 8, 2)`  | 2, 4, 6    |
| `range(5, 0, -2)` | 5, 3, 1    |
| `range(3, 3)`     | Nenhum     |

Para somar de 1 até `n` inclusive, escreve `range(1, n + 1)`. Se o início já está além do fim na direção do passo, o intervalo é vazio.

## Acumuladores e contagens

O estado inicial depende da operação: uma soma começa em zero e um produto em um, enquanto uma contagem começa em zero e aumenta apenas quando a condição se verifica.

<CodePlayground
  language="python"
  title={'Média dos valores positivos'}
  code={
    'valores = [3, -1, 4, 0, 2]\ntotal = 0\ncontagem = 0\nfor valor in valores:\n    if valor > 0:\n        total += valor\n        contagem += 1\nprint(total, contagem)\nprint(total / contagem)'
  }
/>

O acumulador soma `3 + 4 + 2 = 9` e a contagem é 3, por isso a média é `9 / 3 = 3`, não `9 / 5`. Se não houver positivos, a contagem é zero e a divisão precisa de um ramo que trate esse caso.

`break` termina o ciclo mais próximo e `continue` passa ao próximo teste ou próximo elemento. Um `else` de um ciclo executa quando o ciclo acaba normalmente, sem `break`, e não significa que a última condição de um `if` foi falsa.

## Máximo e empates

Para encontrar o máximo de uma sequência não vazia, começa pelo primeiro valor, não por zero, pois se todos os valores forem negativos, zero seria um máximo inventado. Ao procurar também a posição, decide como tratar empates:

<CodePlayground
  language="python"
  title="Guardar o primeiro máximo"
  code={
    'valores = [-5, -2, -2, -8]\nif not valores:\n    raise ValueError("Não há máximo sem valores")\nmaximo = valores[0]\nposicao = 0\nfor i in range(1, len(valores)):\n    if valores[i] > maximo:\n        maximo = valores[i]\n        posicao = i\nprint(maximo, posicao)'
  }
/>

Usar `>` conserva a primeira ocorrência do máximo −2 na posição 1, enquanto usar `>=` guardaria a última, posição 2. O estado do ciclo tem dois nomes: o maior valor visto até agora e a posição em que o encontrámos.

## Primalidade e for else

Um inteiro é primo se for pelo menos 2 e os seus únicos divisores positivos forem 1 e ele próprio. Para 9, encontrar o divisor 3 é suficiente para concluir que não é primo, enquanto para 13 nenhum dos inteiros de 2 até 12 divide exatamente.

<CodePlayground
  language="python"
  title="Parar quando aparece um divisor"
  code={
    'n = 9\nif n < 2:\n    print("Não é primo")\nelse:\n    for divisor in range(2, n):\n        if n % divisor == 0:\n            print("Não é primo; divisor:", divisor)\n            break\n    else:\n        print("É primo")'
  }
/>

O `else` está alinhado com o `for` e só executa se não houve `break`. O teste `n < 2` trata 0, 1 e negativos; para 2, o intervalo é vazio e a conclusão é primo. Não uses o último valor do ciclo para decidir se encontraste um divisor, pois um ciclo vazio nem sequer atribui esse nome.

## Ciclos encaixados

Para uma tabela com duas linhas e três colunas, o ciclo exterior escolhe a linha e o interior percorre as suas colunas, num total de seis visitas a células. Se `break` estiver no ciclo interior, sai apenas desse ciclo. Não alteres a coleção que estás a percorrer sem compreender como isso muda os elementos que o iterador ainda vai visitar.

## Fatorial

O fatorial de 5 é `5 × 4 × 3 × 2 × 1 = 120`. Começamos com o acumulador em 1, porque é o elemento neutro da multiplicação, e multiplicamos por cada valor de 2 até `n`:

```python
n = 5
fatorial = 1
k = 2
while k <= n:
    fatorial *= k
    k += 1
print(fatorial)  # 120
```

O ciclo termina porque `k` cresce e ultrapassa `n`. Com `for`, o mesmo cálculo percorre `range(2, n + 1)` sem precisar de atualizar `k` à mão. Este é o padrão dos problemas de repetição da turma: inicializar o acumulador, percorrer os valores e devolver o resultado.

## Máximo divisor comum

O problema 6.03 pede o maior inteiro que divide dois valores. Para `a = 18` e `b = 12`, qualquer divisor comum positivo é no máximo 12. Testamos candidatos por ordem decrescente:

```python
a, b = 18, 12
for candidato in range(min(a, b), 0, -1):
    if a % candidato == 0 and b % candidato == 0:
        break
print(candidato)  # 6
```

12 divide 12 mas não 18, e o mesmo sucede com 9: divide 18 mas não 12. O primeiro candidato que divide ambos é 6 e, como percorremos em ordem decrescente, é o maior. Este trecho exige dois inteiros estritamente positivos; o candidato 1 garante uma correspondência antes de o ciclo acabar.

## Dois maiores valores

No problema 6.01, os valores são distintos e há pelo menos dois. Para `[-5, -2, -8, -1]`, começamos com os dois primeiros, ordenados: maior −2 e segundo −5. Ao ler −8, nenhum muda, enquanto ao ler −1 o maior anterior passa a segundo e −1 passa a maior. Inicializar ambos a zero inventaria valores que não estão na lista.

| Valor novo | Maior antes | Segundo antes | Maior depois | Segundo depois |
| ---------- | ----------- | ------------- | ------------ | -------------- |
| −8         | −2          | −5            | −2           | −5             |
| −1         | −2          | −5            | −1           | −2             |

Se o novo valor não ultrapassa o maior, mas ultrapassa o segundo, só atualizamos o segundo. Repetições exigiriam decidir se procuramos dois valores distintos ou duas ocorrências; a hipótese do problema evita essa ambiguidade.
