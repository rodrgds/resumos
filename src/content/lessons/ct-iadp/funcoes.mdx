O total de 3 unidades a 2,50 euros é 7,50 euros. Uma função dá um nome a esse cálculo e recebe os valores de cada compra, para o reutilizar sem copiar a multiplicação.

## Definição e chamada

```python
def total_simples(quantidade, preco):
    return quantidade * preco

print(total_simples(3, 2.5))  # 7.5
```

A chamada associa 3 a `quantidade` e 2.5 a `preco`. A função calcula e devolve 7.5. Depois passamos a uma versão com desconto.

## Retorno e desconto

Vamos calcular o preço de uma compra com desconto. O desconto é uma fração entre 0 e 1. `0.10` significa 10 por cento.

<CodePlayground

Na chamada com desconto, o fator é `1 - 0.10 = 0.90`: pagamos 90% de 7,50 euros, ou 6,75 euros. Desconto zero mantém o total e desconto um dá zero. O `return` termina a chamada e entrega o valor. Se uma função chega ao fim sem `return`, devolve `None`.

`print` mostra algo, mas não devolve esse valor. Uma função que apenas escreve 7.5 não permite somar o resultado a outra compra. Mantém o cálculo separado da apresentação quando precisas de reutilizar o valor.

## Parâmetros e argumentos

Os nomes na definição, `quantidade`, `preco` e `desconto`, são **parâmetros**. Os valores fornecidos na chamada são **argumentos**.

`total_compra(3, 2.5)` usa posições. `total_compra(preco=2.5, quantidade=3)` usa nomes. O valor por defeito só se aplica quando omites o argumento. Não pode haver dois argumentos diferentes para o mesmo parâmetro.

Argumentos posicionais devem aparecer antes dos argumentos por nome. `*args` pode recolher argumentos posicionais adicionais num tuplo e `**kwargs` argumentos por nome num dicionário. Usa-os quando a quantidade variável faz parte do problema, não para evitar definir os dados necessários.

## Número variável de argumentos e lambda

`*valores` recolhe os argumentos posicionais num tuplo. Uma chamada com uma lista só passa um argumento; `*lista` na chamada expande os seus elementos.

```python
def somar(*valores):
    return sum(valores)

print(somar(2, 4, 6))    # 12
print(somar(*[2, 4, 6])) # 12
```

`**opcoes` recolhe argumentos por nome num dicionário. A expansão `**dicionario` fornece argumentos pelos nomes das chaves. Usa nomes explícitos quando a função precisa sempre dos mesmos dados.

Uma expressão `lambda x: x * x` cria uma função que devolve uma única expressão. Pode servir como chave de ordenação ou argumento de `map`. `map` produz um iterador; `list(map(...))` materializa os resultados.

```python
quadrados = list(map(lambda x: x * x, [2, 3, 4]))
print(quadrados)  # [4, 9, 16]
```

Para várias instruções, validação ou um cálculo que precisa de um nome claro, usa `def`.

## Âmbito e mutabilidade

Um nome atribuído dentro da função é normalmente local à chamada. Não altera automaticamente um nome com o mesmo nome fora dela. Mas uma função que recebe uma lista pode alterar essa lista:

```python
def acrescentar_zero(valores):
    valores.append(0)
```

O chamador observa a alteração porque partilha o objeto. Se queres devolver outra lista, escreve `return valores + [0]`. Documenta qual das duas operações prometes.

Valores por defeito são criados quando a definição da função é executada. Por isso, evita uma lista como argumento por defeito:

```python
def juntar(valor, valores=None):
    if valores is None:
        valores = []
    valores.append(valor)
    return valores
```

Agora cada chamada que omite `valores` cria uma lista nova. `def juntar(valor, valores=[]):` reutilizaria a mesma lista entre chamadas.

## Nomes locais e globais

Uma função pode ler um nome definido no módulo. Uma atribuição dentro da função cria normalmente um nome local, mesmo quando existe um global com o mesmo nome. `global` declara que a atribuição deve alterar o nome do módulo.

```python
limite = 10

def novo_limite():
    limite = 20
    return limite

print(novo_limite(), limite)  # 20 10
```

Se acrescentares `global limite` antes da atribuição na função, o segundo valor passa a 20. Ler um nome local antes da sua atribuição pode causar `UnboundLocalError`. Passar o limite como parâmetro e devolver o novo valor torna a dependência visível e evita depender da ordem de chamadas.

## Contratos e validação

Um contrato diz que entradas são válidas e que resultado deve ser devolvido. Para a média, vamos exigir uma sequência não vazia de números:

Os testes verificam uma observação, vários valores, sinais diferentes e o caso vazio. Não tratam a média de uma lista vazia como zero, porque zero seria um resultado numérico inventado.

No exemplo, `raise ValueError(...)` interrompe a função e assinala uma entrada inválida. O bloco `try` executa a chamada; `except ValueError` trata esse erro; o `else` executa apenas se não houve essa exceção. `assert condicao` verifica uma expectativa e lança `AssertionError` se for falsa. É útil para conferir estes exemplos, mas pode ser desativado quando Python corre com otimização. Para validar entradas num programa que vai ser usado por outros, prefere uma condição e `raise`.

## Imports e módulos

Um módulo reúne nomes relacionados. `import math` permite usar `math.sqrt(9)`. `from math import sqrt` permite usar `sqrt(9)`. `import numpy as np` dá um nome curto ao módulo, não copia os seus dados.

Não chames ao teu ficheiro `pandas.py` ou `math.py`, porque pode esconder o módulo que queres importar. Num projeto com vários ficheiros, executa o programa a partir da pasta indicada e mantém os imports reproduzíveis.

## Composição de funções

O problema 13.01 usa funções de vogal e consoante para procurar vogais entre duas consoantes da mesma palavra. Aqui consideramos apenas as letras de `a` a `z` e as vogais `a`, `e`, `i`, `o`, `u`, sem acentos. Primeiro define cada teste isolado:

```python
def eh_vogal(letra):
    return letra.lower() in ("a", "e", "i", "o", "u")

def eh_consoante(letra):
    letra = letra.lower()
    return "a" <= letra <= "z" and not eh_vogal(letra)

print(eh_vogal("A"))      # True
print(eh_consoante("b"))  # True
print(eh_consoante("3"))  # False
```

`eh_consoante` reutiliza `eh_vogal` em vez de repetir a lista de vogais. Testa cada função isolada antes de a compores. Numa palavra, só as posições de 1 até `len(palavra) - 2` têm dois vizinhos. Em `"Today"`, as vogais de `"Tod"` e `"day"` satisfazem o teste; em `"go"`, nenhuma posição tem dois vizinhos. A procura deve reiniciar em cada palavra, para não ligar letras separadas por espaços.

## Vogais entre consoantes

Continuando o problema 13.01, usamos `eh_vogal` e `eh_consoante` para decidir sobre cada posição interior de cada palavra. A entrada contém apenas letras ASCII e espaços; cada teste recebe um carácter.

```python
def contar_vogais_entre_consoantes(frase):
    total = 0
    for palavra in frase.split():
        for i in range(1, len(palavra) - 1):
            if (eh_consoante(palavra[i - 1])
                    and eh_vogal(palavra[i])
                    and eh_consoante(palavra[i + 1])):
                total += 1
    return total

print(contar_vogais_entre_consoantes("Today I will go to the movies"))  # 4
```

Os três testes usam a mesma posição `i`: vizinho esquerdo, centro e vizinho direito. As ocorrências são `Tod`, `day`, `wil` e `mov`. O `y` é consoante segundo o contrato dado, mesmo quando a sua função na palavra inglesa é outra. Palavras de uma ou duas letras têm intervalo interior vazio e não acrescentam ocorrências.
