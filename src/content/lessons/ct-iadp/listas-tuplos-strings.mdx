As quantidades `[2, 3, 5, 4]` conservam a ordem das quatro vendas. Podemos escolher a primeira, as duas últimas ou todas as que excedem a média. Listas, tuplos e strings são sequências: partilham índices e slices, mas diferem no que podemos alterar.

## Índices e slices

Com `valores = [10, 20, 30, 40, 50]`, os índices positivos são 0 a 4. `valores[-1]` é 50 e `valores[-5]` é 10.

`valores[inicio:fim:passo]` seleciona do início, incluído, ao fim, excluído. `valores[1:4]` dá `[20, 30, 40]`. `valores[::2]` dá `[10, 30, 50]`. `valores[::-1]` inverte a ordem. Um índice fora dos limites dá erro; um slice pode cortar nos limites e devolver uma sequência vazia.

| Operação         | Resultado para `valores` |
| ---------------- | ------------------------ |
| `len(valores)`   | 5                        |
| `valores[:2]`    | `[10, 20]`               |
| `valores[2:]`    | `[30, 40, 50]`           |
| `valores[-3:-1]` | `[30, 40]`               |
| `30 in valores`  | `True`                   |

## Métodos e mutação de listas

`append(x)` acrescenta um elemento. `extend(iteravel)` acrescenta cada elemento do iterável. Com uma lista `[1]`, `append([2, 3])` cria `[1, [2, 3]]`; `extend([2, 3])` cria `[1, 2, 3]`.

`insert(i, x)` insere antes da posição `i`. `remove(x)` retira a primeira ocorrência de um valor e falha se não o encontrar. `pop(i)` retira e devolve o elemento naquela posição. Sem argumento, `pop` usa a última posição.

`lista.sort()` altera a própria lista e devolve `None`. `sorted(lista)` devolve outra lista ordenada. Não escrevas `lista = lista.sort()`, porque perderias a associação à lista.

`index(x)` devolve a posição da primeira ocorrência e falha se o valor não existir. `count(x)` conta ocorrências e pode devolver zero. `reverse()` inverte a lista atual; `clear()` remove todos os seus elementos. Estes métodos de alteração devolvem `None`, exceto operações como `pop`, que devolvem o elemento retirado.

`del lista[i]` remove por posição e `del lista[inicio:fim]` remove um slice. `del lista[:]` esvazia o objeto, conservando os nomes que o referem; `del lista` apaga a associação desse nome, não necessariamente o objeto. `list(iteravel)` constrói outra lista a partir dos seus elementos.

## Atribuição e cópia de listas

Atribuir uma lista a outro nome não cria uma cópia:

Esta cópia é **superficial**: numa lista de listas, copia a lista exterior, mas continua a partilhar as listas interiores. `[[0] * 3] * 2` repete referências à mesma linha. Para linhas independentes, usa `[[0] * 3 for _ in range(2)]`.

## Compreensões de listas

Uma compreensão calcula um elemento por cada valor percorrido, com um filtro opcional:

```python
quadrados = [n * n for n in range(1, 4)]
positivos = [n for n in [-1, 2, 0, 3] if n > 0]
```

Os resultados são `[1, 4, 9]` e `[2, 3]`. Para seguir a execução, começa pelo `for`: escolhe cada `n`, testa o `if` quando existe e só então calcula a expressão à esquerda. No segundo caso, −1 e 0 são rejeitados antes de entrar no resultado. Se a expressão tiver muitos ramos, usa um ciclo normal para tornar os passos legíveis.

## Vetores e matrizes com listas

Uma lista de números pode representar um vetor. Para vetores de igual comprimento, o produto escalar soma produtos das posições correspondentes. Em `[2, 3, 4]` e `[1, 0, -2]`, calculamos `2 × 1 + 3 × 0 + 4 × (−2) = −6`.

<CodePlayground
  language="python"
  title={'Calcular o produto escalar com um ciclo'}
  code={
    'a = [2, 3, 4]\nb = [1, 0, -2]\nif len(a) != len(b):\n    raise ValueError("Vetores com dimensões diferentes")\nproduto = 0\nfor i in range(len(a)):\n    produto += a[i] * b[i]\nprint(produto)\n'
  }
/>

O acumulador começa em zero. Após cada posição, vale 2, 2 e −6. A tabela seguinte mostra cada passo:

| Posição | `a[i]` | `b[i]` | Produto | Acumulado |
| ------- | ------ | ------ | ------- | --------- |
| 0       | 2      | 1      | 2       | 2         |
| 1       | 3      | 0      | 0       | 2         |
| 2       | 4      | −2     | −8      | −6        |

`zip(a, b)` também emparelha valores, mas termina quando a sequência mais curta termina. Verifica os comprimentos antes de o usares para este cálculo.

Uma lista de listas representa uma matriz. `m[i][j]` acede à coluna `j` da linha `i`. `len(m)` conta linhas; `len(m[i])` conta elementos dessa linha. Uma matriz retangular tem todas as linhas do mesmo comprimento.

<CodePlayground
  language="python"
  title={'Somar posições correspondentes de duas matrizes'}
  code={
    'a = [[2, 1], [0, 3]]\nb = [[4, 0], [5, -1]]\nif len(a) != len(b) or any(len(x) != len(y) for x, y in zip(a, b)):\n    raise ValueError("Matrizes com dimensões diferentes")\nsoma = []\nfor i in range(len(a)):\n    linha = []\n    for j in range(len(a[i])):\n        linha.append(a[i][j] + b[i][j])\n    soma.append(linha)\nprint(soma)\n'
  }
/>

O ciclo externo escolhe a linha e o interno percorre as colunas, por isso criamos uma lista nova em cada linha. `[[0] * 2] * 2` repetiria referências à mesma lista: alterar uma linha poderia alterar a outra. Usa `[[0] * 2 for _ in range(2)]` para criar duas linhas independentes.

A **transposta** troca linhas e colunas: a célula `[i][j]` passa para `[j][i]`. Se a matriz tem duas linhas e três colunas, a transposta tem três linhas e duas colunas.

```python
a = [[2, 1, 4], [0, 3, 5]]
transposta = [[a[i][j] for i in range(len(a))] for j in range(len(a[0]))]
print(transposta)  # [[2, 0], [1, 3], [4, 5]]
```

Este trecho exige uma matriz não vazia e retangular. A compreensão exterior escolhe a coluna original; a interior recolhe um valor de cada linha. Para procurar o máximo e a sua posição numa matriz, percorre as células com dois ciclos e conserva o par `(i, j)` quando encontras um valor maior. Inicializa o máximo com uma célula existente, para também funcionar com valores negativos.

Uma soma de listas, `a + b`, concatena as linhas; não soma as células. A [parte de NumPy](/cadeiras/ct-iadp/numpy/) apresenta operações vetorizadas, com arrays e eixos explícitos.

## Tuplos e desempacotamento

Um tuplo é uma sequência que não permite substituir os seus elementos. `ponto = (2, 5)` pode representar duas coordenadas. `x, y = ponto` associa a primeira a `x` e a segunda a `y`. O número de nomes deve corresponder ao número de valores, a menos que uses captura com `*`.

Um tuplo de um elemento precisa de vírgula: `(3,)`. `(3)` é apenas o inteiro 3 entre parênteses. Um tuplo pode conter uma lista; não podes substituir essa lista dentro do tuplo, mas a lista continua a ser mutável.

## Transformar texto

Uma string é imutável. `nome[0] = "A"` falha. Métodos como `strip`, `lower` e `replace` devolvem novas strings, pelo que precisas de guardar o resultado se quiseres usá-lo depois.

<CodePlayground
  language="python"
  title={'Separar e normalizar texto'}
  code={
    'linha = "  Porto;3;2.50  "\ncampos = linha.strip().split(";")\ncidade = campos[0].lower()\nquantidade = int(campos[1])\npreco = float(campos[2])\nprint(cidade, quantidade * preco)\nprint(" | ".join(campos))'
  }
/>

`strip` retira espaços nos extremos, `split(";")` produz três campos e `join` volta a reuni-los com outro separador. Sem argumento, `split()` divide por sequências de espaços em branco e ignora extremos: `" a  b ".split()` dá `["a", "b"]`. Com `split(" ")`, cada espaço é um separador e podem surgir campos vazios. `strip("ab")` retira caracteres `a` e `b` dos extremos; não retira uma substring exata.

`find` devolve o índice da primeira ocorrência, ou -1 se não existir. `count` conta ocorrências não sobrepostas. `startswith` e `endswith` testam extremos. Ao ordenar strings, Python compara códigos dos caracteres, não regras linguísticas de ordenação.

`upper()` converte para maiúsculas. `isalpha()`, `isdigit()` e `isalnum()` testam, respetivamente, letras, algarismos e a mistura das duas classes; a string vazia dá `False`. `islower()` e `isupper()` testam os caracteres com distinção de caixa, ignorando outros como algarismos. Estas operações seguem Unicode, não apenas o alfabeto ASCII.

`ord("A")` devolve o código Unicode 65; `chr(65)` faz a operação inversa. Não uses `eval` para converter dados recebidos: `int` e `float` convertem valores sem executar uma expressão Python.

## Produto de matrizes

O produto de matrizes `N × M` por `M × P` tem forma `N × P`. Cada célula soma os produtos de uma linha da primeira por uma coluna da segunda. Não é a multiplicação de elementos nas mesmas posições. Para matrizes não vazias e retangulares:

```python
a = [[1, 2], [3, 4]]
b = [[5, 6], [7, 8]]
c = [[0, 0], [0, 0]]
for i in range(2):
    for j in range(2):
        s = 0
        for k in range(2):
            s += a[i][k] * b[k][j]
        c[i][j] = s
print(c)  # [[19, 22], [43, 50]]
```

Confere a célula `[0][0]`: `1 × 5 + 2 × 7 = 19`. Os três ciclos correspondem às linhas de `a`, às colunas de `b` e à dimensão partilhada. É o problema 12.03 da turma, com matrizes pequenas que podes verificar à mão.
