<Exercise
  revision={1}
  id="limite-range"
  title={'Somar um intervalo'}
  explanation="/cadeiras/ct-iadp/condicoes-ciclos/#percorrer-valores-com-for"
  answer={{ kind: 'number', value: 20, tolerance: 0 }}
>
  <p>
    Qual é a soma dos valores de <code>{'range(2, 9, 2)'}</code>?
  </p>
  <div slot="hint">O limite 9 não é incluído.</div>
  <div slot="hint-more">Enumera 2, 4, 6 e 8.</div>
  <div slot="solution">A soma é 2 + 4 + 6 + 8 = 20. Há quatro iterações.</div>
  <div slot="mistakes">
    Incluir 9 ou 10, ou confundir quatro iterações com quatro unidades.
  </div>
</Exercise>

<Exercise
  revision={1}
  id="while-estado"
  title={'Seguir o estado'}
  explanation="/cadeiras/ct-iadp/condicoes-ciclos/#repetir-enquanto-uma-condição-vale"
  answer={{ kind: 'number', value: 7, tolerance: 0 }}
>
  <div>
    Começa com x = 1 e total = 0. Enquanto x menor que 5, soma x a total e
    duplica x. Quanto vale total no fim?
  </div>
  <div slot="hint">A atualização de x acontece depois da soma.</div>
  <div slot="hint-more">
    Os valores somados são 1, 2 e 4; o teste seguinte usa 8.
  </div>
  <div slot="solution">
    O total é 7. O ciclo termina quando x chega a 8, porque 8 não é menor que 5.
  </div>
  <div slot="mistakes">
    Somar 8 antes de testar a condição ou incrementar x em vez de o duplicar.
  </div>
</Exercise>

<Exercise
  id="corrigir-media"
  revision={2}
  title="Tratar o caso sem positivos"
  explanation="/cadeiras/ct-iadp/condicoes-ciclos/#acumular-contar-e-procurar"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def media_positivos(valores):\n    pass',
    tests: [
      {
        name: 'Mistura de sinais',
        code: 'resultado = media_positivos([3, -1, 4, 0, 2])\nprint(int(resultado) if isinstance(resultado, float) and resultado.is_integer() else repr(resultado))',
        output: '3',
      },
      {
        name: 'Lista vazia',
        code: 'print(repr(media_positivos([])))',
        output: 'None',
      },
      {
        name: 'Sem positivos',
        code: 'print(repr(media_positivos([-2, 0])))',
        output: 'None',
      },
      {
        name: 'Frações e denominador',
        code: 'resultado = media_positivos([-10, 0, 0.5, 1.5])\nprint(int(resultado) if isinstance(resultado, float) and resultado.is_integer() else repr(resultado))',
        output: '1',
      },
      {
        name: 'Conservar a entrada',
        code: 'v = [1, -2, 3]\nr = media_positivos(v)\nprint(int(r) if isinstance(r, float) and r.is_integer() else repr(r))\nprint(v)',
        output: '2\n[1, -2, 3]',
      },
    ],
  }}
>
  <div>
    Define <code>{'media_positivos(valores)'}</code>: devolve a média dos
    números estritamente positivos, ou <code>{'None'}</code> se não existirem.
    Não alteres a lista recebida. Os testes verificam resultados; compara a tua
    explicação do denominador com a <code>{'li'}</code>ção.
  </div>
  <div slot="hint">Conta apenas os valores maiores que zero.</div>
  <div slot="hint-more">
    Se a contagem for zero, devolve <code>{'None'}</code> antes de dividir.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'def media_positivos(valores):\n    positivos = [valor for valor in valores if valor > 0]\n    if not positivos:\n        return None\n    return sum(positivos) / len(positivos)'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Dividir pelo comprimento original, contar zero como positivo, devolver
    dentro do ciclo ou apagar elementos da entrada.
  </div>
</Exercise>
