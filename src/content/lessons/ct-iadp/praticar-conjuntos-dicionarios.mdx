  </div>

<Exercise
  id="contagem-chave"
  revision={2}
  title="Contar sem perder ocorrências"
  explanation="/cadeiras/ct-iadp/conjuntos-dicionarios/#contar-ocorrências"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def contagens(valores):\n    pass',
    tests: [
      {
        name: 'Entrada vazia',
        code: 'print(dict(sorted(contagens([]).items())))',
        output: '{}',
      },
      {
        name: 'Repetições separadas',
        code: 'print(dict(sorted(contagens(["a", "b", "a"]).items())))',
        output: "{'a': 2, 'b': 1}",
      },
      {
        name: 'Chaves numéricas',
        code: 'print(dict(sorted(contagens([3, -1, 3, 3]).items())))',
        output: '{-1: 1, 3: 3}',
      },
      {
        name: 'Chaves de tuplos',
        code: 'print(dict(sorted(contagens([(1, 2), (1, 2), (2, 1)]).items())))',
        output: '{(1, 2): 2, (2, 1): 1}',
      },
      {
        name: 'Conservar a entrada',
        code: 'v = ["b", "a", "b"]\nr = contagens(v)\nprint(dict(sorted(r.items())))\nprint(v)',
        output: "{'a': 1, 'b': 2}\n['b', 'a', 'b']",
      },
    ],
  }}
>
  <div>
    Define <code>{'contagens(valores)'}</code>, que devolve um dicionário de
    frequências. Os valores são hashable. A lista vazia dá um dicionário vazio;
    conserva a entrada.
  </div>
  <div slot="hint">Cada valor é uma chave.</div>
  <div slot="hint-more">
    O primeiro encontro de uma chave tem contagem anterior zero.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'def contagens(valores):\n    resultado = {}\n    for valor in valores:\n        resultado[valor] = resultado.get(valor, 0) + 1\n    return resultado'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Converter a entrada em conjunto perde repetições. Colocar{' '}
    <code>{'return'}</code> dentro do ciclo interrompe a contagem.
  </div>
</Exercise>
