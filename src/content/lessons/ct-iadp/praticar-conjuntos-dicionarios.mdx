<Exercise
  id="contagem-chave"
  revision={2}
  title="Contar sem perder ocorrências"
  explanation="/cadeiras/ct-iadp/conjuntos-dicionarios/#contar-ocorrências"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def contagens(valores):\n    pass',
    tests: [
      {
        name: 'Entrada vazia',
        code: 'print(contagens([]) == {})',
        output: 'True',
      },
      {
        name: 'Repetições separadas',
        code: 'print(contagens(["a", "b", "a"]) == {"a": 2, "b": 1})',
        output: 'True',
      },
      {
        name: 'Chaves numéricas',
        code: 'print(contagens([3, -1, 3, 3]) == {3: 3, -1: 1})',
        output: 'True',
      },
      {
        name: 'Chaves de tuplos',
        code: 'print(contagens([(1, 2), (1, 2), (2, 1)]) == {(1, 2): 2, (2, 1): 1})',
        output: 'True',
      },
      {
        name: 'Conservar a entrada',
        code: 'v = ["b", "a", "b"]\nr = contagens(v)\nprint(r == {"b": 2, "a": 1} and v == ["b", "a", "b"])',
        output: 'True',
      },
    ],
  }}
>
  <div>
    Define contagens(valores), que devolve um dicionário de frequências. Os
    valores são hashable. A lista vazia dá um dicionário vazio; conserva a
    entrada.
  </div>
  <div slot="hint">Cada valor é uma chave.</div>
  <div slot="hint-more">
    O primeiro encontro de uma chave tem contagem anterior zero.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'def contagens(valores):\n    resultado = {}\n    for valor in valores:\n        resultado[valor] = resultado.get(valor, 0) + 1\n    return resultado'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Converter a entrada em conjunto perde repetições. Colocar return dentro do
    ciclo interrompe a contagem.
  </div>
</Exercise>

<Exercise
  revision={1}
  id="dicionario-setdefault"
  title="Ler ou inserir sem substituir"
  explanation="/cadeiras/ct-iadp/conjuntos-dicionarios/#alterar-um-dicionário-e-interpretar-o-retorno"
  answer={{ kind: 'number', value: 2, tolerance: 0 }}
>
  <div>
    <code>{'stock = {"A": 2}; resultado = stock.setdefault("A", 9)'}</code>.
    Quanto vale resultado?
  </div>
  <div slot="hint">A chave A já existe.</div>
  <div slot="hint-more">
    O valor por defeito só é inserido quando a chave está ausente.
  </div>
  <div slot="solution">
    Devolve 2 e stock conserva a chave A associada a 2. A chamada não substitui
    um valor existente.
  </div>
  <div slot="mistakes">
    Confundir setdefault com uma atribuição explícita ou com update.
  </div>
</Exercise>
