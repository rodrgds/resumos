<Exercise
  revision={1}
  id="data-parse"
  title={'Interpretar um formato explícito'}
  explanation="/cadeiras/ct-iadp/datas-tempos/#converter-datas-em-pandas"
  answer={{ kind: 'number', value: 4, tolerance: 0 }}
>
  <div>
    A string 03/04/2026 é convertida com format="%d/%m/%Y". Qual é o número do
    mês?
  </div>
  <div slot="hint">%d lê o dia e %m o mês.</div>
  <div slot="hint-more">O segundo campo é 04.</div>
  <div slot="solution">
    O mês é abril, número 4. Sem um formato explícito, a convenção da entrada
    podia ser interpretada de forma diferente.
  </div>
  <div slot="mistakes">Tratar a primeira componente como mês.</div>
</Exercise>

<Exercise
  revision={1}
  id="mes-dias"
  title={'Escolher calendário ou duração'}
  explanation="/cadeiras/ct-iadp/datas-tempos/#tipos-da-biblioteca-padrão"
  answer={{
    kind: 'self',
    checklist: [
      'Obtive 2 de março para a soma de 30 dias.',
      'Obtive 28 de fevereiro para a soma de um mês.',
      'Expliquei o ajuste ao último dia válido do mês.',
    ],
  }}
>
  <div>
    Partindo de 31 de janeiro de 2026, compara somar 30 dias com somar um mês
    por relativedelta.
  </div>
  <div slot="hint">Fevereiro de 2026 tem 28 dias.</div>
  <div slot="hint-more">Um mês não representa uma duração fixa de 30 dias.</div>
  <div slot="solution">
    <code>{'timedelta(days=30)'}</code> dá 2 de março.{' '}
    <code>{'relativedelta(months=1)'}</code> dá 28 de fevereiro, porque o mês
    seguinte não tem dia 31.
  </div>
  <div slot="mistakes">
    Substituir meses por 30 dias ou supor que a data inválida é conservada.
  </div>
</Exercise>

<Exercise
  id="duracao-total-minutos"
  revision={2}
  title="Contar todos os dias da duração"
  explanation="/cadeiras/ct-iadp/datas-tempos/#ler-formatar-e-subtrair"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def minutos_entre(inicio, fim):\n    pass',
    tests: [
      {
        name: 'Passar a meia-noite',
        code: 'resultado = minutos_entre("2026-10-03T23:45", "2026-10-04T01:15")\nprint(int(resultado) if isinstance(resultado, float) and resultado.is_integer() else repr(resultado))',
        output: '90',
      },
      {
        name: 'Mais de um dia',
        code: 'resultado = minutos_entre("2026-10-03T12:00", "2026-10-04T13:00")\nprint(int(resultado) if isinstance(resultado, float) and resultado.is_integer() else repr(resultado))',
        output: '1500',
      },
      {
        name: 'Instantes iguais',
        code: 'resultado = minutos_entre("2026-10-03T12:00", "2026-10-03T12:00")\nprint(int(resultado) if isinstance(resultado, float) and resultado.is_integer() else repr(resultado))',
        output: '0',
      },
      {
        name: 'Ordem inversa',
        code: 'resultado = minutos_entre("2026-10-03T12:00", "2026-10-03T10:30")\nprint(int(resultado) if isinstance(resultado, float) and resultado.is_integer() else repr(resultado))',
        output: '-90',
      },
    ],
  }}
>
  <div>
    Define <code>{'minutos_entre(inicio, fim)'}</code>: recebe strings ISO sem
    fuso no formato AAAA-MM-DDTHH:MM e devolve a diferença fim menos inicio em
    minutos. A diferença pode ser negativa; não é preciso ler fusos neste
    exercício.
  </div>
  <div slot="hint">Converte as duas strings antes de subtrair.</div>
  <div slot="hint-more">
    A duração completa vem de <code>{'total_seconds()'}</code>, não apenas de{' '}
    <code>{'seconds'}</code>.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'from datetime import datetime\n\ndef minutos_entre(inicio, fim):\n    duracao = datetime.fromisoformat(fim) - datetime.fromisoformat(inicio)\n    return duracao.total_seconds() / 60'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Usar <code>{'seconds'}</code> perde dias e normaliza a parte restante de
    durações negativas. Comparar só as horas perde a mudança de data.
  </div>
</Exercise>
