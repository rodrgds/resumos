  explanation="/cadeiras/ct-iadp/ficheiros/#linhas-e-campos"
  answer={{
    kind: 'self',
    checklist: [
      'Identifiquei que a vírgula dentro das aspas pertence ao campo.',
      'Escolhi `csv.reader` ou `csv.DictReader`.',
      'Conservei a necessidade de converter os campos numéricos.',
    ],
  }}
>
  <div>
    Por que <code>{'split(",")'}</code> não é suficiente para ler uma linha CSV
    com um nome entre aspas que contém uma vírgula?
  </div>
  <div slot="hint">CSV tem regras para aspas e separadores.</div>
  <div slot="hint-more">
    Uma separação literal não distingue a vírgula de um campo da vírgula entre
    campos.
  </div>
  <div slot="solution">
    O módulo <code>{'csv'}</code> interpreta aspas e escapes e mantém o nome num
    único campo. Depois da leitura, os valores numéricos ainda precisam de
    conversão.
  </div>
  <div slot="mistakes">
    Afirmar que todo o CSV usa sempre vírgula ou que <code>{'DictReader'}</code>{' '}
    devolve automaticamente números.
  </div>
</Exercise>

<Exercise
  id="ler-csv-quantidades"
  revision={2}
  title="Ler separadores dentro de um campo"
  explanation="/cadeiras/ct-iadp/ficheiros/#linhas-e-campos"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def ler_quantidades(texto):\n    pass',
    tests: [
      {
        name: 'Duas linhas',
        code: 'print(repr(ler_quantidades("produto,quantidade\\npão,2\\nleite,3\\n")))',
        output: "[('pão', 2), ('leite', 3)]",
      },
      {
        name: 'Vírgula dentro de aspas',
        code: 'print(repr(ler_quantidades(\'produto,quantidade\\n"pão, integral",4\\n\')))',
        output: "[('pão, integral', 4)]",
      },
      {
        name: 'Apenas cabeçalho',
        code: 'print(repr(ler_quantidades("produto,quantidade\\n")))',
        output: '[]',
      },
      {
        name: 'Sem quebra de linha final',
        code: 'print(repr(ler_quantidades("produto,quantidade\\narroz,0")))',
        output: "[('arroz', 0)]",
      },
    ],
  }}
>
  <div>
    Define <code>{'ler_quantidades(texto)'}</code>: recebe um CSV com cabeçalho
    <code>{'produto,quantidade'}</code> e devolve pares{' '}
    <code>{'(produto, quantidade)'}</code>, com quantidade inteira. Usa as
    regras de CSV, incluindo nomes entre aspas com vírgulas. Um ficheiro só com
    cabeçalho devolve lista vazia.
  </div>
  <div slot="hint">Trata a string como um ficheiro de texto em memória.</div>
  <div slot="hint-more">
    <code>StringIO</code> e <code>{'csv.DictReader'}</code> permitem usar os
    nomes do cabeçalho.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'import csv\nfrom io import StringIO\n\ndef ler_quantidades(texto):\n    return [(linha["produto"], int(linha["quantidade"]))\n            for linha in csv.DictReader(StringIO(texto))]'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    <code>{'split'}</code> por vírgula quebra nomes entre aspas;{' '}
    <code>{'DictReader'}</code> não converte a quantidade para inteiro.
  </div>
</Exercise>

<Exercise
  id="media-sequencial"
  revision={1}
  title="Calcular a média sem guardar a lista"
  explanation="/cadeiras/ct-iadp/ficheiros/#ler-em-sequência-sem-guardar-tudo"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def media_texto(texto):\n    pass',
    tests: [
      {
        name: 'Três valores',
        code: 'print(repr(media_texto("1\\n2\\n3\\n")))',
        output: '2.0',
      },
      {
        name: 'Ignora linhas em branco',
        code: 'print(repr(media_texto("4\\n\\n2\\n")))',
        output: '3.0',
      },
      {
        name: 'Sem quebra de linha final',
        code: 'print(repr(media_texto("5")))',
        output: '5.0',
      },
      {
        name: 'Sem valores',
        code: 'try:\n    media_texto("")\nexcept ValueError:\n    print("ValueError")\nelse:\n    print("Não lançou ValueError")',
        output: 'ValueError',
      },
    ],
  }}
>
  <div>
    Define <code>{'media_texto(texto)'}</code>: recebe números, um por linha, e
    devolve a média. Percorre as linhas sem guardar a lista completa. Linhas em
    branco são ignoradas. Sem valores, lança <code>{'ValueError'}</code>.
  </div>
  <div slot="hint">Trata a string como um ficheiro de texto em memória.</div>
  <div slot="hint-more">
    Acumula a soma e a contagem linha a linha; só divides no fim.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'from io import StringIO\n\ndef media_texto(texto):\n    soma = 0.0\n    contagem = 0\n    ficheiro = StringIO(texto)\n    for linha in ficheiro:\n        linha = linha.strip()\n        if linha == "":\n            continue\n        soma += float(linha)\n        contagem += 1\n    if contagem == 0:\n        raise ValueError("Sem valores")\n    return soma / contagem'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Guardar todas as linhas quando só precisas de soma e contagem; dividir por
    um total fixo em vez da contagem lida; esquecer o fim do ficheiro e as
    linhas em branco.
  </div>
</Exercise>
