<Exercise
  revision={1}
  id="csv-separador"
  title={'Ler campos com aspas'}
  explanation="/cadeiras/ct-iadp/ficheiros/#linhas-e-campos"
  answer={{
    kind: 'self',
    checklist: [
      'Identifiquei que a vírgula dentro das aspas pertence ao campo.',
      'Escolhi csv.reader ou csv.DictReader.',
      'Conservei a necessidade de converter os campos numéricos.',
    ],
  }}
>
  <div>
    Por que split(",") não é suficiente para ler uma linha CSV com um nome entre
    aspas que contém uma vírgula?
  </div>
  <div slot="hint">CSV tem regras para aspas e separadores.</div>
  <div slot="hint-more">
    Uma separação literal não distingue a vírgula de um campo da vírgula entre
    campos.
  </div>
  <div slot="solution">
    O módulo csv interpreta aspas e escapes e mantém o nome num único campo.
    Depois da leitura, os valores numéricos ainda precisam de conversão.
  </div>
  <div slot="mistakes">
    Afirmar que todo o CSV usa sempre vírgula ou que DictReader devolve
    automaticamente números.
  </div>
</Exercise>

<Exercise
  id="ler-csv-quantidades"
  revision={1}
  title="Ler separadores dentro de um campo"
  explanation="/cadeiras/ct-iadp/ficheiros/#linhas-e-campos"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def ler_quantidades(texto):\n    pass',
    tests: [
      {
        name: 'Duas linhas',
        code: 'print(ler_quantidades("produto,quantidade\\npão,2\\nleite,3\\n") == [("pão", 2), ("leite", 3)])',
        output: 'True',
      },
      {
        name: 'Vírgula dentro de aspas',
        code: 'print(ler_quantidades(\'produto,quantidade\\n"pão, integral",4\\n\') == [("pão, integral", 4)])',
        output: 'True',
      },
      {
        name: 'Apenas cabeçalho',
        code: 'print(ler_quantidades("produto,quantidade\\n") == [])',
        output: 'True',
      },
      {
        name: 'Sem quebra de linha final',
        code: 'print(ler_quantidades("produto,quantidade\\narroz,0") == [("arroz", 0)])',
        output: 'True',
      },
    ],
  }}
>
  <div>
    Define ler_quantidades(texto): recebe um CSV com cabeçalho
    produto,quantidade e devolve pares (produto, quantidade), com quantidade
    inteira. Usa as regras de CSV, incluindo nomes entre aspas com vírgulas. Um
    ficheiro só com cabeçalho devolve lista vazia.
  </div>
  <div slot="hint">Trata a string como um ficheiro de texto em memória.</div>
  <div slot="hint-more">
    StringIO e csv.DictReader permitem usar os nomes do cabeçalho.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'import csv\nfrom io import StringIO\n\ndef ler_quantidades(texto):\n    return [(linha["produto"], int(linha["quantidade"]))\n            for linha in csv.DictReader(StringIO(texto))]'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    split por vírgula quebra nomes entre aspas; DictReader não converte a
    quantidade para inteiro.
  </div>
</Exercise>
