<Exercise
  revision={1}
  id="media-contrato"
  title={'Justificar entradas inválidas'}
  explanation="/cadeiras/ct-iadp/funcoes/#testar-um-contrato-pequeno"
  answer={{
    kind: 'self',
    checklist: [
      'Defini a entrada válida como uma sequência não vazia de números.',
      'Verifiquei o caso vazio antes da divisão.',
      'Expliquei que zero é um resultado numérico, não uma ausência de observações.',
    ],
  }}
>
  <div>
    Define uma média que rejeita uma sequência vazia. Explica por que devolver
    zero no caso vazio altera o significado da função.
  </div>
  <div slot="hint">A média divide a soma pelo número de observações.</div>
  <div slot="hint-more">Sem observações, o denominador seria zero.</div>
  <div slot="solution">
    Verifica a entrada e lança <code>{'ValueError'}</code> se estiver vazia.
    Para entradas válidas, devolve <code>{'sum(valores) / len(valores)'}</code>.
    Zero seria a média real de alguns conjuntos e confundiria essas situações
    com dados inexistentes.
  </div>
  <div slot="mistakes">
    Ignorar o contrato, dividir por zero ou acrescentar um elemento fictício.
  </div>
</Exercise>

<Exercise
  id="funcoes-expandir-argumentos"
  revision={1}
  title="Passar os elementos como argumentos"
  explanation="/cadeiras/ct-iadp/funcoes/#número-variável-de-argumentos-e-lambda"
  answer={{
    kind: 'choice',
    options: [
      {
        text: '`somar(*valores)`',
        correct: true,
        explanation:
          'Expande a lista e fornece três argumentos numéricos; a função soma 2, 4 e 6.',
      },
      {
        text: '`somar(valores)`',
        correct: false,
        explanation:
          'Fornece uma lista como único argumento. `sum` tenta somá-la ao inteiro inicial zero e dá TypeError.',
      },
      {
        text: '`somar(**valores)`',
        correct: false,
        explanation:
          'A expansão com dois asteriscos exige uma correspondência de nomes, não uma lista de argumentos posicionais.',
      },
    ],
  }}
>
  <div>
    A função <code>{'def'}</code> <code>{'somar(*valores)'}</code> devolve{' '}
    <code>{'sum(valores)'}</code>. Tens a lista valores ={' '}
    <code>{'[2, 4, 6]'}</code>. Que chamada devolve 12?
  </div>
  <div slot="hint">
    Na definição, o asterisco recolhe os argumentos; na chamada, expande
    elementos.
  </div>
  <div slot="hint-more">
    A função deve receber três números, não uma única lista.
  </div>
  <div slot="solution">
    <code>{'somar(*valores)'}</code> equivale aqui a{' '}
    <code>{'somar(2, 4, 6)'}</code>. Os nomes coincidentes dentro e fora da
    função pertencem a âmbitos diferentes.
  </div>
  <div slot="mistakes">
    Confundir passar uma coleção com passar os seus elementos ou usar a expansão
    de argumentos por nome para uma lista.
  </div>
</Exercise>
