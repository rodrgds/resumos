<Exercise
  id="alias-copia"
  title={'Prever uma alteração partilhada'}
  explanation="/cadeiras/ct-iadp/listas-tuplos-strings/#dois-nomes-para-a-mesma-lista"
  answer={{ kind: 'number', value: 1, tolerance: 0 }}
>
  <p>a = [1, 2]; b = a; c = a.copy(); b[0] = 9. Quanto vale c[0]?</p>
  <div slot="hint">Só a e b apontam para a mesma lista.</div>
  <div slot="hint-more">
    c foi criada antes da alteração e tem os seus próprios elementos exteriores.
  </div>
  <div slot="solution">
    c[0] continua a ser 1. a[0] e b[0] passam ambos a 9.
  </div>
  <div slot="mistakes">
    Tratar toda a atribuição como uma cópia ou concluir que a cópia superficial
    partilha estes inteiros substituídos.
  </div>
</Exercise>

<Exercise
  id="matriz-linhas"
  title={'Criar linhas independentes'}
  explanation="/cadeiras/ct-iadp/listas-tuplos-strings/#dois-nomes-para-a-mesma-lista"
  answer={{
    kind: 'self',
    checklist: [
      'Identifiquei que as duas posições exteriores referem a mesma lista interior.',
      'Usei [[0] * 3 for _ in range(2)].',
      'Conferi que alterar matriz[0][0] não muda matriz[1][0].',
    ],
  }}
>
  <p>
    Explica por que [[0] * 3] * 2 não permite alterar uma célula de uma linha
    sem afetar a outra. Escreve uma construção correta.
  </p>
  <div slot="hint">A repetição da lista exterior repete referências.</div>
  <div slot="hint-more">
    É preciso criar a linha dentro de cada iteração, em vez de a repetir depois.
  </div>
  <div slot="solution">
    A primeira expressão cria uma linha e refere-a duas vezes. A compreensão
    executa [0] * 3 em cada iteração e cria duas linhas independentes.
  </div>
  <div slot="mistakes">
    Dizer apenas que Python não suporta matrizes ou fazer uma cópia superficial
    da lista exterior.
  </div>
</Exercise>

<Exercise
  id="matriz-linhas-partilhadas"
  title="Reconhecer linhas partilhadas"
  explanation="/cadeiras/ct-iadp/listas-tuplos-strings/#vetores-e-matrizes-com-listas"
  answer={{ kind: 'number', value: 7, tolerance: 0 }}
>
  <p>m = [[0, 0]] * 2; m[0][1] = 7. Quanto vale m[1][1]?</p>
  <div slot="hint">A multiplicação repete referências à lista interior.</div>
  <div slot="hint-more">As duas posições de m referem a mesma linha.</div>
  <div slot="solution">
    O valor é 7. A alteração afeta o único objeto de linha. Para linhas
    independentes, usa [[0, 0] for _ in range(2)].
  </div>
  <div slot="mistakes">
    Confundir repetir uma referência com criar uma cópia de cada linha.
  </div>
</Exercise>
