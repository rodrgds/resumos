<Exercise
  id="matriz-linhas"
  revision={2}
  title="Distinguir cópia exterior de linhas independentes"
  explanation="/cadeiras/ct-iadp/listas-tuplos-strings/#atribuição-e-cópia-de-listas"
  answer={{ kind: 'self', checklist: ["Previ [[9, 0], [9, 0]] tanto em a como em b.", "Expliquei as referências partilhadas entre as linhas e entre as cópias.", "Construí duas linhas independentes e confirmei que só a primeira muda."] }}
>

Segue estas instruções sem as executar:

```python
a = [[0, 0]] * 2
b = a.copy()
b[0][0] = 9
```

1. Que valores têm `a` e `b` no fim?
2. Por que a cópia não separa as células interiores?
3. Cria uma matriz de duas linhas independentes, copia também as linhas e mostra que alterar a cópia conserva a original.

<div slot="hint">

Conta quantas listas interiores são criadas pela primeira instrução.

</div>

<div slot="solution">

`a` e `b` ficam ambos `[[9, 0], [9, 0]]`. A multiplicação criou uma linha e repetiu a sua referência. `copy()` criou outra lista exterior, mas as posições continuam a referir a mesma linha interior.

```python
a = [[0, 0] for _ in range(2)]
b = [linha.copy() for linha in a]
b[0][0] = 9
print(a)  # [[0, 0], [0, 0]]
print(b)  # [[9, 0], [0, 0]]
```

Aqui as linhas são novas e os elementos são inteiros. Para estruturas ainda mais profundas, copiar apenas estes dois níveis pode continuar a partilhar objetos mutáveis.

</div>
</Exercise>

      },

>
  <div>
    Define <code>{'produto_matrizes(a, b)'}</code>: devolve o produto de duas
    matrizes não vazias e retangulares em listas de listas de números, com pelo
    menos uma coluna cada. Dimensões incompatíveis causam{' '}
    <code>{'ValueError'}</code>. Não alteres as entradas.
  </div>
  <div slot="hint">
    Cada célula soma os produtos de uma linha por uma coluna.
  </div>
  <div slot="hint-more">
    Três ciclos: linhas de a, colunas de b e dimensão partilhada.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'def produto_matrizes(a, b):\n    if len(a[0]) != len(b):\n        raise ValueError("Dimensões incompatíveis")\n    return [[sum(a[i][k] * b[k][j] for k in range(len(b)))\n             for j in range(len(b[0]))] for i in range(len(a))]'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Somar células em vez de somar produtos linha por coluna; trocar os limites
    dos três ciclos; alterar as matrizes recebidas.
  </div>
</Exercise>
