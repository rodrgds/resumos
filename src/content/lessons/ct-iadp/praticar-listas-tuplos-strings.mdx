<Exercise
  revision={1}
  id="alias-copia"
  title={'Prever uma alteração partilhada'}
  explanation="/cadeiras/ct-iadp/listas-tuplos-strings/#dois-nomes-para-a-mesma-lista"
  answer={{ kind: 'number', value: 1, tolerance: 0 }}
>
  <p>a = [1, 2]; b = a; c = a.copy(); b[0] = 9. Quanto vale c[0]?</p>
  <div slot="hint">Só a e b apontam para a mesma lista.</div>
  <div slot="hint-more">
    c foi criada antes da alteração e tem os seus próprios elementos exteriores.
  </div>
  <div slot="solution">
    c[0] continua a ser 1. a[0] e b[0] passam ambos a 9.
  </div>
  <div slot="mistakes">
    Tratar toda a atribuição como uma cópia ou concluir que a cópia superficial
    partilha estes inteiros substituídos.
  </div>
</Exercise>

<Exercise

  title="Calcular posições correspondentes"

  answer={{
    kind: 'code',
    language: 'python',

    tests: [
      {
        name: 'Produtos com sinais',
        code: 'print(produto_escalar([2, 3, 4], [1, 0, -2]) == -6)',
        output: 'True',
      },
      {
        name: 'Vetores vazios',
        code: 'print(produto_escalar([], []) == 0)',
        output: 'True',
      },
      {
        name: 'Um elemento e frações',
        code: 'print(produto_escalar([0.5], [4]) == 2)',
        output: 'True',
      },
      {
        name: 'Não truncar o vetor maior',
        code: 'try:\n    produto_escalar([1, 2], [3])\nexcept ValueError:\n    print(True)\nelse:\n    print(False)',
        output: 'True',
      },
      {
        name: 'Conservar ambas as entradas',
        code: 'a, b = [2, 1], [3, 4]\nr = produto_escalar(a, b)\nprint(r == 10 and a == [2, 1] and b == [3, 4])',
        output: 'True',
      },
    ],
  }}
>
  <div>
    Define produto_escalar(a, b) para listas de números: soma os produtos de
    posições correspondentes. Comprimentos diferentes causam ValueError. Duas
    listas vazias dão zero. Não alteres as entradas.
  </div>
  <div slot="hint">O acumulador começa em zero.</div>
  <div slot="hint-more">
    Verifica os comprimentos antes de emparelhar com zip.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'def produto_escalar(a, b):\n    if len(a) != len(b):\n        raise ValueError("Comprimentos diferentes")\n    return sum(x * y for x, y in zip(a, b))'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Somar as listas concatena elementos. zip termina na mais curta e não rejeita
    por si só comprimentos diferentes.
  </div>
</Exercise>

    ],
  }}
>
  <div>
    Escreve a transposta de [[2, 1, 4], [0, 3, 5]] com ciclos ou compreensões.
    Explica quais dos índices percorrem as linhas e as colunas originais. Não
    alteres a entrada.
  </div>
  <div slot="hint">
    A primeira linha do resultado é a primeira coluna da entrada.
  </div>
  <div slot="hint-more">A nova célula [j][i] recebe a antiga [i][j].</div>
  <div slot="solution">
    O resultado é [[2, 0], [1, 3], [4, 5]]. Cria três linhas novas com duas
    células e atribui resultado[j][i] = original[i][j]. Uma compreensão pode
    escolher j fora e i dentro. Não repitas a mesma linha interior com
    multiplicação.
  </div>
  <div slot="mistakes">
    Inverter a ordem das linhas, conservar a forma 2 × 3 ou percorrer o número
    de linhas como se fosse também o número de colunas.
  </div>
</Exercise>
