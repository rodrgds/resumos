<Exercise
  id="array-axis"
  revision={2}
  title="Reduzir e conferir a forma"
  explanation="/cadeiras/ct-iadp/numpy/#duas-dimensões-e-eixos"
  answer={{ kind: 'self', checklist: ["Obtive [7, 4, 6] com forma (3,) para axis=0.", "Obtive [9, 8] com forma (2,) para axis=1.", "Calculei 48 bytes de dados antes da redução."] }}
>

Um array `float64` guarda `[[2, 3, 4], [5, 1, 2]]`: lojas em linhas e produtos em colunas.

1. Calcula `a.sum(axis=0)` e `a.sum(axis=1)` e indica ambas as formas, sem `keepdims`.
2. Que soma responde ao total de cada produto?
3. Quantos bytes ocupam os dados de `a`, sabendo que cada `float64` usa oito bytes e excluindo a estrutura do objeto?

<div slot="hint">

Antes de somar, decide se o resultado precisa de dois ou três totais.

</div>

<div slot="solution">

`axis=0` junta as duas lojas: `[2 + 5, 3 + 1, 4 + 2] = [7, 4, 6]`, com forma `(3,)`. É o total por produto.

`axis=1` junta os produtos dentro de cada loja: `[2 + 3 + 4, 5 + 1 + 2] = [9, 8]`, com forma `(2,)`. O eixo reduzido desaparece; a dimensão restante conta os resultados.

Há `2 × 3 = 6` elementos. Os dados ocupam `6 × 8 = 48` bytes. O 64 no tipo conta bits, não bytes.

</div>
</Exercise>

      },
      {
        text: '`(3,)`',
        correct: false,
        explanation: 'Aplica um fator por coluna, não um por linha.',
      },
    ],
  }}
>
  <div>
    Para uma matriz (2, 3), queres multiplicar cada linha por um fator próprio.
    Qual deve ser a forma do array de fatores?
  </div>
  <div slot="hint">Compara as formas a partir da direita.</div>
  <div slot="solution">
    Usa fatores com forma (2, 1). Por exemplo,{' '}
    <code>{'np.array([0.9, 0.8])[:, None]'}</code>.
  </div>
  <div slot="mistakes">
    Supor que o número de fatores basta sem conferir o alinhamento das
    dimensões.
  </div>
</Exercise>

  <p>
    a = <code>{'np.array([1, 2, 3])'}</code>; <code>{'b = a'}</code>

  </p>
  <div slot="hint">Um slice básico pode devolver uma vista.</div>
  <div slot="solution">

    <code>{'a[:2].copy()'}</code>.
  </div>
  <div slot="mistakes">
    Transferir a regra dos slices de listas para arrays NumPy.
  </div>
