<Exercise
  revision={1}
  id="array-axis"
  title={'Prever o tamanho da redução'}
  explanation="/cadeiras/ct-iadp/numpy/#duas-dimensões-e-eixos"
  answer={{
    kind: 'choice',
    options: [
      {
        text: '`(3,)`',
        correct: true,
        explanation:
          'O eixo das duas linhas é reduzido; sobra um valor por coluna.',
      },
      {
        text: '`(2,)`',
        correct: false,
        explanation: 'Seria o resultado de reduzir axis=1.',
      },
      {
        text: '`(2, 3)`',
        correct: false,
        explanation:
          'A soma por um eixo reduz uma dimensão, salvo opções como keepdims.',
      },
    ],
  }}
>
  <p>
    Um array tem forma (2, 3). Qual é a forma de <code>{'a.sum(axis=0)'}</code>?
  </p>
  <div slot="hint">O eixo 0 representa as linhas neste array.</div>
  <div slot="hint-more">
    O resultado precisa de um total para cada uma das três colunas.
  </div>
  <div slot="solution">
    A forma é (3,). Em <code>{'[[2, 3, 4], [5, 1, 2]]'}</code>, os valores
    seriam <code>{'[7, 4, 6]'}</code>.
  </div>
  <div slot="mistakes">
    Pensar que <code>{'axis=0'}</code> significa devolver um valor por linha.
  </div>
</Exercise>

<Exercise
  revision={1}
  id="broadcast-forma"
  title={'Escolher o desconto por linha'}
  explanation="/cadeiras/ct-iadp/numpy/#broadcasting"
  answer={{
    kind: 'choice',
    options: [
      {
        text: '`(2, 1)`',
        correct: true,
        explanation:
          'O eixo das colunas tem tamanho 1 e alarga para as três colunas.',
      },
      {
        text: '`(2,)`',
        correct: false,
        explanation: 'A última dimensão 2 não é compatível com 3.',
      },
      {
        text: '`(3,)`',
        correct: false,
        explanation: 'Aplica um fator por coluna, não um por linha.',
      },
    ],
  }}
>
  <div>
    Para uma matriz (2, 3), queres multiplicar cada linha por um fator próprio.
    Qual deve ser a forma do array de fatores?
  </div>
  <div slot="hint">Compara as formas a partir da direita.</div>
  <div slot="hint-more">
    Precisas de conservar dois fatores e permitir que cada um se repita em três
    colunas.
  </div>
  <div slot="solution">
    Usa fatores com forma (2, 1). Por exemplo,{' '}
    <code>{'np.array([0.9, 0.8])[:, None]'}</code>.
  </div>
  <div slot="mistakes">
    Supor que o número de fatores basta sem conferir o alinhamento das
    dimensões.
  </div>
</Exercise>

<Exercise
  revision={1}
  id="vista-array"
  title={'Reconhecer dados partilhados'}
  explanation="/cadeiras/ct-iadp/numpy/#vistas-e-cópias"
  answer={{ kind: 'number', value: 8, tolerance: 0 }}
>
  <p>
    a = <code>{'np.array([1, 2, 3])'}</code>; <code>{'b = a'}</code>
    <code>{'[:2]'}</code>; <code>{'b[0]'}</code> = 8. Quanto vale{' '}
    <code>{'a[0]'}</code>?
  </p>
  <div slot="hint">Um slice básico pode devolver uma vista.</div>
  <div slot="hint-more">A vista refere a primeira parte dos mesmos dados.</div>
  <div slot="solution">
    <code>{'a[0]'}</code> passa a 8. Para separar os dados, usa b ={' '}
    <code>{'a[:2].copy()'}</code>.
  </div>
  <div slot="mistakes">
    Transferir a regra dos slices de listas para arrays NumPy.
  </div>
</Exercise>

<Exercise
  revision={1}
  id="array-memoria"
  title="Calcular bytes dos dados"
  explanation="/cadeiras/ct-iadp/numpy/#tipo-e-memória"
  answer={{ kind: 'number', value: 48, tolerance: 0 }}
>
  <div>
    Um array tem forma (2, 3) e dtype float64. Quantos bytes ocupam os seus
    dados, sem contar a estrutura do objeto?
  </div>
  <div slot="hint">
    Calcula quantos elementos existem e quantos bytes tem cada um.
  </div>
  <div slot="hint-more">Há seis elementos. Cada float64 usa oito bytes.</div>
  <div slot="solution">
    2 × 3 × 8 = 48 bytes. <code>{'a.size'}</code> é 6,{' '}
    <code>{'a.itemsize'}</code> é 8 e <code>{'a.nbytes'}</code> é 48.
  </div>
  <div slot="mistakes">
    Tratar 64 bits como 64 bytes ou somar as dimensões em vez de as multiplicar.
  </div>
</Exercise>
