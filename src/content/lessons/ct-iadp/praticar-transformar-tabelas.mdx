<Exercise
  revision={1}
  id="media-nulos"
  title={'Conservar o denominador correto'}
  explanation="/cadeiras/ct-iadp/transformar-tabelas/#representar-ausência"
  answer={{ kind: 'number', value: 4, tolerance: 0 }}
>
  <div>
    Uma <code>{'Series'}</code> <code>{'Float64'}</code> tem 2, um valor ausente
    e 6. Quanto vale <code>{'mean()'}</code> sem preencher ausências?
  </div>
  <div slot="hint">
    <code>{'mean'}</code> ignora normalmente os valores ausentes.
  </div>
  <div slot="hint-more">Há dois valores conhecidos cuja soma é 8.</div>
  <div slot="solution">
    A média conhecida é 8 / 2 = 4. Se preenchesses com zero, a pergunta e o
    denominador seriam diferentes.
  </div>
  <div slot="mistakes">
    Dividir por três ou interpretar a ausência automaticamente como zero.
  </div>
</Exercise>

    tests: [
      {
        name: 'Produto por linha',
        code: 'import pandas as pd\ndf = pd.DataFrame({"quantidade": [2, 3], "preco": [1.5, 1.2]}, index=[8, 3])\nr = com_total(df)\nprint(r.index.tolist())\nprint(r.columns.tolist())\nprint(r["total"].round(2).tolist())',
        output: "[8, 3]\n['quantidade', 'preco', 'total']\n[3.0, 3.6]",
      },
      {
        name: 'Ausência diferente de zero',
        code: 'import pandas as pd\ndf = pd.DataFrame({"quantidade": [0, None, 2], "preco": [5, 3, None]})\nr = com_total(df)\nprint(r["total"].isna().tolist())\nprint(r.loc[0, "total"])',
        output: '[False, True, True]\n0.0',
      },
      {
        name: 'Conservar entrada e valores',
        code: 'import pandas as pd\ndf = pd.DataFrame({"quantidade": [4], "preco": [2.0]})\nantes = df.copy(deep=True)\nr = com_total(df)\nprint("Entrada preservada:", df.equals(antes))\nprint("Colunas preservadas:", r[["quantidade", "preco"]].equals(antes))\nprint(r.loc[0, "total"])',
        output: 'Entrada preservada: True\nColunas preservadas: True\n8.0',
      },
    ],
  }}
>
  <div>
    Define <code>{'com_total(vendas)'}</code>: devolve outra tabela com as
    colunas originais e uma coluna <code>total</code> igual a{' '}
    <code>quantidade</code> vezes <code>preco</code>. Não alteres a entrada.
    Quantidades ou preços ausentes produzem total ausente; não os transformes em
    zero. As colunas de entrada são numéricas e não existe <code>total</code>.
  </div>
  <div slot="hint">A multiplicação de duas colunas é elemento a elemento.</div>
  <div slot="hint-more">
    Cria uma cópia ou usa <code>{'assign'}</code>; não precisas de um ciclo.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'def com_total(vendas):\n    return vendas.assign(total=vendas["quantidade"] * vendas["preco"])'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Alterar a entrada, somar preços e quantidades ou substituir valores em falta
    por zero.
  </div>
</Exercise>
