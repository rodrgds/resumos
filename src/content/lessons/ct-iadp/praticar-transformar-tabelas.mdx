  answer={{ kind: 'number', value: 4, tolerance: 0 }}
>
  <div>
    Uma Series Float64 tem 2, um valor ausente e 6. Quanto vale mean() sem
    preencher ausências?
  </div>

  <div slot="hint-more">Há dois valores conhecidos cuja soma é 8.</div>

  </div>

    Dividir por três ou interpretar a ausência automaticamente como zero.

<Exercise

  title="Calcular outra tabela sem preencher nulos"

  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def com_total(vendas):\n    pass',
    tests: [
      {
        name: 'Produto por linha',
        code: 'import pandas as pd\ndf = pd.DataFrame({"quantidade": [2, 3], "preco": [1.5, 1.2]}, index=[8, 3])\nr = com_total(df)\nprint(r.index.tolist() == [8, 3] and r.columns.tolist() == ["quantidade", "preco", "total"] and r["total"].round(2).tolist() == [3.0, 3.6])',
        output: 'True',
      },
      {
        name: 'Ausência diferente de zero',
        code: 'import pandas as pd\ndf = pd.DataFrame({"quantidade": [0, None, 2], "preco": [5, 3, None]})\nr = com_total(df)\nprint(r["total"].isna().tolist() == [False, True, True] and r.loc[0, "total"] == 0)',
        output: 'True',
      },
      {
        name: 'Conservar entrada e valores',
        code: 'import pandas as pd\ndf = pd.DataFrame({"quantidade": [4], "preco": [2.0]})\nantes = df.copy(deep=True)\nr = com_total(df)\nprint(df.equals(antes) and r[["quantidade", "preco"]].equals(antes) and r.loc[0, "total"] == 8)',
        output: 'True',
      },
    ],
  }}
>
  <div>
    Define com_total(vendas): devolve outra tabela com as colunas originais e
    uma coluna total igual a quantidade vezes preco. Não alteres a entrada.
    Quantidades ou preços ausentes produzem total ausente; não os transformes em
    zero. As colunas de entrada são numéricas e não existe total.
  </div>
  <div slot="hint">A multiplicação de duas colunas é elemento a elemento.</div>
  <div slot="hint-more">
    Cria uma cópia ou usa assign; não precisas de um ciclo.
  </div>
  <div slot="solution">
    <pre>
      <code>
        {
          'def com_total(vendas):\n    return vendas.assign(total=vendas["quantidade"] * vendas["preco"])'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    Alterar a entrada, somar preços e quantidades ou substituir valores em falta
    por zero.
  </div>
</Exercise>
