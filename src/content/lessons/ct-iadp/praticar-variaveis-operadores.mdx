  </div>

<Exercise
  revision={1}
  id="divisao-negativa"
  title={'Distinguir chão de truncatura'}
  explanation="/cadeiras/ct-iadp/variaveis-operadores/#operadores-e-precedência"
  answer={{ kind: 'number', value: -4, tolerance: 0 }}
>
  <p>Quanto vale -7 // 2?</p>
  <div slot="hint">
    A divisão pelo chão arredonda em direção a menos infinito.
  </div>
  <div slot="hint-more">
    O quociente real é -3,5. Qual é o inteiro imediatamente abaixo?
  </div>
  <div slot="solution">
    O resultado é -4. Com resto 1, a identidade é -7 = (-4) × 2 + 1.
  </div>
  <div slot="mistakes">Responder -3 por confundir // com int(-3.5).</div>
</Exercise>
