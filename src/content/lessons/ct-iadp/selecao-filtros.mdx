Tens quatro vendas com cidade, produto, quantidade e preço. Para responder quanto vendeu Braga, tens de construir a tabela e depois escolher as linhas certas. A primeira decisão é se o enunciado fala de rótulos, posições ou valores, porque é ela que determina a operação.

## Construir uma tabela

Uma **Series** é uma sequência de valores com rótulos. Um **DataFrame** é uma tabela com colunas e um índice de linhas, e cada coluna pode ter um tipo diferente. A construção detalhada, os tipos e o alinhamento por rótulos estão em [Series e DataFrames](/cadeiras/ct-iadp/series-dataframes/). Aqui usamos essa base para selecionar.

Há quatro observações e quatro colunas, por isso `shape` é `(4, 4)`. Cada linha representa uma venda, ou seja a unidade de análise desta tabela.

`vendas["quantidade"]` devolve uma Series. `vendas[["quantidade"]]` devolve um DataFrame com uma coluna, por isso a forma e as operações seguintes mudam.

`pd.Series([10, 20], index=["a", "b"])` associa 10 a `a` e 20 a `b`. Os rótulos participam nas operações, ou seja a série não é apenas um array com legenda.

## Inspecionar antes de transformar

| Operação     | Pergunta                                          |
| ------------ | ------------------------------------------------- |
| `df.head(3)` | Como são as primeiras três linhas?                |
| `df.tail(3)` | Como termina a tabela?                            |
| `df.shape`   | Quantas linhas e colunas tem?                     |
| `df.columns` | Que nomes têm as colunas?                         |
| `df.index`   | Como estão identificadas as linhas?               |
| `df.dtypes`  | Que tipo tem cada coluna?                         |

`info()` escreve informação e devolve `None`. Os tipos de strings podem aparecer como `object`, `string` ou `str`, consoante a versão e a construção, por isso confere o significado dos valores e não apenas o nome visual do tipo.

## Ler um CSV

```python
vendas = pd.read_csv("vendas.csv", sep=";", decimal=",")
```

`sep` indica o separador dos campos e `decimal` o separador decimal dentro de valores numéricos. `dtype={"codigo": "string"}` evita que um código como `"0012"` perca os zeros iniciais. `usecols` lê apenas as colunas necessárias e `parse_dates` pode interpretar colunas de datas, mas confere sempre o formato recebido.

No navegador, os exemplos usam `StringIO` e dados visíveis. Num notebook local, substitui esse objeto pelo caminho do ficheiro. Exporta com `df.to_csv("resultado.csv", index=False)` se o índice não fizer parte dos dados, porque sem esse argumento pandas escreve-o como mais uma coluna.

## O alinhamento usa rótulos

Não somamos a primeira posição à primeira posição: somamos os valores da mesma cidade, ou seja Braga 21 e Porto 12. Quando um rótulo só está num dos lados, a operação normal produz um valor em falta nesse rótulo. `fill_value=0` só é adequado aqui porque interpretamos a ausência como nenhuma quantidade para acrescentar.

Usa também `s.loc[rotulo]` e `s.iloc[posicao]` numa Series. `s[0]` pode procurar o rótulo inteiro 0, por isso exemplos antigos que o usavam para a primeira posição devem escrever `s.iloc[0]`.

## Tornar o índice explícito

`df.set_index("codigo")` devolve uma tabela com essa coluna como índice. `reset_index()` devolve o índice para uma coluna e cria posições de zero em diante. Um índice pode ter valores repetidos, por isso verifica `df.index.is_unique` ou `df["codigo"].is_unique` quando o problema exige uma chave única, em vez de o assumir.

## Rótulos com loc, posições com iloc

Imagina uma tabela com índices 10, 20 e 30 e coluna `x` com 2, 4 e 6. `df.loc[20]` procura o rótulo 20 e devolve a linha com `x = 4`. `df.iloc[1]` procura a segunda posição e devolve a mesma linha por outro caminho. Os dois podem coincidir nesta tabela, mas representam pedidos diferentes: rótulo contra posição.

| Pedido                          | Expressão                       |
| ------------------------------- | ------------------------------- |
| Linha com rótulo 20             | `df.loc[20]`                    |
| Segunda linha                   | `df.iloc[1]`                    |
| Duas primeiras linhas           | `df.iloc[:2]`                   |
| Rótulos de 10 até 20, incluídos | `df.loc[10:20]`                 |
| Coluna quantidade               | `df["quantidade"]`              |
| Colunas produto e quantidade    | `df[["produto", "quantidade"]]` |

O slice de `iloc` exclui o limite final. O slice de rótulos de `loc` inclui normalmente ambos os extremos existentes.

## Construir uma máscara

<CodePlayground
  language="python"
  title={'Selecionar uma venda'}
  code={
    'import pandas as pd\nvendas = pd.DataFrame({\n    "cidade": ["Porto", "Porto", "Braga", "Braga"],\n    "produto": ["pão", "leite", "pão", "arroz"],\n    "quantidade": [2, 3, 5, 4],\n}, index=[10, 20, 30, 40])\nmascara = (vendas["cidade"] == "Braga") & (vendas["quantidade"] >= 5)\nprint(mascara.to_list())\nprint(vendas.loc[mascara, ["produto", "quantidade"]].to_string())\nprint(vendas.iloc[:2, 1].to_list())'
  }
/>

Só a linha 30 cumpre ambas as condições, pelo que o resultado contém pão com quantidade 5. Uma máscara deve ter a forma e os rótulos adequados à tabela, porque uma máscara construída noutra tabela pode alinhar por rótulos ou dar erro.

## Combinar condições

Em Series, usa `&` para e, `|` para ou e `~` para negar, e coloca cada comparação entre parênteses. `and` e `or` tentam obter um único valor lógico da Series e dão erro por ambiguidade.

```python
mascara = (df["quantidade"] >= 2) & (df["quantidade"] <= 5)
mascara = df["quantidade"].between(2, 5)
```

As duas expressões incluem os extremos 2 e 5. `df["cidade"].isin(["Porto", "Braga"])` testa pertença a um conjunto de valores.

## Selecionar sem mudar os dados

`df.loc[mascara, colunas]` devolve uma seleção. Para alterares a tabela original, atribui numa operação:

```python
df.loc[df["quantidade"] < 0, "quantidade"] = 0
```

A alteração só faz sentido se zero for a correção definida no problema. Evita `df[mascara]["quantidade"] = 0`, porque são duas seleções e a atribuição pode atingir um objeto intermédio.

Quando queres uma tabela independente, usa `filtradas = df.loc[mascara].copy()`. Assim o destino da alteração fica explícito.

## Selecionar um valor

`df.at[rotulo, coluna]` procura uma célula por rótulos. `df.iat[linha, coluna]` procura-a por posições. São úteis quando esperas um escalar, ou seja não substituem uma máscara para selecionar várias linhas.
