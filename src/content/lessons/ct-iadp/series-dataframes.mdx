Tens quatro vendas com cidade, produto, quantidade e preço. Antes de filtrares, precisas de construir a tabela e perceber como pandas identifica cada linha.

## Construir uma tabela

Uma **Series** é uma sequência de valores com rótulos. Um **DataFrame** é uma tabela com colunas e um índice de linhas. Cada coluna pode ter um tipo diferente.

<CodePlayground
  language="python"
  title={'Tabela de vendas'}
  code={
    'import pandas as pd\nvendas = pd.DataFrame({\n    "cidade": ["Porto", "Porto", "Braga", "Braga"],\n    "produto": ["pão", "leite", "pão", "arroz"],\n    "quantidade": [2, 3, 5, 4],\n    "preco": [1.5, 1.2, 1.5, 2.0],\n})\nprint(vendas.to_string(index=False))\nprint(vendas.shape)\nprint(vendas.dtypes)'
  }
/>

Há quatro observações e quatro colunas, por isso `shape` é `(4, 4)`. Cada linha representa uma venda. É a unidade de análise desta tabela.

`vendas["quantidade"]` devolve uma Series. `vendas[["quantidade"]]` devolve um DataFrame com uma coluna. A forma e as operações seguintes mudam.

## Tipos por coluna

Corre `vendas.dtypes` antes de calculares. Números podem chegar como texto depois de ler um ficheiro. Códigos como `"0012"` devem ficar como texto para conservar os zeros. Tipos de strings podem aparecer como `object`, `string` ou `str`, consoante a versão. Confere o significado dos valores, não apenas o nome do tipo.

## Índice de linhas

`df.set_index("codigo")` devolve uma tabela com essa coluna como índice. `reset_index()` devolve o índice para uma coluna e cria posições de zero em diante. Um índice pode ter valores repetidos. Verifica `df.index.is_unique` quando o problema exige uma chave única, em vez de o assumires.

## Alinhamento por rótulos

<CodePlayground
  language="python"

Não somamos a primeira posição à primeira posição. Somamos os valores da mesma cidade: Braga 21 e Porto 12. Quando um rótulo só está num dos lados, a operação normal produz ausência nesse rótulo. `fill_value=0` só é adequado quando a ausência significa nenhuma quantidade para acrescentar.

Usa `s.loc[rotulo]` para rótulos e `s.iloc[posicao]` para posições. `s[0]` pode procurar o rótulo inteiro 0. Em código novo, escreve `s.iloc[0]` para a primeira posição.
