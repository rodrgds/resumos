Uma coluna de cidade pode conter `"Porto"`, `" porto "` e `"PORTO"`. São três strings diferentes, mas podem identificar a mesma cidade. Normalizar texto exige uma regra sobre o que deve ser tratado como equivalente.

## Métodos de strings numa coluna

<CodePlayground
  language="python"
  title={'Normalizar sem inventar dados'}
  code={
    'import pandas as pd\ncidades = pd.Series([" Porto ", "BRAGA", None, "porto"], dtype="string")\nlimpas = cidades.str.strip().str.lower()\nprint(limpas.to_list())\nprint(limpas.str.contains("port", regex=False, na=False).to_list())\nprint(limpas.value_counts(dropna=False).to_string())'
  }
/>

As strings conhecidas ficam `porto`, `braga` e `porto`. A ausência mantém-se. `na=False` define que as linhas sem texto não são selecionadas. A propriedade `.str` aplica métodos de texto aos elementos da Series.

## Procurar texto literal

`str.contains` pode interpretar o padrão como expressão regular. Um ponto numa expressão regular significa normalmente qualquer carácter, não um ponto literal. Indica `regex=False` para procurar texto literal.

```python
codigos = pd.Series(["PT-001", "PT-014", "sem código"], dtype="string")
extraidos = codigos.str.extract(r"^PT-(\d{3})$", expand=False)
```

O padrão exige o prefixo `PT-`, exatamente três algarismos e nenhum texto extra. O resultado conserva os algarismos como texto, incluindo zeros iniciais. A linha sem correspondência fica em falta.

## Categorias ordenadas

Uma coluna categórica representa valores de um conjunto de categorias. Pode reduzir repetição e permitir uma ordem explícita. Converter uma string para categoria não corrige erros ortográficos.

<CodePlayground
  language="python"
  title={'Dar ordem às categorias'}
  code={
    'import pandas as pd\ntipo = pd.CategoricalDtype(categories=["baixo", "m\u00e9dio", "alto"], ordered=True)\nprioridades = pd.Series(["alto", "baixo", "m\u00e9dio", "baixo"], dtype=tipo)\nprint(prioridades.sort_values().to_list())\nprint((prioridades > "m\u00e9dio").to_list())'
  }
/>

A ordem é baixo, baixo, médio, alto. `.cat.codes` mostra códigos internos, mas esses códigos não são medidas numéricas.

## Converter medidas em intervalos

`pd.cut` transforma números em categorias por intervalo. Declara os limites e quais dos extremos entram em cada intervalo:

<CodePlayground
  language="python"
  title="Classificar quantidades por intervalo"
  code={
    'import pandas as pd\nquantidades = pd.Series([0, 9, 10, 19, 20, None])\ngrupos = pd.cut(quantidades, bins=[0, 10, 20], right=False, labels=["0-9", "10-19"])\nprint(grupos.astype("string").to_list())\nprint(grupos.isna().to_list())'
  }
/>

Com `right=False`, os intervalos são `[0, 10)` e `[10, 20)`: 10 fica no segundo e 20 fica de fora. Os nomes dos grupos devem corresponder a estas condições.

## Categorias não observadas e ausências

Uma categoria pode existir no tipo sem aparecer nos dados. Ao agrupar categorias, indica `observed=True` para considerar apenas combinações observadas ou `observed=False` quando queres também categorias definidas sem observações. Um valor fora das categorias declaradas pode transformar-se em ausência durante a conversão. Confere as strings antes e o número de nulos depois.
