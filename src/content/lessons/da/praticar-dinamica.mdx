<Exercise
  id="da-mochila-reconstrucao"
  title="Valor e seleção numa mochila"
  explanation="/cadeiras/da/programacao-dinamica/#mochila-0-1"
  revision={1}
  answer={{
    kind: 'self',
    checklist: [
      'Obtive valor 12, objetos A e C.',
      'Comparei as duas alternativas na última célula.',
      'Reconstruí recuando uma linha por objeto.',
    ],
  }}
>
  <div>
    Capacidade W=6, com objetos A=(2,4), B=(3,5), C=(4,8). Cada par é peso e
    valor. Calcula o valor ótimo e reconstrói os objetos através das
    alternativas incluir/excluir.
  </div>
  <div slot="hint">
    <p>Compara incluir C, que deixa capacidade 2, com excluir C.</p>
  </div>
  <div slot="hint-more">
    <p>Sem C, A+B dá valor 9. Com C, ainda cabe A e dá 8+4.</p>
  </div>
  <div slot="solution">
    <div>
      O valor ótimo é 12 com A e C, peso 6. Na célula F[3,6], incluir C dá
      8+F[2,2]=12, superior a F[2,6]=9. Recuamos para (2,2), excluímos B porque
      pesa 3, e incluímos A. O objeto C não pode voltar a aparecer porque cada
      inclusão recua uma linha.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Usar F[i,w-p_i] em vez de F[i-1,w-p_i] permite repetir um objeto. O ótimo
      não exige ocupar exatamente a capacidade em todas as instâncias.
    </div>
  </div>
</Exercise>

<Exercise
  id="da-troco-stock"
  title="Um alvo possível no ilimitado e impossível com stock"
  explanation="/cadeiras/da/programacao-dinamica/#trocos-ilimitados-e-com-stock"
  revision={1}
  answer={{
    kind: 'self',
    checklist: [
      'Listei as somas 0,2,5,7.',
      'Declarei o alvo impossível com stock.',
      'Distingui linha anterior e mesma linha.',
    ],
  }}
>
  <div>
    As denominações são 2 e 5 e o alvo é 8. Com stocks 1 e 1, existe solução?
    Explica o que muda na recorrência em relação ao stock ilimitado.
  </div>
  <div slot="hint">
    <p>As quantidades permitidas são apenas zero ou um de cada moeda.</p>
  </div>
  <div slot="hint-more">
    <div>
      As somas possíveis são 0,2,5,7. No ilimitado, quatro moedas de 2 pagam 8.
    </div>
  </div>
  <div slot="solution">
    <div>
      Com stock 1 para cada denominação não há solução. A célula de alvo 8 fica
      infinita. A recorrência limitada escolhe q entre 0 e o stock e usa a linha
      anterior C[i-1,t-qc_i], impedindo reutilizar a mesma denominação para lá
      da quantidade escolhida. Na versão ilimitada, C[i,t-c_i] usa a mesma linha
      e permite quatro moedas de 2.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Devolver quatro moedas de 2 viola o stock. Zero na célula impossível
      significaria falsamente pagar 8 sem moedas.
    </div>
  </div>
</Exercise>

<Exercise
  id="da-kadane-codigo"
  title="Calcular a melhor soma sem alterar o vetor"
  explanation="/cadeiras/da/programacao-dinamica/#o-subvetor-m%C3%A1ximo-em-tempo-linear"
  revision={1}
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def maior_soma(valores):\n    pass',
    tests: [
      { name: 'Intervalo interior', code: 'print(maior_soma([-4, 3, -1, 5, -6, 2]))', output: '7' },
      { name: 'Só negativos', code: 'print(maior_soma([-8, -2, -5]))', output: '-2' },
      { name: 'Um elemento', code: 'print(maior_soma([4]))', output: '4' },
      { name: 'Zeros', code: 'print(maior_soma([0, 0, 0]))', output: '0' },
      { name: 'Recomeçar depois de uma perda', code: 'print(maior_soma([5, -10, 6, 2]))', output: '8' },
      { name: 'Conservar os dados', code: 'a = [2, -1, 3]\nprint(maior_soma(a))\nprint(a)', output: '4\n[2, -1, 3]' },
      { name: 'Lista vazia', code: 'print(maior_soma([]))', output: 'None' },
    ],
  }}
>
  <div>
    Define <code>{"maior_soma(valores)"}</code>. Para uma lista não vazia de inteiros,
    devolve a maior soma de um intervalo contíguo não vazio. Para uma lista
    vazia, devolve <code>{"None"}</code>. Não alteres a lista nem imprimas na função.
    Procura uma solução com tempo O(n) e memória auxiliar O(1).
  </div>
  <div slot="hint">
    Separa o melhor intervalo terminado na posição atual do melhor de todas
    as posições já tratadas.
  </div>
  <div slot="hint-more">
    Inicializa ambos com o primeiro elemento. Para cada seguinte, compara
    recomeçar nesse elemento com prolongar o intervalo anterior.
  </div>
  <div slot="solution">

```python
def maior_soma(valores):
    if not valores:
        return None
    atual = melhor = valores[0]
    for i in range(1, len(valores)):
        atual = max(valores[i], atual + valores[i])
        melhor = max(melhor, atual)
    return melhor
```

    Antes de atualizar o máximo global, atual é a melhor soma de um intervalo
    que termina em i. Cada índice é visitado uma vez e só guardamos dois
    acumuladores. A verificação automática cobre os resultados e a conservação
    da lista nos casos públicos; a complexidade e o invariante exigem esta
    justificação. Enumerar intervalos pode passar os casos, mas não cumpre O(n).

  </div>
  <div slot="mistakes">
    Inicializar a zero aceita um intervalo vazio nas listas só com negativos.
    Somar todos os positivos ignora a contiguidade. Usar valores[1:] copia
    parte da lista e já não usa memória auxiliar constante.
  </div>
</Exercise>
