## Python

Este programa soma os primeiros cinco números naturais. Muda o limite do `range` e compara o resultado.

<CodePlayground
  language="python"
  code={'numeros = range(1, 6)\nprint(sum(numeros))'}
/>

## C++

Os dados de entrada já contêm o número 5. O programa lê esse número e calcula o quadrado. Podes mudar ambos antes de executar.

<CodePlayground
  language="cpp"
  input="5"
  code={
    '#include <iostream>\n\nint main() {\n    int n;\n    std::cin >> n;\n    std::cout << n * n << "\\n";\n}'
  }
/>

## Java

Usa a classe `Main` como ponto de entrada. Este exemplo conta os elementos de uma lista.

<CodePlayground
  language="java"
  code={
    'import java.util.Arrays;\n\npublic class Main {\n    public static void main(String[] args) {\n        java.util.List<String> nomes = Arrays.asList("Ana", "Rui", "Inês");\n        System.out.println(nomes.size());\n    }\n}'
  }
/>

## JavaScript

Aqui, `filter` guarda os números pares. Este editor executa JavaScript sem a página web. Para experimentar o DOM, usa o exemplo de HTML abaixo.

<CodePlayground
  language="javascript"
  code={
    'const numeros = [1, 2, 3, 4, 5, 6];\nconsole.log(numeros.filter(n => n % 2 === 0).join(", "));'
  }
/>

## SQL

Cada execução começa com uma base de dados vazia. Cria a tabela, insere os dados e faz a consulta no mesmo bloco.

## Usar numa página

Numa página MDX, importa `CodePlayground.astro` e passa a linguagem e o código. O campo `input` é opcional.

```mdx
import CodePlayground from '../../../components/CodePlayground.astro';

<CodePlayground language="python" code={'print(2 + 3)'} />
```

Os exemplos servem para programas pequenos. Python inclui a biblioteca padrão, C++ usa C++17 e Java usa Java 8. Não há instalação de pacotes, acesso à rede ou ficheiros do teu computador. O botão **Parar** termina a execução.
