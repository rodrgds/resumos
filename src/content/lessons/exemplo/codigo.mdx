## Python

Este programa soma os primeiros cinco números naturais. Muda o limite do `range` e compara o resultado.

<CodePlayground
  language="python"

## C

`printf` escreve o resultado. Aqui, o ciclo soma os números de 1 a 5 e mostra `15`.

<CodePlayground
  language="c"
  code={
    '#include <stdio.h>\n\nint main(void) {\n    int soma = 0;\n    for (int n = 1; n <= 5; n++) soma += n;\n    printf("%d\\n", soma);\n    return 0;\n}'
  }
/>

## C++

Os dados de entrada já contêm o número 5. O programa lê esse número e calcula o quadrado. Podes mudar ambos antes de executar.

<CodePlayground

## Haskell

`filter even` guarda os pares; `map (^2)` calcula os seus quadrados. O resultado é `[4,16,36]`. Muda a lista e volta a executar. Este motor usa GHC e aceita um programa com `main`, sem entrada interativa.

<CodePlayground
  language="haskell"
  code={'main :: IO ()\nmain = print (map (^2) (filter even [1..6]))'}
/>

## Prolog

Os factos dizem quem é progenitor de quem. A regra `avo` liga duas gerações. `findall` junta as respostas numa lista, que aqui é `[ana]`.

<CodePlayground
  language="prolog"
  code={
    'progenitor(ana, rui).\nprogenitor(rui, ines).\n\navo(X, Y) :- progenitor(X, Z), progenitor(Z, Y).\n\nmain :- findall(X, avo(X, ines), Avos), writeln(Avos).'
  }
/>

O motor é SWI-Prolog. O código comum funciona, mas as bibliotecas específicas de SICStus, usado em PFL, podem ser diferentes.

## PHP

`array_sum` soma os valores do array. `count` conta-os. A divisão dá a média, `16`.

<CodePlayground
  language="php"
  code={
    '<?php\n$notas = [14, 16, 18];\necho array_sum($notas) / count($notas), "\\n";'
  }
/>

## Usar numa página

Numa página MDX, importa `CodePlayground.astro` e passa a linguagem e o código. O campo `input` é opcional.

```mdx
import CodePlayground from '../../../components/CodePlayground.astro';

<CodePlayground language="python" code={'print(2 + 3)'} />
```

Os exemplos servem para programas pequenos. Python inclui a biblioteca padrão, C usa C17, C++ usa C++17, Java usa Java 8 e PHP usa PHP 8.4. Estes editores não substituem o ambiente de uma cadeira: não incluem Minix, processos POSIX, MPI, Laravel ou pacotes de terceiros. O botão **Parar** termina a execução.
