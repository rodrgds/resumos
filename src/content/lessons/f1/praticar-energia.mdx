<Exercise

  <p>
    {

    }
  </p>
  <p slot="hint">
    {
      'O trabalho conservativo é o negativo da variação de potencial, ou seja W = −ΔU.'
    }
  </p>

<Exercise
  id="f1-loop"
  title={'Garantir contacto no topo'}
  explanation="/cadeiras/f1/trabalho-energia/#completar-uma-volta-vertical"
  answer={{ kind: 'number', value: 1.5, tolerance: 0.01, unit: 'm' }}
>
  <p>
    {
      'Um ponto material parte do repouso e desliza sem atrito pelo interior de uma pista circular de raio 0,60 m. Qual a altura mínima de partida, medida do fundo, em metros?'
    }
  </p>
  <p slot="hint">{'No topo, a normal não pode ser negativa.'}</p>
  <p slot="hint-more">
    {'No limite, v_topo² = gR. Junta essa energia à subida de 2R.'}
  </p>
  <p slot="solution">
    {
      'Escreve as duas relações: energia mgh = mg(2R) + mv²/2 e contacto v² = gR no limite. Então h_min = 2R + R/2 = 2,5 × 0,60 = 1,50 m. Chegar ao topo parado faria perder contacto antes, porque faltaria a curvatura necessária.'
    }
  </p>
  <p slot="mistakes">
    {
      'Usar apenas a altura 2R ou adicionar energia de rotação a um ponto material.'
    }
  </p>
</Exercise>

<Exercise
  id="f1-estabilidade"
  revision={2}
  title="Equilíbrio com segunda derivada nula"
  explanation="/cadeiras/f1/trabalho-energia/#equilíbrio-e-estabilidade"
  answer={{ kind: 'self', checklist: ["Obtenho F = −4ax³ e equilíbrio na origem.", "Reconheço que U segundo em zero não decide a estabilidade.", "Justifico a estabilidade pelo sentido da força nos dois lados."] }}
>
  <div>

Uma partícula move-se em uma dimensão com $U(x)=ax^4$, onde $a>0$ tem unidade $\mathrm{J/m^4}$. Localiza os pontos de equilíbrio e classifica a sua estabilidade. Explica por que o teste da segunda derivada, aplicado na origem, não basta.

  </div>
  <div slot="hint">Quando a segunda derivada é nula, examina a força ou o potencial numa vizinhança.</div>
  <div slot="solution">

A força é $F_x=-U'(x)=-4ax^3$. Anula-se apenas em $x=0$. A segunda derivada é $U''(x)=12ax^2$, pelo que $U''(0)=0$: esse teste é inconclusivo.

Para $x>0$, $F_x<0$; para $x<0$, $F_x>0$. Nos dois lados, a força aponta para a origem. Além disso, $U(x)>U(0)$ para todo $x\ne0$. A origem é um mínimo estrito e o equilíbrio é estável. A força restauradora não é linear em x, por isso não é um oscilador harmónico simples.

  </div>
</Exercise>

<Exercise
  id="f1-parar-trecho"
  revision={1}
  title={'Saber se o estado final é acessível'}
  explanation="/cadeiras/f1/trabalho-energia/#balanço-de-energia"
  answer={{ kind: 'number', value: 4, tolerance: 0.01, unit: 'm' }}
>
  <div>
    {
      'Um bloco entra a 4 m/s num trecho horizontal rugoso de 5 m. O coeficiente de atrito cinético é 0,20 e g = 10 m/s². Não há outras forças horizontais. A que distância da entrada pára?'
    }
  </div>
  <div slot="hint">
    {
      'Compara a energia inicial com o trabalho necessário para atravessar todo o trecho.'
    }
  </div>
  <div slot="hint-more">{'Na paragem, mv²/2 = μ_k mgd. A massa cancela.'}</div>
  <div slot="solution">
    {
      'd = 4²/(2 × 0,20 × 10) = 4 m. O bloco pára antes da saída. Um balanço até 5 m daria uma energia cinética final negativa por unidade de massa, e esse estado não é acessível.'
    }
  </div>
  <div slot="mistakes">
    {
      'Calcular uma velocidade de saída a partir de energia cinética negativa ou usar o comprimento total como distância de travagem.'
    }
  </div>
</Exercise>

<Exercise

  title={'Classificar equilíbrios com a segunda derivada'}
  explanation="/cadeiras/f1/trabalho-energia/#equilíbrio-e-estabilidade"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'Instável em x = ±1 m; estável na origem.',
        correct: true,
        explanation:
          'U′ = 4x − 4x³ anula-se em 0 e ±1; U″ = 4 − 12x² dá +4 na origem e −8 em ±1.',
      },
      {
        text: 'Instável na origem; estável em x = ±1 m.',
        correct: false,
        explanation: 'Troca os sinais: na origem U″ é positivo, logo é mínimo.',
      },
      {
        text: 'Instável em x = ±2 m.',
        correct: false,
        explanation:
          'Em ±2 a força não se anula, por isso não são equilíbrios.',
      },
      {
        text: 'Todos instáveis, porque o potencial tem potências pares.',
        correct: false,
        explanation:
          'A paridade não decide; o sinal de U″ em cada zero de U′ decide.',
      },
    ],
  }}
>
  <div>
    {
      'Uma partícula move-se com U(x) = 2x² − x⁴, em joules e metros. Onde o equilíbrio é instável? Adaptação da questão 8 do exame de 14 de junho de 2023.'
    }
  </div>
  <div slot="hint">
    {'Anula a força e avalia a segunda derivada em cada zero.'}
  </div>
  <div slot="solution">
    {
      'F_x = −U′ = −4x + 4x³. Os zeros são x = 0 e x = ±1 m. Com U″(x) = 4 − 12x², a origem é mínimo estável e ±1 são máximos instáveis.'
    }
  </div>
  <div slot="mistakes">
    {
      'Escolher os zeros da energia em vez dos zeros da força, ou ler estabilidade da paridade do potencial.'
    }
  </div>
</Exercise>

<Exercise
  id="f1-atrito-trabalho-vel-constante"
  title={'Trabalho do atrito a velocidade constante'}
  explanation="/cadeiras/f1/trabalho-energia/#trabalho-de-uma-força"
  answer={{ kind: 'number', value: -173.21, tolerance: 0.05, unit: 'J' }}
>
  <div>
    {
      'Um bloco de 5 kg é puxado numa horizontal com força de 20 N a 30° da horizontal, com componente vertical para baixo, e avança 10 m com velocidade constante. Usa g = 9,81 m/s². Qual o trabalho do atrito cinético, em joules? Modela a questão 9 do exame de recurso de 26 de junho de 2023.'
    }
  </div>
  <div slot="hint">
    {
      'A velocidade constante diz que a resultante é nula, por isso o atrito iguala a componente horizontal do puxão.'
    }
  </div>
  <div slot="hint-more">{'f_k = 20 cos 30° e o trabalho é −f_k × 10.'}</div>
  <div slot="solution">
    {
      'A resultante nula dá f_k = 20 cos 30° ≈ 17,32 N, sem precisar da normal. O trabalho é −17,32 × 10 ≈ −173,2 J. Pela normal, N = 5 × 9,81 − 20 sin 30° = 39,05 N, e −μ_k N d teria de dar o mesmo valor.'
    }
  </div>
  <div slot="mistakes">
    {
      'Calcular a normal sem a componente vertical do puxão, ou usar a resultante nula para concluir trabalho total nulo do atrito.'
    }
  </div>
</Exercise>

<Exercise
  id="f1-potencial-rapidez"
  title={'Ler força e rapidez no potencial'}
  explanation="/cadeiras/f1/trabalho-energia/#equilíbrio-e-estabilidade"
  answer={{ kind: 'number', value: 4, tolerance: 0.01, unit: 'm/s' }}
>
  <div>
    {
      'Uma partícula de 1 kg move-se com U(x) = 2x² J e energia mecânica E = 16 J. Qual o módulo da velocidade em x = 2 m?'
    }
  </div>
  <div slot="hint">{'A diferença E − U é a energia cinética.'}</div>
  <div slot="hint-more">
    {'U(2) = 2 × 4 = 8 J. A energia cinética é E − U.'}
  </div>
  <div slot="solution">
    {
      'K = 16 − 8 = 8 J. Então v = √(2K/m) = √16 = 4 m/s. Em x = 4 m, U = 32 J excede E: esse ponto é inacessível.'
    }
  </div>
  <div slot="mistakes">{'Ler a energia potencial como energia cinética.'}</div>
</Exercise>
