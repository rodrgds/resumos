<Exercise
  id="f1-trabalho-sinal"
  title={'Trabalho da mola'}
  explanation="/cadeiras/f1/trabalho-energia/#energia-potencial"
  answer={{ kind: 'number', value: -3, tolerance: 0.01, unit: 'J' }}
>
  <p>
    {
      'Uma mola de k = 150 N/m passa do alongamento 0 a 0,20 m. Qual o trabalho feito pela mola, em joules?'
    }
  </p>
  <p slot="hint">
    {
      'O trabalho conservativo é o negativo da variação de potencial, ou seja W = −ΔU.'
    }
  </p>
  <p slot="hint-more">{'W = −k(x_f² − x_i²)/2.'}</p>
  <p slot="solution">
    {
      'W = −150 × 0,20²/2 = −3 J. A força externa num alongamento quase estático faz +3 J, porque equilibra a mola em cada ponto.'
    }
  </p>
  <p slot="mistakes">
    {'Confundir trabalho da mola com trabalho da força que a estica.'}
  </p>
</Exercise>

<Exercise
  id="f1-loop"
  title={'Garantir contacto no topo'}
  explanation="/cadeiras/f1/trabalho-energia/#completar-uma-volta-vertical"
  answer={{ kind: 'number', value: 1.5, tolerance: 0.01, unit: 'm' }}
>
  <p>
    {
      'Um ponto material parte do repouso e desliza sem atrito pelo interior de uma pista circular de raio 0,60 m. Qual a altura mínima de partida, medida do fundo, em metros?'
    }
  </p>
  <p slot="hint">{'No topo, a normal não pode ser negativa.'}</p>
  <p slot="hint-more">
    {'No limite, v_topo² = gR. Junta essa energia à subida de 2R.'}
  </p>
  <p slot="solution">
    {
      'Escreve as duas relações: energia mgh = mg(2R) + mv²/2 e contacto v² = gR no limite. Então h_min = 2R + R/2 = 2,5 × 0,60 = 1,50 m. Chegar ao topo parado faria perder contacto antes, porque faltaria a curvatura necessária.'
    }
  </p>
  <p slot="mistakes">
    {
      'Usar apenas a altura 2R ou adicionar energia de rotação a um ponto material.'
    }
  </p>
</Exercise>

<Exercise
  id="f1-estabilidade"
  title={'Distinguir um equilíbrio estável'}
  explanation="/cadeiras/f1/trabalho-energia/#equilíbrio-e-estabilidade"
  answer={{
    kind: 'self',
    checklist: [
      "Localizo os pontos onde U'(x) = 0.",
      'Determino o sentido da força num pequeno afastamento de cada lado.',
      'Relaciono mínimo de potencial com força restauradora.',
    ],
  }}
>
  <p>
    {
      'Explica por que U(x) = kx²/2, com k positivo, tem equilíbrio estável em x = 0.'
    }
  </p>
  <p slot="hint">{'Calcula F = −dU/dx.'}</p>
  <p slot="hint-more">
    {'Para x positivo, F = −kx é negativa; para x negativo, é positiva.'}
  </p>
  <p slot="solution">
    {
      "U'(0) = 0 e U''(0) = k > 0. A origem é um mínimo. Um pequeno afastamento gera uma força dirigida de volta à origem, por isso o equilíbrio é estável."
    }
  </p>
  <p slot="mistakes">
    {
      'Concluir estabilidade apenas porque a força se anula no ponto, sem estudar a vizinhança.'
    }
  </p>
</Exercise>

<Exercise
  id="f1-parar-trecho"
  revision={1}
  title={'Saber se o estado final é acessível'}
  explanation="/cadeiras/f1/trabalho-energia/#balanço-de-energia"
  answer={{ kind: 'number', value: 4, tolerance: 0.01, unit: 'm' }}
>
  <div>
    {
      'Um bloco entra a 4 m/s num trecho horizontal rugoso de 5 m. O coeficiente de atrito cinético é 0,20 e g = 10 m/s². Não há outras forças horizontais. A que distância da entrada pára?'
    }
  </div>
  <div slot="hint">
    {
      'Compara a energia inicial com o trabalho necessário para atravessar todo o trecho.'
    }
  </div>
  <div slot="hint-more">{'Na paragem, mv²/2 = μ_k mgd. A massa cancela.'}</div>
  <div slot="solution">
    {
      'd = 4²/(2 × 0,20 × 10) = 4 m. O bloco pára antes da saída. Um balanço até 5 m daria uma energia cinética final negativa por unidade de massa, e esse estado não é acessível.'
    }
  </div>
  <div slot="mistakes">
    {
      'Calcular uma velocidade de saída a partir de energia cinética negativa ou usar o comprimento total como distância de travagem.'
    }
  </div>
</Exercise>

<Exercise
  id="f1-potencial-rapidez"
  title={'Ler força e rapidez no potencial'}
  explanation="/cadeiras/f1/trabalho-energia/#equilíbrio-e-estabilidade"
  answer={{ kind: 'number', value: 4, tolerance: 0.01, unit: 'm/s' }}
>
  <div>
    {
      'Uma partícula de 1 kg move-se com U(x) = 2x² J e energia mecânica E = 16 J. Qual o módulo da velocidade em x = 2 m?'
    }
  </div>
  <div slot="hint">{'A diferença E − U é a energia cinética.'}</div>
  <div slot="hint-more">
    {'U(2) = 2 × 4 = 8 J. A energia cinética é E − U.'}
  </div>
  <div slot="solution">
    {
      'K = 16 − 8 = 8 J. Então v = √(2K/m) = √16 = 4 m/s. Em x = 4 m, U = 32 J excede E: esse ponto é inacessível.'
    }
  </div>
  <div slot="mistakes">{'Ler a energia potencial como energia cinética.'}</div>
</Exercise>
