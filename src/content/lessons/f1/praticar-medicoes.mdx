  answer={{ kind: 'number', value: 1.5, tolerance: 0.01, unit: 's' }}
>
  <p>
    {
      'Cinco máximos positivos consecutivos ocorrem de t = 1 s a t = 7 s. Qual o período médio, em segundos?'
    }
  </p>
  <p slot="hint">{'Cinco picos delimitam quatro intervalos.'}</p>
  <p slot="hint-more">{'T = (7 − 1)/4.'}</p>
  <p slot="solution">

    }
  </p>
  <p slot="mistakes">
    {
      'Dividir o intervalo total por cinco ou misturar máximos e mínimos como ciclos completos.'
    }
  </p>
</Exercise>

<Exercise
  id="f1-decremento"
  title={'Estimar a taxa de decaimento'}
  explanation="/cadeiras/f1/medir-oscilacoes/#ajustar-o-decaimento"
  answer={{
    kind: 'number',
    value: 0.1115717757,
    tolerance: 0.001,
    unit: 's⁻¹',
  }}
>
  <p>
    {
      'Dois picos do mesmo sinal, separados por 4 s, têm amplitudes 1,00 e 0,64 na mesma unidade. Qual a taxa γ da envolvente exp(−γt), em s⁻¹?'
    }
  </p>
  <p slot="hint">{'Usa a razão das amplitudes, não a diferença.'}</p>
  <p slot="hint-more">{'γ = ln(1,00/0,64)/4.'}</p>
  <p slot="solution">
    {
      'γ ≈ 0,11157 s⁻¹. O argumento do logaritmo é adimensional e γ tem unidade de inverso do tempo.'
    }
  </p>
  <p slot="mistakes">
    {
      'Tomar a diferença de amplitudes como taxa exponencial ou inverter a razão e obter γ negativo.'
    }
  </p>
</Exercise>

<Exercise
  id="f1-incerteza"
  title={'Propagar a incerteza do período'}
  explanation="/cadeiras/f1/medir-oscilacoes/#incerteza-e-conclusão"
  answer={{ kind: 'number', value: 2, tolerance: 0.01, unit: '%' }}
>
  <p>
    {
      'No modelo de pêndulo simples sem correção de amortecimento, T = 2,00 ± 0,02 s e g é fixo. Qual a incerteza relativa aproximada de ℓ, em percentagem?'
    }
  </p>
  <p slot="hint">{'O comprimento depende do quadrado do período.'}</p>
  <p slot="hint-more">{'Δℓ/ℓ ≈ 2ΔT/T.'}</p>
  <p slot="solution">
    {
      '2 × 0,02/2,00 = 0,02, ou 2%. É uma aproximação para pequenas incertezas sob o modelo escolhido.'
    }
  </p>
  <p slot="mistakes">
    {'Usar 1% sem contabilizar o quadrado ou escrever 0,02% em vez de 2%.'}
  </p>
</Exercise>

<Exercise
  id="f1-picos-baseline"
  revision={1}
  title={'Retirar o desvio do sensor'}
  explanation="/cadeiras/f1/medir-oscilacoes/#ajustar-o-decaimento"
  answer={{
    kind: 'number',
    value: 0.3465735903,
    tolerance: 0.002,
    unit: 's⁻¹',
  }}
>
  <div>
    {
      'Um sinal tem linha de base constante de 3 m/s². Dois máximos positivos consecutivos, separados por 2 s, têm valores lidos de 7 e 5 m/s². Admitindo amortecimento linear, qual a taxa γ do decaimento da amplitude?'
    }
  </div>
  <div slot="hint">
    {'As amplitudes são medidas desde a linha de base, não desde zero.'}
  </div>
  <div slot="hint-more">
    {'Os afastamentos são 7 − 3 = 4 e 5 − 3 = 2 m/s². Calcula ln(4/2)/2.'}
  </div>
  <div slot="solution">
    {
      'γ = ln 2/2 ≈ 0,3466 s⁻¹. Usar os valores brutos daria ln(7/5)/2 ≈ 0,1682 s⁻¹, que mede uma razão alterada pelo desvio do sensor.'
    }
  </div>
  <div slot="mistakes">
    {
      'Tomar a razão 7/5 sem subtrair a linha de base ou confundir dois máximos consecutivos com meio período.'
    }
  </div>
</Exercise>
