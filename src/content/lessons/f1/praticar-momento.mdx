<Exercise
  id="f1-haste-densidade"
  title={'Centro de massa não uniforme'}
  explanation="/cadeiras/f1/centro-massa-momento/#centro-de-massa"
  answer={{ kind: 'number', value: 2, tolerance: 0.01, unit: 'm' }}
>
  <p>
    {
      'Uma haste ocupa 0 ≤ x ≤ 3 m e tem densidade linear λ(x) = cx, com c positivo. Qual a coordenada do centro de massa, em metros?'
    }
  </p>
  <p slot="hint">
    {
      'Calcula a massa total antes do primeiro momento, porque a densidade varia com x.'
    }
  </p>
  <p slot="hint-more">{'M = cL²/2 e integral de x dm = cL³/3.'}</p>
  <p slot="solution">
    {
      'X_CM = (cL³/3)/(cL²/2) = 2L/3 = 2 m. Fica mais perto da extremidade onde há mais massa.'
    }
  </p>
  <p slot="mistakes">{'Usar o ponto médio de uma haste que não é uniforme.'}</p>
</Exercise>

<Exercise
  id="f1-impulso"
  title={'Impulso com ressalto'}
  explanation="/cadeiras/f1/centro-massa-momento/#impulso-e-conservação"
  answer={{ kind: 'number', value: -5, tolerance: 0.01, unit: 'N·s' }}
>
  <p>
    {
      'Uma bola de 0,50 kg move-se em x com +6 m/s e, depois de bater numa parede, sai com −4 m/s. Qual a componente x do impulso da parede, em N·s?'
    }
  </p>
  <p slot="hint">
    {'Impulso é a diferença de momentos com sinal, ou seja atende ao sentido.'}
  </p>
  <p slot="hint-more">{'J_x = m(v_f − v_i) = 0,50(−4 − 6).'}</p>
  <p slot="solution">
    {'J_x = −5 N·s. O sinal indica impulso contrário ao eixo x positivo.'}
  </p>
  <p slot="mistakes">
    {'Subtrair apenas as rapidezes, ignorando a inversão do sentido.'}
  </p>
</Exercise>

<Exercise
  id="f1-colisao-juntos"
  title={'Choque perfeitamente inelástico'}
  explanation="/cadeiras/f1/centro-massa-momento/#colisões-em-uma-dimensão"
  answer={{ kind: 'number', value: 1.6, tolerance: 0.01, unit: 'm/s' }}
>
  <p>
    {
      'Um corpo de 2 kg a +4 m/s colide com outro de 3 kg parado e ficam juntos. Sem impulso externo, qual a velocidade final, em m/s?'
    }
  </p>
  <p slot="hint">{'Há uma única velocidade final para os dois corpos.'}</p>
  <p slot="hint-more">{'Momento inicial = 2 × 4. Massa final = 2 + 3.'}</p>
  <p slot="solution">
    {
      'u = 8/5 = 1,6 m/s. A energia cinética passa de 16 J para 6,4 J; 9,6 J deixam de ser energia cinética.'
    }
  </p>
  <p slot="mistakes">
    {
      'Impor conservação da energia cinética num choque em que os corpos ficam juntos.'
    }
  </p>
</Exercise>

<Exercise
  id="f1-choque-frontal"
  revision={1}
  title={'Resolver um choque com sentidos opostos'}
  explanation="/cadeiras/f1/centro-massa-momento/#colisões-em-uma-dimensão"
  answer={{
    kind: 'self',
    checklist: [
      'Uso velocidades com sinal no mesmo eixo.',
      'Obtenho u₁ = −3 m/s e u₂ = +1 m/s.',
      'Verifico momento total nulo e energia cinética de 6 J antes e depois.',
    ],
  }}
>
  <div>
    {
      'Um corpo de 1 kg a +3 m/s colide elasticamente, em uma dimensão, com outro de 3 kg a −1 m/s. O impulso externo é desprezável. Determina as duas velocidades finais e verifica as conservações.'
    }
  </div>
  <div slot="hint">
    {'Escreve uma equação para o momento e outra para a velocidade relativa.'}
  </div>
  <div slot="hint-more">
    {
      'O momento é nulo, logo u₁ + 3u₂ = 0. A separação satisfaz u₂ − u₁ = 3 − (−1) = 4 m/s.'
    }
  </div>
  <div slot="solution">
    {
      'Substituindo u₁ = −3u₂, temos 4u₂ = 4, logo u₂ = +1 m/s e u₁ = −3 m/s. O momento final é −3 + 3 × 1 = 0 kg·m/s. A energia final é (1 × 9 + 3 × 1)/2 = 6 J, igual à inicial.'
    }
  </div>
  <div slot="mistakes">
    {
      'Trocar velocidades como se as massas fossem iguais, perder o sinal da segunda velocidade ou conservar apenas energia sem momento.'
    }
  </div>
</Exercise>

<Exercise
  id="f1-barco-referencia"
  revision={1}
  title={'Distinguir o deslocamento relativo'}
  explanation="/cadeiras/f1/centro-massa-momento/#movimento-do-centro-de-massa"
  answer={{ kind: 'number', value: -0.75, tolerance: 0.005, unit: 'm' }}
>
  <div>
    {
      'Uma pessoa de 60 kg percorre 3 m relativamente a um barco de 180 kg, ambos inicialmente em repouso. Despreza forças horizontais externas. O eixo positivo tem o sentido da marcha da pessoa. Qual o deslocamento do barco relativamente à margem?'
    }
  </div>
  <div slot="hint">
    {'O centro de massa mantém a posição, mas os 3 m são medidos no barco.'}
  </div>
  <div slot="hint-more">
    {
      'Se o barco se deslocar d, a pessoa desloca-se d + 3 em relação à margem. Usa 180d + 60(d + 3) = 0.'
    }
  </div>
  <div slot="solution">
    {
      '240d = −180, portanto d = −0,75 m. A pessoa desloca-se 2,25 m em relação à margem. O barco recua para manter o centro de massa fixo.'
    }
  </div>
  <div slot="mistakes">
    {'Atribuir à pessoa 3 m em relação à margem e obter −1 m para o barco.'}
  </div>
</Exercise>

<Exercise
  id="f1-placa-composta"
  title={'Confirmar uma placa composta'}
  explanation="/cadeiras/f1/centro-massa-momento/#centro-de-massa"
  answer={{
    kind: 'self',
    checklist: [
      'Calculo o CM de cada retângulo com a mesma origem.',
      'Combino como massas pontuais e obtenho o mesmo valor.',
      'Confirmo com o retângulo completo menos o recorte como massa negativa.',
    ],
  }}
>
  <div>
    {
      'Uma placa em L resulta de dois retângulos uniformes com a mesma densidade. O cálculo por peças dá X_CM = 0,42 m. Descreve um método alternativo que confirma este valor.'
    }
  </div>
  <div slot="hint">{'Trata o recorte como massa negativa.'}</div>
  <div slot="hint-more">
    {'Completa o retângulo e subtrai a peça em falta com a mesma densidade.'}
  </div>
  <div slot="solution">
    {
      'Os três modos têm de coincidir: soma de peças, retângulo completo menos recorte como massa negativa e integral direto. Se divergirem, revê áreas e origens.'
    }
  </div>
  <div slot="mistakes">
    {'Somar centros geométricos sem ponderar pelas áreas.'}
  </div>
</Exercise>

  <div slot="hint">{'Separa o impacto rápido da subida lenta.'}</div>

    {
      'No impacto o impulso externo é desprezável; na subida o peso faz trabalho.'
    }
  </div>
  <div slot="solution">

  </div>
