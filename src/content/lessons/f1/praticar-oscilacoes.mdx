<Exercise

  revision={2}
  title={'Determinar a amplitude'}
  explanation="/cadeiras/f1/oscilacoes/#condições-iniciais-e-fase"
  answer={{ kind: 'number', value: 0.05, tolerance: 0.0001, unit: 'm' }}
>
  <p>
    {
      'Um oscilador harmónico simples ideal tem ω_0 = 10 rad/s, x_0 = 0,03 m e v_0 = 0,40 m/s. Qual a amplitude, em metros?'
    }
  </p>
  <p slot="hint">{'A posição inicial não é necessariamente a amplitude.'}</p>
  <p slot="hint-more">{'A² = x_0² + (v_0/ω_0)².'}</p>
  <p slot="solution">
    {
      'A = sqrt(0,03² + 0,04²) = 0,05 m. A energia inicial contém uma parte cinética e outra potencial.'
    }
  </p>
  <p slot="mistakes">
    {'Tomar A = x_0 sem verificar se a velocidade inicial é zero.'}
  </p>
</Exercise>

<Exercise
  id="f1-meia-amplitude"
  title={'Tempo de meia amplitude'}
  explanation="/cadeiras/f1/oscilacoes/#decaimento-e-fator-de-qualidade"
  answer={{ kind: 'number', value: 0.6931471806, tolerance: 0.002, unit: 's' }}
>
  <p>
    {
      'A envolvente é A(t) = A_0 exp(−t), com t em segundos. Quanto tempo demora a amplitude a cair para metade?'
    }
  </p>
  <p slot="hint">{'Divide a equação por A_0 antes de aplicar logaritmo.'}</p>
  <p slot="hint-more">{'exp(−t) = 1/2, portanto t = ln 2.'}</p>
  <p slot="solution">
    {
      't = ln 2 ≈ 0,693 s. Para energia média proporcional ao quadrado da amplitude, o tempo de meia energia seria cerca de 0,347 s.'
    }
  </p>
  <p slot="mistakes">
    {'Confundir a metade da amplitude com a metade da energia.'}
  </p>
</Exercise>

    ],

>
  <p>
    {
      'Num oscilador forçado com amortecimento positivo, onde fica o máximo da amplitude?'
    }
  </p>
  <p slot="hint">
    {'Distingue a frequência natural da frequência que maximiza a resposta.'}
  </p>
  <p slot="hint-more">
    {'Examina Ω_res = sqrt(ω_0² − 2γ²) e a condição para a raiz.'}
  </p>
  <p slot="solution">
    {
      'Quando γ < ω_0/sqrt(2), o pico é a uma frequência inferior a ω_0. Para amortecimento maior, a amplitude não tem esse pico a frequência positiva.'
    }
  </p>
  <p slot="mistakes">
    {
      'Usar a frequência da oscilação livre amortecida como a frequência do máximo de resposta.'
    }
  </p>
</Exercise>

<Exercise
  id="f1-fase-velocidade"
  revision={1}
  title={'Escolher o quadrante da fase'}
  explanation="/cadeiras/f1/oscilacoes/#condições-iniciais-e-fase"
  answer={{
    kind: 'self',
    checklist: [
      'Obtenho A = 0,12 m a partir da velocidade inicial.',
      'Escolho φ = π/2, ou um valor equivalente módulo 2π.',
      'Substituo em x(0) e v(0) para confirmar posição nula e velocidade negativa.',
    ],
  }}
>
  <div>
    {
      'Num movimento harmónico simples ideal, ω₀ = 5 rad/s, x(0) = 0 e v(0) = −0,60 m/s. Escreve x(t) = A cos(ω₀t + φ), com A positivo, e justifica a fase.'
    }
  </div>
  <div slot="hint">
    {
      'A origem é uma passagem pelo equilíbrio, não uma extremidade da oscilação.'
    }
  </div>
  <div slot="hint-more">
    {
      'x(0) = A cos φ = 0 e v(0) = −Aω₀ sin φ < 0. Por isso cos φ = 0 e sin φ = 1.'
    }
  </div>
  <div slot="solution">
    {
      'A = |v₀|/ω₀ = 0,60/5 = 0,12 m. Podemos escrever x(t) = 0,12 cos(5t + π/2), com t em segundos e x em metros. Em t = 0, x = 0 e v = −0,12 × 5 = −0,60 m/s.'
    }
  </div>
  <div slot="mistakes">
    {
      'Escolher −π/2, que daria velocidade inicial positiva, ou tomar a amplitude como zero por o corpo começar no equilíbrio.'
    }
  </div>
</Exercise>
