<Exercise
  id="f1-viga"
  title={'Equilíbrio da viga'}
  explanation="/cadeiras/f1/rotacao/#equilíbrio-de-um-corpo-rígido"
  answer={{ kind: 'number', value: 175, tolerance: 0.01, unit: 'N' }}
>
  <p>
    {
      'Uma viga uniforme de 4 m e peso 200 N tem apoios nas extremidades. Uma carga de 100 N está a 1 m do apoio esquerdo. Qual a reação do apoio esquerdo, em N?'
    }
  </p>
  <p slot="hint">
    {'Toma momentos no apoio esquerdo para obter primeiro a reação direita.'}
  </p>
  <p slot="hint-more">{'4R_B = 200 × 2 + 100 × 1; R_A + R_B = 300.'}</p>
  <p slot="solution">
    {
      'Escolhe momentos em B para eliminar R_B: 4R_A = 200 × 2 + 100 × 3. Então R_A = 700/4 = 175 N e R_B = 300 − 175 = 125 N. O peso da viga atua no centro por ser uniforme.'
    }
  </p>
  <p slot="mistakes">
    {'Esquecer o peso da viga ou trocar a reação esquerda pela direita.'}
  </p>
</Exercise>

<Exercise
  id="f1-cilindro-atrito"
  title={'Verificar o rolamento'}
  explanation="/cadeiras/f1/rotacao/#rolamento-sem-deslizamento"
  answer={{ kind: 'number', value: 0.1924500897, tolerance: 0.001 }}
>
  <p>
    {
      'Um cilindro maciço parte do repouso numa rampa a 30°. Qual o coeficiente mínimo de atrito estático para rolar sem deslizar? Dá um número adimensional.'
    }
  </p>
  <p slot="hint">
    {'O atrito necessário vem das equações de translação e rotação.'}
  </p>
  <p slot="hint-more">{'Para o cilindro, f = Mg sin θ/3 e N = Mg cos θ.'}</p>
  <p slot="solution">
    {
      'Das equações Ma = Mg sinθ − f e fR = Iα com a = Rα, obtém-se f = Mg sinθ/3. Então μ_s mínimo = f/N = tan(30°)/3 ≈ 0,19245. Um atrito disponível menor torna inválida a hipótese de rolamento puro.'
    }
  </p>
  <p slot="mistakes">
    {
      'Assumir rolamento sem verificar se o contacto pode fornecer o torque necessário.'
    }
  </p>
</Exercise>

<Exercise
  id="f1-momento-angular"
  title={'Energia ao fechar os braços'}
  explanation="/cadeiras/f1/rotacao/#conservação-e-precessão"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'O momento angular mantém-se e a energia cinética pode aumentar.',
        correct: true,
        explanation: 'O trabalho muscular pode aumentar K sem torque externo.',
      },
      {
        text: 'A energia cinética conserva-se sempre que o momento angular se conserva.',
        correct: false,
        explanation: 'As condições das duas conservações são diferentes.',
      },
      {
        text: 'A velocidade angular mantém-se quando I diminui.',
        correct: false,
        explanation: 'Se Iω é constante, uma redução de I aumenta ω.',
      },
    ],
  }}
>
  <p>
    {
      'Uma pessoa numa plataforma sem torque externo fecha os braços, reduzindo a inércia. Qual afirmação é válida?'
    }
  </p>
  <p slot="hint">
    {'Escreve I_i ω_i = I_f ω_f, porque não há torque externo.'}
  </p>
  <p slot="hint-more">
    {'A energia é Iω²/2 e existe trabalho interno dos músculos.'}
  </p>
  <p slot="solution">
    {
      'O momento angular conserva-se. A velocidade angular aumenta e a energia cinética pode aumentar devido ao trabalho interno.'
    }
  </p>
  <p slot="mistakes">
    {
      'Tratar a conservação de uma grandeza como prova de conservação de todas as outras.'
    }
  </p>

<Exercise
  id="f1-impacto-aro"
  revision={1}
  title={'Escolher a conservação num eixo fixo'}
  explanation="/cadeiras/f1/rotacao/#impacto-e-energia-de-rotação"
  answer={{
    kind: 'number',
    value: 4.7619047619,
    tolerance: 0.005,
    unit: 'rad/s',
  }}
>
  <div>
    {
      'Um aro fino uniforme de 2 kg e raio 0,20 m está parado num eixo fixo perpendicular pelo centro. Uma massa pontual de 0,10 kg chega tangencialmente ao bordo a 20 m/s e fica presa. O impulso do torque externo axial é desprezável. Qual o módulo da velocidade angular final?'
    }
  </div>
  <div slot="hint">
    {
      'Conserva o momento angular em torno do eixo. Inclui a massa presa na inércia final.'
    }
  </div>
  <div slot="hint-more">
    {'L_i = mvR. Para o aro, I = MR²; depois do impacto, I_f = (M + m)R².'}
  </div>
  <div slot="solution">
    {
      'L_i = 0,10 × 20 × 0,20 = 0,40 kg·m²/s. I_f = 2,10 × 0,20² = 0,084 kg·m². Logo ω_f = 0,40/0,084 ≈ 4,762 rad/s. O apoio pode fornecer impulso linear e o choque perde energia cinética.'
    }
  </div>
  <div slot="mistakes">
    {
      'Usar MR²/2, que corresponde a um disco, esquecer a massa presa ou conservar energia cinética no choque inelástico.'
    }
  </div>
</Exercise>

<Exercise
  id="f1-eixos-paralelos"
  title={'Mudar o eixo da haste'}
  explanation="/cadeiras/f1/rotacao/#momento-de-inércia"
  answer={{
    kind: 'number',
    value: 0.3333333333,
    tolerance: 0.002,
    unit: 'kg·m²',
  }}
>
  <div>
    {
      'Uma haste uniforme de M = 1 kg e ℓ = 1 m roda em torno de um eixo perpendicular pela extremidade. Qual o momento de inércia?'
    }
  </div>
  <div slot="hint">{'Parte do centro de massa e desloca o eixo.'}</div>
  <div slot="hint-more">{'I_CM = Mℓ²/12 e d = ℓ/2.'}</div>
  <div slot="solution">{'I = Mℓ²/12 + M(ℓ/2)² = Mℓ²/3 ≈ 0,333 kg·m².'}</div>
  <div slot="mistakes">
    {'Usar o valor do centro sem aplicar os eixos paralelos.'}
  </div>
</Exercise>

<Exercise
  id="f1-pendulo-fisico"
  title={'Período de uma haste suspensa'}
  explanation="/cadeiras/f1/rotacao/#pêndulo-físico"
  answer={{ kind: 'number', value: 1.638, tolerance: 0.005, unit: 's' }}
>
  <div>
    {
      'Uma haste uniforme de 1 m está suspensa pela extremidade. Usa g = 9,81 m/s² e pequenos ângulos. Qual o período?'
    }
  </div>
  <div slot="hint">{'Precisas de I_O e da distância ao centro de massa.'}</div>
  <div slot="hint-more">
    {'I_O = Mℓ²/3 e d = ℓ/2. Depois T = 2π√(I_O/(Mgd)).'}
  </div>
  <div slot="solution">
    {
      'T = 2π√(2ℓ/(3g)) ≈ 1,638 s. É menor que o período de um ponto material a 1 m, porque a massa está distribuída.'
    }
  </div>
  <div slot="mistakes">
    {'Substituir o tamanho da haste pelo comprimento de um fio simples.'}
  </div>
</Exercise>
