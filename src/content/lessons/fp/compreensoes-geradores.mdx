Depois de tratares funções como valores, esta página responde a esta pergunta: como transformas e filtras uma coleção numa só expressão?

Para obter os quadrados dos números positivos, percorres uma coleção, selecionas valores e transformas cada selecionado. Uma compreensão junta essas decisões numa expressão, porque não muda a coleção de entrada.

## Compreensões de listas

A forma `[expressao for x in xs if condicao]` percorre `xs`, verifica a condição e acrescenta o valor da expressão apenas nos casos aceites.

<CodePlayground
  language="python"
  title="Compreender o filtro e a transformação"

    'valores = [-2, 0, 3, 4]\nquadrados = [x * x for x in valores if x > 0]\nprint(quadrados)\nprint(valores)\nprint(["par" if x % 2 == 0 else "ímpar" for x in range(4)])'
  }
/>

O filtro retira -2 e 0 e a transformação calcula 9 e 16, por isso o resultado tem duas posições. Na expressão `a if condicao else b`, o resultado é `a` quando a condição é verdadeira, ou `b` caso contrário. Este `if ... else` escolhe o valor de cada elemento e não filtra entradas, por isso o último exemplo conserva quatro posições.

A compreensão equivale a começar uma lista vazia, percorrer a entrada e acrescentar os resultados aceites. A expressão compacta deve continuar legível. Se há vários estados, validações ou efeitos, um ciclo com nome para cada passo pode explicar melhor o algoritmo.

## Percursos aninhados

As cláusulas `for` seguem a mesma ordem dos ciclos correspondentes. Em `[(i, j) for i in range(2) for j in range(3)]`, o `i` fica fixo enquanto `j` percorre 0, 1 e 2. O resultado tem seis pares.

```python
matriz = [[1, 2], [3, 4]]
plana = [valor for linha in matriz for valor in linha]
print(plana)
```

A saída é `[1, 2, 3, 4]`. Este código remove um nível de listas, não qualquer profundidade. Para estruturas com profundidade variável, usa a decomposição recursiva da lição anterior.

Também podes criar conjuntos com `{x * x for x in valores}` e dicionários com `{nome: len(nome) for nome in nomes}`. Um conjunto elimina resultados repetidos. Num dicionário, uma chave repetida fica com o último valor produzido.

## Iteráveis e iteradores

Um **iterável** permite obter um percurso; listas e strings são exemplos. Um **iterador** conserva a posição de um percurso e produz o próximo valor com `next`. `iter(xs)` cria um iterador e `next(it)` avança-o. Quando esgota, lança `StopIteration`, que `for` trata para terminar.

Uma lista permite começar um novo percurso. Um iterador esgotado não volta ao início. Esta diferença explica o comportamento de `map`, `filter` e dos geradores.

## Geradores e yield

Uma expressão `(x * x for x in range(4))` cria um **gerador**. Produz valores quando são pedidos em vez de guardar logo uma lista. É um aprofundamento do modelo de iteração usado pelas compreensões.

<CodePlayground
  language="python"
  title="Consumir um gerador"
  input=""
  code={
    'quadrados = (x * x for x in range(4))\nprint(next(quadrados))\nprint(list(quadrados))\nprint(list(quadrados))\n\ndef contagem(n):\n    while n > 0:\n        yield n\n        n -= 1\n\nprint(list(contagem(3)))'
  }
/>

`next` retira o zero. A primeira conversão em lista consome 1, 4 e 9; a segunda recebe uma sequência já esgotada. Na função `contagem`, `yield` entrega um valor e suspende a execução. O próximo pedido retoma depois dessa instrução, conservando os nomes locais. Chamar `contagem(3)` cria o gerador; o corpo só começa no primeiro pedido. `return` termina o gerador, sem produzir mais valores.

## Escolher entre lista e gerador

Usa uma lista quando precisas de índices, de vários percursos ou de guardar os resultados. Um gerador permite consumir um valor de cada vez, o que pode reduzir memória. Não reduz necessariamente o trabalho total se acabares por consumir tudo.

`sum(x * x for x in range(100))` consome os valores sem precisar de uma lista intermédia. Se guardares o gerador e tentares somá-lo duas vezes, a segunda soma vale zero. Criar um novo gerador inicia um novo percurso. O custo da expressão que calcula cada valor continua a existir, mesmo quando a produção é adiada.
