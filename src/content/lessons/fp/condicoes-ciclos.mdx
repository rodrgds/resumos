Uma condição decide se uma instrução corre. Um ciclo decide quantas vezes ela corre. Para compreender ambos, segue o estado do programa, ou seja, os valores associados aos nomes em cada momento.

## Comparar e combinar condições

`==`, `!=`, `<`, `<=`, `>` e `>=` comparam valores. Para verificar se uma nota está entre 0 e 20, incluindo os extremos, podes escrever `0 <= nota <= 20`. Não uses `is` para comparar números ou texto: `is` pergunta se tens o mesmo objeto.

`not p` nega uma condição; `p and q` exige ambas; `p or q` exige pelo menos uma. A ordem de precedência é `not`, `and`, `or`, mas parênteses tornam a intenção explícita.

Python avalia `and` e `or` com **curto-circuito**. Em `divisor != 0 and total / divisor > 2`, a divisão só ocorre quando o divisor é diferente de zero. Estes operadores devolvem um dos operandos, não necessariamente `bool`: `"" or "sem nome"` vale `"sem nome"`. Nas condições iniciais, usa comparações que produzam `True` ou `False`.

## Escolher um ramo

Uma cadeia `if` / `elif` / `else` escolhe no máximo um ramo, o primeiro cuja condição é verdadeira. Dois `if` separados podem executar ambos. A indentação define o corpo; usa quatro espaços de forma consistente.

A entrada 10 passa a validação e escolhe o segundo ramo. O programa escreve `aprovado`. Com 21 escreve `inválida`; com 9 escreve `reprovado`. Testar 9, 10, 20 e 21 verifica as fronteiras, onde um `>` no lugar de `>=` costuma mudar o resultado.

## Ciclos for e a função range

`for` percorre os elementos de um iterável. `range(inicio, fim, passo)` produz inteiros até ao limite `fim`, que fica excluído. O passo não pode ser zero. `range(1, 5)` produz 1, 2, 3, 4; `range(5, 0, -2)` produz 5, 3, 1. Uma direção incompatível com os limites produz um percurso vazio.

Para somar os quadrados dos inteiros de 1 até `n`, inicializamos um **acumulador** com zero e acrescentamos um termo em cada iteração.

<CodePlayground
  language="python"
  title="Somar quadrados"
  input="4"
  code={
    'n = int(input())\nsoma = 0\nfor k in range(1, n + 1):\n    soma += k * k\nprint(soma)'
  }
/>

| `k` | `soma` antes | Termo acrescentado | `soma` depois |
| --- | ------------ | ------------------ | ------------- |
| 1   | 0            | 1                  | 1             |
| 2   | 1            | 4                  | 5             |
| 3   | 5            | 9                  | 14            |
| 4   | 14           | 16                 | 30            |

Depois de tratar `k`, a soma contém os quadrados de 1 até `k`. Esta propriedade é um **invariante** do ciclo e explica o resultado. Se `n` é zero, não há iterações e a soma vazia vale zero. Para um produto, o valor inicial costuma ser 1, porque multiplicar por zero destruiria o resultado.

## Ciclos while e terminação

`while` testa a condição antes de cada iteração. Pode executar zero vezes. Usa-o quando o fim depende dos dados ou de uma condição que muda durante o cálculo.

<CodePlayground
  language="python"
  title="Extrair e somar dígitos"
  input="3083"
  code={
    'n = int(input())\nsoma = 0\nwhile n > 0:\n    soma += n % 10\n    n //= 10\nprint(soma)'
  }
/>

`n % 10` extrai o último dígito. `n // 10` elimina-o. Para 3083, os dígitos tratados são 3, 8, 0, 3 e a soma vale 14. Como `n` é inteiro não negativo e diminui até zero, o ciclo termina. Sem a atualização de `n`, a condição continuaria verdadeira.

Este algoritmo assume entrada não negativa. Para aceitar inteiros negativos, usa `n = abs(n)` antes do ciclo. Para a entrada zero, a soma permanece zero, que é o resultado pretendido.

## Sentinelas, break, continue e else

Uma **sentinela** marca o fim dos dados e não deve ser tratada como uma entrada normal. Se zero termina uma sequência de medições positivas, testa-o antes de o acrescentar à soma.

`break` sai do ciclo mais interno. `continue` passa à próxima iteração; num `while`, confirma que não salta a atualização necessária à terminação. O `else` de um ciclo corre quando o percurso termina normalmente, sem `break`, mesmo que não tenha havido iterações.

```python
for divisor in range(2, 7):
    if 7 % divisor == 0:
        print("composto")
        break
else:
    print("primo")
```

O exemplo escreve `primo`, porque nenhum divisor interrompe o ciclo. O `else` está alinhado com `for`, não com `if`. Ao alterar 7, também tens de alterar o limite se pretenderes testar todos os divisores próprios; na lição de funções vamos separar esse cálculo da entrada.

## Escolher o percurso

Percorre valores diretamente quando só precisas deles. Usa índices quando precisas de uma posição, e `enumerate` quando precisas de ambos. Num ciclo aninhado, o corpo interior executa para cada valor do exterior. Se há três linhas e quatro colunas, visitas 12 pares, não sete.
