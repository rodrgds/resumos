## Comparar e combinar condições

Com `nota = 10`, a condição `nota >= 10` é verdadeira; com `nota = 9`, é falsa. Uma condição permite escolher instruções. Um ciclo repete-as e pode alterar o **estado**, os valores associados aos nomes, em cada iteração.

`==`, `!=`, `<`, `<=`, `>` e `>=` comparam valores. Para verificar se uma nota está entre 0 e 20, incluindo os extremos, podes escrever `0 <= nota <= 20`. Não uses `is` para comparar números ou texto: `is` pergunta se tens o mesmo objeto.

`not p` nega uma condição; `p and q` exige ambas; `p or q` exige pelo menos uma. A ordem de precedência é `not`, `and`, `or`, mas parênteses tornam a intenção explícita.

Numa condição, `False`, `None`, zero e coleções vazias contam como falso. Os restantes valores destes tipos contam como verdadeiro. Por exemplo, `if texto:` testa se uma string não está vazia; não testa se contém a palavra `"True"`.

Python avalia `and` e `or` com **curto-circuito**. Em `divisor != 0 and total / divisor > 2`, a divisão só ocorre quando o divisor é diferente de zero. Estes operadores devolvem um dos operandos, não necessariamente `bool`: `"" or "sem nome"` vale `"sem nome"`. Nas condições iniciais, usa comparações que produzam `True` ou `False`.

## Escolher um ramo

Uma cadeia `if` / `elif` / `else` escolhe no máximo um ramo, o primeiro cuja condição é verdadeira. Dois `if` separados podem executar ambos. A indentação define o corpo; usa quatro espaços de forma consistente.

## Ciclos for e a função range

`for` percorre os elementos de um **iterável**, que é um objeto que fornece valores um a um. `range(inicio, fim, passo)` fornece inteiros até ao limite `fim`, que fica excluído. `range(fim)` começa em zero; omitir o passo usa 1. O passo não pode ser zero. `range(1, 5)` produz 1, 2, 3, 4; `range(5, 0, -2)` produz 5, 3, 1. Uma direção incompatível com os limites produz um percurso vazio. Por exemplo, `range(5, 0)` não produz valores. `sum` soma os valores de um iterável.

Para somar os quadrados dos inteiros de 1 até `n`, inicializamos um **acumulador** com zero e acrescentamos um termo em cada iteração. Para estes números, `soma += k * k` abrevia `soma = soma + k * k`: calcula o novo total e volta a associá-lo a `soma`.

<CodePlayground
  language="python"
  title="Somar quadrados"
  input="4"
  code={
    'n = int(input())\nsoma = 0\nfor k in range(1, n + 1):\n    soma += k * k\nprint(soma)'
  }
/>

| `k` | `soma` antes | Termo acrescentado | `soma` depois |
| --- | ------------ | ------------------ | ------------- |
| 1   | 0            | 1                  | 1             |
| 2   | 1            | 4                  | 5             |
| 3   | 5            | 9                  | 14            |
| 4   | 14           | 16                 | 30            |

Depois de tratar `k`, a soma contém os quadrados de 1 até `k`. Esta propriedade é um **invariante** do ciclo e explica o resultado. Se `n` é zero, não há iterações e a soma vazia vale zero. Para um produto, o valor inicial costuma ser 1, porque multiplicar por zero destruiria o resultado.

## Ciclos while e terminação

`while` testa a condição antes de cada iteração. Pode executar zero vezes. Usa-o quando o fim depende dos dados ou de uma condição que muda durante o cálculo.

<CodePlayground
  language="python"
  title="Extrair e somar dígitos"
  input="3083"
  code={somaDigitos}
/>

`n % 10` extrai o último dígito e `n // 10` elimina-o, por isso `n //= 10` guarda esse quociente em `n`.

| `n` antes | Dígito `n % 10` | `soma` depois | `n` depois |
| --------- | --------------- | ------------- | ---------- |
| 3083      | 3               | 3             | 308        |
| 308       | 8               | 11            | 30         |
| 30        | 0               | 11            | 3          |
| 3         | 3               | 14            | 0          |

O dígito zero mantém a soma, mas não termina o ciclo: ainda resta o prefixo 3. A paragem depende de `n == 0`, depois de retirar todos os dígitos. Para `n > 0`, o quociente inteiro por 10 é menor que `n` e continua não negativo, por isso chega a zero. Sem a atualização de `n`, a condição continuaria verdadeira.

Este algoritmo assume entrada não negativa. Para aceitar inteiros negativos, usa `n = abs(n)` antes do ciclo. Para a entrada zero, a soma permanece zero, que é o resultado pretendido.

## Sentinelas, break, continue e else

Uma **sentinela** marca o fim dos dados e não deve ser tratada como uma entrada normal. Se zero termina uma sequência de medições positivas, testa-o antes de o acrescentar à soma.

```python
soma = 0
n = int(input())
while n != 0:
    if n > 0:
        soma += n
    n = int(input())
print(soma)
```

Com entradas `3`, `5` e `0`, a soma passa por 0, 3 e 8; o zero termina o ciclo sem ser somado. Sem a leitura nova no fim do corpo, o ciclo repetiria a primeira medição.

`break` sai do ciclo mais interno. `continue` passa à próxima iteração; num `while`, confirma que não salta a atualização necessária à terminação. O `else` de um ciclo corre quando o percurso termina sem `break`, mesmo que não tenha havido iterações.

```python
for divisor in range(2, 7):
    if 7 % divisor == 0:
        print("composto")
        break
else:
    print("primo")
```

O exemplo escreve `primo`, porque nenhum divisor interrompe o ciclo. O `else` está alinhado com `for`, não com `if`. Ao alterar 7, também tens de alterar o limite se pretenderes testar todos os divisores próprios; na lição de funções vamos separar esse cálculo da entrada.

## Escolher o percurso

Percorre valores diretamente quando só precisas deles. Usa índices quando precisas de uma posição, e `enumerate` quando precisas de ambos. Num ciclo aninhado, o corpo interior executa para cada valor do exterior.

```python
for linha in range(2):
    for coluna in range(3):
        print(linha, coluna)
```

Os pares visitados são `(0, 0)`, `(0, 1)`, `(0, 2)`, `(1, 0)`, `(1, 1)` e `(1, 2)`: seis, não cinco. Se há três linhas e quatro colunas, visitas 12 pares, não sete.
