Para procurar a nota de uma pessoa, um índice de lista não exprime diretamente a pergunta. Um dicionário associa uma chave, como o nome, a um valor, como a nota. Para saber quem participou numa atividade, um conjunto guarda pertença sem contar repetições.

## Dicionários, chaves e valores

`notas = {"Ana": 15, "Bruno": 12}` cria duas associações. `notas["Ana"]` vale 15. Atribuir novamente à mesma chave substitui o valor, não cria outra entrada. `del notas["Bruno"]` retira a associação.

Uma chave tem de ser **hashable**, ou seja, ter um código numérico, chamado **hash**, que não muda durante a sua vida. Objetos iguais têm de ter hashes iguais; objetos diferentes podem partilhar um hash. O dicionário usa esse código para encontrar candidatos e a igualdade para distinguir chaves.

Strings, inteiros e tuplos de elementos hashable servem. Listas, dicionários e conjuntos mutáveis não servem como chaves. Os valores não têm essa restrição.

`chave in d` verifica chaves, não valores. `d[chave]` lança `KeyError` se a chave não existir. `d.get(chave, padrao)` devolve o padrão sem criar a entrada. `d.keys()`, `d.values()` e `d.items()` permitem percorrer chaves, valores e pares. Os dicionários conservam ordem de inserção, mas não ordenam as chaves.

## Contar frequências

Queremos contar votos, incluindo nomes repetidos. Antes de ver um nome pela primeira vez, a frequência é zero. Cada ocorrência aumenta-a em um.

Depois de cada iteração, o dicionário conta todas as ocorrências já visitadas. Para os quatro votos, Ana fica com 3 e Bruno com 1. A lista vazia produz `{}`. A função não altera a lista recebida, embora construa e atualize um dicionário local.

Para ordenar a apresentação, percorre `sorted(contagem)`. A ordenação não é necessária para a contagem, só para escolher a ordem de saída.

## Dicionários com coleções como valores

Um dicionário pode agrupar vários valores por chave. Se cada cadeira tem uma lista de notas, `notas["FP"]` pode ser `[12, 16]`. Alterar essa lista muda o conteúdo alcançável pelo dicionário.

```python
notas = {"FP": [12, 16], "MD": [14]}
notas["FP"].append(18)
for cadeira, valores in notas.items():
    print(cadeira, sum(valores) / len(valores))
```

A saída é `FP 15.333333333333334` e `MD 14.0`. O cálculo exige listas não vazias; se permitires uma lista vazia, define primeiro o resultado nesse caso. Não acrescentes nem retires chaves durante uma iteração sobre o próprio dicionário.

## Conjuntos e pertença

`set` guarda elementos únicos e hashable. `set()` cria o conjunto vazio; `{}` cria um dicionário. Um conjunto não tem índices e a sua ordem de iteração não deve determinar a resposta do programa.

| Operação | Pergunta                               | Resultado no exemplo      |
| -------- | -------------------------------------- | ------------------------- |
| `A \| B` | Quem está em pelo menos uma atividade? | Ana, Bruno, Carla, Duarte |
| `A & B`  | Quem está em ambas?                    | Bruno                     |
| `A - B`  | Quem está em A e não em B?             | Ana, Carla                |
| `A ^ B`  | Quem está exatamente numa?             | Ana, Carla, Duarte        |

Usámos `sorted` para tornar a saída determinística. A diferença não é comutativa: `robotica - python` só contém Duarte. `A <= B` pergunta se A é subconjunto de B; `A < B` exige também que sejam diferentes. `add` acrescenta um elemento; `discard` retira-o se existir; `remove` falha se faltar. `frozenset` é a versão imutável e pode ser uma chave de dicionário.

## Escolher a estrutura

Uma lista conserva ordem e repetições. Um tuplo representa uma sequência cujo recipiente não queremos alterar. Um conjunto conserva unicidade. Um dicionário conserva associações e permite contar ou agrupar.

Converter uma lista em conjunto perde a multiplicidade. Se recebeste `['Ana', 'Ana', 'Bruno']`, o conjunto permite saber quem votou, mas não quantos votos houve.

Se o resultado exige a ordem original sem repetições, percorre a lista e usa um conjunto auxiliar para reconhecer os nomes já vistos, sem usar a ordem do conjunto como saída. Começa com uma lista de resultado e um conjunto vazios. Quando um nome ainda não está no conjunto, acrescenta-o às duas coleções; se já está, passa ao seguinte. Assim a lista conserva a primeira ocorrência de cada nome.
