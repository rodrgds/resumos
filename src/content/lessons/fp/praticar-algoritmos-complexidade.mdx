<Exercise
 id="binaria-condicao"
 title="Construir um contraexemplo à pesquisa binária"
 revision={2}
 explanation="/cadeiras/fp/algoritmos-complexidade/#pesquisa-linear-e-pesquisa-binária"
 answer={{kind: 'self', checklist: ['Segui os meios 1 e 2, com valores 1 e 8.', 'Obtive None apesar de 4 existir.', 'Justifiquei a pré-condição de ordenação.']}}
>

Aplica a função `binaria` da lição à lista `[4, 1, 8, 2]` para procurar 4.
Regista os intervalos visitados e o resultado. Usa esse percurso para explicar
por que não basta os valores serem distintos. Se ordenares a lista, a posição
devolvida ainda identifica a posição na entrada original?

<div slot="hint">Um valor maior que o meio pode estar à sua esquerda nesta lista.</div>
<div slot="solution">
No intervalo `[0, 3]`, o meio é 1 e contém 1. Como 4 é maior, a função conserva
`[2, 3]` e perde o índice 0, onde estava o alvo. O meio seguinte é 2 e contém 8;
a função passa para `[2, 1]`, um intervalo vazio, e devolve `None`.

A exclusão só é válida com a lista ordenada. A pesquisa linear encontra 4 no
índice 0. Ordenando, obtemos `[1, 2, 4, 8]` e encontramos 4 no índice 2, que é
uma posição da lista nova e não da entrada original.

</div>
</Exercise>

<Exercise
  id="binaria-passos"
  title="Seguir uma pesquisa sem resultado"
  revision={3}
  explanation="/cadeiras/fp/algoritmos-complexidade/#pesquisa-linear-e-pesquisa-binária"
  answer={{kind: 'self', checklist: ['Segui [0, 6], [0, 2] e [2, 2].', 'Terminei em [3, 2] e None.', 'Distingui 3 iterações de 6 comparações entre valores.']}}
>

Segue a função `binaria` da lição ao procurar 9 em `[2, 5, 8, 11, 14, 17, 20]`. Regista `inicio`, `fim`, `meio` e o valor do meio em cada iteração. Indica o resultado, o número de iterações e o número de comparações entre o alvo e um valor da lista. Conta cada `==` e cada `<` executado, sem contar a condição do `while`.

<div slot="hint">Numa iteração sem igualdade, a função também executa o teste `<`.</div>
<div slot="solution">

| Intervalo | Meio | Valor | Intervalo seguinte |
| --------- | ---- | ----- | ------------------ |
| `[0, 6]`  | 3    | 11    | `[0, 2]`           |
| `[0, 2]`  | 1    | 5     | `[2, 2]`           |
| `[2, 2]`  | 2    | 8     | `[3, 2]`           |

O último intervalo é vazio porque `inicio > fim`, por isso a função devolve `None`. Houve três iterações e seis comparações entre valores: em cada iteração, a igualdade falhou e foi preciso avaliar `<`. Definir a operação contada evita confundir iterações com comparações.

</div>
</Exercise>

<Exercise
  id="linear-primeira"
  title="Devolver a primeira posição"
  revision={1}
  explanation="/cadeiras/fp/algoritmos-complexidade/#pesquisa-linear-e-pesquisa-binária"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def primeira_posicao(valores, alvo):\n    return None',
    tests: [
      {
        name: 'Desordenada e com repetição',
        code: 'print(primeira_posicao([8, 3, 8, 1], 8))',
        output: '0',
      },
      {
        name: 'Repetição depois do início',
        code: 'print(primeira_posicao([2, 7, 7, 9], 7))',
        output: '1',
      },
      {
        name: 'Última posição',
        code: 'print(primeira_posicao([3, 1, 4], 4))',
        output: '2',
      },
      {
        name: 'Alvo ausente',
        code: 'print(primeira_posicao([2, 7], 5))',
        output: 'None',
      },
      {
        name: 'Lista vazia',
        code: 'print(primeira_posicao([], 1))',
        output: 'None',
      },
      {
        name: 'Entrada preservada',
        code: 'xs = [8, 3, 8, 1]\nprint(primeira_posicao(xs, 3))\nprint(xs)',
        output: '1\n[8, 3, 8, 1]',
      },
    ],
  }}
>
  <div>
    Define <code>{"primeira_posicao(valores, alvo)"}</code>: recebe uma lista, que pode estar
    desordenada, e devolve o índice da primeira ocorrência do alvo, ou <code>{"None"}</code> se
    faltar. Conserva a entrada. Justifica para ti por que podes parar quando
    encontras o primeiro igual.
  </div>
  <div slot="hint">
    Sem ordenação, não podes descartar metade por comparar com o meio.
  </div>
  <div slot="hint-more">
    <code>{"enumerate"}</code> fornece o índice e o valor. Devolve o índice no primeiro igual; só
    devolve <code>{"None"}</code> depois do percurso.
  </div>
  <div slot="solution">
    O percurso começa no índice zero e avança por ordem. Quando encontra o alvo,
    todas as posições anteriores já foram excluídas. No pior caso faz n
    comparações para uma lista de n elementos.

```python
def primeira_posicao(valores, alvo):
    for indice, valor in enumerate(valores):
        if valor == alvo:
            return indice
    return None
```

  </div>
  <div slot="mistakes">
    Ordenar a entrada e devolver o índice novo, usar zero para ausência ou
    continuar a procurar e devolver a última ocorrência.
  </div>
</Exercise>
