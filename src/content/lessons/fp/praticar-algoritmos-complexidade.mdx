<Exercise
  id="linear-primeira"
  title="Devolver a primeira posição"
  revision={1}
  explanation="/cadeiras/fp/algoritmos-complexidade/#pesquisa-linear-e-pesquisa-binária"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def primeira_posicao(valores, alvo):\n    return None',
    tests: [
      {
        name: 'Desordenada e com repetição',
        code: 'print(primeira_posicao([8, 3, 8, 1], 8))',
        output: '0',
      },
      {
        name: 'Repetição depois do início',
        code: 'print(primeira_posicao([2, 7, 7, 9], 7))',
        output: '1',
      },
      {
        name: 'Última posição',
        code: 'print(primeira_posicao([3, 1, 4], 4))',
        output: '2',
      },
      {
        name: 'Alvo ausente',
        code: 'print(primeira_posicao([2, 7], 5))',
        output: 'None',
      },
      {
        name: 'Lista vazia',
        code: 'print(primeira_posicao([], 1))',
        output: 'None',
      },
      {
        name: 'Entrada preservada',
        code: 'xs = [8, 3, 8, 1]\nprint(primeira_posicao(xs, 3))\nprint(xs)',
        output: '1\n[8, 3, 8, 1]',
      },
    ],
  }}
>
  <div>
    Define <code>{"primeira_posicao(valores, alvo)"}</code>: recebe uma lista, que pode estar
    desordenada, e devolve o índice da primeira ocorrência do alvo, ou <code>{"None"}</code> se
    faltar. Conserva a entrada. Justifica para ti por que podes parar quando
    encontras o primeiro igual.
  </div>
  <div slot="hint">
    Sem ordenação, não podes descartar metade por comparar com o meio.
  </div>
  <div slot="hint-more">
    <code>{"enumerate"}</code> fornece o índice e o valor. Devolve o índice no primeiro igual; só
    devolve <code>{"None"}</code> depois do percurso.
  </div>
  <div slot="solution">
    O percurso começa no índice zero e avança por ordem. Quando encontra o alvo,
    todas as posições anteriores já foram excluídas. No pior caso faz n
    comparações para uma lista de n elementos.

```python
def primeira_posicao(valores, alvo):
    for indice, valor in enumerate(valores):
        if valor == alvo:
            return indice
    return None
```

  </div>
  <div slot="mistakes">
    Ordenar a entrada e devolver o índice novo, usar zero para ausência ou
    continuar a procurar e devolver a última ocorrência.
  </div>
</Exercise>

<div slot="hint-more">
