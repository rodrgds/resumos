<Exercise
  id="somar-multiplos"
  title="Somar com limites inclusivos"
  revision={1}
  explanation="/cadeiras/fp/condicoes-ciclos/#ciclos-for-e-a-função-range"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'n = int(input())\ntotal = 0\nprint(total)',
    tests: [
      { name: 'Sem termos', code: '', output: '0', input: '0' },
      { name: 'Antes do primeiro múltiplo', code: '', output: '0', input: '2' },
      { name: 'Limite incluído', code: '', output: '3', input: '3' },
      { name: 'Vários termos', code: '', output: '18', input: '10' },
      { name: 'Outro limite incluído', code: '', output: '30', input: '12' },
    ],
  }}
>
  <p>
    Lê um inteiro n não negativo e escreve a soma dos múltiplos positivos de 3
    entre 1 e n, incluindo n se for múltiplo de 3. Para n = 10, somas 3 + 6 + 9
    = 18. Usa um ciclo para praticar o acumulador.
  </p>
  <div slot="hint">
    Começa a soma em zero. O último valor permitido é n.
  </div>
  <div slot="hint-more">
    Podes percorrer range(3, n + 1, 3), ou percorrer todos os inteiros e testar
    o resto.
  </div>
  <div slot="solution">
    O passo 3 visita só os múltiplos. O limite n + 1 permite incluir n. Quando n
    é menor que 3, o percurso é vazio e o total permanece zero.

```python
n = int(input())
total = 0
for valor in range(3, n + 1, 3):
    total += valor
print(total)
```

  </div>
  <div slot="mistakes">
    Excluir n com range(3, n, 3), imprimir dentro do ciclo ou esquecer a
    inicialização.
  </div>
</Exercise>
