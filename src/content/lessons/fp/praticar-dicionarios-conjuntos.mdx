<Exercise
  id="diferenca-conjuntos"
  title="Comparar grupos de inscrições"
  revision={2}
  explanation="/cadeiras/fp/dicionarios-conjuntos/#conjuntos-e-pertença"
  answer={{kind: 'self', checklist: ['Obtive {1, 2} e {4} nas diferenças.', 'Obtive {3} na interseção e {1, 2, 4} na diferença simétrica.', 'Expliquei a perda das repetições.']}}
>

Duas atividades têm conjuntos de inscritos `A = {1, 2, 3}` e `B = {3, 4}`. Calcula `A - B`, `B - A`, `A & B` e `A ^ B`, explicando que inscritos seleciona cada operação. Se a lista original de A fosse `[1, 1, 2, 3]`, conseguirias recuperar quantas inscrições fez a pessoa 1 a partir do conjunto?

<div slot="hint">Distingue estar nas duas atividades de estar exatamente numa.</div>
<div slot="solution">
`A - B` é `{1, 2}`, os inscritos apenas em A. `B - A` é `{4}`, os inscritos apenas em B, por isso a diferença tem direção. `A & B` é `{3}`, os inscritos em ambas. `A ^ B` é `{1, 2, 4}`, os inscritos exatamente numa.

A conversão de `[1, 1, 2, 3]` em conjunto elimina a segunda ocorrência de 1. O conjunto não permite recuperar essa contagem; uma lista ou um dicionário de frequências conserva a informação necessária.

</div>
</Exercise>

  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def sem_repetidos(nomes):\n    return []',
    tests: [
      {
        name: 'Ordem da primeira ocorrência',
        code: 'print(sem_repetidos(["Bruno", "Ana", "Bruno", "Carla", "Ana"]))',
        output: "['Bruno', 'Ana', 'Carla']",
      },
      { name: 'Lista vazia', code: 'print(sem_repetidos([]))', output: '[]' },
      {
        name: 'Uma string repetida',
        code: 'print(sem_repetidos(["FP", "FP", "FP"]))',
        output: "['FP']",
      },
      {
        name: 'Maiúsculas distinguem nomes',
        code: 'print(sem_repetidos(["Ana", "ana", "Ana"]))',
        output: "['Ana', 'ana']",
      },
      {
        name: 'Entrada preservada',
        code: 'nomes = ["B", "A", "B"]\nprint(sem_repetidos(nomes))\nprint(nomes)',
        output: "['B', 'A']\n['B', 'A', 'B']",
      },
    ],
  }}
>
  <div>
    Define <code>{"sem_repetidos(nomes)"}</code>: recebe uma lista de strings e devolve outra
    lista sem repetições, pela ordem da primeira ocorrência. Conserva a lista
    recebida. Maiúsculas e minúsculas distinguem nomes.
  </div>
  <div slot="hint">
    Precisas da ordem da lista e de reconhecer rapidamente o que já apareceu.
  </div>
  <div slot="hint-more">
    Mantém um conjunto de nomes vistos e uma lista de resultado. Acrescenta
    apenas quando o nome ainda falta no conjunto.
  </div>
  <div slot="solution">
    O conjunto decide se já vimos o nome. A lista regista a ordem em que cada
    nome apareceu pela primeira vez. Nenhuma operação altera nomes.

```python
def sem_repetidos(nomes):
    vistos = set()
    resultado = []
    for nome in nomes:
        if nome not in vistos:
            vistos.add(nome)
            resultado.append(nome)
    return resultado
```

  </div>
  <div slot="mistakes">
    Usar <code>{"sorted(set(nomes))"}</code>, que muda a ordem, ou retirar elementos da lista
    recebida durante o percurso.
  </div>
</Exercise>

<Exercise
  id="agrupar-por-chave"
  title="Agrupar valores por chave"
  revision={2}
  explanation="/cadeiras/fp/dicionarios-conjuntos/#dicionários-com-coleções-como-valores"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def agrupar(pares):\n    return {}',
    tests: [
      { name: 'Duas chaves', code: 'print(agrupar([("FP", 12), ("MD", 14), ("FP", 16)]))', output: "{'FP': [12, 16], 'MD': [14]}" },
      { name: 'Vazio', code: 'print(agrupar([]))', output: '{}' },
      { name: 'Listas distintas por chave e entrada intacta', code: 'pares = [("FP", 12), ("MD", 14), ("FP", 12)]\ngrupos = agrupar(pares)\ngrupos["FP"].append(18)\nprint(grupos)\nprint(pares)', output: "{'FP': [12, 12, 18], 'MD': [14]}\n[('FP', 12), ('MD', 14), ('FP', 12)]" },
    ],
  }}
>

  <div>
    Define <code>agrupar(pares)</code>: recebe uma lista de pares (chave, valor),
    com chaves hashable, e devolve um dicionário com uma lista própria de valores
    por chave, pela ordem de chegada. Não alteres a entrada. Com a lista vazia,
    devolve um dicionário vazio. Por exemplo, `[('FP', 12), ('MD', 14), ('FP', 16)]`
    produz `{'FP': [12, 16], 'MD': [14]}`.
  </div>
  <div slot="hint">
    Cria a lista na primeira ocorrência e acrescenta nas seguintes.
  </div>
  <div slot="hint-more">
    Testa com uma chave repetida não adjacente, como `("FP", 12)` e depois `("FP", 16)`: sem o teste `if chave not in grupos`, a segunda ocorrência substitui a lista em vez de acrescentar.
  </div>
  <div slot="solution">
    Para cada par, se a chave falta, cria `[valor]`; senão, acrescenta o valor à lista existente.

```python
def agrupar(pares):
    grupos = {}
    for chave, valor in pares:
        if chave not in grupos:
            grupos[chave] = []
        grupos[chave].append(valor)
    return grupos
```

  </div>
  <div slot="mistakes">
    Substituir a lista em vez de acrescentar (`grupos[chave] = [valor]` sempre); partilhar a mesma lista entre chaves com um valor por defeito mutável; alterar chaves durante a iteração do próprio dicionário.
  </div>

</Exercise>
