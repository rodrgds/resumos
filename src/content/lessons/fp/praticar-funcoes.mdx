<Exercise
  id="primo-programar"
  title="Devolver uma decisão"
  revision={1}
  explanation="/cadeiras/fp/funcoes/#contrato-e-decomposição"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def e_primo(n):\n    return False',
    tests: [
      {
        name: 'Não positivos',
        code: 'print(e_primo(-3), e_primo(0))',
        output: 'False False',
      },
      {
        name: 'Fronteira',
        code: 'print(e_primo(1), e_primo(2))',
        output: 'False True',
      },
      { name: 'Ímpar primo', code: 'print(e_primo(17))', output: 'True' },
      {
        name: 'Compostos pares e ímpares',
        code: 'print(e_primo(4), e_primo(9), e_primo(25))',
        output: 'False False False',
      },
    ],
  }}
>
  <div>
    Define <code>{"e_primo(n)"}</code>, que recebe um inteiro e devolve <code>{"True"}</code> exatamente quando n
    é primo. Inteiros menores que 2 não são primos. Não leias dados nem imprimas
    no corpo da função.
  </div>
  <div slot="hint">
    Trata primeiro os inteiros que ficam fora da definição de primo.
  </div>
  <div slot="hint-more">
    Para n &gt;= 2, procura um divisor de 2 até n - 1. Se encontrares um, já
    podes devolver <code>{"False"}</code>.
  </div>
  <div slot="solution">
    Um divisor encontrado basta para rejeitar o número. O <code>{"True"}</code> fica depois do
    ciclo, quando todos os divisores foram excluídos. Para 2, o ciclo vazio
    chega corretamente a <code>{"True"}</code>.

```python
def e_primo(n):
    if n < 2:
        return False
    for divisor in range(2, n):
        if n % divisor == 0:
            return False
    return True
```

  </div>
  <div slot="mistakes">
    Devolver <code>{"True"}</code> na primeira iteração sem divisor, testar só a paridade ou
    considerar 1 primo.
  </div>
</Exercise>

<Exercise

  title="Devolver em vez de imprimir"
  revision={1}
  explanation="/cadeiras/fp/funcoes/#return-e-print"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def saudar(nome):\n    return ""',
    tests: [
      { name: 'Devolve texto', code: 'print(saudar("Ana"))', output: 'Olá, Ana' },
      { name: 'Reutiliza', code: 'print(saudar("Ana") + "!")', output: 'Olá, Ana!' },
    ],
  }}
>

  <div>
    Define <code>saudar(nome)</code> para devolver o texto, sem imprimir dentro da função.
  </div>
  <div slot="hint">
    `print` escreve; `return` entrega o valor ao chamador.
  </div>
  <div slot="hint-more">
    O teste `saudar("Ana") + "!"` só passa se a função devolver texto: com `print` dentro e sem `return`, o resultado é `None` e a concatenação falha com `TypeError`.
  </div>
  <div slot="solution">
    Devolve `"Olá, " + nome` e imprime apenas fora da função. Uma função que imprime devolve `None`.

```python
def saudar(nome):
    return "Olá, " + nome
```

  </div>
  <div slot="mistakes">
    Usar `print` em vez de `return` e devolver `None`; incluir a exclamação dentro da função quando o contrato pede só a saudação.
  </div>

</Exercise>
