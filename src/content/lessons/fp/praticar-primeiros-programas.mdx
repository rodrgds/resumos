<Exercise
  id="duracao-programar"
  title="Converter minutos"
  revision={2}
  explanation="/cadeiras/fp/primeiros-programas/#segundos-em-horas-minutos-e-segundos"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'total = int(input())\nprint(0, 0, 0)',
    tests: [
      { name: 'Zero', code: '', output: '0 0 0', input: '0' },
      { name: 'Menos de uma hora', code: '', output: '0 0 59', input: '59' },
      { name: 'Uma hora', code: '', output: '0 1 0', input: '60' },
      { name: 'Fim de um dia', code: '', output: '0 23 59', input: '1439' },
      { name: 'Um dia completo', code: '', output: '1 0 0', input: '1440' },
      { name: 'Dias, horas e minutos', code: '', output: '2 1 1', input: '2941' },
    ],
  }}
>
  <div>
    Escreve um programa que lê uma linha com minutos inteiros não negativos e
    escreve dias, horas e minutos, separados por espaços. As horas vão de 0 a 23
    e os minutos de 0 a 59. Não precisas de definir funções.
  </div>
  <div slot="hint">
    Usa // e % para retirar unidades completas e conservar o resto.
  </div>
  <div slot="hint-more">
    Depois de <code>{"total // 1440"}</code>, usa <code>{"total % 1440"}</code> para calcular horas e minutos.
  </div>
  <div slot="solution">
    Cada dia retira 1440 minutos. As horas são calculadas sobre o resto, não
    sobre o total. Para 2941, 2 × 1440 + 1 × 60 + 1 = 2941.

```python
total = int(input())
dias = total // 1440
resto = total % 1440
horas = resto // 60
minutos = resto % 60
print(dias, horas, minutos)
```

  </div>
  <div slot="mistakes">
    Usar / para unidades completas, deixar as horas ultrapassar 23 ou
    acrescentar mensagens à saída.
  </div>
</Exercise>

>

<div>
  Antes de correres, escreve numa folha o valor e o tipo de cada expressão: `12
  + 3`, `"12" + "3"`, `3661 // 3600` e `3661 % 3600`. Só depois confirma com
  `print` e `type()`.
</div>
<div slot="hint">
  `12` é um inteiro e `"12"` é texto. O operador `+` faz coisas diferentes em
  cada tipo.
</div>
<div slot="hint-more">
  `//` dá o quociente inteiro e `%` dá o resto. Em `3661 // 3600`, pergunta
  quantas horas completas cabem em 3661 segundos; em `3661 % 3600`, o que sobra.
</div>
<div slot="solution">
  `12 + 3` vale 15 (`int`); `"12" + "3"` vale `"123"` (`str`, concatenação);
  `3661 // 3600` vale 1 e `3661 % 3600` vale 61 (ambos `int`). Confirmas com
  `type(12 + 3)` e `type(3661 // 3600)`.
</div>
<div slot="mistakes">
  Ler `"12"` como número e prever 15; esperar `3.5` de uma divisão com `//`;
  confundir o resto com o quociente em `3661 % 3600`.
</div>

</Exercise>
