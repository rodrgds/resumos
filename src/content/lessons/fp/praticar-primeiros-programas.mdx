<Exercise
  id="duracao-programar"
  title="Converter minutos"
  revision={2}
  explanation="/cadeiras/fp/primeiros-programas/#segundos-em-horas-minutos-e-segundos"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'total = int(input())\nprint(0, 0, 0)',
    tests: [
      { name: 'Zero', code: '', output: '0 0 0', input: '0' },
      { name: 'Menos de uma hora', code: '', output: '0 0 59', input: '59' },
      { name: 'Uma hora', code: '', output: '0 1 0', input: '60' },
      { name: 'Fim de um dia', code: '', output: '0 23 59', input: '1439' },
      { name: 'Um dia completo', code: '', output: '1 0 0', input: '1440' },
      { name: 'Dias, horas e minutos', code: '', output: '2 1 1', input: '2941' },
    ],
  }}
>
  <div>
    Escreve um programa que lê uma linha com minutos inteiros não negativos e
    escreve dias, horas e minutos, separados por espaços. As horas vão de 0 a 23
    e os minutos de 0 a 59. Não precisas de definir funções.
  </div>
  <div slot="hint">
    Usa // e % para retirar unidades completas e conservar o resto.
  </div>
  <div slot="hint-more">
    Depois de total // 1440, usa total % 1440 para calcular horas e minutos.
  </div>
  <div slot="solution">
    Cada dia retira 1440 minutos. As horas são calculadas sobre o resto, não
    sobre o total. Para 2941, 2 × 1440 + 1 × 60 + 1 = 2941.

```python
total = int(input())
dias = total // 1440
resto = total % 1440
horas = resto // 60
minutos = resto % 60
print(dias, horas, minutos)
```

  </div>
  <div slot="mistakes">
    Usar / para unidades completas, deixar as horas ultrapassar 23 ou
    acrescentar mensagens à saída.
  </div>
</Exercise>
