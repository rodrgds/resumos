<Exercise
  id="recursao-progresso"
  title="Escolher uma redução"
  revision={1}
  explanation="/cadeiras/fp/recursao/#justificar-que-termina"
  answer={{
    kind: 'choice',
    options: [
      { text: 'f(n)', correct: false, explanation: 'Não faz progresso.' },
      {
        text: 'f(n + 1)',
        correct: false,
        explanation: 'Aumenta a distância ao caso base.',
      },
      {
        text: 'f(n - 1)',
        correct: true,
        explanation: 'Reduz n em uma unidade até zero.',
      },
    ],
  }}
>
  <p>
    {
      'Para uma entrada inteira n > 0 e caso base n == 0, qual chamada se aproxima do caso base?'
    }
  </p>
  <div slot="hint">
    {'A quantidade que mede o problema deve diminuir sem sair do domínio.'}
  </div>
  <div slot="hint-more">
    {
      'Retirar uma unidade de um inteiro positivo mantém um inteiro não negativo.'
    }
  </div>
  <div slot="solution">
    {
      'f(n - 1) aproxima-se de zero. f(n) não muda o problema, e f(n + 1) afasta-se.'
    }
  </div>
  <div slot="mistakes">
    {'Ter um caso base correto sem verificar o passo recursivo.'}
  </div>
</Exercise>

<Exercise
  id="recursao-digitos"
  title="Somar por decomposição"
  revision={1}
  explanation="/cadeiras/fp/recursao/#recursão-sobre-dígitos"
  answer={{ kind: 'number', value: 17, tolerance: 0 }}
>
  <p>{'Qual é o resultado da soma recursiva dos dígitos de 9008?'}</p>
  <div slot="hint">{'A primeira chamada retira o último dígito, 8.'}</div>
  <div slot="hint-more">{'As restantes contribuições são 0, 0 e 9.'}</div>
  <div slot="solution">
    {
      '8 + 0 + 0 + 9 = 17. Os zeros interiores não são o caso base; o caso base é o prefixo inteiro zero.'
    }
  </div>
  <div slot="mistakes">
    {'Parar no primeiro dígito zero em vez de continuar com o prefixo.'}
  </div>
</Exercise>

<Exercise
  id="recursao-aninhada"
  title="Resolver uma estrutura aninhada"
  revision={1}
  explanation="/cadeiras/fp/recursao/#estruturas-aninhadas"
  answer={{
    kind: 'self',
    checklist: [
      'Obtive 10 e 0 nos testes.',
      'Tratei listas com qualquer profundidade finita.',
      'Devolvi o resultado de cada chamada.',
    ],
  }}
>
  <p>
    {
      'Completa uma soma recursiva para [1, [2, [3]], [], 4] e para []. Esperas 10 e 0. O domínio contém apenas números e listas finitas sem ciclos.'
    }
  </p>
  <div slot="work">
    <CodePlayground
      language="python"
      title="Resolver uma estrutura aninhada"
      input=""
      code={
        'def soma_aninhada(xs):\n    return None\n\nprint(soma_aninhada([1, [2, [3]], [], 4]))\nprint(soma_aninhada([]))'
      }
    />
  </div>
  <div slot="hint">
    {'Se o elemento é uma lista, o subproblema tem a mesma estrutura.'}
  </div>
  <div slot="hint-more">
    {'Soma o resultado da chamada interior ao acumulador da chamada atual.'}
  </div>
  <div slot="solution">
    {
      'A soma exterior junta 1, a soma interior 5, a soma vazia 0 e 4, produzindo 10. Cada lista vazia devolve zero.'
    }
    <pre>
      <code>
        {
          'def soma_aninhada(xs):\n    total = 0\n    for x in xs:\n        total += soma_aninhada(x) if isinstance(x, list) else x\n    return total\n\nprint(soma_aninhada([1, [2, [3]], [], 4]))\nprint(soma_aninhada([]))'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    {'Assumir apenas um nível interior ou não devolver o acumulador.'}
  </div>
</Exercise>
