  answer={{

    tests: [
      {
        name: 'Vários níveis e lista vazia interior',
        code: 'print(soma_aninhada([1, [2, [3]], [], 4]))',
        output: '10',
      },
      { name: 'Lista vazia', code: 'print(soma_aninhada([]))', output: '0' },
      {
        name: 'Só listas vazias',
        code: 'print(soma_aninhada([[], [[], []]]))',
        output: '0',
      },
      {
        name: 'Negativos e decimais',
        code: 'print(soma_aninhada([-2, [1.5, [0.5]], 4]))',
        output: '4.0',
      },
      {
        name: 'Entrada preservada',
        code: 'xs = [1, [2, [3]], 4]\nprint(soma_aninhada(xs))\nprint(xs)',
        output: '10\n[1, [2, [3]], 4]',
      },
    ],
  }}
>
  <div>
    Define soma_aninhada(xs): devolve a soma de todos os números nas listas,
    mesmo dentro de outras listas. O domínio contém apenas números e listas
    finitas sem referências cíclicas. Conserva a entrada. Pratica a decomposição
    recursiva; os testes verificam o resultado e a preservação dos dados.
  </div>
  <div slot="hint">
    Um número contribui diretamente. Uma lista coloca o mesmo problema num nível
    interior.
  </div>
  <div slot="hint-more">
    Percorre os elementos. Se isinstance(x, list), soma o resultado de
    soma_aninhada(x); caso contrário, soma x.
  </div>
  <div slot="solution">
    Cada lista vazia devolve zero. Na primeira entrada, a chamada exterior junta
    1, a soma interior 5, a soma vazia 0 e 4, produzindo 10. Cada chamada tem o
    seu acumulador.

```python
def soma_aninhada(xs):
    total = 0
    for x in xs:
        if isinstance(x, list):
            total += soma_aninhada(x)
        else:
            total += x
    return total
```

  </div>
  <div slot="mistakes">
    Tratar apenas um nível, devolver antes de acabar o percurso ou retirar
    elementos da entrada.
  </div>
</Exercise>
