<Exercise
  id="texto-transformacao"
  title="Filtrar e normalizar"
  revision={1}
  explanation="/cadeiras/fp/strings/#construir-uma-transformação"
  answer={{
    kind: 'self',
    checklist: [
      'A saída de A3٢B5 é 35.',
      'A entrada sem dígitos produz string vazia.',
      'Conservei a ordem e restringi a ASCII.',
    ],
  }}
>
  <p>
    {
      'Escreve uma função que conserva apenas dígitos ASCII, na ordem original. Para "A3٢B5" deve devolver "35", e para "abc", "".'
    }
  </p>
  <div slot="work">
    <CodePlayground
      language="python"
      title="Filtrar e normalizar"
      input=""
      code={
        'def digitos_ascii(texto):\n    return None\n\nprint(digitos_ascii("A3٢B5"))\nprint(repr(digitos_ascii("abc")))'
      }
    />
  </div>
  <div slot="hint">{'O carácter ٢ é um dígito Unicode, mas não ASCII.'}</div>
  <div slot="hint-more">
    {'Uma comparação com "0" e "9" permite restringir o domínio.'}
  </div>
  <div slot="solution">
    {
      'Percorre o texto e conserva os caracteres que satisfazem "0" <= c <= "9". isdigit sozinho também aceita ٢ e não cumpre este contrato.'
    }
    <pre>
      <code>
        {
          'def digitos_ascii(texto):\n    return "".join(c for c in texto if "0" <= c <= "9")\n\nprint(digitos_ascii("A3٢B5"))\nprint(repr(digitos_ascii("abc")))'
        }
      </code>
    </pre>
  </div>
  <div slot="mistakes">
    {'Trocar o contrato por todos os dígitos Unicode sem notar a diferença.'}
  </div>
</Exercise>
