<Exercise
  id="texto-transformacao"
  title="Conservar só dígitos ASCII"
  revision={2}
  explanation="/cadeiras/fp/strings/#construir-uma-transformação"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def digitos_ascii(texto):\n    return ""',
    tests: [
      {
        name: 'Distinguir Unicode de ASCII',
        code: 'print(repr(digitos_ascii("A3٢B5")))',
        output: "'35'",
      },
      {
        name: 'Sem dígitos',
        code: 'print(repr(digitos_ascii("abc")))',
        output: "''",
      },
      {
        name: 'Texto vazio',
        code: 'print(repr(digitos_ascii("")))',
        output: "''",
      },
      {
        name: 'Ordem, extremos e repetições',
        code: 'print(repr(digitos_ascii("90-1 009")))',
        output: "'901009'",
      },
    ],
  }}
>
  <div>
    Define <code>{"digitos_ascii(texto)"}</code>: devolve uma string com apenas os dígitos de "0"
    até "9", pela ordem original. Para "A3٢B5", devolve "35". O carácter ٢ é um
    dígito Unicode, mas não pertence ao intervalo ASCII pedido.
  </div>
  <div slot="hint">
    Decide para cada carácter se pertence ao resultado.
  </div>
  <div slot="hint-more">
    A condição "0" &lt;= caractere &lt;= "9" aceita só os dez dígitos pedidos.
  </div>
  <div slot="solution">
    A string começa vazia. Cada carácter aceite é acrescentado no fim,
    conservando a ordem e as repetições. <code>{"isdigit()"}</code> sozinho também aceita ٢. Nos
    testes, repr mostra as aspas para tornar a string vazia visível.

```python
def digitos_ascii(texto):
    resultado = ""
    for caractere in texto:
        if "0" <= caractere <= "9":
            resultado += caractere
    return resultado
```

  </div>
  <div slot="mistakes">
    Aceitar todos os dígitos Unicode, ordenar os caracteres ou eliminar
    repetições.
  </div>
</Exercise>

<Exercise
  id="fatia-limites"
  title="Explicar os limites"
  revision={1}
  explanation="/cadeiras/fp/strings/#fatias"
  answer={{ kind: 'self', checklist: ['Indiquei início incluído e fim excluído.', 'Expliquei s[4:] e s[:100].', 'Distingui fatia de índice.'] }}
>

Com `s = "programar"`, explica `s[0:4]`, `s[4:]` e `s[:100]`, e porque `s[9]` falha.

<div slot="hint">A fatia inclui o início e exclui o fim.</div>
<div slot="hint-more">
  Conta os caracteres de `"programar"`: `s[0]` é `p` e `s[3]` é `g`, por isso
  `s[0:4]` termina em `g`. Para `s[9]`, compara 9 com `len(s) - 1`.
</div>
<div slot="solution">
  `s[0:4]` vale `"prog"`; `s[4:]` vale `"ramar"`; `s[:100]` devolve a string
  inteira porque a fatia tolera limites. `s[9]` falha porque o último índice é
  8.
</div>
<div slot="mistakes">
  Incluir o carácter do fim na fatia; esperar `IndexError` em `s[:100]` como na
  indexação; usar `s[len(s)]` como último carácter válido.
</div>

</Exercise>
