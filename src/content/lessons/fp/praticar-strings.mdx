<Exercise
  id="nome-formal"
  title="Transformar um nome completo"
  explanation="/cadeiras/fp/strings/#texto-é-imutável"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def nome_formal(nome):\n    return ""',
    tests: [
      { name: 'Vários nomes', code: 'print(nome_formal("Ana Maria Silva"))', output: 'Silva, A. M.' },
      { name: 'Espaços nas pontas e entre nomes', code: 'print(nome_formal("  Bruno   Costa  "))', output: 'Costa, B.' },
      { name: 'Unicode e dois nomes', code: 'print(nome_formal("Álvaro Sá"))', output: 'Sá, Á.' },
    ],
  }}
>

Define `nome_formal(nome)`: recebe uma string com pelo menos dois nomes separados
por espaços e devolve o último nome, uma vírgula e as iniciais dos anteriores.
Cada inicial é o primeiro carácter do respetivo nome, seguido de ponto; separa
as iniciais com um espaço. Conserva as maiúsculas e minúsculas recebidas.
Ignora espaços adicionais. Não há partículas com tratamento especial.
Por exemplo, `"Ana Maria Silva"` deve produzir `"Silva, A. M."`.

<div slot="hint">Separa o texto com `split()` e distingue o último campo dos anteriores.</div>
<div slot="solution">
`split()` agrupa espaços consecutivos. `partes[-1]` é o último nome e
`partes[:-1]` contém os nomes que fornecem iniciais. Como há pelo menos dois
nomes, cada um destes campos existe e não está vazio.

```python
def nome_formal(nome):
    partes = nome.split()
    iniciais = []
    for parte in partes[:-1]:
        iniciais.append(parte[0] + ".")
    return partes[-1] + ", " + " ".join(iniciais)
```

Para Ana Maria Silva, as iniciais são `["A.", "M."]`, que `join` reúne em
`"A. M."`. O último nome conserva-se inteiro. A função constrói texto novo;
não altera a string recebida.

</div>
</Exercise>

<Exercise
  id="texto-transformacao"
  title="Conservar só dígitos ASCII"
  revision={2}
  explanation="/cadeiras/fp/strings/#construir-uma-transformação"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def digitos_ascii(texto):\n    return ""',
    tests: [
      {
        name: 'Distinguir Unicode de ASCII',
        code: 'print(repr(digitos_ascii("A3٢B5")))',
        output: "'35'",
      },
      {
        name: 'Sem dígitos',
        code: 'print(repr(digitos_ascii("abc")))',
        output: "''",
      },
      {
        name: 'Texto vazio',
        code: 'print(repr(digitos_ascii("")))',
        output: "''",
      },
      {
        name: 'Ordem, extremos e repetições',
        code: 'print(repr(digitos_ascii("90-1 009")))',
        output: "'901009'",
      },
    ],
  }}
>
  <div>
    Define <code>{"digitos_ascii(texto)"}</code>: devolve uma string com apenas os dígitos de "0"
    até "9", pela ordem original. Para "A3٢B5", devolve "35". O carácter ٢ é um
    dígito Unicode, mas não pertence ao intervalo ASCII pedido.
  </div>
  <div slot="hint">
    Decide para cada carácter se pertence ao resultado.
  </div>
  <div slot="hint-more">
    A condição "0" &lt;= caractere &lt;= "9" aceita só os dez dígitos pedidos.
  </div>
  <div slot="solution">
    A string começa vazia. Cada carácter aceite é acrescentado no fim,
    conservando a ordem e as repetições. <code>{"isdigit()"}</code> sozinho também aceita ٢. Nos
    testes, repr mostra as aspas para tornar a string vazia visível.

```python
def digitos_ascii(texto):
    resultado = ""
    for caractere in texto:
        if "0" <= caractere <= "9":
            resultado += caractere
    return resultado
```

  </div>
  <div slot="mistakes">
    Aceitar todos os dígitos Unicode, ordenar os caracteres ou eliminar
    repetições.
  </div>
</Exercise>
