<Exercise
  id="matriz-linhas"
  title="Evitar linhas partilhadas"
  revision={2}
  explanation="/cadeiras/fp/tuplos-listas/#listas-de-listas-e-cópia-superficial"
  answer={{
    kind: 'code',
    language: 'python',
    starter: 'def zeros(linhas, colunas):\n    return [[0] * colunas] * linhas',
    tests: [
      {
        name: 'Alterar só a primeira linha',
        code: 'm = zeros(3, 2)\nm[0][0] = 5\nprint(m)',
        output: '[[5, 0], [0, 0], [0, 0]]',
      },
      { name: 'Sem linhas', code: 'print(zeros(0, 3))', output: '[]' },
      { name: 'Sem colunas', code: 'print(zeros(2, 0))', output: '[[], []]' },
      {
        name: 'Linhas vazias independentes',
        code: 'm = zeros(2, 0)\nm[0].append(5)\nprint(m)',
        output: '[[5], []]',
      },
      { name: 'Uma célula', code: 'print(zeros(1, 1))', output: '[[0]]' },
    ],
  }}
>
  <div>
    Corrige <code>{"zeros(linhas, colunas)"}</code> para devolver uma matriz de zeros com linhas
    independentes. As dimensões são inteiros não negativos; não imprimas.
  </div>
  <div slot="hint">
    A repetição exterior repete referências à mesma linha, não a copia.
  </div>
  <div slot="hint-more">
    Cria uma lista nova em cada iteração, mesmo quando há zero colunas.
  </div>
  <div slot="solution">

```python
def zeros(linhas, colunas):
    matriz = []
    for i in range(linhas):
        matriz.append([0] * colunas)
    return matriz
```

    Cada iteração cria outra linha. Com zero linhas, obténs <code>{"[]"}</code>; com duas linhas
    e zero colunas, obténs duas listas vazias distintas. Alterar uma delas não
    afeta a outra.

  </div>
  <div slot="mistakes">
    Repetir a mesma lista interior, copiar só a lista exterior ou usar <code>{"print"}</code> em
    vez de <code>{"return"}</code>.
  </div>
</Exercise>

<Exercise
  id="alias-previsao"
  title="Prever alias e cópia"
  revision={1}
  explanation="/cadeiras/fp/tuplos-listas/#alias-contra-cópia-igualdade-contra-identidade"
  answer={{
    kind: 'self',
    checklist: [
      'Previ [1, 2, 3] para a com alias antes de correr.',
      'Previ a intacta [1, 2] e b [1, 2, 3] com cópia.',
      'Confirmei a partilha com is: True no alias, False na cópia.',
    ],
  }}
>

<div>
  Antes de correres, prevê o conteúdo de `a` e `b` nestes dois programas: com `b
  = a` seguido de `b.append(3)`, e com `b = a.copy()` seguido de `b.append(3)`,
  partindo de `a = [1, 2]`. Depois corre e compara.
</div>
<div slot="hint">
  `b = a` cria outro nome para o mesmo objeto; `a.copy()` cria outro recipiente
  com os mesmos elementos.
</div>
<div slot="hint-more">
  Depois de cada programa, avalia `b is a`: `True` confirma partilha, `False`
  confirma objetos distintos. O `append` altera o objeto, não o nome.
</div>
<div slot="solution">
  Com alias, `a` passa a `[1, 2, 3]` e `b is a` vale `True`. Com cópia, `a` fica
  `[1, 2]`, `b` fica `[1, 2, 3]` e `b is a` vale `False`. Conteúdos iguais
  (`==`) não implicam o mesmo objeto (`is`).
</div>
<div slot="mistakes">
  Esperar que `b = a` congele o conteúdo; esperar que a cópia partilhe a lista
  exterior; usar `==` para verificar partilha em vez de `is`.
</div>

</Exercise>
