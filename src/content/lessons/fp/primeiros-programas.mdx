## Instruções e valores

Em `print("Olá")`, o texto entre aspas é uma **string** e `print` mostra-o no ecrã:

```python
print("Olá")
```

A saída é `Olá`. Um programa executa instruções; este só apresenta texto. Para converter uma duração, vamos receber um número inteiro de segundos e calcular horas, minutos e segundos. Com a entrada `3661`, queremos obter `1 1 1`.

## Decompor o problema

Um **algoritmo** descreve passos precisos para resolver uma classe de problemas. Uma hora tem 3600 segundos, por isso em 3661 cabe uma hora completa e sobram 61 segundos. Nesse resto cabe um minuto completo e sobra um segundo. A mesma divisão com resto funciona para qualquer duração inteira não negativa, incluindo zero.

Decompor é separar o problema em partes. Aqui, cada contagem usa a mesma divisão com resto. Abstrair é conservar só os dados que interessam ao cálculo: para converter a duração, não precisas de saber quem a mediu.

## Valores, tipos e variáveis

Uma expressão calcula um valor. `3661 // 3600` calcula o número de horas completas. Os dois operandos são inteiros, do tipo `int`; o resultado também é inteiro. O **tipo** determina as operações que um valor suporta.

| Tipo    | Valores          | Operação típica                   |
| ------- | ---------------- | --------------------------------- |
| `int`   | `0`, `12`, `-3`  | Contar unidades inteiras          |
| `float` | `2.5`, `-0.25`   | Calcular uma aproximação numérica |
| `str`   | `"FEUP"`, `"12"` | Manipular texto                   |
| `bool`  | `True`, `False`  | Representar uma condição          |

`12` e `"12"` têm tipos diferentes. `12 + 3` vale `15`; `"12" + "3"` vale `"123"`, porque `+` concatena texto. `type(valor)` permite inspecionar o tipo. `None` representa a ausência de um resultado útil; não é o número zero nem a string vazia.

A atribuição `total = 3661` associa o nome `total` ao objeto inteiro `3661`. Python calcula primeiro o lado direito e só depois altera a associação do lado esquerdo. Em `total = total + 1`, lê o valor antigo, soma 1 e guarda 3662. Isto não é uma equação matemática. `=` atribui; `==` compara.

Os nomes distinguem maiúsculas de minúsculas. `total` e `Total` são nomes diferentes. `True`, `False` e `None` têm maiúscula inicial. `true` pode ser um nome, mas lê-lo sem definição causa `NameError`.

## Operadores e precedência

| Expressão  | Resultado | Significado                      |
| ---------- | --------- | -------------------------------- |
| `7 / 2`    | `3.5`     | Divisão                          |
| `7 // 2`   | `3`       | Quociente arredondado para baixo |
| `7 % 2`    | `1`       | Resto                            |
| `2 ** 3`   | `8`       | Potência                         |
| `"FP" * 2` | `"FPFP"`  | Repetição de texto               |

Para inteiros e divisor não nulo, `a == (a // b) * b + a % b`. Com negativos, arredondar para baixo não é cortar as casas decimais: `-7 // 2` vale `-4` e `-7 % 2` vale `1`.

A potência precede multiplicação e divisão, que precedem adição e subtração. Usa parênteses para exprimir a intenção: `(2 + 3) * 4` vale 20, enquanto `2 + 3 * 4` vale 14.

:::details[Ver pormenores de potência e negativos]
Há pormenores que a regra escolar não cobre: `-2 ** 2` vale `-4`, mas `(-2) ** 2` vale `4`; `2 ** 3 ** 2` vale `512`, porque a potência associa à direita.
:::

Números `float` são aproximações binárias. `0.1 + 0.2` produz
`0.30000000000000004`, por isso `0.1 + 0.2 == 0.3` dá `False`. Estas frações
decimais não têm representação binária finita. Para resultados de medição,
decide a tolerância ou o arredondamento pedido. Mostrar o resultado com duas
casas decimais produz `0.30`, mas não altera o valor calculado. A lição de
ficheiros e testes apresenta `math.isclose` para comparar aproximações.

## Entrada e saída

`input()` lê uma linha e devolve uma string, sem a mudança de linha final. `int(input())` converte essa string num inteiro. `float("3.5")` usa ponto decimal; `float("3,5")` falha. Por agora, o programa seguinte assume entrada válida.

Os parênteses fazem uma **chamada**: pedem a uma função que execute uma operação. Em `int(input())`, a chamada interior lê primeiro o texto; a exterior converte esse resultado. Uma instrução por linha permite seguir a ordem do programa de cima para baixo. O texto depois de `#` é um comentário, que Python ignora.

`print(a, b)` escreve dois valores separados por um espaço. Uma f-string começa com `f` antes das aspas e coloca expressões entre chavetas. Se `media = 12.5`, `f"{media:.2f}"` produz `"12.50"`, com duas casas decimais. A saída pedida por um exercício faz parte do contrato, por isso não acrescentes mensagens a um programa que só deve escrever números.

## Segundos em horas, minutos e segundos

    'total = int(input())\nhoras = total // 3600\nresto = total % 3600\nminutos = resto // 60\nsegundos = resto % 60\nprint(horas, minutos, segundos)'
  }

O contrato exige segundos inteiros não negativos. As horas podem ultrapassar 23, pois medimos uma duração, não a hora do dia. Os minutos e segundos ficam entre 0 e 59. Com 3661, o programa calcula por passos:

| Passo             | Cálculo        | Resultado |
| ----------------- | -------------- | --------- |
| Horas completas   | `3661 // 3600` | 1         |
| Resto após horas  | `3661 % 3600`  | 61        |
| Minutos completos | `61 // 60`     | 1         |
| Segundos          | `61 % 60`      | 1         |

A saída é `1 1 1`. Confirma no sentido inverso: $1\times3600+1\times60+1=3661$. Para 59, esperas `0 0 59`; para 3600, `1 0 0`; para 0, `0 0 0`. Reserva a comparação global com a entrada para depois de cada passo bater certo num caso pequeno.

## Sintaxe, execução e lógica

Um erro de **sintaxe** impede o interpretador de compreender o programa, como esquecer os dois pontos depois de `if`. Um erro de **execução** surge ao executar uma operação, como converter `"Ana"` com `int`. Um erro de **lógica** produz um resultado diferente do pedido, como usar `/` no cálculo de horas completas.

Lê a última linha da mensagem de erro para identificar o tipo, depois a linha indicada. Para um resultado errado, acompanha os valores das variáveis após cada instrução. Escolhe um caso pequeno com resultado conhecido antes de tentar uma entrada grande.
