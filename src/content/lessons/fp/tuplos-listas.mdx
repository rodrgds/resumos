Uma lista e um tuplo conservam uma sequência de objetos. A diferença principal é se podemos substituir, inserir ou retirar elementos na própria sequência. Essa escolha afeta o estado do programa e o que uma função pode alterar.

## Sequências e tuplos

Strings, listas e tuplos suportam `len`, índices, fatias e pertença com `in`. Uma lista escreve-se `[12, 15]`; um tuplo pode escrever-se `(12, 15)`. A vírgula é que cria o tuplo: `(12,)` tem um elemento, mas `(12)` é apenas o inteiro 12 entre parênteses.

O **desempacotamento** associa elementos a nomes: `x, y = (3, 4)`. Nesta forma, o número de nomes tem de coincidir com o número de elementos. `a, b = b, a` troca os valores porque o lado direito é calculado antes das atribuições.

Um tuplo é imutável, mas pode conter objetos mutáveis. Em `registo = ("Ana", [12, 15])`, não podes substituir `registo[0]`, mas podes alterar a lista `registo[1]`. Imutabilidade do recipiente não significa imutabilidade de todos os objetos alcançáveis a partir dele.

## Alterar uma lista

| Operação          | Efeito                                               |
| ----------------- | ---------------------------------------------------- |
| `xs.append(x)`    | Acrescenta um elemento, mesmo que `x` seja uma lista |
| `xs.extend(ys)`   | Acrescenta cada elemento de `ys`                     |
| `xs.insert(i, x)` | Insere antes da posição `i`                          |
| `xs.pop(i)`       | Retira e devolve o elemento dessa posição            |
| `xs.remove(x)`    | Retira a primeira ocorrência de `x`; falha se faltar |
| `del xs[i]`       | Retira o elemento sem o devolver                     |
| `xs[a:b] = ys`    | Substitui uma fatia, podendo mudar o comprimento     |

`append`, `extend`, `insert`, `remove`, `sort` e `reverse` devolvem `None`. Não escrevas `xs = xs.append(4)`, porque acabarias com `xs` associado a `None`. `xs + ys` cria outra lista. Não alteres o comprimento da lista que estás a percorrer sem uma estratégia explícita; retirar um elemento pode deslocar o seguinte e fazê-lo escapar ao ciclo.

## Alias contra cópia, igualdade contra identidade

`b = a` não copia a lista. Cria outro nome para o mesmo objeto, um **alias**. `a == b` compara conteúdos; `a is b` testa se os nomes referem o mesmo objeto.

`append` altera a lista partilhada por `notas` e `alias`. A alteração em `copia` atinge outra lista. Dois objetos distintos podem ter conteúdo igual. A identidade ajuda a seguir partilha, mas um cálculo que só depende dos valores não deve depender dela.

## Listas de listas e cópia superficial

`a.copy()` e `a[:]` criam uma cópia **superficial**. Copiam o recipiente, mantendo referências aos elementos. Se os elementos forem listas, continuam partilhados.

<CodePlayground
  language="python"
  title="Cópia superficial de uma matriz"
  input=""
  code={
    'matriz = [[1, 2], [3, 4]]\ncopia = matriz.copy()\ncopia[0][0] = 9\nprint(matriz)\nprint(copia)\nindependente = [linha.copy() for linha in matriz]\nindependente[0][0] = 7\nprint(matriz)\nprint(independente)'
  }
/>

As duas primeiras saídas têm o 9 porque a primeira linha é partilhada. A compreensão final copia cada linha; neste exemplo, como os elementos das linhas são inteiros, a alteração já é independente. Para estruturas mais profundas, copiar um só nível adicional pode não chegar.

<ShallowCopyDiagram />

O esquema mostra o estado após `copia[0][0] = 9`. Cada caixa é um objeto; cada seta é uma referência a esse objeto. As listas exteriores são distintas, mas as referências nas posições 0 e 1 de ambas chegam às mesmas listas interiores. Por isso, alterar um elemento da primeira linha através de `copia` também muda o que vemos através de `matriz`.

Evita `[[0] * 3] * 2` para criar duas linhas independentes. A repetição exterior repete a referência à mesma linha. Usa `[[0] * 3 for _ in range(2)]` quando precisares de uma linha nova em cada posição.

## Percorrer e combinar sequências

`enumerate(xs)` produz pares com índice e valor. `zip(xs, ys)` combina elementos na mesma posição e, por defeito, termina na sequência mais curta. Se o contrato exige comprimentos iguais, verifica-o antes de combinar.

O produto interno de dois vetores com o mesmo comprimento é a soma dos produtos correspondentes. Para `[2, 3]` e `[4, 5]`, calculamos $2\times4+3\times5=23$. Para dois vetores vazios, a soma é zero.

```python
def produto_interno(u, v):
    if len(u) != len(v):
        raise ValueError("comprimentos diferentes")
    soma = 0
    for a, b in zip(u, v):
        soma += a * b
    return soma

print(produto_interno([2, 3], [4, 5]))
```

O resultado é 23. `raise` comunica uma entrada inválida; veremos como tratar essa exceção no fim do percurso.

## Ordenar sem confundir os resultados

`sorted(xs)` devolve uma lista nova e deixa `xs` intacta. `xs.sort()` ordena a lista existente e devolve `None`. `reverse=True` pede ordem decrescente. Para ordenar registos por um campo, usa `key`; a [lição de programação funcional](/cadeiras/fp/programacao-funcional/#funções-de-ordem-superior-e-lambda) explica como passar essa função.
