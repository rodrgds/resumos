Uma máquina de estados finita, FSM, guarda apenas a parte do passado necessária para decidir o comportamento seguinte. Para reconhecer se um número binário é múltiplo de 3, não precisamos de guardar todos os bits recebidos: chega guardar o resto da divisão por 3.

## Moore e Mealy

Numa Moore, a saída depende só do estado atual. Numa Mealy, pode depender também das entradas atuais. Em ambos os casos, o próximo estado depende do estado e das entradas.

Num diagrama Moore, escreve a saída dentro do estado e a condição na seta. Num Mealy, escreve condição/saída na seta. Uma saída Mealy pode mudar entre flancos se a entrada mudar; não a trates como um valor sempre registado.

## Resto de uma sequência binária

Se o prefixo lido vale $v$ e chega um bit $b$, o novo valor é $2v+b$. Para o resto $r$ módulo 3:

$$r^+=(2r+b)\bmod3.$$

Usamos estados R0, R1, R2 e saída $z=1$ em R0. O reset põe a máquina em R0. Aqui o prefixo vazio é interpretado como zero; se a especificação exigir pelo menos um bit, é preciso guardar também essa informação.

| Estado | $b=0$ | $b=1$ | $z$ |
| ------ | ----- | ----- | --- |
| R0     | R0    | R1    | 1   |
| R1     | R2    | R0    | 0   |
| R2     | R1    | R2    | 0   |

Ao ler `110`, passamos R0 → R1 → R0 → R0. O número é 6, múltiplo de 3. Ao ler `101`, passamos R0 → R1 → R2 → R2: 5 deixa resto 2. A saída observada depois de cada flanco corresponde ao prefixo já recebido.

## Síntese com flip-flops D

Codifica R0=`00`, R1=`01`, R2=`10`. São necessários dois flip-flops, porque $\lceil\log_2 3\rceil=2$. Escolhe recuperação de `11` para `00`, com saída 0.

A tabela anterior, expandida para bits $q_1,q_0,b$ com próximo estado $n_1n_0$, dá:

| $q_1q_0$     | $b=0\to n_1n_0$ | $b=1\to n_1n_0$ |
| ------------ | --------------- | --------------- |
| 00 pronto R0 | 00              | 01              |
| 01 pronto R1 | 10              | 00              |
| 10 pronto R2 | 01              | 10              |
| 11 inválido  | 00              | 00              |

Cada linha com próximo bit 1 gera um termo do produto. Da tabela completa obtém-se:

$$D_1=\overline q_1q_0\overline b+q_1\overline q_0b,$$

$$D_0=\overline q_1\overline q_0b+q_1\overline q_0\overline b,$$

$$z=\overline q_1\overline q_0.$$

Cada termo de D vem de uma linha cuja próxima saída do flip-flop é 1. As equações dão `00` para o estado inválido, como escolhido. O circuito tem lógica combinatória para D e dois flip-flops que atualizam juntos.

Em one-hot usamos um bit por estado: $h_0,h_1,h_2$ representam R0,R1,R2, com exatamente um bit a 1. A escrita `h0 h1 h2` dá R0=`100`, R1=`010`, R2=`001`. Para obter o próximo bit de cada estado, reúne as setas que chegam a esse estado:

$$normal_0=h_0\overline b+h_1b,$$
$$normal_1=h_0b+h_2\overline b,$$
$$normal_2=h_1\overline b+h_2b.$$

Por exemplo, R0 recebe uma seta de R0 com b=0 e outra de R1 com b=1. São os dois produtos de $normal_0$. Cada equação é uma OR de duas AND de duas entradas.

Estas equações só garantem a máquina pretendida nos códigos válidos. `000` ficaria em `000`, porque todos os produtos valem 0. O reset estabelece `100`. Se exigirmos recuperação de qualquer código inválido, precisamos também de verificar o invariante:

$$val=h_0\overline h_1\overline h_2+\overline h_0h_1\overline h_2+\overline h_0\overline h_1h_2.$$

Com $inv=\overline{val}$, escolhemos

$$h_0^+=normal_0+inv,$$
$$h_1^+=normal_1\,val,$$
$$h_2^+=normal_2\,val.$$

Se val=1, conservamos as transições normais. Se val=0, os próximos bits são `100`, mesmo num código com vários bits a 1. O custo desta recuperação é adicional ao das três equações base; one-hot não elimina estados inválidos.

## Reconhecer padrões e produzir um impulso

Para detetar `101` com sobreposição, os estados distinguem os prefixos já reconhecidos: nenhum, `1`, `10` e deteção `101`. Depois de detetar, o último `1` já pode iniciar outra ocorrência. Em `10101`, há duas deteções. Voltar incondicionalmente ao estado inicial perderia a segunda.

Uma Moore completa para esse caso tem esta tabela. A saída indicada é a do estado atual, e só D deteta o padrão:

| Estado | Prefixo útil                  | Saída | Próximo com 0 | Próximo com 1 |
| ------ | ----------------------------- | ----- | ------------- | ------------- |
| A      | Nenhum                        | 0     | A             | B             |
| B      | `1`                           | 0     | C             | B             |
| C      | `10`                          | 0     | A             | D             |
| D      | Deteção `101`, termina em `1` | 1     | C             | B             |

Partindo de A, `10101` dá B,C,D,C,D. Observamos 0,0,1,0,1 depois dos flancos. Em D, um novo 0 já completa o prefixo `10`, por isso a transição vai para C. É esta informação conservada que permite a sobreposição.

Para produzir um impulso de um ciclo quando um botão fica 1, usa estados Espera, Impulso e Libertação. Espera entra em Impulso quando x=1; Impulso passa a Libertação se x ainda for 1, ou Espera se já for 0; Libertação conserva enquanto x=1. A saída só é 1 em Impulso. Sem Libertação, uma entrada longa pode provocar vários impulsos.

## Minimização e comunicação

Para minimizar uma Moore, agrupa primeiro estados com a mesma saída. Divide um grupo quando dois dos seus estados, para a mesma entrada, transitam para grupos diferentes. Repete até estabilizar. Só estados que continuam indistinguíveis podem ser fundidos; ter a mesma saída hoje não chega.

:::details[Exemplo de partição]

Considera esta Moore, com estado inicial A:

| Estado | Saída | Próximo com 0 | Próximo com 1 |
| ------ | ----- | ------------- | ------------- |
| A      | 0     | B             | D             |
| B      | 0     | C             | D             |
| C      | 0     | C             | C             |
| D      | 1     | E             | D             |
| E      | 1     | D             | E             |

Começamos com $\{A,B,C\}$ e $\{D,E\}$. A entrada 1 separa C de A,B, pois C permanece no grupo de saída 0 enquanto A,B vão para saída 1. Ficamos com $\{A,B\},\{C\},\{D,E\}$. A entrada 0 separa agora A de B: A vai para o grupo A,B, mas B para C. A partição final é $\{A\},\{B\},\{C\},\{D,E\}$. D e E continuam juntos porque ambas as suas transições ficam no seu próprio grupo.

A máquina reduzida tem quatro estados: A, B, C e H, que representa D/E. A vai para B/H, B para C/H, C para C/C e H para H/H, respetivamente com 0/1. Conserva as saídas 0,0,0,1. Não conseguimos fundir A e B, apesar da mesma saída inicial: a sequência 01 termina em saída 1 a partir de A e 0 a partir de B.

:::

Duas máquinas podem coordenar-se por handshake de quatro fases, com dados, `valid` e `ack` no tempo:

| Passo | Dados          | valid | ack | Regra                       |
| ----- | -------------- | ----- | --- | --------------------------- |
| 1     | emissor fixa D | 0     | 0   | D estabiliza antes de valid |
| 2     | D estável      | 1     | 0   | emissor pede aceitação      |
| 3     | D estável      | 1     | 1   | recetor aceitou D           |
| 4     | D estável      | 0     | 1   | emissor fecha pedido        |
| 5     | livre          | 0     | 0   | recetor fecha confirmação   |

Neste protocolo conservamos D até ao fim da confirmação. O emissor baixa `valid` depois de ver `ack=1`; o recetor baixa `ack` depois de ver `valid=0`. Só então se prepara a transferência seguinte. Mudar D logo após pôr `valid=1` pode fazer o recetor aceitar outra palavra. A confirmação também permite esperar pelo recetor: um impulso de um ciclo sem confirmação pode ser perdido se ele não o observar.

Entre relógios diferentes, entradas podem violar setup/hold e provocar metastabilidade. O modelo de FSM assume entradas amostradas válidas. A implementação exige sincronização apropriada; sincronizar bits independentes não garante uma palavra de dados coerente.
