Uma memória associa a cada endereço uma unidade de dados. Antes de calcular capacidade, identifica o que cada endereço seleciona: um byte, uma palavra de 16 bits ou outra unidade. O número de endereços sozinho não determina o número de bytes.

## Tipos e interface

RAM permite ler e escrever posições por endereço. ROM é usada para conteúdo fixo ou alterado por um procedimento especial. SRAM mantém bits em circuitos enquanto tem alimentação; DRAM guarda carga em condensadores e requer refresh. Ambas são voláteis. Flash é não volátil, mas a escrita e o apagamento têm regras diferentes de uma RAM.

Uma célula SRAM típica usa seis transístores, com armazenamento estável e acesso controlado. Uma célula DRAM típica usa um transístor e um condensador: a carga perde-se com o tempo e a leitura requer reposição, pelo que o controlador faz refresh. Menos elementos por bit permite maior densidade, mas exige esse controlo adicional.

Uma ROM de máscara tem conteúdo definido na fabricação. PROM permite programação; EPROM pode ser apagada com luz ultravioleta; EEPROM pode ser apagada eletricamente. Flash também é apagada eletricamente, habitualmente por blocos. Para firmware atualizável é preciso memória não volátil reprogramável, não uma SRAM que perde conteúdo quando desligada. Estas tecnologias têm limites de escrita; não assumas que a possibilidade de reprogramar é ilimitada.

Registos, caches, RAM e armazenamento formam uma hierarquia que procura combinar acesso rápido, capacidade e custo. Não confundas persistência com velocidade: sobreviver à falta de alimentação não implica acesso tão rápido como um registo.

O acesso aleatório permite selecionar diretamente uma posição. Uma memória de acesso sequencial impõe uma ordem de acesso. Numa memória associativa, CAM, pesquisa-se um conteúdo e obtém-se a posição correspondente.

Num chip, `CS` seleciona, `OE` habilita a saída e `WE` habilita a escrita. Uma barra ou bolha indica controlo ativo a 0. Uma saída desativada pode ficar em alta impedância, Z, para não conduzir o barramento. Z não é um terceiro valor guardado na célula. Nunca atives simultaneamente dois chips que conduzem dados diferentes no mesmo barramento.

## Capacidade

Um chip $2^a\times w$ tem $a$ linhas de endereço e $w$ linhas de dados. Guarda $2^aw$ bits. Um chip $4\text{K}\times8$ tem $2^{12}$ posições e guarda 4096 bytes, ou 4 KiB. Um chip $4\text{K}\times16$ tem as mesmas 12 entradas de endereço, mas guarda 8 KiB.

Uma memória de 24 bits de endereçamento ao byte tem $2^{24}$ bytes, 16 MiB. Se cada posição armazenar 32 bits, a capacidade será quatro vezes maior. Indica sempre a organização usada.

## Alargar e aprofundar

Queremos $8\text{K}\times16$ a partir de chips $4\text{K}\times8$. Para a largura, colocamos dois chips em paralelo: um guarda os bits 7:0, outro os bits 15:8. Recebem o mesmo endereço e controlo.

Para duplicar a profundidade, precisamos de dois destes pares. As 12 linhas inferiores vão a todos os chips; $A_{12}$ escolhe o par. São **quatro chips**, organizados em dois bancos de 16 bits. A capacidade é $8192\times16=131072$ bits, ou 16 KiB. Não multipliques o número de linhas de endereço pelo número de chips.

## Mapa de endereços

Num sistema com endereços de 16 bits, queremos colocar uma RAM de 4 KiB em `0x8000` a `0x8FFF`. Os 12 bits inferiores escolhem a posição interna. Os quatro superiores têm de ser `1000` para selecionar o chip:

$$CS=A_{15}\overline A_{14}\overline A_{13}\overline A_{12}.$$

O primeiro endereço tem todos os bits inferiores a 0; o último tem-nos a 1. São $0x1000=4096$ endereços, contando as duas extremidades. Um bloco de $2^{12}$ bytes deve começar numa fronteira com os 12 bits inferiores a 0 para esta descodificação simples.

Se só descodificarmos $A_{15}=1$, o chip aparece repetido de `0x8000` a `0xFFFF`. `0x8123` e `0x9123` acedem à mesma posição `0x123`. São aliases: a descodificação parcial não criou mais armazenamento. Alterar por um endereço é visível pelo outro.

Na intercalação por endereços pares e ímpares, $A_0$ seleciona o banco e os restantes bits selecionam a posição dentro dele. Isto é diferente de usar o bit mais alto para colocar um banco depois do outro no mapa.

## Erros de memória

Um bit de paridade permite escolher paridade par ou ímpar. Com paridade par, `10110010` já tem quatro bits 1, por isso o bit adicional é 0. Se mudar um bit, a paridade denuncia o erro. Se mudarem dois, pode não o detetar; também não identifica qual bit corrigir.

Um código SECDED acrescenta redundância que permite corrigir um erro de um bit e detetar erros de dois bits no modelo desse código. Não generalizes essa garantia a qualquer número de erros. Capacidade útil e capacidade física com bits de verificação podem ser diferentes.
