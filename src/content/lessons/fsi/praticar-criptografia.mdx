  title="Cifrar para o destinatário"

  answer={{"kind": "number", "value": 13, "tolerance": 0}}
>

Num RSA de brinquedo, Bruno tem chave pública $n=55,e=3$. Ana quer cifrar a mensagem inteira $m=7$ para Bruno. Qual é o valor cifrado? Não uses este esquema para comunicação real.

  <div slot="hint">

A cifragem usa a pública do destinatário.

  </div>

  <div slot="solution">

$7^3=343=6\times55+13$, logo $c=13$. A privada do Bruno é necessária para a operação de recuperação no esquema.

  </div>

  <div slot="mistakes">

A privada da Ana corresponde à assinatura, não à cifragem para Bruno.

  </div>

>

Um servidor publica um ficheiro e o seu SHA-256 na mesma página. Um atacante controla essa página e troca ambos. Explica por que a comparação não prova autenticidade e que tipo de referência seria necessário.

  <div slot="hint">

O hash exige algum segredo?

  </div>

  <div slot="solution">

O hash público do novo ficheiro coincide com o resumo que o atacante publica. Nesse caso, a comparação só comprova consistência com essa referência. Uma assinatura com chave verificada ou um resumo obtido por canal confiável muda a hipótese de confiança.

  </div>

  <div slot="mistakes">

Um hash mais longo não corrige o controlo de ambos os valores.

  </div>

Oito entidades partilham uma chave duradoura diferente por par. Quantas chaves distintas existem? Considera a mesma chave nos dois sentidos de comunicação.

  <div slot="hint">

Contar os pares ordenados duplicaria cada segredo.

  </div>

  <div slot="solution">

$8\times7/2=28$. Num modelo com um KDC adicional e uma chave por entidade com esse centro, seriam oito chaves duradouras destas ligações. A comparação exclui chaves de sessão e outros componentes do centro.

  </div>

  <div slot="mistakes">

Não usar 8 vezes 8, nem incluir pares de uma entidade consigo própria.

  </div>

  answer={{

      { name: 'Fora do alfabeto ASCII', code: 'print(cesar("Á Zç", 1))', output: 'Á Aç' },
      { name: 'Texto vazio', code: 'print(repr(cesar("", 9)))', output: "''" },
    ],
  }}
>

Define `cesar(texto, deslocamento)`: devolve uma string com cada maiúscula ASCII de A a Z deslocada no alfabeto. Mantém todos os outros caracteres. O deslocamento é um inteiro, pode ser negativo ou maior que 25. A string vazia dá uma string vazia. Esta é uma cifra de estudo sem segurança para uso real.

<div slot="hint">

`ord` dá o número de um caráter e `chr` faz a operação inversa. Subtrai `ord('A')` para obter os valores de 0 a 25.

</div>
<div slot="hint-more">

Em Python, `(indice + deslocamento) % 26` dá um índice de 0 a 25, incluindo para deslocamentos negativos. Os caracteres fora de A a Z ficam iguais.

</div>
<div slot="solution">

```python
def cesar(texto, deslocamento):
    resultado = []
    for carater in texto:
        if 'A' <= carater <= 'Z':
            indice = ord(carater) - ord('A')
            carater = chr(ord('A') + (indice + deslocamento) % 26)
        resultado.append(carater)
    return ''.join(resultado)
```

Somar o deslocamento e tomar o resto mantém o índice dentro do alfabeto. Passar o deslocamento oposto recupera as maiúsculas originais. A avaliação automática verifica este contrato nos casos publicados; não avalia a segurança de uma cifra.

</div>
<div slot="mistakes">

Não uses apenas `isupper()`: também aceita maiúsculas de outros alfabetos, fora do contrato. Não elimines espaços nem esqueças a volta de Z para A.

</div>
</Exercise>

>

Para a lista de preços da loja, decide: esconder a pauta em trânsito; provar que veio da direção; detetar alteração acidental face a uma cópia confiável. Escolhe a primitiva de cada objetivo e diz o que ela não resolve sozinha.

  <div slot="hint">

Cada objetivo pede um segredo e uma propriedade diferentes.

  </div>

  <div slot="solution">

Para esconder em trânsito, cifra para a chave pública do destinatário; não prova quem enviou. Para prova pública de origem, assinatura com a privada da direção e verificação com a pública; não esconde o conteúdo. Para alteração acidental face a referência confiável, compara o hash; sem canal confiável para a referência, usa MAC com chave partilhada ou assinatura.

  </div>

  <div slot="mistakes">

Não proposes hash público publicado no mesmo canal controlado pelo atacante como prova de origem.

  </div>
