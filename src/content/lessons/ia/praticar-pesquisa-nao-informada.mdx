Implementa `distancia(grafo, inicio, objetivo)` para um grafo dirigido finito com custo 1 por aresta. O dicionário associa nomes a listas de sucessores; uma chave ausente tem zero sucessores. Devolve o menor número de arestas ou `None` se não houver caminho, sem imprimir nem alterar o grafo.

  <div slot="hint">

Guarda a distância juntamente com cada estado na fila.

  </div>
  <div slot="hint-more">

O início tem distância 0, inclusive quando já é o objetivo. Mantém um conjunto de visitados.

  </div>
  <div slot="solution">

```python
from collections import deque

def distancia(grafo, inicio, objetivo):
    fila = deque([(inicio, 0)])
    visitados = {inicio}
    while fila:
        atual, d = fila.popleft()
        if atual == objetivo:
            return d
        for seguinte in grafo.get(atual, []):
            if seguinte not in visitados:
                visitados.add(seguinte)
                fila.append((seguinte, d + 1))
    return None
```

A fila visita por distância crescente. Marcar na inserção evita ciclos e repetição. Os casos verificam distância e preservação da entrada; a escolha da estrutura e a explicação da complexidade são autoavaliação.

  </div>
  <div slot="mistakes">

Usar DFS e devolver o primeiro caminho, esquecer visitados, não tratar início igual ao objetivo ou consumir listas de sucessores.

  </div>
</Exercise>
