<Exercise
  id="lc-promocao-byte"
  revision={1}
  title="Complementar um byte"
  explanation="/cadeiras/lc/c-estruturado/#promoções-e-conversões-de-inteiros"
  answer={{ kind: 'number', value: 13, tolerance: 0 }}
>
  <div>
    Com uint8_t byte = 0x96, quanto vale (uint8_t)~byte &gt;&gt; 3 em decimal?
    Considera int capaz de representar todos os valores de uint8_t.
  </div>
  <div slot="hint">O cast acontece antes do deslocamento.</div>
  <div slot="hint-more">
    Escreve o complemento de oito bits de 0x96 e divide-o por 8 com quociente
    inteiro.
  </div>
  <div slot="solution">
    0x96 tem complemento de oito bits 0x69, que vale 105. Depois do cast, a
    promoção produz um inteiro positivo. O deslocamento dá o quociente inteiro
    de 105/8, ou 13.
  </div>
  <div slot="mistakes">
    Fazer o complemento num inteiro com sinal e deslocar antes do cast não
    corresponde à expressão pedida.
  </div>
</Exercise>

<Exercise
  id="lc-ligacao-objeto"
  revision={1}
  title="Localizar uma referência indefinida"
  explanation="/cadeiras/lc/c-estruturado/#compilar-e-ligar"
  answer={{
    kind: 'self',
    checklist: [
      'Distingui declaração de definição.',
      'Indiquei que a falha é na ligação.',
      'Acrescentei o objeto ou biblioteca que fornece a função.',
    ],
  }}
>
  <div>
    main.c inclui counter.h, compila sem erros, mas cc main.o -o demo falha com
    uma referência indefinida a counter_tick. Explica a causa e corrige o
    comando, sabendo que a definição está em counter.o.
  </div>
  <div slot="hint">Incluir um cabeçalho permite conferir a chamada.</div>
  <div slot="hint-more">
    O linker precisa do código objeto onde a função foi definida.
  </div>
  <div slot="solution">
    O cabeçalho declara counter_tick e por isso a compilação de main.c é
    possível. main.o conserva uma referência externa. Na ligação falta
    counter.o. Usa cc main.o counter.o -o demo, ou liga uma biblioteca que
    contenha esse objeto depois de main.o.
  </div>
  <div slot="mistakes">
    Copiar a declaração para main.c não fornece a definição. Não é uma falha de
    execução do Minix.
  </div>
</Exercise>

<Exercise
  id="lc-comparacao-sinal"
  revision={1}
  title="Comparar uma posição negativa"
  explanation="/cadeiras/lc/c-estruturado/#promoções-e-conversões-de-inteiros"
  answer={{
    kind: 'self',
    checklist: [
      'Identifiquei a conversão para unsigned.',
      'Validei a posição negativa antes do cast.',
      'Mantive a comparação com o limite coerente.',
    ],
  }}
>
  <div>
    Num sistema com int e unsigned int de 32 bits, delta vale -2 e width é
    unsigned int com valor 100. Explica por que delta &lt; width dá falso e
    escreve um teste seguro para 0 ≤ delta &lt; width.
  </div>
  <div slot="hint">A comparação aplica as conversões aritméticas usuais.</div>
  <div slot="hint-more">O valor convertido de -2 é 4294967294.</div>
  <div slot="solution">
    Como unsigned int representa valores que int não representa, delta
    converte-se para unsigned int. O valor 4294967294 é maior do que 100. Um
    teste seguro é delta &gt;= 0 &amp;&amp; (unsigned int)delta &lt; width. O
    segundo operando só é avaliado se a posição não for negativa.
  </div>
  <div slot="mistakes">
    Converter delta para unsigned antes de testar o sinal perde a possibilidade
    de detetar diretamente a posição negativa.
  </div>
</Exercise>
