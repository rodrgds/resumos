<Exercise
  id="lc-delta-positivo-200"
  title="Usar o nono bit"
  explanation="/cadeiras/lc/rato/#reconstruir-nove-bits"
  answer={{ kind: 'number', value: 200, tolerance: 0 }}
>
  <p>
    Um pacote válido sem overflow é 08 C8 00. Quanto vale delta X em decimal?
  </p>
  <div slot="hint">O bit de sinal de X está no primeiro byte.</div>
  <div slot="hint-more">Em 0x08, o bit 4 está a 0.</div>
  <div slot="solution">
    O sinal X é 0, por isso delta X é o byte baixo 0xC8 sem sinal, ou +200. Não
    há overflow. Um cast para int8_t produziria um resultado diferente e
    incorreto para o protocolo.
  </div>
  <div slot="mistakes">
    Usar o bit 7 de C8 como sinal de um delta que tem nove bits.
  </div>
</Exercise>

<Exercise
  id="lc-delta-negativo-251"
  title="Converter para o ecrã"
  explanation="/cadeiras/lc/rato/#reconstruir-nove-bits"
  answer={{ kind: 'number', value: 351, tolerance: 0 }}
>
  <p>
    Um pacote válido é 28 00 05. O cursor tem screen_y = 100 e o ecrã cresce
    para baixo. Sem aplicar limites, qual é o novo screen_y?
  </p>
  <div slot="hint">O bit 5 de 0x28 é o sinal Y.</div>
  <div slot="hint-more">delta Y é 5 - 256 e o ecrã usa screen_y - delta Y.</div>
  <div slot="solution">
    delta Y = -251 nas coordenadas físicas do rato. screen_y = 100 - (-251) =
    351. O movimento físico foi para baixo, por isso a coordenada do ecrã
    aumenta.
  </div>
  <div slot="mistakes">
    Interpretar 0x05 sempre como +5 ou somar delta Y numa coordenada de ecrã que
    cresce para baixo.
  </div>
</Exercise>

<Exercise
  id="lc-pacote-sincronizacao"
  title="Não reiniciar no byte de dados"
  explanation="/cadeiras/lc/rato/#montagem-e-sincronização"
  answer={{
    kind: 'self',
    checklist: [
      'Aceitei 0x08 como primeiro byte.',
      'Guardei 0x18 como dado X.',
      'Completei o pacote com 0x00 sem reiniciar.',
    ],
  }}
>
  <p>
    A montagem começa com índice 0 e recebe 08 18 00. Um programa reinicia o
    pacote sempre que vê bit 3 a 1, mesmo a meio. Explica por que falha e
    interpreta o pacote corretamente.
  </p>
  <div slot="hint">O bit 3 pode também estar ativo num byte de dados.</div>
  <div slot="hint-more">0x18 é o segundo byte, não um novo cabeçalho.</div>
  <div slot="solution">
    Depois de aceitar 0x08, o índice é 1. 0x18 deve ocupar o byte X e 0x00 o
    byte Y. O pacote tem delta X +24, delta Y 0, sem botões. O teste de
    sincronização só deve escolher o primeiro byte quando o índice é 0;
    reiniciar em 0x18 perde o pacote.
  </div>
  <div slot="mistakes">
    Assumir que bit 3 a 1 identifica exclusivamente um cabeçalho em qualquer
    posição.
  </div>
</Exercise>
