<Exercise
  id="uml-multiplicidade"
  title="Ler o extremo certo"
  explanation="/cadeiras/ldts/diagramas-uml/#multiplicidades"
  answer={{
    kind: 'self',
    checklist: [
      'Uma equipa relaciona-se com uma a três pessoas.',
      'Uma pessoa relaciona-se com zero ou uma equipa.',
      'Lê cada multiplicidade para um objeto do extremo oposto.',
    ],
  }}
>
  <p>
    Uma associação liga Equipa e Pessoa. No extremo Pessoa está 1..3, e no
    extremo Equipa está 0..1. Explica o que significa cada multiplicidade.
  </p>
  <div slot="hint">
    <p>Cada extremo conta objetos daquele tipo.</p>
  </div>
  <div slot="hint-more">
    <p>Para uma equipa, olha para o número junto de Pessoa.</p>
  </div>
  <div slot="solution">
    <p>
      Cada equipa tem de uma a três pessoas. Cada pessoa pode não ter equipa ou
      pertencer a uma. A multiplicidade não significa que existem apenas três
      pessoas no sistema inteiro.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Não troques o sentido de leitura nem interpretes a multiplicidade como
      total global.
    </p>
  </div>
</Exercise>

<Exercise
  id="uml-mensagens"
  title="Numerar uma chamada aninhada"
  explanation="/cadeiras/ldts/diagramas-uml/#diagrama-de-comunicação"
  answer={{
    kind: 'choice',
    options: [
      {
        text: '2.1',
        correct: true,
        explanation: 'É a primeira chamada aninhada na ativação 2.',
      },
      {
        text: '3',
        correct: false,
        explanation: '3 seria uma mensagem seguinte ao mesmo nível de 2.',
      },
      {
        text: '1.2',
        correct: false,
        explanation: 'Esse número pertence a uma chamada dentro da ativação 1.',
      },
    ],
  }}
>
  <p>
    A mensagem 2 é Controlador para Modelo.validar. Durante essa chamada, Modelo
    chama Mapa.livre. Qual numeração mostra essa chamada dentro da ativação 2?
  </p>
  <div slot="hint">
    <p>O prefixo conserva o número da chamada exterior.</p>
  </div>
  <div slot="hint-more">
    <p>Acrescenta o nível da primeira chamada interna.</p>
  </div>
  <div slot="solution">
    <p>
      A mensagem é 2.1: livre(...). Outra chamada dentro de validar poderia ser
      2.2. A numeração torna visível o aninhamento que uma lista plana perde.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Uma chamada interna não termina a ativação exterior antes de acontecer.
    </p>
  </div>
</Exercise>

<Exercise
  id="uml-guarda"
  title="Evento, condição e efeito"
  explanation="/cadeiras/ldts/diagramas-uml/#diagrama-de-estados"
  answer={{
    kind: 'self',
    checklist: [
      'Enviar é o evento.',
      'Saldo suficiente é a guarda.',
      'Descontar é o efeito, e a transição não ocorre se a guarda falhar.',
    ],
  }}
>
  <p>
    Lê a transição enviar [saldo suficiente] / descontar. Identifica os três
    elementos e o que acontece quando o saldo não é suficiente.
  </p>
  <div slot="hint">
    <p>A forma é evento [guarda] / efeito.</p>
  </div>
  <div slot="hint-more">
    <p>A guarda decide se o evento permite a transição.</p>
  </div>
  <div slot="solution">
    <p>
      Enviar desencadeia a tentativa; saldo suficiente tem de ser verdadeiro;
      descontar é executado se a transição ocorrer. Se a guarda for falsa, esta
      transição não acontece e o seu efeito não é executado.
    </p>
  </div>
  <div slot="mistakes">
    <p>Não executes o efeito só porque o evento chegou.</p>
  </div>
</Exercise>
