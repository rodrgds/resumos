Abre o catálogo sem estilo: o texto está lá, mas sem cores nem colunas. Cada regra CSS escolhe partes da página com um seletor e declara o aspeto. Quando várias regras atingem o mesmo elemento, a cascata decide qual ganha. Depois medimos cada caixa e dispomos as caixas com flexbox ou grid.

## Seletores

A folha externa é ligada pelo `link` no `head` do HTML. Também podes escrever regras num elemento `style` ou declarações no atributo `style`; a folha externa permite reutilizar regras entre páginas. Uma regra contém um seletor e declarações `propriedade: valor`, separadas por ponto e vírgula.

Uma regra como `.livro > h2 { color: navy; }` escolhe os `h2` filhos diretos de um elemento com classe `livro`. O espaço escolhe descendentes a qualquer profundidade. A vírgula separa seletores, não acrescenta uma condição.

| Seletor                        | Elementos selecionados                                  |
| ------------------------------ | ------------------------------------------------------- |
| `article.livro`                | `article` com a classe `livro`                          |
| `[name="q"]`                   | Elementos com esse atributo e valor                     |
| `.livro p`                     | Parágrafos descendentes de `.livro`                     |
| `.livro > p`                   | Parágrafos filhos diretos                               |
| `h2 + p`                       | O `p` imediatamente a seguir a um `h2`, com o mesmo pai |
| `h2 ~ p`                       | Todos os irmãos `p` posteriores a um `h2`               |
| `li:first-child`               | `li` que é o primeiro elemento filho                    |
| `li:first-of-type`             | O primeiro `li` entre os irmãos                         |
| `li:nth-child(2n)`             | `li` numa posição par entre todos os elementos filhos   |
| `input:checked`                | Controlos marcados                                      |
| `a:hover`, `a:focus-visible`   | Ligações sob o apontador ou com foco visível            |
| `p::first-letter`, `p::before` | Uma parte ou um pseudo-elemento do `p`                  |

Desenha a árvore antes de responder. Uma `section` contém `h2`, `p` e `p` como filhos diretos. O primeiro `p` é o segundo filho e o primeiro do seu tipo. Por isso corresponde a `p:first-of-type`, mas não a `p:first-child`, que exigiria ser o primeiro filho. O índice de `:nth-child` começa em 1 e conta elementos, não nós de texto.

`[href^="https://"]` testa o início de um atributo; `[href$=".pdf"]` testa o fim; `[href*="livro"]` procura uma parte. `[class~="livro"]` procura uma palavra numa lista separada por espaços, enquanto `[lang|="pt"]` aceita `pt` ou um valor que comece por `pt-`. `p.ativo` seleciona o próprio parágrafo com a classe; `p .ativo` seleciona um descendente. Uma pseudo-classe, como `:checked`, testa um elemento; um pseudo-elemento, como `::before`, representa uma parte gerada, normalmente com `content`.

`:not(.esgotado)` exclui uma condição; `:is(.livro, .revista)` reúne alternativas; `.livro:has(button)` escolhe o elemento pela existência de um descendente que corresponde. Em seletores aninhados, `&` representa o seletor exterior. Para uma pergunta de seleção, desenha os pais e irmãos antes de contar especificidade.

## Cascata e herança

A especificidade só decide entre declarações que já estão no mesmo nível da cascata. Primeiro contam origem e importância, e a ordem das camadas quando existem; depois a especificidade; por fim, a posição no código. Aqui vamos comparar declarações normais do autor, sem camadas:

```css
#catalogo .preco {
  color: red;
} /* (1, 1, 0) */
ul#catalogo li span.preco {
  color: green;
} /* (1, 1, 3) */
```

Ambas atingem o mesmo `span.preco`. Resolve por etapas. Primeiro confirma que as duas declarações estão no mesmo nível de origem, importância e camada. Depois compara o trio `(IDs, classes/atributos/pseudo-classes, elementos/pseudo-elementos)` da esquerda para a direita: `(1, 1, 0)` contra `(1, 1, 3)`. O empate nas duas primeiras posições resolve-se na terceira, por isso a segunda ganha. Dez classes não ultrapassam um identificador. `*` e combinadores não acrescentam especificidade.

`:where(...)` tem especificidade zero. `:is`, `:not` e `:has` usam a maior especificidade entre os argumentos. Um estilo em linha tem precedência sobre as regras normais da folha do autor; `!important` altera a importância, não a especificidade. Declarações importantes do utilizador podem ultrapassar as do autor. Não resumas a cascata a "o seletor mais comprido ganha".

```css
@layer base, componentes;
@layer base {
  #catalogo p {
    color: red;
  }
}
@layer componentes {
  p {
    color: blue;
  }
}
```

Para declarações normais, a camada posterior ganha antes de contar especificidade, por isso o parágrafo fica azul. Regras normais sem camada ficam acima das normais com camada. A prioridade das camadas inverte-se para declarações importantes.

Herança é outro mecanismo. `color` e propriedades de texto costumam herdar; margem, borda e padding não. Uma declaração diretamente no filho vence um valor herdado, mesmo que o seletor no pai tenha muitos IDs. `inherit` pede o valor calculado do pai; `initial` pede o valor inicial da propriedade; `unset` herda se a propriedade é herdada e usa o inicial nos restantes casos.

## Medidas e modelo de caixa

Uma caixa tem conteúdo, padding, border e margin. Com `box-sizing: content-box`, a largura declarada mede o conteúdo. Se temos `width: 240px`, padding de 12px em cada lado e border de 2px:

$$
\text{largura até à borda}=240+2\times12+2\times2=268\text{ px}.
$$

Com margem de 10px em cada lado, a ocupação horizontal é 288px. Com `border-box`, os mesmos 240px já incluem padding e borda, e o conteúdo tem 212px. A margem continua fora dos 240px.

No diagrama, confirma onde ficam os extremos de `width: 240px`: em `content-box` ficam nas extremidades do conteúdo; em `border-box`, nas extremidades exteriores da borda. As margens ficam fora de `width` nos dois casos.

As abreviaturas seguem os lados da caixa. `padding: 4px` aplica 4px aos quatro lados. `padding: 4px 8px` dá 4px em cima e em baixo e 8px nos lados; `padding: 4px 8px 12px` dá 4px em cima, 8px nos lados e 12px em baixo. Com quatro valores, a ordem é cima, direita, baixo, esquerda. `max-width` limita uma largura flexível; `overflow: auto` permite deslocar conteúdo que não cabe, sem o apagar.

Margens verticais de blocos em fluxo normal podem colapsar. Duas margens positivas de 16px e 24px dão 24px entre os blocos, não 40px. Essa regra não se aplica da mesma forma aos itens flex e grid. Padding não colapsa.

`rem` usa o tamanho de letra da raiz. `em` em `font-size` usa o tamanho do pai; em outras propriedades, usa o tamanho de letra do próprio elemento. Se a raiz tem 16px e um filho usa `font-size: 2em` dentro de um pai com 20px, o filho tem 40px. Nesse filho, `padding: 1em` mede 40px, mas `padding: 1rem` mede 16px. Percentagens dependem da propriedade e da caixa de referência. `vw` e `vh` dependem do viewport.

## Fluxo e posicionamento

Um bloco participa normalmente numa sequência vertical. Um elemento inline participa nas linhas de texto, com regras de largura e altura diferentes. `inline-block` participa na linha e aceita dimensões de caixa. `display: none` retira a caixa do layout; `visibility: hidden` conserva o espaço.

| `position` | Efeito                                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| `static`   | Fluxo normal; `top` e `left` não deslocam a caixa                                                          |
| `relative` | Desloca visualmente e conserva o lugar original                                                            |
| `absolute` | Sai do fluxo; posiciona-se pela caixa de referência, frequentemente o antepassado posicionado mais próximo |
| `fixed`    | Sai do fluxo e, no caso habitual, usa o viewport                                                           |
| `sticky`   | Permanece no fluxo e fica preso ao limite definido durante o scroll                                        |

Compara com dois casos. Com `relative`, a caixa desloca-se visualmente mas conserva o lugar original, e os vizinhos não se movem. Com `absolute`, a caixa sai do fluxo e posiciona-se pela caixa de referência, normalmente o antepassado posicionado mais próximo. Um antepassado transformado também pode estabelecer essa referência, incluindo para `fixed`. `z-index` compara níveis dentro de contextos de empilhamento; um filho não salta arbitrariamente acima de um contexto exterior. Para texto à volta de uma imagem usa `float: left` na imagem e `clear: both` no bloco que deve recomeçar abaixo. Para grelhas e alinhamento, usa flexbox ou grid.

## Flexbox e grid

Flexbox dispõe itens principalmente num eixo. `flex-direction` define o eixo principal; `justify-content` alinha nesse eixo e `align-items` no transversal. `flex-wrap` permite novas linhas. `flex: 1 1 200px` dá crescimento 1, redução 1 e base de 200px, não uma largura fixa garantida.

Grid define linhas e colunas. `1fr` reparte espaço disponível, depois de considerar outras medidas e limites. `minmax(0, 1fr)` permite uma coluna reduzir sem o mínimo automático do conteúdo a forçar o layout. `gap` cria intervalos entre itens. `grid-column: 1 / 3` vai da linha 1 à linha 3 e ocupa duas colunas. `grid-template-areas` dá nomes a zonas retangulares.

## Cor, variáveis e movimento

Cor pode usar nomes, hexadecimal, `rgb` ou `hsl`. O fundo pertence à caixa definida por `background`; `background-size: cover` pode cortar a imagem para cobrir a área. A fonte deve ter uma família de recurso, e `line-height` sem unidade acompanha o tamanho da letra.

```css
:root {
  --cor-livro: #345;
}
.livro {
  border-color: var(--cor-livro);
}
button {
  transition: transform 150ms ease;
}
button:hover {
  transform: translateY(-2px);
}
@media (prefers-reduced-motion: reduce) {
  button {
    transition: none;
  }
}
```

Uma custom property participa na cascata e costuma herdar. `transform` muda o desenho da caixa sem reservar um novo lugar no fluxo. `transition` interpola uma alteração de propriedade; não inicia por si uma sequência repetida. Testa o layout com textos longos, zoom e largura pequena. Uma media query responde ao ambiente, mas não corrige uma largura mínima que já não cabe.
