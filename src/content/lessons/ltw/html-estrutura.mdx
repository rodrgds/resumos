Uma página HTML descreve o significado e a ordem do conteúdo. Um título continua a ser um título sem CSS, ou seja o navegador percebe a hierarquia antes de qualquer estilo. Um botão continua ativável por teclado. É essa estrutura que o navegador transforma numa árvore, o DOM, que o JavaScript pode depois alterar.

## Cliente e servidor

Ao abrir uma página dinâmica, o navegador envia um pedido HTTP. O servidor executa o PHP, consulta os dados e responde com HTML. O navegador interpreta esse HTML e pode fazer novos pedidos para CSS, imagens e JavaScript.

Internet é a rede que transporta dados; a Web é um dos serviços que a usa. O DNS permite obter endereços IP a partir de um nome como `biblioteca.example`. O navegador liga-se ao servidor e, em HTTPS, estabelece uma ligação protegida por TLS antes de trocar as mensagens HTTP. O pedido pode ser respondido sem consultar uma base de dados, por exemplo quando serve uma imagem.

O código PHP não chega ao navegador, por isso abrir `pagina.php` como ficheiro local não substitui um servidor. Alterar o DOM com JavaScript só muda o estado daquela página; não guarda nada na base de dados.

## Documento, elementos e atributos

Este é um documento completo:

```html
<!doctype html>
<html lang="pt-PT">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Catálogo da biblioteca</title>
    <link rel="stylesheet" href="estilo.css" />
    <script src="catalogo.js" defer></script>
  </head>
  <body>
    <header><h1>Biblioteca</h1></header>
    <nav aria-label="Principal"><a href="/livros/">Livros</a></nav>
    <main>
      <article>
        <h2>Redes de computadores</h2>
        <p>Disponível para reserva.</p>
      </article>
    </main>
  </body>
</html>
```

O `doctype` pede o modo de renderização normal. `lang` declara a língua. O `head` contém metadados, incluindo o título do separador; o `body` contém o conteúdo. `defer` permite descarregar o script durante a leitura do HTML e executá-lo depois de analisar o documento. Não confere execução assíncrona a cada linha do programa.

Um elemento habitual tem etiqueta de abertura, conteúdo e etiqueta de fecho. Os elementos vazios, como `img`, `input` e `meta`, não têm conteúdo nem etiqueta de fecho. Os atributos acrescentam informação à abertura. `id` identifica um elemento e deve ser único no documento; `class` pode listar várias classes e repetir-se em vários elementos.

```html
<p id="aviso" class="mensagem urgente">Só resta um exemplar.</p>
```

`aviso` é o identificador; `mensagem` e `urgente` são duas classes. Um atributo booleano, como `disabled`, vale pela presença. Escrever `disabled="false"` continua a desativar o controlo.

## Escolher a etiqueta

`main` identifica o conteúdo principal. `nav` agrupa navegação. `article` representa conteúdo que pode ser lido por si, como uma notícia; `section` agrupa uma secção temática, normalmente com título. `header` e `footer` podem pertencer à página ou a um artigo. `div` e `span` agrupam conteúdo sem lhe acrescentar significado.

Usa `a` para navegar e `button` para agir. Dentro de um formulário, declara `type="button"` num botão que não deve submeter. Usa `ul` para uma lista sem ordem relevante, `ol` para passos ordenados e `dl` para pares de termos e descrições. Não uses níveis de título para escolher o tamanho da letra; respeita a hierarquia do conteúdo e altera o aspeto com CSS.

`strong` indica importância; `em` dá ênfase. `code` marca código e `pre` preserva espaços e mudanças de linha. No texto normal, o navegador colapsa sequências de espaços. Escreve `&lt;` para mostrar `<` e `&amp;` para mostrar `&` quando precisam de ser texto.

Uma imagem informativa precisa de `alt` que comunique a informação relevante. Uma imagem decorativa tem `alt=""`. `figure` pode reunir imagem e `figcaption`. Para áudio e vídeo, `controls` oferece controlos nativos; legendas e transcrições dão acesso à informação sem depender do som. SVG descreve formas; canvas oferece uma área onde um programa desenha píxeis.

## Ligações e caminhos

Em `https://biblioteca.example/livros/?q=redes#resultados`, o fragmento `resultados` aponta para um `id` da página. O fragmento não é enviado no pedido HTTP. `href="/livros/"` começa na raiz do sítio; `href="capa.png"` resolve relativamente ao endereço do documento; `../` sobe um nível do caminho.

Para prever um caminho relativo, substitui o último segmento da base, não o domínio inteiro. A partir de `https://biblioteca.example/catalogo/item.html`, `../ajuda.html` resolve para `https://biblioteca.example/ajuda.html`.

## Tabelas

Uma tabela representa dados em linhas e colunas. A legenda explica o conjunto, e os cabeçalhos identificam o significado das células:

```html
<table>
  <caption>
    Exemplares disponíveis
  </caption>
  <thead>
    <tr>
      <th scope="col">Livro</th>
      <th scope="col">Exemplares</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Redes</th>
      <td>3</td>
    </tr>
    <tr>
      <th scope="row">SQL</th>
      <td>1</td>
    </tr>
  </tbody>
</table>
```

`rowspan` ocupa várias linhas e `colspan` ocupa várias colunas. Uma célula com `rowspan="2"` ocupa também a sua coluna na linha seguinte: não escrevas outra célula para essa posição. Uma célula com `colspan="2"` consome duas posições na própria linha. Desenha a grelha e marca as posições já ocupadas antes de acrescentar as restantes células. Usa CSS, não tabelas, para dispor o menu e o conteúdo de uma página.

## Formulários e dados enviados

Um formulário define o destino em `action` e o método em `method`. Com `GET`, os parâmetros aparecem na query string, apropriada para uma pesquisa. Com `POST`, a codificação habitual coloca-os no corpo do pedido. `POST` não cifra os dados; HTTPS é que protege o transporte.

Escreve `Ana` e quantidade `2`: sem a caixa de aviso obténs `nome=Ana&quantidade=2`; ao marcá-la, acrescenta `&aviso=sim`. O `id` liga o campo à sua `label`; o `name` dá o nome do parâmetro. Trocar `id` sem atualizar `for` quebra a associação, e remover `name` faz desaparecer o parâmetro.

A submissão inclui controlos com nome que participam no envio. Uma checkbox não marcada não envia valor; se não tiver `value`, a marcada usa normalmente `on`. Num grupo de radio buttons com o mesmo `name`, só a opção selecionada envia. Um campo `disabled` não envia; um campo `readonly` continua a enviar quando o tipo admite esse atributo. O botão de submissão acionado pode também enviar o seu par nome/valor.

`select` envia o valor da opção selecionada. Um `select multiple` pode enviar vários valores com o mesmo nome. `textarea` escreve o valor inicial entre as etiquetas. `fieldset` e `legend` dão nome a um grupo de controlos. Um `datalist` ligado a um `input` por `list` sugere valores, mas permite escrever outro; um `select` limita a escolha às suas opções. `type="password"` oculta o desenho dos caracteres, não os cifra. `type="hidden"` esconde o controlo na página, mas o cliente pode alterar o valor. Um upload exige `method="post"` e `enctype="multipart/form-data"`; o servidor tem de validar o ficheiro recebido.

## Validação e limites

`required`, `min`, `max`, `minlength`, `maxlength`, tipos como `email` e `pattern` ajudam o utilizador antes do envio. `placeholder` é uma sugestão que desaparece ao escrever, não substitui uma `label`. `type="tel"` pode escolher um teclado útil, mas não impõe sozinho um formato de número.

A validação do navegador pode ser contornada, por isso o PHP precisa de verificar de novo presença, tipo, limites e permissões. A quantidade zero pode chegar ao servidor mesmo quando o formulário tem `min="1"`.

Se o DOM não corresponde ao que escreveste, verifica aninhamento e elementos permitidos. Em `<p>Texto<div>Bloco</div></p>`, o navegador fecha o parágrafo antes do `div`. O inspetor mostra a árvore real, e o validador identifica erros estruturais.
