<Exercise
  id="ltw-seletores-cascata"
  title="Selecionar e decidir a cor"
  explanation="/cadeiras/ltw/css-estilo-layout/#cascata-e-herança"
  answer={{"kind": "self", "checklist": ["Contei as duas especificidades empatadas.", "Expliquei inherit a partir do ul azul."]}}
>

Prevê a cor de B. Considera regras normais do autor sem camadas e sem outras declarações.

```html
<section id="zona">
  <ul class="lista">
    <li>A</li>
    <li class="ativo">B</li>
  </ul>
</section>
```

```css
#zona {
  color: blue;
}
.lista li {
  color: green;
}
section .lista > li.ativo {
  color: red;
}
.lista li:first-child + li {
  color: inherit;
}
```

<div slot="hint">

A regra no section fornece herança; as restantes atingem diretamente B.

</div>
<div slot="hint-more">

As duas últimas têm (0,2,2). A última declara inherit.

</div>
<div slot="solution">

B fica azul. A segunda regra tem (0,1,1). A terceira e a quarta têm (0,2,2), por isso a quarta ganha pela posição e pede inherit. O ul herda blue de #zona; B herda esse valor do seu pai. Não é o ID do antepassado que ganha diretamente sobre o seletor de B.

</div>
<div slot="mistakes">

Não comparar a especificidade do pai com declarações diretas do filho.

</div>
</Exercise>

<Exercise
  id="ltw-medir-caixa"
  title="Medir uma caixa"
  explanation="/cadeiras/ltw/css-estilo-layout/#medidas-e-modelo-de-caixa"
  answer={{"kind": "self", "checklist": ["Obtive 202/212 em content-box.", "Obtive 180/190 e conteúdo 158 em border-box."]}}
>

Uma caixa tem width 180px, padding 8px de cada lado, border 3px de cada lado e margin 5px de cada lado. Calcula a largura até à borda e a ocupação com margens em content-box. Repete em border-box.

<div slot="hint">

Padding e border somam-se ao conteúdo em content-box.

</div>
<div slot="hint-more">

Em border-box, width já inclui padding e border, mas não margin.

</div>
<div slot="solution">

Em content-box: 180+16+6=202px até à borda, e 212px com margens. Em border-box: 180px até à borda e 190px com margens; o conteúdo mede 158px. Os valores horizontais não dependem de colapso de margens verticais.

</div>
<div slot="mistakes">

Não somar padding e border de novo ao width de border-box.

</div>
</Exercise>

<Exercise
  id="ltw-posicao-irmaos"
  title="Distinguir filho e irmão"
  explanation="/cadeiras/ltw/css-estilo-layout/#seletores"
  answer={{"kind": "self", "checklist": ["Distingui um irmão de todos os posteriores.", "Identifiquei span como alvo do terceiro seletor."]}}
>

Num ul há quatro li, com classes primeiro, segundo, terceiro e quarto. O segundo tem um span filho. Quais li escolhem `li.primeiro + li`, `li.primeiro ~ li` e `li > span`? Justifica.

<div slot="hint">

Os combinadores + e ~ ligam irmãos posteriores.

</div>
<div slot="hint-more">

O tipo selecionado é o que está no extremo direito do seletor.

</div>
<div slot="solution">

O primeiro seletor escolhe só o segundo li. O segundo escolhe segundo, terceiro e quarto. O terceiro não escolhe nenhum li: escolhe o span filho direto do segundo li. Combinadores descrevem relações, não mudam o tipo da seleção final.

</div>
<div slot="mistakes">

Não dizer que li > span escolhe o pai li.

</div>
</Exercise>

<Exercise
  id="ltw-layout-responsivo"
  title="Construir duas colunas"
  explanation="/cadeiras/ltw/css-estilo-layout/#flexbox-e-grid"
  answer={{"kind": "self", "checklist": ["Defini a largura pequena e a condição >=700px.", "Usei espaço automático antes do botão."]}}
>

Escreve CSS para .catalogo com uma coluna abaixo de 700px e duas colunas iguais a partir de 700px, gap 16px. Dentro de cada .livro, alinha o botão no fundo sem fixar a altura do texto.

<div slot="hint">

Usa grid no catálogo e flex em coluna no cartão.

</div>
<div slot="hint-more">

A media query pode mudar grid-template-columns; a margem automática absorve espaço antes do botão.

</div>
<div slot="solution">

Uma solução é:

```css
.catalogo {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}
.livro {
  display: flex;
  flex-direction: column;
}
.livro button {
  margin-top: auto;
}
@media (min-width: 700px) {
  .catalogo {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}
```

A grelha estica os cartões na linha por defeito. A margem automática aproveita o espaço vertical livre antes do botão.

</div>
<div slot="mistakes">

Não mudar apenas width dos cartões sem definir o layout, nem trocar o eixo principal pelo transversal.

</div>
</Exercise>
