<Exercise
  id="ltw-envio-controlos"
  title="Prever os parâmetros"
  explanation="/cadeiras/ltw/html-estrutura/#formulários-e-dados-enviados"
  answer={{"kind": "self", "checklist": ["Identifiquei os três pares enviados.", "Justifiquei disabled, checkbox e ausência de name."]}}
>

O utilizador escreve Ana, não marca a checkbox e prime o botão. Escreve os pares enviados e explica as exclusões.

```html
<form method="post">
  <input id="nome" name="pessoa" value="Ana" />
  <input name="codigo" value="R7" disabled />
  <input name="sala" value="B2" readonly />
  <input type="checkbox" name="aviso" value="sim" />
  <input value="oculto-sem-nome" type="hidden" />
  <button name="acao" value="reservar">Reservar</button>
</form>
```

<div slot="hint">

Começa pelos controlos com name. Depois verifica disabled e seleção.

</div>
<div slot="hint-more">

O botão acionado também tem name/value; readonly não é disabled.

</div>
<div slot="solution">

Os pares são pessoa=Ana, sala=B2 e acao=reservar. codigo está disabled; aviso não está marcado; o hidden não tem name. O id nome não determina o nome enviado.

</div>
<div slot="mistakes">

Não enviar a checkbox como false, não excluir readonly e não trocar id por name.

</div>
</Exercise>

<Exercise
  id="ltw-estrutura-acessivel"
  title="Corrigir uma página"
  explanation="/cadeiras/ltw/html-estrutura/#escolher-a-etiqueta"
  answer={{"kind": "self", "checklist": ["Usei ligação com href para navegar.", "Corrigi o aninhamento e expliquei a árvore real."]}}
>

Uma página usa `<div onclick="abrir()">Ajuda</div>` para navegar para ajuda.html e `<p>Escolhe<div>Livro</div></p>` para um bloco. Corrige os dois fragmentos e explica o efeito para teclado e DOM.

<div slot="hint">

Pergunta se a primeira interação navega ou executa uma ação local.

</div>
<div slot="hint-more">

Uma ligação usa href. Um div não pode permanecer dentro de um p nessa posição.

</div>
<div slot="solution">

Usa `<a href="ajuda.html">Ajuda</a>`. O navegador dá à ligação foco e ativação por teclado. Para o segundo, usa `<div><p>Escolhe</p><div>Livro</div></div>`, se o bloco separado for mesmo necessário. O HTML original fecha implicitamente o parágrafo antes do div, alterando a árvore.

</div>
<div slot="mistakes">

Adicionar apenas tabindex ao div não lhe dá toda a semântica de uma ligação.

</div>
</Exercise>

<Exercise
  id="ltw-caminho-fragmento"
  title="Resolver um endereço"
  explanation="/cadeiras/ltw/html-estrutura/#ligações-e-caminhos"
  answer={{"kind": "self", "checklist": ["Resolvi o URL para /livros/item.html.", "Separei query de fragmento."]}}
>

A página está em https://catalogo.example/ano/lista.html. Resolve `../livros/item.html?id=8#reserva`. Qual o caminho e a query enviados ao servidor?

<div slot="hint">

Resolve o endereço relativamente à pasta /ano/.

</div>
<div slot="hint-more">

O fragmento é interpretado no cliente.

</div>
<div slot="solution">

O URL é https://catalogo.example/livros/item.html?id=8#reserva. O alvo HTTP é /livros/item.html?id=8. A parte #reserva não é enviada, mesmo que o servidor produza a página.

</div>
<div slot="mistakes">

Não anexar ../ ao nome completo lista.html nem enviar o fragmento na query.

</div>
</Exercise>
