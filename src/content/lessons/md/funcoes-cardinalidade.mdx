Uma função $f:A\to B$ associa a cada elemento de $A$ exatamente um elemento de $B$. A fórmula de cálculo não define tudo: o domínio e o contradomínio podem mudar as propriedades da mesma expressão.

## Total e funcional

Uma função é uma relação com duas condições:

- **Totalidade:** para cada $a\in A$, existe $b\in B$ com $(a,b)\in f$.
- **Funcionalidade:** se $(a,b)\in f$ e $(a,c)\in f$, então $b=c$.

Uma relação só funcional é uma função parcial. Não tem necessariamente um valor para todas as origens. A imagem é $f(A)=\operatorname{rng}(f)=\{f(a):a\in A\}$; pode ser menor do que o contradomínio $B$.

Se $A=\{1,2,3\}$ e $B=\{a,b,c\}$, a relação $\{(1,a),(2,a),(3,b)\}$ é função. Não atingir $c$ não viola totalidade. Já $\{(1,a),(1,b),(2,c),(3,c)\}$ é total e não funcional.

Os conjuntos vazios também têm de ser tratados. Existe uma única função $\emptyset\to B$, a relação vazia. Se $A\ne\emptyset$, não existe função $A\to\emptyset$.

## Injetiva, sobrejetiva e bijetiva

Uma função é **injetiva** se valores iguais só vêm de origens iguais:

$$
\forall a_1,a_2\in A,
\quad f(a_1)=f(a_2)\to a_1=a_2.
$$

É **sobrejetiva** se atinge todo o contradomínio:

$$
\forall b\in B,\quad\exists a\in A,\quad f(a)=b.
$$

É **bijetiva** se tem ambas as propriedades. Cada destino tem exatamente uma origem.

Para provar injetividade, começa com $f(a_1)=f(a_2)$ e tenta obter $a_1=a_2$. Para a refutar, apresenta duas origens distintas com o mesmo valor. Para provar sobrejetividade, toma um $b$ arbitrário do contradomínio e encontra uma origem admissível. Para a refutar, apresenta um destino que nunca é atingido.

## O domínio muda a resposta

Considere-se a expressão $f(x)=x^2$:

| Função                    | Injetiva?                                           | Sobrejetiva?                            |
| ------------------------- | --------------------------------------------------- | --------------------------------------- |
| $\mathbb Z\to\mathbb Z$   | Não, $f(1)=f(-1)$.                                  | Não, por exemplo não atinge $-1$ nem 2. |
| $\mathbb N\to\mathbb N$   | Sim, dois naturais com quadrados iguais são iguais. | Não, 2 não é quadrado de um natural.    |
| $[0,\infty)\to[0,\infty)$ | Sim.                                                | Sim, a origem de $y$ é $\sqrt y$.       |

Resolver $x^2=y$ em $\mathbb R$ não prova sobrejetividade em $\mathbb Z$, porque a origem tem de pertencer ao domínio indicado.

Para $g:\mathbb Z\to\mathbb Z$, $g(x)=2x-3$, a injetividade vem de $2x-3=2y-3\Rightarrow x=y$. A imagem são os inteiros ímpares: todo o resultado é ímpar e, dado um ímpar $2k+1$, a origem $k+2$ serve. Não é sobrejetiva para $\mathbb Z$, mas é bijetiva para esse conjunto de ímpares.

## Inversa como relação e como função

A relação $f^{-1}$ existe sempre: troca os pares. Para ser uma função $B\to A$, precisa de totalidade e funcionalidade.

- Se $f$ é injetiva, $f^{-1}$ é funcional, mas pode faltar uma origem para algum $b\in B$.
- Se $f$ é sobrejetiva, $f^{-1}$ é total, mas pode ter vários destinos para uma mesma origem.
- Se $f$ é bijetiva, $f^{-1}$ é uma função total.

Para uma função total $f:A\to B$:

$$
\begin{aligned}
f\text{ é injetiva}&\Longleftrightarrow f^{-1}\circ f=\operatorname{id}_A,\\
f\text{ é sobrejetiva}&\Longleftrightarrow f\circ f^{-1}=\operatorname{id}_B.
\end{aligned}
$$

O par $(a_1,a_2)$ pertence a $f^{-1}\circ f$ se $f(a_1)=f(a_2)$. Por isso, a primeira igualdade diz que as únicas origens com imagem igual são as iguais. Já $f\circ f^{-1}$ é a identidade sobre a imagem de $f$, que coincide com $B$ precisamente no caso sobrejetivo.

Para uma relação geral $R\subseteq A\times B$, a totalidade equivale a $\operatorname{id}_A\subseteq R^{-1}\circ R$ e a funcionalidade a $R\circ R^{-1}\subseteq\operatorname{id}_B$. Estas inclusões não pressupõem que $R$ já seja função.

## Composição

Para $f:A\to B$ e $g:B\to C$, $(g\circ f)(x)=g(f(x))$. Aplicamos primeiro $f$.

Se ambas são injetivas, a composição é injetiva: $g(f(x))=g(f(y))$ implica $f(x)=f(y)$ e depois $x=y$. Se ambas são sobrejetivas, para cada $c\in C$ existe $b\in B$ com $g(b)=c$ e depois $a\in A$ com $f(a)=b$.

A recíproca exige cuidado. Se $g\circ f$ é injetiva, $f$ tem de ser injetiva, mas $g$ pode falhar injetividade fora da imagem de $f$. Se $g\circ f$ é sobrejetiva, $g$ tem de ser sobrejetiva, mas $f$ pode não atingir todo o $B$.

Para bijeções, a inversa inverte a ordem:

$$
(g\circ f)^{-1}=f^{-1}\circ g^{-1}.
$$

## Cardinalidade finita e infinita

Dois conjuntos têm a mesma cardinalidade quando existe uma bijeção entre eles. Para conjuntos finitos, uma injeção $A\to B$ exige $|A|\le|B|$ e uma sobrejeção exige $|A|\ge|B|$. Se ambos são finitos e têm o mesmo tamanho, uma função é injetiva se e só se é sobrejetiva.

Para conjuntos infinitos, um subconjunto próprio pode ter a mesma cardinalidade que o conjunto. $n\mapsto2n$ é uma bijeção de $\mathbb N$ para os naturais pares. O subconjunto tem menos elementos no sentido de inclusão, mas não no sentido de cardinalidade.

Uma bijeção $h:\mathbb N\to\mathbb Z$ é:

$$
h(n)=\begin{cases}
 n/2,&n\text{ par},\\
 -(n+1)/2,&n\text{ ímpar}.
\end{cases}
$$

A sequência de imagens é $0,-1,1,-2,2,\ldots$. A inversa é $h^{-1}(z)=2z$ para $z\ge0$ e $h^{-1}(z)=-2z-1$ para $z<0$. As duas fórmulas mostram que cada inteiro tem uma origem e que essa origem é única.

Um conjunto é **numerável** se é finito ou tem bijeção com $\mathbb N$. Os racionais são numeráveis: podemos percorrer pares numerador-denominador por diagonais e omitir frações repetidas. Os reais não são numeráveis. Não concluas que dois conjuntos têm a mesma cardinalidade só porque ambos são infinitos.
