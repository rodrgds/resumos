<Exercise
  id="md-equivalencia-mod-4"
  title="Equivalência por congruência"
  explanation="/cadeiras/md/conjuntos-relacoes/#uma-equivalência-definida-por-uma-conta"
  answer={{"kind": "self", "checklist": ["Relacionei a condição com a congruência módulo 4.", "Justifiquei as três propriedades.", "Escrevi quatro classes disjuntas que cobrem os inteiros."]}}
>

Em $\mathbb Z$, define $aRb$ se $4\mid(a+3b)$. Prova que é uma equivalência e escreve as classes de 0, 1, 2 e 3.

<div slot="hint">

$a+3b=(a-b)+4b$.

</div>

<div slot="hint-more">

A relação equivale a $a\equiv_4 b$. Usa diferenças para as três propriedades.

</div>

<div slot="solution">

$4\mid(a+3b)$ equivale a $4\mid(a-b)$. É reflexiva porque $a-a=0$; simétrica porque trocar os termos nega a diferença; transitiva porque $(a-b)+(b-c)=a-c$. As classes são $[r]=\{4k+r:k\in\mathbb Z\}$, para $r=0,1,2,3$. Todo o inteiro tem exatamente um destes restos.

</div>

<div slot="mistakes">

As classes não são os conjuntos {0}, {1}, {2}, {3}. Cada uma contém infinitos inteiros, incluindo negativos.

</div>

</Exercise>

<Exercise
  id="md-particao-relacao"
  title="Construir uma relação a partir de uma partição"
  explanation="/cadeiras/md/conjuntos-relacoes/#relações-de-equivalência-e-partições"
  answer={{"kind": "self", "checklist": ["Incluí os pares dentro de cada bloco.", "Incluí todos os laços e as duas direções entre 1 e 3.", "Concluí R composto com R igual a R e justifiquei as inclusões."]}}
>

Em $A=\{1,2,3,4\}$, usa a partição $\{\{1,3\},\{2\},\{4\}\}$ para construir uma equivalência. Lista os pares e calcula $R\circ R$.

<div slot="hint">

Dois elementos relacionam-se quando pertencem ao mesmo bloco.

</div>

<div slot="hint-more">

Cada bloco $B$ contribui $B\times B$. Para a composição, usa reflexividade e transitividade.

</div>

<div slot="solution">

$R=\{(1,1),(1,3),(3,1),(3,3),(2,2),(4,4)\}$. Pela transitividade, $R\circ R\subseteq R$. Pela reflexividade, qualquer $(a,b)\in R$ pode usar $b$ como intermédio, pois $(b,b)\in R$, logo $R\subseteq R\circ R$. Portanto $R\circ R=R$.

</div>

<div slot="mistakes">

Não ligues elementos de blocos diferentes e não omitas os blocos com um só elemento.

</div>

</Exercise>
