<Exercise
  id="md-inducao-soma-impares"
  revision={1}
  title="Uma soma por indução"
  explanation="/cadeiras/md/inducao-recorrencia/#soma-dos-quadrados"
  answer={{"kind": "self", "checklist": ["Verifiquei a base n = 0.", "Escrevi a hipótese para n e o objetivo para n + 1.", "Separei o novo termo e usei a hipótese apenas na soma antiga."]}}
>

Prova $\sum_{i=1}^{n}(2i-1)=n^2$ para todo o $n\in\mathbb N$, interpretando a soma vazia como 0.

<div slot="hint">

Na passagem ao sucessor, o novo termo é $2n+1$.

</div>

<div slot="hint-more">

$n^2+(2n+1)=(n+1)^2$.

</div>

<div slot="solution">

Base: para $n=0$, a soma é $0=0^2$. Passo: supondo $\sum_{i=1}^n(2i-1)=n^2$, temos $\sum_{i=1}^{n+1}(2i-1)=n^2+2(n+1)-1=n^2+2n+1=(n+1)^2$. Pelo princípio de indução, a igualdade vale para todos os naturais.

</div>

<div slot="mistakes">

Usar diretamente a fórmula para n + 1 antes de a provar seria circular. A hipótese só fornece a fórmula para n.

</div>

</Exercise>

<Exercise
  id="md-recursao-quadrados"
  revision={2}
  title="Uma função recursiva com dois ramos"
  explanation="/cadeiras/md/inducao-recorrencia/#funções-recursivas"
  answer={{"kind": "self", "checklist": ["Conferi a base e que cada chamada usa um natural menor.", "No caso múltiplo de 3 apliquei a hipótese a n/3.", "Nos restantes casos apliquei a hipótese a n − 1."]}}
>

Define $f(0)=0$, $f(n)=9f(n/3)$ para $n>0$ múltiplo de 3 e $f(n)=f(n-1)+2n-1$ nos restantes casos positivos. Prova $f(n)=n^2$ por indução forte.

<div slot="hint">

A chamada do ramo múltiplo de 3 não é geralmente ao antecessor.

</div>

<div slot="hint-more">

Para $n>0$ múltiplo de 3, $n/3<n$. Nos outros casos positivos, $n-1<n$.

</div>

<div slot="solution">

Base: $f(0)=0^2$. Assume $f(k)=k^2$ para todos os $k<n$. Se $n$ é múltiplo positivo de 3, $f(n)=9(n/3)^2=n^2$. Caso contrário, $f(n)=(n-1)^2+2n-1=n^2$. Os argumentos recursivos são menores, por isso a hipótese forte aplica-se nos dois ramos.

</div>

<div slot="mistakes">

Indução simples fornece apenas a igualdade para o antecessor. Não autoriza automaticamente uma chamada em n/3.

</div>

</Exercise>
<Exercise
  id="md-inducao-grafos-ciclos"
  revision={1}
  title="Indução em ciclos pares"
  explanation="/cadeiras/md/inducao-recorrencia/#indução-simples"
  answer={{"kind": "self", "checklist": ["Exibi a construção de C2n para C2n+2.", "Usei a hipótese só no ciclo menor.", "Tratei a base C4 explicitamente."]}}
>

Prova por indução que o ciclo par $C_{2n}$ é bipartido para $n \ge 2$.

<div slot="hint">

Transforma $C_{2n}$ em $C_{2n+2}$ inserindo dois vértices numa aresta.

</div>

<div slot="hint-more">

Os dois vértices novos ficam em partes opostas.

</div>

<div slot="solution">

$C_4$ é bipartido com dois vértices de cada lado. Dado $C_{2n}$ bipartido, escolhe uma aresta $uv$ e substitui-a por $u-x-y-v$. Põe $x$ na parte de $v$ e $y$ na parte de $u$; as três arestas novas ligam partes opostas e o resto herda a bipartição pela hipótese. Logo $C_{2n+2}$ é bipartido.

</div>

<div slot="mistakes">

Não apliques a hipótese ao objeto que queres construir. Constrói o maior a partir do menor.

</div>

</Exercise>
