Depois de escolher o modelo para cada variável aleatória, esta página responde a como varia a média entre amostras.

Os valores de uma população variam entre unidades. A média de uma amostra também varia, mas entre **amostras**. A distribuição amostral, ou seja, a distribuição das médias entre amostras, descreve essa segunda variação.

## Estatística, estimador e estimativa

Antes de recolher dados, $X_1,\ldots,X_n$ são variáveis aleatórias e $\bar X=\sum_iX_i/n$ é uma estatística aleatória. Se a usamos para estimar $\mu$, chamamos-lhe estimador. Depois de observar $x_1,\ldots,x_n$, obtemos uma estimativa numérica $\bar x$.

Um estimador é não enviesado quando a sua esperança é o parâmetro. Para observações i.i.d. com média $\mu$ e variância finita $\sigma^2$,

$$E(\bar X)=\mu,\qquad \operatorname{Var}(\bar X)=\frac{\sigma^2}{n}.$$

A primeira igualdade vem da linearidade; a segunda usa a independência para somar variâncias. O **erro padrão** é o desvio padrão do estimador:

$$SE(\bar X)=\frac{\sigma}{\sqrt n},\qquad \widehat{SE}(\bar X)=\frac{s}{\sqrt n}$$

quando $\sigma$ é estimado. $s$ mede dispersão das observações; $s/\sqrt n$ estima a dispersão de médias. Quadruplicar n reduz este erro padrão para metade, mantendo o modelo e a variância.

### Exemplo: enumerar as amostras

Uma população tem valores 0 e 2, equiprováveis. Duas escolhas independentes com reposição produzem $(0,0),(0,2),(2,0),(2,2)$, cada par com probabilidade $1/4$.

As médias possíveis são 0, 1 e 2, com probabilidades $1/4,1/2,1/4$. A população tem média 1 e variância 1. A média amostral também tem esperança 1, mas variância $1/2$. Com apenas duas escolhas, a sua distribuição é discreta, não normal.

## Média normal: resultado exato

Se cada $X_i\sim N(\mu,\sigma^2)$ e as observações são independentes,

$$
\bar X\sim N\left(\mu,\frac{\sigma^2}{n}\right),\qquad
\sum_iX_i\sim N(n\mu,n\sigma^2).
$$

Não é necessário esperar por uma amostra grande. Se os tempos individuais são normais com média 20 e desvio 6, a média de nove tempos tem desvio $6/3=2$:

$$P(\bar X>23)=1-\Phi\left(\frac{23-20}{2}\right)\approx0,0668.$$

Usar o desvio individual 6 responderia a uma pergunta sobre um único tempo.

## Teorema do Limite Central

Para observações i.i.d. com média finita e variância $0<\sigma^2<\infty$, quando n cresce,

$$\frac{\bar X-\mu}{\sigma/\sqrt n}\ \xrightarrow{d}\ N(0,1).$$

Assim, $\bar X$ pode ser aproximadamente normal mesmo que os dados individuais sejam assimétricos. O teorema não transforma os dados em normais, não remove dependência nem corrige uma amostra enviesada.

A regra prática $n\ge30$ é útil em situações moderadas, mas não garante uma boa aproximação perante assimetria extrema ou caudas muito pesadas. Se não sabemos a forma populacional e n é pequeno, a aproximação normal da média pode não ser defensável.

**Exemplo.** Uma população não normal tem média 50 e desvio 14. Para 49 observações i.i.d., o erro padrão da média é 2. Sob aproximação normal,

$$P(48<\bar X<54)\approx\Phi(2)-\Phi(-1)\approx0,8186.$$

Escrevemos «aproximadamente» porque não foi assumida uma população normal.

O exemplo parte de uma população exponencial e simula médias para n igual a 1, 5 e 30; a linha normal de comparação usa média 10 e desvio $10/\sqrt n$. Compara a assimetria e a dispersão entre os três casos.

## Proporção amostral

Se X conta sucessos em n ensaios independentes com probabilidade p, $X\sim B(n,p)$. A proporção amostral é $\widehat P=X/n$:

$$E(\widehat P)=p,\qquad \operatorname{Var}(\widehat P)=\frac{p(1-p)}n.$$

Para a proporção ajustada $\widetilde P=(X+2)/(n+4)$,

$$
E(\widetilde P)=\frac{np+2}{n+4},\qquad
\operatorname{Var}(\widetilde P)=\frac{np(1-p)}{(n+4)^2}.
$$

O ajustamento introduz enviesamento $(2-4p)/(n+4)$ em direção a 0,5. Isso não impede que seja útil para construir intervalos; ser não enviesado não é o único critério de qualidade.

## Aproximar uma binomial

A aproximação $X\approx N(np,np(1-p))$ usa, como critério prático, **$n>25$ e $\min\{np,n(1-p)\}>5$**. A contagem é discreta e a normal é contínua, pelo que fazemos correção de continuidade:

| Acontecimento | Intervalo da normal aproximante Y |
| ------------- | --------------------------------- |
| $X\le k$      | $Y<k+0,5$                         |
| $X\ge k$      | $Y>k-0,5$                         |
| $X=k$         | $k-0,5<Y<k+0,5$                   |
| $a\le X\le b$ | $a-0,5<Y<b+0,5$                   |

### Exemplo: transformar percentagens em contagens

Se $X\sim B(80;0,4)$, perguntar se pelo menos 45% têm sucesso significa $X\ge36$. As condições verificam-se: n é 80, $np=32$ e $n(1-p)=48$.

A normal aproximante tem média 32 e desvio $\sqrt{19,2}\approx4,3818$. Com correção,

$$
P(X\ge36)\approx P(Y>35,5)
=1-\Phi\left(\frac{35,5-32}{\sqrt{19,2}}\right)\approx0,2122.
$$

Para «pelo menos 45%» noutro tamanho de amostra, arredonda a contagem mínima **para cima** antes da correção. Para probabilidade de uma contagem exata, usa a faixa de largura 1; uma normal dá probabilidade zero a um ponto isolado.
