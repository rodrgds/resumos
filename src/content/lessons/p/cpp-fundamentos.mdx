Vens de Python e queres o primeiro programa C++ a correr. Esta página constrói esse programa, explica cada peça e mostra onde C++ decide de forma diferente: nos tipos dos operandos.

Uma receita enumera passos por ordem para chegar a um resultado. Um **programa** é a mesma ideia para um computador: uma lista de instruções escritas de forma exata, que o computador segue por ordem.

Este programa completo escreve uma mensagem fixa no ecrã:

```cpp
#include <iostream>

int main() {
    std::cout << "Olá\n";
}
```

Ao correr o programa, vês `Olá` numa linha. A primeira linha traz a ferramenta de escrita no ecrã; o bloco `int main()` marca onde o computador começa; a linha do meio escreve o texto. Cada instrução simples termina com `;`. Blocos delimitados por chavetas não levam `;` adicional. `\n` dentro do texto muda de linha. As secções abaixo explicam cada peça.

Uma mensagem fixa chega para começar, mas um programa útil guarda valores que mudam, como uma quantidade ou um preço. Cada valor fica numa **variável**: um espaço com nome para guardar um valor. Cada variável tem um **tipo**: a regra que diz que valores lá cabem e como cada expressão é calculada. Um **compilador** traduz o teu texto para a língua do computador e produz um **executável**: o ficheiro que corres para ver o resultado. Os exemplos acompanham os valores desde o que escreves (a entrada) até ao que aparece no ecrã (a saída).

## Declarar variáveis com tipos fixos

`int main()` define a função de entrada do programa, ou seja, o bloco onde o computador começa. As chavetas delimitam o corpo da função; cada declaração ou instrução simples termina com `;`. Chegar ao fim de `main` equivale a `return 0;`, que indica sucesso ao sistema. `\n` dentro de uma string representa uma mudança de linha.

`int` guarda inteiros, `double` guarda valores de vírgula flutuante, `char` guarda uma unidade de carácter e `bool` guarda `true` ou `false`. Um **objeto** é uma região de armazenamento com um tipo; uma variável dá-lhe um nome. Inicializa as variáveis antes da primeira leitura.

```cpp
// Excerto de declarações.
int quantidade = 0;
double preco = 2.75;
char letra = 'A';
bool encontrado = false;
const int limite = 20;
auto total = 3.5; // O compilador deduz double; o tipo continua fixo.
```

`const` impede alterar o objeto através desse nome. `auto` pede ao compilador que deduza o tipo a partir do inicializador, não adia a decisão para a execução. Uma inicialização com chavetas, como `int n{3};`, impede certas conversões que perdem informação. `int n{3.7};` é rejeitado; `int n = 3.7;` converte para `3`.

A largura de `int` e de `long` depende do sistema, por isso não assumes tamanhos fixos. Usa `sizeof(T)` para medir bytes e `<limits>` para consultar limites. Nos exemplos desta cadeira, `char` conta armazenamento, não letras visuais de Unicode.

## Operadores e divisão

`+`, `-`, `*`, `/` e `%` fazem operações aritméticas. `%` calcula o resto de uma divisão inteira. `==` compara; `=` atribui. Os operadores relacionais, como `<` e `>=`, produzem um `bool`.

<CodePlayground
  language="cpp"
  title="Tipos e divisão"
  code={
    '#include <iostream>\n\nint main() {\n    int a = 7;\n    int b = 2;\n    double truncado = a / b;\n    double quociente = static_cast<double>(a) / b;\n    std::cout << truncado << " " << quociente << "\\n";\n    std::cout << a % b << " " << std::boolalpha << (a > b) << "\\n";\n}\n'
  }
/>

Saída:

```text
3 3.5
1 true
```

A expressão `a / b` é avaliada antes da atribuição. Como os dois operandos são inteiros, o resultado é `3`, ou seja, só depois passa a `3.0` no destino. Com `static_cast<double>(a)`, convertes antes de dividir e obténs `3.5`.

A divisão inteira trunca em direção a zero. Por exemplo, `-7 / 2` dá `-3` e `-7 % 2` dá `-1`, mantendo `a == (a / b) * b + a % b` quando a operação é representável. Dividir um inteiro por zero tem comportamento indefinido. O overflow de um inteiro com sinal também tem comportamento indefinido; não podes contar com que volte ao menor valor. Os valores `double` são aproximados, por isso a igualdade exata nem sempre serve para comparar resultados de contas.

:::tip[Ideia-chave]

A divisão usa os tipos dos operandos, não o tipo do destino. Com dois inteiros, `7 / 2` vale `3`, por isso converte antes de dividir quando queres a fração.
:::

`&&` representa "e", `||` representa "ou" e `!` nega uma condição. Os dois primeiros usam **curto-circuito**, ou seja, em `n != 0 && soma / n > 10` a divisão só é avaliada se `n != 0`. Usa parênteses quando ajudam a ver a ordem. Não escrevas `0 <= nota <= 20`: C++ compara primeiro `0 <= nota`, produz `0` ou `1`, e compara esse resultado com `20`. Escreve `0 <= nota && nota <= 20`.

`++i` incrementa antes de produzir o valor; `i++` produz o valor anterior e incrementa. Num ciclo que ignora esse valor, ambos avançam uma posição. Evita alterar a mesma variável várias vezes na mesma expressão.

## Entrada e saída com iostream

`#include <iostream>` disponibiliza os fluxos padrão. `std::cout << valor` escreve; `std::cin >> valor` tenta extrair um valor do tipo da variável. `std::` indica o namespace da biblioteca padrão. Na condição de um `if` ou `while`, o fluxo vale falso se uma leitura anterior ativou `failbit` ou `badbit`. Encontrar o fim e ativar apenas `eofbit` não torna uma leitura bem-sucedida falsa. A página [Ficheiros e validação](/cadeiras/p/ficheiros/#ler-sem-antecipar-o-fim) desenvolve estes estados com registos completos.

Não uses uma variável como se a leitura tivesse resultado sem confirmar o estado do fluxo. Em `if (!(std::cin >> n))`, o programa deteta entrada ausente ou inválida. Esta validação é diferente de verificar se o valor está no intervalo permitido.

## Escolha com switch

Quando a escolha depende de um valor inteiro com casos fixos, `switch` evita uma cadeia de `if`. Cada `case` precisa de `break` (ou `return`) para não continuar no caso seguinte.

```cpp
// Excerto: classifica uma opção de menu.
int opcao = 2;
switch (opcao) {
    case 1: std::cout << "um\n"; break;
    case 2: std::cout << "dois\n"; break;
    default: std::cout << "outra\n"; break;
}
```

Com `opcao = 2`, o programa escreve `dois`. Sem o `break` do caso 1, escolher 1 executaria também o caso 2. O `default` trata os valores não listados.

## Escolha, iteração e âmbito

`if` executa um ramo conforme uma condição. `else` corresponde ao `if` sem `else` mais próximo. `switch` compara um valor integral ou enumeração com casos constantes; sem `break`, `return` ou outra saída, a execução continua no caso seguinte. `while` testa antes da iteração; `do ... while` testa depois e executa pelo menos uma vez.

O `for` separa inicialização, condição e avanço. Vamos ler uma quantidade de notas e contar as que são pelo menos `10`. O intervalo de notas deste exemplo é de `0` a `20` e a quantidade não pode exceder `1000`.

<CodePlayground
  language="cpp"
  title="Contar valores válidos"
  input={'5\n9 10 15 0 20'}
  code={
    '#include <iostream>\n\nint main() {\n    int quantidade = 0;\n    if (!(std::cin >> quantidade) || quantidade < 0 || quantidade > 1000) {\n        std::cout << "Quantidade invalida\\n";\n        return 0;\n    }\n    int aprovadas = 0;\n    for (int i = 0; i < quantidade; ++i) {\n        int nota = 0;\n        if (!(std::cin >> nota) || nota < 0 || nota > 20) {\n            std::cout << "Nota invalida\\n";\n            return 0;\n        }\n        if (nota >= 10) ++aprovadas;\n    }\n    std::cout << "Aprovadas: " << aprovadas << "\\n";\n}\n'
  }
/>

Saída:

```text
Aprovadas: 3
```

Segue o exemplo com entrada `5` e notas `9 10 15 0 20`:

| Antes da iteração `i` | Notas já lidas   | `aprovadas` |
| --------------------- | ---------------- | ----------- |
| 0                     | nenhuma          | 0           |
| 1                     | 9                | 0           |
| 2                     | 9, 10            | 1           |
| 3                     | 9, 10, 15        | 2           |
| 4                     | 9, 10, 15, 0     | 2           |
| 5                     | 9, 10, 15, 0, 20 | 3           |

Antes da iteração de índice `i`, já lemos `i` notas válidas e `aprovadas` conta apenas essas notas. Esta afirmação é um **invariante** do ciclo. A leitura seguinte e o `if` mantêm-no, e `++i` aproxima o fim. Quando `i` atinge a quantidade, todas as notas foram consideradas. Para quantidade zero, o corpo não corre.

`while` testa antes de cada iteração e pode correr zero vezes. `do ... while` testa depois e corre pelo menos uma vez. Usa `while` quando o corpo pode não fazer sentido nenhuma vez, como ler notas de uma quantidade que pode ser zero.

Uma variável declarada num bloco só é visível nesse bloco e nos blocos interiores que não a ocultam. O `i` declarado no `for` deixa de estar visível depois dele. Uma variável local normal tem duração automática: a sua vida termina ao sair do bloco. Âmbito indica onde o nome é visível; duração de vida indica quando o objeto existe. Não são a mesma coisa.

## Compilar e correr com g++

Guarda o programa num ficheiro `notas.cpp`. Num terminal com GCC disponível, na pasta do ficheiro, corre:

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic notas.cpp -o notas
./notas
```

O primeiro comando compila e liga o programa. `-o` escolhe o executável, `-std=c++17` fixa a linguagem e as opções `-W` ativam avisos. Se não houver erros, executa o segundo comando e introduz os números. Depois de mudares o código, volta a compilar, porque correr um executável antigo não valida a versão nova.

:::details[Toolchain no macOS e no Windows]

No macOS, o comando `g++` pode identificar o Clang. Confirma com `g++ --version`; os programas destas páginas usam C++17 portátil. No Windows, usa a toolchain indicada pela cadeira ou um terminal WSL com GCC. Projetos com vários ficheiros precisam de um ambiente local.
:::

## Projetos com CMake e CLion

CMake descreve que fontes formam cada executável. O CLion permite configurar a toolchain, correr o CMake e depurar. O IDE usa o compilador configurado, que não é necessariamente o mesmo em todas as máquinas.

```cmake
cmake_minimum_required(VERSION 3.16)
project(notas LANGUAGES CXX)
add_executable(notas main.cpp)
target_compile_features(notas PRIVATE cxx_std_17)
set_target_properties(notas PROPERTIES CXX_EXTENSIONS OFF)
```

Para este projeto, guarda o programa como `main.cpp` junto de `CMakeLists.txt` e corre `cmake -S . -B build`, seguido de `cmake --build build`. O executável aparece na pasta de build, ou numa subpasta da configuração escolhida. A página [Organizar e depurar programas](/cadeiras/p/organizar-programas/) desenvolve a compilação separada e o uso do depurador.

## Referências contra cópias

Uma função pode receber uma cópia ou dar acesso ao objeto original. A escolha faz parte do contrato, não depende de o tipo ser "imutável" noutra linguagem. Vê [Funções, arrays e texto](/cadeiras/p/funcoes-arrays/#valor-referência-e-const) para seguir a diferença linha a linha.

## Strings

`std::string` é o tipo habitual para texto e gere o seu armazenamento. `std::cin >> texto` lê até ao próximo espaço; `std::getline` lê uma linha. Os [exemplos de texto](/cadeiras/p/funcoes-arrays/#strings-e-linhas) distinguem estas duas operações e as strings de C.

## Ler e escrever ficheiros

Ficheiros usam fluxos como a entrada padrão, mas a abertura e os erros precisam de tratamento. A página [Ficheiros e validação](/cadeiras/p/ficheiros/#ler-sem-antecipar-o-fim) explica o ciclo correto e por que `while (!eof())` é inadequado.
