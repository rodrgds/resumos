Uma função de contagem pode receber as notas já lidas e devolver um total, sem tratar a entrada nem imprimir. O seu contrato indica que dados recebe, se os pode alterar e que resultado devolve. Separar estas decisões permite testar a contagem sem fornecer dados pelo teclado.

## Parâmetros e argumentos

Os **parâmetros** são os nomes declarados na função: `a` e `b` em `int maximo(int a, int b)`. Os **argumentos** são as expressões fornecidas na chamada: `4` e `9` em `maximo(4, 9)`. O parâmetro recebe uma cópia ou acesso conforme o contrato; o argumento diz qual o valor ou objeto usado nessa chamada.

## Declarar e chamar funções

A declaração `int maximo(int a, int b);` anuncia o tipo do resultado e dos parâmetros. A definição acrescenta o corpo. A declaração tem de estar visível antes da chamada; a definição necessária tem de existir quando o programa é ligado.

```cpp
// Excerto: definição de uma função.
int maximo(int a, int b) {
    return a > b ? a : b;
}
```

O operador condicional `condicao ? a : b` escolhe `a` se a condição é verdadeira e `b` caso contrário. Aqui `4 > 9` é falso, por isso `maximo(4, 9)` devolve `9`. Repara que `return` termina a chamada sem imprimir; o chamador decide se guarda, calcula ou imprime. Uma função `void` não devolve valor.

Uma **sobrecarga** usa o mesmo nome com listas de parâmetros diferentes. O compilador escolhe pela chamada; o tipo de retorno, por si só, não distingue duas sobrecargas. Argumentos por defeito permitem omitir os últimos argumentos, por exemplo `void imprimir(int n, char separador = ' ');`. O valor por defeito tem de estar visível no ponto da chamada. Não o repitas na definição se já o declaraste num cabeçalho.

## Valor, referência e const

  }

Saída:

```text
4

```

Segue o programa linha a linha. `n` começa em `4`. `incrementar_copia(n)` cria um parâmetro independente com o valor `4`; incrementar esse parâmetro não toca em `n`, que continua `4`. `incrementar(n)` recebe uma referência ao original e deixa `n` com `5`. `comprimento("Ana Maria")` conta 9 unidades: 3 de `Ana`, 1 espaço e 5 de `Maria`. Uma referência é um nome alternativo para um objeto. Tem de ser inicializada e nunca muda de destino. Atribuir à referência altera o objeto referido.

| Parâmetro         | O que a função recebe          | Uso habitual                           |
| ----------------- | ------------------------------ | -------------------------------------- |
| `int n`           | Um valor independente          | Números pequenos, só de leitura        |
| `T& objeto`       | Acesso ao original             | Alteração faz parte da operação        |
| `const T& objeto` | Acesso de leitura ao original  | Evitar copiar uma string ou coleção    |
| `T* objeto`       | Um endereço, que pode ser nulo | Opcionalidade ou acesso a um intervalo |

`const T&` impede alterações através dessa referência; não torna constantes todas as outras formas de acesso ao objeto. Evitar uma cópia de um `int` raramente justifica uma referência. Retornar um `std::string` por valor é seguro e permite ao compilador evitar cópias; retornar uma referência a uma variável local deixa acesso a um objeto que já morreu.

## Parâmetros apontadores

A próxima secção passa arrays como `const int* valores`. Lê assim: `valores` guarda o endereço do primeiro inteiro e `valores[i]` acede ao elemento nessa posição. Ainda não precisas de aritmética de apontadores; a página [Apontadores e memória](/cadeiras/p/apontadores-memoria/#endereço-de-e-dereferenciação) explica-a depois com objetos e setas.

## Arrays C e dimensões

Um array `int v[4]` contém quatro inteiros contíguos. Os índices válidos são `0`, `1`, `2` e `3`. `v[4]` está fora do array. Um array não aumenta de tamanho e não transporta automaticamente o seu comprimento quando é passado como argumento.

Numa lista de parâmetros, `const int valores[]` é ajustado para `const int* valores`. Por isso, a função abaixo recebe também `n`. `std::size_t`, de `<cstddef>`, é o tipo inteiro sem sinal usado para tamanhos e índices. Não representa valores negativos.

<CodePlayground
  language="cpp"
  title="Somar um intervalo de array"
  code={
    '#include <cstddef>\n#include <iostream>\n\nint soma(const int* valores, std::size_t n) {\n    int total = 0;\n    for (std::size_t i = 0; i < n; ++i) total += valores[i];\n    return total;\n}\n\nint main() {\n    int valores[] = {4, -2, 7, 1};\n    std::cout << soma(valores, 4) << "\\n";\n    std::cout << soma(valores + 1, 2) << "\\n";\n    std::cout << soma(nullptr, 0) << "\\n";\n}\n'
  }
/>

Saída:

```text
10
5
0
```

O contrato de `soma` exige `n` elementos válidos e que todas as somas parciais caibam em `int`. Na segunda chamada, o intervalo contém `-2` e `7`, por isso soma `5`. Na chamada vazia, o ciclo não desreferencia o apontador.

| Intervalo                   | Índices originais | Evolução de `total` |
| --------------------------- | ----------------- | ------------------- |
| Array completo              | 0, 1, 2, 3        | 0 → 4 → 2 → 9 → 10  |
| Dois valores a partir de -2 | 1, 2              | 0 → -2 → 5          |
| Vazio                       | nenhum            | 0                   |

O índice `i` é relativo ao início recebido. Na segunda chamada, `valores[0]` dentro da função é o `-2` que está no índice 1 do array do chamador.

`sizeof(valores)` dentro desta função mede o apontador, não o array do chamador. Para um tamanho fixo com interface que o conserva, usa `std::array<T, N>`. Para tamanho variável, usa `std::vector<T>`. Um `std::vector<int>` guarda uma sequência de inteiros; `std::vector<int> v{4, -2, 7}` cria três elementos. A página [Templates e STL](/cadeiras/p/templates-stl/#vector-o-array-que-cresce) desenvolve esta coleção.

Um **for por intervalo**, como `for (int x : valores)`, visita cada elemento de um array cujo tamanho é conhecido ou de uma coleção. `x` recebe uma cópia de cada inteiro; alterar `x` não altera o elemento. Com `for (int& x : valores)`, `x` refere-se ao elemento e permite alterá-lo. Um apontador isolado não fornece o tamanho para este percurso.

Um array C multidimensional tem os elementos da última dimensão contíguos. Em `int matriz[2][3]`, há duas linhas de três inteiros. Percorre com dois índices, um por dimensão:

```cpp
// Excerto: soma todos os elementos de uma matriz 2x3.
int soma_matriz(const int matriz[][3], int linhas) {
    int total = 0;
    for (int l = 0; l < linhas; ++l)
        for (int c = 0; c < 3; ++c) total += matriz[l][c];
    return total;
}
```

Com `{{1, 2, 3}, {4, 5, 6}}`, a soma é `21`. Uma função que recebe `const int matriz[][3]` precisa de conhecer a dimensão interior para avançar entre linhas. Isto não equivale a `int**`: um apontador para linhas de três inteiros e um apontador para apontadores têm representações e tipos diferentes.

## Structs e tipos compostos

Uma `struct` reúne campos que descrevem um valor, por exemplo um ponto.

```cpp
// Excerto: tipo e acesso aos seus campos.
struct Ponto {
    double x;
    double y;
};
Ponto p{2.0, 3.0};
```

`p.x` vale `2.0`. `Ponto` é um tipo; `p` é um objeto desse tipo. O compilador pode introduzir **padding**, bytes entre campos ou no fim para alinhar os objetos. Por isso, `sizeof(Ponto)` não deve ser deduzido somando tamanhos de campos. Não graves a memória bruta de uma struct como formato portátil de ficheiro.

`struct` e `class` permitem membros e métodos. A diferença sintática central é o acesso por defeito: público na `struct`, privado na `class`. Uma enumeração com âmbito, como `enum class Estado { livre, ocupado };`, cria valores nomeados e evita confundir um estado com um inteiro qualquer.

## Strings e linhas

`std::string` guarda uma sequência de unidades `char`. `size()` conta essas unidades, não caracteres Unicode visuais. Para ler ou alterar unidades do texto, usa índices de `0` a `size() - 1`; numa string vazia não há nenhuma. `at()` verifica esse limite e lança uma exceção. `texto[texto.size()]` permite consultar o terminador nulo, mas não é mais uma unidade do texto nem permite guardar outro carácter nessa posição. `+` concatena strings e `==` compara o conteúdo. `substr(pos, quantidade)` extrai uma parte; `find` devolve uma posição ou `std::string::npos` quando não encontra.

Depois de `>>` ler um número, o fim de linha pode continuar na entrada, por isso um `getline` imediato leria esse resto vazio. Neste formato, a idade ocupa a primeira linha e o nome a segunda. Descarta o resto da primeira linha antes de leres o nome.

Saída:

```text
Ana Maria | 19 | 9
```

`ignore` descarta até ao `\n`, incluindo-o. `std::getline` guarda os espaços interiores e retira o terminador. A alternativa `getline(std::cin >> std::ws, nome)` descarta também espaços iniciais e linhas vazias; só a uses quando isso corresponde ao formato pretendido.

Para separar campos dentro de uma linha, `find` localiza um separador e `substr` extrai cada parte. Com `s = "azul,verde"`, `s.find(',')` devolve `4`. `s.substr(0, 4)` é `"azul"` e `s.substr(5)` é `"verde"`. Quando `find` não encontra o carácter, devolve `std::string::npos`; nesse caso não há segundo campo.

## Strings de C e o terminador

Uma string de C é uma sequência de `char` terminada por `\0`. O array `char nome[] = "Ana";` tem quatro posições: `A`, `n`, `a`, `\0`. O terminador não aparece no texto impresso, mas ocupa memória. `<cstring>` fornece `strlen`, que percorre até ao terminador, e operações de cópia. Estas funções exigem que os apontadores e capacidades estejam corretos.

Arrays de `char` comparados com `==` não comparam o texto, comparam endereços depois da conversão para apontadores. Usa `std::string`, ou `std::strcmp` quando o contrato pede strings de C válidas. `strcpy` não verifica o tamanho do destino. Reservar só três posições para copiar `"Ana"` é insuficiente.

## Recursão e progresso

Uma função recursiva chama-se a si própria. Precisa de um caso base e de uma medida que diminua até esse caso. A soma recursiva de `1` até `n` pode usar `soma(0) = 0` e `soma(n) = n + soma(n - 1)` para `n > 0`. O contrato exige `n >= 0` e uma soma representável no tipo escolhido. Se não tratares `0`, podes criar chamadas sem fim.

Para `n = 3`, a descida constrói chamadas e a subida combina resultados:

| Passo  | Chamada                 | Resultado |
| ------ | ----------------------- | --------- |
| descer | `soma(3) = 3 + soma(2)` | pendente  |
| descer | `soma(2) = 2 + soma(1)` | pendente  |
| descer | `soma(1) = 1 + soma(0)` | pendente  |
| base   | `soma(0) = 0`           | 0         |
| subir  | `1 + 0`                 | 1         |
| subir  | `2 + 1`                 | 3         |
| subir  | `3 + 3`                 | 6         |

A descida reduz `n` e a subida combina os resultados. Uma entrada negativa nunca se aproxima do caso base.

Cada chamada conserva os seus parâmetros e variáveis locais. Um grande número de chamadas pode esgotar a pilha. Quando um ciclo resolve o mesmo problema com um acumulador, não precisas de recursão. Usa-a quando a decomposição do problema a torna clara, não como substituição automática de qualquer ciclo.
