      O ciclo entra outra vez, a extração falha e o corpo pode usar valores
      antigos. A condição deve ser{' '}
      <code>while (entrada &gt;&gt; nome &gt;&gt; nota)</code>, para só usar um

<Exercise
  id="validar-registo-funcao"
  revision={2}
  title="Escrever a validação em três passos"
  explanation="/cadeiras/p/ficheiros/#separar-linhas-e-registos"
  answer={{
    kind: 'self',
    checklist: [
      'Separei ler, detetar sobra e confirmar intervalo.',
      'Rejeitei Ana sem nota, Eva 12abc e linha vazia.',
      'Aceitei espaços iniciais e finais, mas rejeitei conteúdo extra e notas fora do intervalo.',
    ],
  }}
>
  <div>
    Escreve <code>bool registo_valido(const std::string&amp; linha)</code> que
    aceita só linhas com um nome sem espaços e um inteiro de 0 a 20, sem conteúdo extra.
    São permitidos espaços iniciais e finais. Testa <code>Ana 15</code>,
    <code>Ana</code>, <code>Eva 12abc</code>, a linha vazia, <code>Rui 20   </code>
    e <code>Eva 21</code>. Justifica cada rejeição e confirma que um erro numa linha
    não impede a leitura da seguinte.
  </div>
  <div slot="hint">
    <p>Trata separadamente campos em falta, conteúdo extra e nota fora do intervalo.</p>
  </div>
  <div slot="solution">
      <code>Ana 15</code> dá <code>leu</code> verdadeiro, <code>sobra</code>{' '}
      falso e intervalo verdadeiro: válida. <code>Ana</code> falha em{' '}
      <code>leu</code>. <code>Eva 12abc</code> tem <code>sobra</code>{' '}
      verdadeira. A vazia falha em <code>leu</code>. A condição final é{' '}
      <code>leu &amp;&amp; !sobra &amp;&amp; intervalo</code>.
      <code>Rui 20   </code> é válido porque só sobram espaços; <code>Eva 21</code>
      é inválido pelo intervalo. Uma implementação completa é:

```cpp
#include <sstream>
#include <string>

bool registo_valido(const std::string& linha) {
    std::istringstream entrada(linha);
    std::string nome, extra;
    int nota = 0;
    if (!(entrada >> nome >> nota)) return false;
    if (entrada >> extra) return false;
    return 0 <= nota && nota <= 20;
}
```

      Cada chamada constrói outro fluxo, por isso uma falha não contamina a linha seguinte.

  </div>
</Exercise>
