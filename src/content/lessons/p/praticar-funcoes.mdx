<Exercise
  id="referencia-atribuicao"
  title="A referência não muda de destino"
  explanation="/cadeiras/p/funcoes-arrays/#valor-referência-e-const"
  answer={{ kind: 'number', value: 9, tolerance: 0 }}
>
  <p>
    Segue <code>int a = 4; int b = 9; int&amp; r = a; r = b; b = 2;</code>.
    Quanto vale <code>a</code> no fim?
  </p>
  <div slot="hint">
    <p>r é um nome alternativo para a.</p>
  </div>
  <div slot="hint-more">
    <p>
      r = b atribui o valor de b ao objeto referido; não redireciona a
      referência.
    </p>
  </div>
  <div slot="solution">
    <p>
      <code>r = b</code> guarda <code>9</code> em <code>a</code>. A última
      atribuição altera apenas <code>b</code> para <code>2</code>. O resultado é{' '}
      <code>a = 9</code>, <code>b = 2</code> e <code>r = 9</code>.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Não interpretes uma atribuição à referência como uma troca de endereço.
    </p>
  </div>
</Exercise>

<Exercise
  id="array-contrato"
  title="Passar um subintervalo válido"
  explanation="/cadeiras/p/funcoes-arrays/#arrays-c-e-dimensões"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'soma(v + 2, 2)',
        correct: true,
        explanation: 'Os dois elementos são os índices 2 e 3.',
      },
      {
        text: 'soma(v + 2, 3)',
        correct: false,
        explanation: 'A terceira leitura seria v[4], fora do array.',
      },
      {
        text: 'soma(v + 4, 1)',
        correct: false,
        explanation: 'v + 4 marca o fim e não aponta para um elemento.',
      },
      {
        text: 'soma(nullptr, 1)',
        correct: false,
        explanation: 'Uma leitura por um apontador nulo viola o contrato.',
      },
    ],
  }}
>
  <p>
    Um array <code>v</code> tem quatro elementos. Qual chamada satisfaz o
    contrato da função <code>soma</code> da lição?
  </p>
  <div slot="hint">
    <p>Marca os índices 0 a 3 e a posição depois do fim.</p>
  </div>
  <div slot="hint-more">
    <p>
      O argumento v + 2 começa no índice 2; só existem dois elementos a partir
      daí.
    </p>
  </div>
  <div slot="solution">
    <p>
      <code>soma(v + 2, 2)</code> lê os índices <code>2</code> e <code>3</code>.
      O tamanho deve acompanhar o intervalo real, não o tamanho inicial do
      array.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Formar uma posição depois do fim pode ser válido; ler a partir dela não é.
    </p>
  </div>
</Exercise>

<Exercise
  id="corrigir-intervalo"
  title="Programar uma contagem num intervalo fechado"
  explanation="/cadeiras/p/funcoes-arrays/#declarar-e-chamar-funções"
  answer={{
    kind: 'self',
    checklist: [
      'Incluí os dois limites.',
      'Obtive 0, 3 e 3 nos casos apresentados.',
      'Mantive a coleção sem alterações e sem cópias desnecessárias.',
    ],
  }}
>
  <p>
    O contrato pede o número de valores em [minimo, maximo], incluindo os
    extremos. Corrige a função sem alterar os dados de teste. O programa inicial
    compila e corre, mas os resultados nos limites estão errados.
  </p>
  <div slot="work">
    <CodePlayground
      language="cpp"
      title="Corrige e volta a correr"
      code={
        '#include <iostream>\n#include <vector>\n\nint contar(const std::vector<int>& valores, int minimo, int maximo) {\n    int total = 0;\n    for (int x : valores)\n        if (minimo < x && x < maximo) ++total;\n    return total;\n}\n\nint main() {\n    std::cout << "Vazio: " << contar({}, 1, 3) << " (esperado 0)\\n";\n    std::cout << "Limites: " << contar({1, 2, 3}, 1, 3) << " (esperado 3)\\n";\n    std::cout << "Repetidos: " << contar({2, 2, 2}, 2, 2) << " (esperado 3)\\n";\n}\n'
      }
    />
  </div>
  <div slot="hint">
    <p>Compara a condição com a definição de intervalo fechado.</p>
  </div>
  <div slot="hint-more">
    <p>Um valor igual ao limite inferior ou superior também deve contar.</p>
  </div>
  <div slot="solution">
    <p>
      A condição correta é <code>minimo &lt;= x &amp;&amp; x &lt;= maximo</code>
      . O vazio continua a dar zero, o intervalo de 1 a 3 inclui os três valores
      e o intervalo reduzido a 2 inclui as três repetições. A referência
      constante conserva a coleção original.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Não alteres só um dos limites. Não mudes os resultados esperados para
      esconder a falha.
    </p>
  </div>
</Exercise>
