<Exercise
  id="referencia-atribuicao"
  revision={1}
  title="A referência não muda de destino"
  explanation="/cadeiras/p/funcoes-arrays/#valor-referência-e-const"
  answer={{ kind: 'number', value: 9, tolerance: 0 }}
>
  <div>
    Segue <code>int a = 4; int b = 9; int&amp; r = a; r = b; b = 2;</code>.
    Quanto vale <code>a</code> no fim?
  </div>
  <div slot="hint">
    <p>r é um nome alternativo para a.</p>
  </div>
  <div slot="hint-more">
    <div>
      r = b atribui o valor de b ao objeto referido; não redireciona a
      referência.
    </div>
  </div>
  <div slot="solution">
    <div>
      <code>r = b</code> guarda <code>9</code> em <code>a</code>. A última
      atribuição altera apenas <code>b</code> para <code>2</code>. O resultado é{' '}
      <code>a = 9</code>, <code>b = 2</code> e <code>r = 9</code>.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Não interpretes uma atribuição à referência como uma troca de endereço.
    </div>
  </div>
</Exercise>

  answer={{

      {
        text: 'soma(v + 2, 2)',
        correct: true,
        explanation: 'Os dois elementos são os índices 2 e 3.',
      },
      {
        text: 'soma(v + 2, 3)',
        correct: false,
        explanation: 'A terceira leitura seria v[4], fora do array.',
      },
      {
        text: 'soma(v + 4, 1)',
        correct: false,
        explanation: 'v + 4 marca o fim e não aponta para um elemento.',
      },
      {
        text: 'soma(nullptr, 1)',
        correct: false,
        explanation: 'Uma leitura por um apontador nulo viola o contrato.',
      },
    ],
  }}
>
  <div>
    Um array <code>v</code> contém <code>1, 2, 3, 4</code>. Qual chamada
    satisfaz o contrato da função <code>soma</code> da lição?
  </div>
  <div slot="hint">
    <p>Marca os índices 0 a 3 e a posição depois do fim.</p>
  </div>
  <div slot="hint-more">
    <div>
      O argumento v + 2 começa no índice 2; só existem dois elementos a partir
      daí.
    </div>
  </div>
  <div slot="solution">
    <div>
      <code>soma(v + 2, 2)</code> lê os índices <code>2</code> e <code>3</code>.
      O tamanho deve acompanhar o intervalo real, não o tamanho inicial do
      array.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Formar uma posição depois do fim pode ser válido; ler a partir dela não é.
    </div>
  </div>
</Exercise>

<Exercise
  id="corrigir-intervalo"
  revision={1}
  title="Programar uma contagem num intervalo fechado"
  explanation="/cadeiras/p/excecoes-testes/#testar-com-asserts"
  answer={{
    kind: 'self',
    checklist: [
      'Incluí os dois limites.',
      'Obtive 0, 3 e 3 nos casos apresentados.',
      'Mantive a coleção sem alterações e sem cópias desnecessárias.',
    ],
  }}
>
  <div>
    O contrato pede o número de valores em [minimo, maximo], incluindo os
    extremos. Corrige a função sem alterar os dados de teste. O programa inicial
    compila e corre, mas os resultados nos limites estão errados.
  </div>
  <div slot="work">
    <CodePlayground
      language="cpp"
      title="Contar os extremos do intervalo"
      code={
        '#include <iostream>\n#include <vector>\n\nint contar(const std::vector<int>& valores, int minimo, int maximo) {\n    int total = 0;\n    for (int x : valores)\n        if (minimo < x && x < maximo) ++total;\n    return total;\n}\n\nint main() {\n    std::cout << "Vazio: " << contar({}, 1, 3) << " (esperado 0)\\n";\n    std::cout << "Limites: " << contar({1, 2, 3}, 1, 3) << " (esperado 3)\\n";\n    std::cout << "Repetidos: " << contar({2, 2, 2}, 2, 2) << " (esperado 3)\\n";\n}\n'
      }
    />
  </div>
  <div slot="hint">
    <p>Compara a condição com a definição de intervalo fechado.</p>
  </div>
  <div slot="hint-more">
    <p>Um valor igual ao limite inferior ou superior também deve contar.</p>
  </div>
  <div slot="solution">
    <div>
      A condição correta é <code>minimo &lt;= x &amp;&amp; x &lt;= maximo</code>
      . O vazio continua a dar zero, o intervalo de 1 a 3 inclui os três valores
      e o intervalo reduzido a 2 inclui as três repetições. A referência
      constante conserva a coleção original.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Não alteres só um dos limites. Não mudes os resultados esperados para
      esconder a falha.
    </div>
  </div>
</Exercise>

<Exercise
  id="inverter-texto"
  revision={1}
  title="Construir uma string invertida"
  explanation="/cadeiras/p/funcoes-arrays/#strings-e-linhas"
  answer={{
    kind: 'self',
    checklist: [
      'Devolvi uma string e não imprimi dentro da função.',
      'Tratei o vazio, um carácter e comprimentos pares e ímpares.',
      'Conservei o texto original e justifiquei os índices usados.',
    ],
  }}
>
  <div>
    Define <code>std::string inverter(const std::string&amp; texto)</code> para
    devolver as unidades do texto pela ordem inversa. Usa apenas texto ASCII,
    como <code>abc</code>, e conserva o argumento. A string vazia devolve uma
    string vazia. Esta resposta é de autoavaliação.
  </div>
  <div slot="work">
    <CodePlayground
      language="cpp"
      title="Escrever a função inverter"
      code={
        '#include <iostream>\n#include <string>\n\nstd::string inverter(const std::string& texto) {\n    return texto; // Substitui pelo algoritmo.\n}\n\nint main() {\n    std::string original = "abc";\n    std::cout << "[" << inverter("") << "] (esperado [])\\n";\n    std::cout << inverter("x") << " (esperado x)\\n";\n    std::cout << inverter(original) << " (esperado cba)\\n";\n    std::cout << inverter("abcd") << " (esperado dcba)\\n";\n    std::cout << original << " (esperado abc)\\n";\n}\n'
      }
    />
  </div>
  <div slot="hint">Constrói outra string e percorre a entrada do fim para o início.</div>
  <div slot="hint-more">
    Começa com <code>i = texto.size()</code>. Enquanto <code>i &gt; 0</code>,
    lê <code>texto[i - 1]</code> e diminui <code>i</code>. Assim, nunca subtrais
    um a zero para formar um índice.
  </div>
  <div slot="solution">

```cpp
std::string inverter(const std::string& texto) {
    std::string resultado;
    for (std::size_t i = texto.size(); i > 0; --i)
        resultado += texto[i - 1];
    return resultado;
}
```

    Para <code>abc</code>, os índices lidos são 2, 1 e 0. No vazio, o ciclo não
    começa. O argumento só é lido; o resultado tem armazenamento próprio.
    Outra solução válida copia o texto e troca pares de posições simétricas.

  </div>
  <div slot="mistakes">
    <code>size()</code> usa um tipo sem sinal. Começar em
    <code>size() - 1</code> no vazio, ou testar <code>i &gt;= 0</code> para
    terminar uma contagem descendente sem sinal, dá limites errados. Inverter
    bytes de texto UTF-8 também pode estragar caracteres, por isso o contrato
    deste exercício limita a entrada a ASCII.
  </div>
</Exercise>
