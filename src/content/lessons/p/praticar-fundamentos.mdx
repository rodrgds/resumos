<Exercise
  id="divisao-conversao"
  revision={1}
  title="Converter antes ou depois"
  explanation="/cadeiras/p/cpp-fundamentos/#operadores-e-divisão"
  answer={{ kind: 'number', value: 2, tolerance: 0 }}
>
  <div>
    Depois de <code>int a = 11, b = 4;</code> e <code>double r = a / b;</code>,
    quanto vale <code>r</code>?
  </div>
  <div slot="hint">
    <p>Identifica os tipos dos operandos antes de olhares para o destino.</p>
  </div>
  <div slot="hint-more">
    <p>Os dois operandos são inteiros; a parte fracionária é truncada.</p>
  </div>
  <div slot="solution">
    <div>
      A divisão inteira dá <code>2</code>. Só depois o resultado passa a{' '}
      <code>double</code>, com valor <code>2.0</code>. Para obter{' '}
      <code>2.75</code>, converte um operando antes de dividir, como em{' '}
      <code>static_cast&lt;double&gt;(a) / b</code>.
    </div>
  </div>
  <div slot="mistakes">
    <p>A declaração do destino não muda a operação que já foi calculada.</p>
  </div>
</Exercise>

<Exercise
  id="ciclo-fronteira"
  revision={1}
  title="Justificar o limite de um ciclo"
  explanation="/cadeiras/p/cpp-fundamentos/#escolha-iteração-e-âmbito"
  answer={{
    kind: 'self',
    checklist: [
      'Enumerei 0, 1, 2 e 3.',
      'Obtive total 6 e distingui o total 10 da alternativa.',
      'Expliquei o risco de usar <= com índices de um array.',
    ],
  }}
>
  <div>
    <p>
      O programa abaixo começa com <code>total = 0</code> e executa{' '}
      <code>total += i</code> enquanto <code>i &lt; 4</code>.
    </p>
    <pre>
      <code>for (int i = 0; i &lt; 4; ++i) total += i;</code>
    </pre>
    <p>
      Indica os valores visitados, o total final e o que mudaria com{' '}
      <code>i &lt;= 4</code>. Num array de quatro elementos, os índices válidos
      são 0 a 3.
    </p>
  </div>
  <div slot="hint">
    <p>Escreve cada valor de i que satisfaz a condição, por ordem.</p>
  </div>
  <div slot="hint-more">
    <div>
      A condição é testada antes do corpo, incluindo depois do último
      incremento.
    </div>
  </div>
  <div slot="solution">
    <div>
      Com <code>i &lt; 4</code>, o corpo usa <code>0, 1, 2, 3</code>, dando{' '}
      <code>0 + 1 + 2 + 3 = 6</code>. Com <code>i &lt;= 4</code>, inclui também{' '}
      <code>4</code>, dando <code>10</code>. Num array de quatro elementos, o
      segundo limite permitiria o índice inválido <code>4</code>.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Não contes o valor que termina o ciclo como se tivesse passado pelo corpo.
    </div>
  </div>
</Exercise>

<Exercise
  id="curto-circuito-protege"
  revision={1}
  title="Proteger uma divisão com curto-circuito"
  explanation="/cadeiras/p/cpp-fundamentos/#operadores-e-divisão"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'A divisão só é avaliada quando n é diferente de zero.',
        correct: true,
        explanation:
          'O && avalia da esquerda para a direita e para na primeira condição falsa.',
      },
      {
        text: 'A divisão é sempre avaliada antes da comparação.',
        correct: false,
        explanation: 'O curto-circuito evita precisamente essa avaliação.',
      },
      {
        text: 'O resultado é sempre verdadeiro quando n é zero.',
        correct: false,
        explanation:
          'Com n igual a zero, a primeira condição é falsa e o conjunto é falso.',
      },
    ],
  }}
>
  <div>
    A condição <code>n != 0 &amp;&amp; soma / n &gt; 10</code> protege uma
    divisão. O que acontece quando <code>n</code> vale zero?
  </div>
  <div slot="hint">
    <p>Lembra-te da ordem de avaliação do &amp;&amp;.</p>
  </div>
  <div slot="hint-more">
    <div>
      Se a primeira condição é falsa, a segunda nem chega a ser calculada.
    </div>
  </div>
  <div slot="solution">
    <div>
      Com <code>n == 0</code>, <code>n != 0</code> é falso e a divisão não é
      avaliada. A condição completa é falsa sem divisão por zero. Com{' '}
      <code>n == 5</code> e <code>soma == 60</code>, a divisão é avaliada e{' '}
      <code>12 &gt; 10</code> é verdadeiro.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Não leias a condição da direita para a esquerda. A proteção depende da
      ordem.
    </div>
  </div>
</Exercise>
