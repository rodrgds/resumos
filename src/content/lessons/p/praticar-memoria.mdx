<Exercise
  id="alias-ponteiros"
  title="Mudar um endereço ou um valor"
  explanation="/cadeiras/p/apontadores-memoria/#endereço-de-e-dereferenciação"
  answer={{
    kind: 'self',
    checklist: [
      'Indiquei a = 5 e b = 7.',
      'Desenhei p para b e q para a.',
      'Distingui cópia do endereço de cópia do objeto.',
    ],
  }}
>
  <p>
    Segue{' '}
    <code>
      int a = 2, b = 7; int* p = &amp;a; int* q = p; p = &amp;b; *q = 5;
    </code>
    . Indica os valores finais e os destinos dos dois apontadores.
  </p>
  <div slot="hint">
    <p>Desenha uma seta por apontador.</p>
  </div>
  <div slot="hint-more">
    <p>
      p = &amp;b altera uma seta; *q = 5 altera o objeto onde acaba a outra.
    </p>
  </div>
  <div slot="solution">
    <p>
      No fim, <code>a = 5</code> e <code>b = 7</code>. <code>p</code> aponta
      para <code>b</code>; <code>q</code> continua a apontar para <code>a</code>
      . Copiar p para q não cria uma ligação que faça as futuras atribuições a p
      aparecerem em q.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Dois apontadores com o mesmo valor inicial continuam a ser objetos
      independentes.
    </p>
  </div>
</Exercise>

<Exercise
  id="delete-alias"
  title="O que fica pendente"
  explanation="/cadeiras/p/apontadores-memoria/#fugas-de-memória-e-double-free"
  answer={{
    kind: 'choice',
    options: [
      {

        correct: true,
        explanation: 'O objeto morreu e q conserva o endereço antigo.',
      },
      {
        text: 'q passa também a nullptr.',
        correct: false,
        explanation: 'A atribuição só modifica p.',
      },
      {
        text: 'O inteiro continua vivo enquanto q existir.',
        correct: false,
        explanation: 'Um apontador cru não prolonga a vida do objeto.',
      },
      {
        text: 'delete q é necessário para libertar a cópia.',
        correct: false,
        explanation:
          'Não houve cópia do inteiro; seria uma segunda libertação.',
      },
    ],
  }}
>
  <p>
    Uma sequência faz{' '}
    <code>int* p = new int(8); int* q = p; delete p; p = nullptr;</code>. Qual
    afirmação é correta?
  </p>
  <div slot="hint">
    <p>A libertação destrói o objeto, não todos os apontadores.</p>
  </div>
  <div slot="hint-more">
    <p>A atribuição a p só altera p.</p>
  </div>
  <div slot="solution">
    <p>
      <code>q</code> conserva o antigo endereço, mas o inteiro já foi destruído.
      Não se pode ler <code>*q</code> nem repetir <code>delete q</code>. O valor
      nulo de <code>p</code> não repara q.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Um endereço que ainda tem o mesmo número não garante que o objeto continue
      vivo.
    </p>
  </div>
</Exercise>
