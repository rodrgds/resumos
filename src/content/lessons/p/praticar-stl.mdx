<Exercise
  id="unique-tamanho"
  title="Fim lógico e tamanho real"
  explanation="/cadeiras/p/templates-stl/#algoritmos-sort-e-find"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'Tamanho 6; intervalo lógico com 3 valores.',
        correct: true,
        explanation: 'unique não altera o tamanho do contentor.',
      },
      {
        text: 'Tamanho 3; intervalo lógico com 3 valores.',
        correct: false,
        explanation: 'Falta erase para destruir os elementos finais.',
      },
      {
        text: 'Tamanho 6; intervalo lógico com 6 valores.',
        correct: false,
        explanation:
          'unique devolve o novo fim depois dos três valores conservados.',
      },
    ],
  }}
>
  <p>
    Num vector com <code>1, 1, 2, 2, 2, 4</code>, chama-se apenas{' '}
    <code>auto fim = std::unique(v.begin(), v.end());</code>. Qual é o tamanho
    de v e quantos valores estão no intervalo até fim?
  </p>
  <div slot="hint">
    <p>unique compacta; não destrói os elementos finais.</p>
  </div>
  <div slot="hint-more">
    <p>Os valores distintos adjacentes são 1, 2 e 4.</p>
  </div>
  <div slot="solution">
    <p>
      O tamanho continua <code>6</code> e o intervalo{' '}
      <code>[v.begin(), fim)</code> tem <code>3</code> valores:{' '}
      <code>1, 2, 4</code>. Os valores depois de fim não fazem parte do
      resultado lógico. <code>v.erase(fim, v.end())</code> reduz o tamanho para
      3.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Não atribuas um conteúdo fixo ao resto do intervalo depois do novo fim
      lógico.
    </p>
  </div>
</Exercise>

<Exercise
  id="comparador-empate"
  title="Reconhecer um comparador inválido"
  explanation="/cadeiras/p/templates-stl/#comparadores-e-pesquisa-ordenada"
  answer={{
    kind: 'self',
    checklist: [
      'Mostrei comp(x, x) verdadeiro no código inicial.',
      'Substituí <= por <.',
      'Expliquei quando stable_sort conserva a ordem anterior.',
    ],
  }}
>
  <p>
    Uma ordenação de notas usa{' '}
    <code>[](int a, int b) &#123; return a &lt;= b; &#125;</code>. Explica o
    problema para notas iguais e corrige o critério.
  </p>
  <div slot="hint">
    <p>Testa o comparador com a e b iguais.</p>
  </div>
  <div slot="hint-more">
    <p>Uma relação estrita exige que comp(x, x) seja falso.</p>
  </div>
  <div slot="solution">
    <p>
      Para duas notas iguais, <code>a &lt;= b</code> dá verdadeiro. Isto viola a
      exigência de ordenação estrita. Para ordem crescente, usa{' '}
      <code>a &lt; b</code>. Se queres conservar a ordem anterior entre notas
      iguais, usa esse comparador com <code>stable_sort</code>.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      A ordem dos iguais e a validade do comparador são decisões diferentes.
    </p>
  </div>
</Exercise>

<Exercise
  id="corrigir-capacidade"
  title="Criar elementos, além de reservar espaço"
  explanation="/cadeiras/p/templates-stl/#vector-o-array-que-cresce"
  answer={{
    kind: 'self',
    checklist: [
      'Distingui size de capacity.',
      'Criei três elementos antes de lhes atribuir valores.',
      'Obtive a saída 0 1 2 sem erro de tamanho.',
    ],
  }}
>
  <p>
    O programa deve criar três elementos e escrever <code>0 1 2</code>. Corrige
    a preparação do vetor. Mantém <code>at</code>, para que um acesso inválido
    continue a ser detetado.
  </p>
  <div slot="work">
    <CodePlayground
      language="cpp"
      title="Corrige e volta a correr"
      code={
        '#include <iostream>\n#include <vector>\n\nint main() {\n    std::vector<int> valores;\n    valores.reserve(3);\n    if (valores.size() != 3) {\n        std::cout << "Nao existem os tres elementos\\n";\n        return 0;\n    }\n    for (std::size_t i = 0; i < 3; ++i) valores.at(i) = static_cast<int>(i);\n    for (int x : valores) std::cout << x << " ";\n    std::cout << "\\n";\n}\n'
      }
    />
  </div>
  <div slot="hint">
    <p>Consulta o tamanho depois de reserve, não só a capacidade.</p>
  </div>
  <div slot="hint-more">
    <p>resize altera o número de elementos existentes.</p>
  </div>
  <div slot="solution">
    <p>
      Substitui <code>valores.reserve(3)</code> por{' '}
      <code>valores.resize(3)</code>, ou constrói logo{' '}
      <code>std::vector&lt;int&gt; valores(3)</code>. Agora existem os índices
      0, 1 e 2, e o ciclo pode atribuir-lhes valores. A saída é{' '}
      <code>0 1 2</code>.
    </p>
  </div>
  <div slot="mistakes">
    <p>
      Trocar at por [] esconderia a verificação e introduziria comportamento
      indefinido, porque reserve não cria elementos.
    </p>
  </div>
</Exercise>
