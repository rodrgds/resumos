  <div>
    Num vector com <code>1, 1, 2, 2, 2, 4</code>, chama-se apenas{' '}
    <code>auto fim = std::unique(v.begin(), v.end());</code>. Qual é o tamanho

  </div>

  </div>

<Exercise
  id="remover-negativos"
  revision={1}
  title="Remover sem saltar o elemento seguinte"
  explanation="/cadeiras/p/templates-stl/#invalidação-de-iteradores"
  answer={{
    kind: 'self',
    checklist: [
      'Removi todos os negativos, incluindo negativos consecutivos.',
      'Conservei zero, positivos, repetições e a ordem relativa.',
      'Usei o iterador devolvido por erase sem o avançar novamente.',
    ],
  }}
>
  <div>
    Define <code>void remover_negativos(std::vector&lt;int&gt;&amp; valores)</code>.
    Altera o vetor recebido, conservando os restantes valores pela mesma ordem.
    Nesta versão, usa um iterador e <code>erase</code> para seguir a
    invalidação. Esta resposta é de autoavaliação.
  </div>
  <div slot="work">
    <CodePlayground
      language="cpp"
      title="Escrever a remoção por iterador"
      code={
        '#include <iostream>\n#include <vector>\n\nvoid remover_negativos(std::vector<int>& valores) {\n    // Escreve o percurso e a remoção.\n}\n\nvoid mostrar(std::vector<int> valores) {\n    remover_negativos(valores);\n    std::cout << "[";\n    for (int x : valores) std::cout << " " << x;\n    std::cout << " ]\\n";\n}\n\nint main() {\n    mostrar({}); // [ ]\n    mostrar({-1, -2}); // [ ]\n    mostrar({1, -1, -2, 0, 3, 3, -4}); // [ 1 0 3 3 ]\n}\n'
      }
    />
  </div>
  <div slot="hint">O elemento seguinte ocupa a posição que acabaste de remover.</div>
  <div slot="hint-more">
    Se removes, usa <code>it = valores.erase(it)</code>. Se conservas, usa
    <code>++it</code>. Os dois casos não devem fazer o mesmo avanço.
  </div>
  <div slot="solution">

```cpp
void remover_negativos(std::vector<int>& valores) {
    auto it = valores.begin();
    while (it != valores.end()) {
        if (*it < 0) it = valores.erase(it);
        else ++it;
    }
}
```

    Em <code>&#123;-1, -2&#125;</code>, remover -1 devolve um iterador para -2.
    Esse valor ainda precisa de ser analisado. Ao remover o último elemento,
    <code>erase</code> devolve <code>end()</code> e o ciclo termina sem o ler.
    Cada remoção pode deslocar o resto do vetor; no pior caso, esta versão tem
    custo quadrático no número de elementos. A combinação
    <code>remove_if</code> e <code>erase</code> da <code>{"li"}</code>ção permite uma passagem
    linear.

  </div>
  <div slot="mistakes">
    Não uses um <code>for</code> com avanço incondicional depois de
    <code>erase</code>. Não conserves o antigo <code>end()</code> nem uses um
    iterador invalidado. Passar o vetor por valor alteraria apenas uma cópia.
  </div>
</Exercise>

<Exercise

    ],
  }}
>
  <div>
    Um <code>map&lt;string, int&gt;</code> tem <code>azul: 3</code> e{' '}
    <code>verde: 2</code>. Queres saber se existe <code>branco</code> sem
    alterar o mapa. Compara <code>frequencias["branco"]</code> com{' '}
    <code>frequencias.find("branco")</code>.
  </div>
  <div slot="hint">
    <p>O primeiro cria a chave quando ela falta.</p>
  </div>
  <div slot="hint-more">
    <div>Compara o tamanho antes e depois de cada forma.</div>
  </div>
  <div slot="solution">
    <div>
      <code>frequencias["branco"]</code> insere <code>branco: 0</code> e o
      tamanho passa a 3. <code>find("branco") == end()</code> responde que a
      chave falta e o tamanho continua 2. Usa <code>operator[]</code> para
      contar e <code>find</code> para consultar.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Não uses <code>operator[]</code> numa função que recebe o mapa por
      referência constante. Nem compila para esse efeito.
    </div>
  </div>
</Exercise>
