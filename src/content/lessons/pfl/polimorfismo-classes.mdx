O tipo de uma função diz que valores podemos passar e como se relacionam com o resultado. Em `trocar :: (a,b) -> (b,a)`, `a` e `b` podem ser diferentes. Em `duplicar :: a -> (a,a)`, as duas posições do resultado têm o mesmo tipo. Estas letras são variáveis de tipo, não variáveis do programa.

## Generalidade sem operações específicas

```haskell
trocar (x,y) = (y,x)
duplicar x = (x,x)
primeiro (x:_) = x
```

As funções apenas deslocam ou selecionam valores. Os tipos mais gerais são `(a,b) -> (b,a)`, `a -> (a,a)` e `[a] -> a`. A última função é parcial: a generalidade do tipo não resolve a ausência de uma equação para `[]`. Um tipo pode estar certo mesmo que a função falhe ou não termine para certas entradas.

Uma lista impõe o mesmo tipo aos elementos. Uma lista de funções também segue essa regra: `[reverse,tail]` pode ter tipo `[[a] -> [a]]`. Cada elemento é uma função de lista para lista; a lista exterior não é uma função. Já `(reverse,length)` é um par e pode juntar resultados de tipos diferentes.

## Operações acrescentam restrições

```haskell
contem x xs = x `elem` xs
maior x y = if x >= y then x else y
media x y = (x+y)/2
```

`elem` compara valores, por isso `contem :: Eq a => a -> [a] -> Bool`. A comparação `>=` pede `Ord a`, dando `maior :: Ord a => a -> a -> a`. A divisão `/` pede `Fractional a`, que já exige `Num a`; por isso `media :: Fractional a => a -> a -> a`. Não é preciso acumular a restrição redundante `Num a` nessa assinatura.

| Classe       | Operações ou capacidade                                             |
| ------------ | ------------------------------------------------------------------- |
| `Eq`         | `==`, `/=`; igualdade disponível para esse tipo.                    |
| `Ord`        | `<`, `<=`, `compare`; também exige `Eq`.                            |
| `Show`       | `show`; transformar um valor em texto.                              |
| `Read`       | `read`; interpretar texto, com risco de erro se o texto não servir. |
| `Num`        | `+`, `-`, `*`, `abs`, literais inteiros.                            |
| `Integral`   | `div`, `mod`, `quot`, `rem`; inclui `Int` e `Integer`.              |
| `Fractional` | `/`, `recip`, literais fracionários.                                |
| `Floating`   | `sqrt`, `sin`, `exp`; exige `Fractional`.                           |

Uma classe agrupa tipos com operações comuns. Não é uma classe de objetos com herança e campos. `Num` nos GHC atuais não tem `Eq` como superclasse. Precisar de aritmética e de igualdade pode portanto exigir `(Num a, Eq a)`. Uma árvore da hierarquia antiga não deve ser usada para retirar essa restrição.

## Deduzir um tipo passo a passo

Considera `duasVezes f x = f (f x)`. Começamos com `x :: a`. A aplicação interior permite `f :: a -> b`. A aplicação exterior usa o mesmo `f` sobre o resultado de tipo `b`, por isso `b` tem de ser `a`. A saída também é `a`. O tipo final é:

```haskell
duasVezes :: (a -> a) -> a -> a
```

Não há operações numéricas nem comparações, por isso não há restrições de classe. Instanciar `a` com `Int` permite passar `(+1)`; instanciar com `Bool` permite passar `not`.

Agora `selecionar p xs = [x | x <- xs, p x]`. Se `xs :: [a]`, cada `x :: a`. Uma condição de compreensão tem tipo `Bool`, logo `p :: a -> Bool`. O resultado volta a ser `[a]`. Obtemos `(a -> Bool) -> [a] -> [a]`.

Em `f x y = [x,y+1]`, a lista iguala os tipos de `x` e `y`. `+` acrescenta `Num a`, mas não obriga a usar `Int`. O tipo mais geral é `Num a => a -> a -> [a]`. Uma assinatura mais específica pode compilar, mas não responde ao pedido de tipo mais geral.

## Aplicação e setas

`a -> b -> c` significa `a -> (b -> c)`: a função recebe um `a` e devolve uma função de `b` para `c`. A aplicação associa no sentido oposto: `f x y` significa `(f x) y`. O tipo `(a -> b) -> a -> b` recebe uma função no primeiro argumento; retirar esses parênteses muda o tipo.

O operador `.` exige que a saída da segunda função possa entrar na primeira:

```haskell
(.) :: (b -> c) -> (a -> b) -> a -> c
```

`length . filter even` recebe uma lista de inteiros e devolve `Int`. A restrição `Integral a` vem de `even`; `length` não inspeciona os elementos. O tipo é `Integral a => [a] -> Int`.

## Números e conversões

O literal `3` pode ser usado em qualquer instância de `Num`; `3.5` exige `Fractional`. A expressão `length xs + 0.5` falha porque `length xs :: Int`, e `Int` não é `Fractional`. Usa `fromIntegral (length xs)` para obter um valor compatível com a divisão ou soma fracionária. A conversão não acontece automaticamente.

`div` e `mod` arredondam o quociente para baixo; `quot` e `rem` truncam-no para zero. Para `-7` e `3`, temos `div=-3`, `mod=2`, `quot=-2`, `rem=-1`. Em ambos os pares vale `a = q*b+r`, com `b` diferente de zero. Escolher um par e depois usar o resto do outro quebra essa relação.

Para conferir a tua dedução, usa `:t nome` no GHCi. Dependendo da versão, funções como `length` e `elem` podem aparecer generalizadas a `Foldable`, em vez de listas. A instância especializada a `[a]` usada nas aulas continua válida; não interpretes essa diferença como um erro da tua dedução.
