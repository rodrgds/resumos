<Exercise

  title="Declarar a convenção de altura"

    qual a altura de uma cadeia com quatro nós?

  </div>

<Exercise
  id="invariante"
  title="A travessia está sempre ordenada?"
  explanation="/cadeiras/pfl/tipos-algebricos-recursao/#exemplo-completo-pesquisa-binária"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'Não; exige a invariância de pesquisa.',
        correct: true,
        explanation:
          'Uma árvore arbitrária pode ter um valor maior à esquerda.',
      },
      {
        text: 'Sim; visitar esquerda antes da raiz chega.',
        correct: false,
        explanation: 'A ordem da visita não impõe a ordem dos valores.',
      },
      {
        text: 'Sim, se não houver repetidos.',
        correct: false,
        explanation: 'Valores distintos podem continuar fora de ordem.',
      },
    ],
  }}
>
  <p>A travessia em ordem de qualquer árvore binária dá uma lista ordenada?</p>
  <div slot="hint">
    <p>Desenha raiz 2 com filho esquerdo 5.</p>
  </div>
  <div slot="hint-more">
    <p>A travessia desse exemplo começa por 5.</p>
  </div>
  <div slot="solution">
    <p>
      A lista [5,2] não está ordenada. É a invariância da árvore de pesquisa que
      justifica o resultado, não a forma binária.
    </p>
  </div>
  <div slot="mistakes">
    <p>Não transportes uma propriedade de BST para todas as árvores.</p>
  </div>
</Exercise>

<Exercise
  id="inducao"
  title="Uma prova sobre uma cauda menor"
  explanation="/cadeiras/pfl/tipos-algebricos-recursao/#justificar-uma-lei-por-indução"
  answer={{
    kind: 'self',
    checklist: [
      'Verifico o caso [].',
      'Enuncio a hipótese para xs.',
      'No passo x:xs uso essa hipótese uma única vez na cauda.',
    ],
  }}
>
  <p>
    Completa a demonstração de length (map f xs)=length xs em listas finitas.
  </p>
  <div slot="hint">
    <p>Expande map e length em x:xs.</p>
  </div>
  <div slot="hint-more">
    <p>Obténs 1+length(map f xs).</p>
  </div>
  <div slot="solution">
    <p>
      No caso [] os dois lados são zero. No passo, a hipótese length(map f
      xs)=length xs transforma 1+length(map f xs) em 1+length xs, que é
      length(x:xs).
    </p>
  </div>
  <div slot="mistakes">
    <p>Não uses a afirmação pretendida sobre a lista inteira como hipótese.</p>
  </div>
</Exercise>
