<Exercise
  id="substituir"
  revision={1}
  title="Aplicação antes da soma"
  explanation="/cadeiras/pfl/haskell-expressoes-tipos/#aplicação-parênteses-e-domínio"
  answer={{ kind: 'number', value: 14, tolerance: 0 }}
>
  <p>Com dobra x = 2*x, quanto vale dobra 4 + dobra (1+2)?</p>
  <div slot="hint">
    <p>Resolve os dois argumentos de dobra separadamente.</p>
  </div>
  <div slot="hint-more">
    <p>A aplicação dobra 4 vale 8; o outro argumento é 3.</p>
  </div>
  <div slot="solution">
    <p>dobra 4 + dobra (1+2) = 8 + 2*3 = 14.</p>
  </div>
  <div slot="mistakes">
    <p>Não incluis a soma exterior no argumento da primeira dobra.</p>
  </div>
</Exercise>

<Exercise
  id="dominio"
  revision={1}
  title="Um programa que compila pode falhar"
  explanation="/cadeiras/pfl/haskell-expressoes-tipos/#aplicação-parênteses-e-domínio"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'head ([] :: [Int])',
        correct: true,
        explanation: 'O tipo é Int, mas não há primeiro elemento.',
      },
      {
        text: '1 + False',
        correct: false,
        explanation: 'Não há instância Num Bool; falha na tipagem.',
      },
      {
        text: 'take 0 [1..]',
        correct: false,
        explanation: 'Devolve a lista vazia sem pedir a lista infinita.',
      },
    ],
  }}
>
  <p>Qual das expressões tem tipo mas falha quando o resultado é pedido?</p>
  <div slot="hint">
    <p>Distingue rejeição pelo compilador de falha na avaliação.</p>
  </div>
  <div slot="hint-more">
    <p>Observa a pré-condição da função head.</p>
  </div>
  <div slot="solution">
    <div>
      head [] tem um tipo e viola a pré-condição de lista não vazia. take 0
      [1..] não exige nenhum elemento.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Não confundas uma estrutura infinita com uma expressão que precisa de a
      percorrer toda.
    </div>
  </div>
</Exercise>

<Exercise
  id="safetail"
  revision={1}
  title="Cobrir a lista vazia"
  explanation="/cadeiras/pfl/haskell-expressoes-tipos/#funções-por-equações"
  answer={{
    kind: 'self',
    checklist: [
      'Trato [] explicitamente.',
      'Retiro a cabeça de uma lista não vazia.',
      'Conservo o tipo [a] -> [a].',
    ],
  }}
>
  <div>
    Define caudaSegura com padrões. Os testes devem produzir [], [] e [2,3].
  </div>
  <div slot="work">
    <CodePlayground
      language="haskell"
      title="Completa e compara com os resultados pedidos"
      code={
        'caudaSegura :: [a] -> [a]\ncaudaSegura xs = undefined\nmain :: IO ()\nmain = do\n  print (caudaSegura [] :: [Int])\n  print (caudaSegura [1::Int])\n  print (caudaSegura [1,2,3::Int])'
      }
    />
  </div>
  <div slot="hint">
    <p>Uma lista só tem dois construtores.</p>
  </div>
  <div slot="hint-more">
    <p>O resultado do caso x:xs é a cauda xs.</p>
  </div>
  <div slot="solution">
    <div>
      caudaSegura [] = []; caudaSegura (_:xs) = xs. As duas equações cobrem as
      formas da lista sem comparar os elementos.
    </div>
  </div>
  <div slot="mistakes">
    <p>Não uses head nem tail na equação do caso vazio.</p>
  </div>
</Exercise>
