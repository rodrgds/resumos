<Exercise
  id="intercalar"
  revision={1}
  title="Separadores só entre elementos"
  explanation="/cadeiras/pfl/listas-recursao/#intercalar-sem-acrescentar-nas-pontas"
  answer={{
    kind: 'self',
    checklist: [
      'Trato zero e um elemento sem separador.',
      'Produzo um separador por intervalo.',
      'A recursão recebe uma lista menor.',
    ],
  }}
>
  <div>
    Implementa intercalar. Para "", "q" e "qrs", com separador ':', os
    resultados pedidos são "", "q" e "q:r:s".
  </div>
  <div slot="work">
    <CodePlayground
      language="haskell"
      title="Completa os três casos"
      code={
        'intercalar :: a -> [a] -> [a]\nintercalar s xs = undefined\nmain :: IO ()\nmain = mapM_ (print . intercalar \':\') ["", "q", "qrs"]'
      }
    />
  </div>
  <div slot="hint">
    <p>Uma lista com um elemento não tem intervalo onde inserir.</p>
  </div>
  <div slot="hint-more">
    <div>
      Depois dos casos [] e [x], conserva a cabeça, o separador e o resultado da
      cauda.
    </div>
  </div>
  <div slot="solution">
    <div>
      intercalar _ [] = []; intercalar _ [x] = [x]; intercalar s (x:xs) =
      x:s:intercalar s xs.
    </div>
  </div>
  <div slot="mistakes">
    <p>Usar só o caso vazio e pôr sempre o separador acrescenta ':' no fim.</p>
  </div>
</Exercise>

<Exercise
  id="permutar"
  revision={1}
  title="Construir possibilidades a partir da cauda"
  explanation="/cadeiras/pfl/listas-recursao/#inserir-em-todas-as-posições-e-permutar"
  answer={{
    kind: 'self',
    checklist: [
      'A lista vazia tem uma possibilidade.',
      'Insiro a cabeça em cada posição de cada permutação da cauda.',
      'Explico por que valores repetidos podem repetir resultados.',
    ],
  }}
>
  <div>
    Implementa posicoes e permutar. Os testes devem dar ["pq","qp"], [[]] e 24.
    A enumeração trata ocorrências, sem eliminar valores iguais.
  </div>
  <div slot="work">
    <CodePlayground
      language="haskell"
      title="Completa a enumeração"
      code={
        'posicoes :: a -> [a] -> [[a]]\nposicoes x xs = undefined\npermutar :: [a] -> [[a]]\npermutar xs = undefined\nmain :: IO ()\nmain = do\n  print (permutar "pq")\n  print (permutar ([] :: [Int]))\n  print (length (permutar "pqrs"))'
      }
    />
  </div>
  <div slot="hint">
    <p>Uma lista de comprimento m tem m+1 posições de inserção.</p>
  </div>
  <div slot="hint-more">
    <div>
      Na posição inicial, usa x:y:ys. Nas seguintes, conserva y em cada
      possibilidade da cauda.
    </div>
  </div>
  <div slot="solution">
    <div>
      posicoes x [] = [[x]]; posicoes x (y:ys) = (x:y:ys):map (y:) (posicoes x
      ys). permutar [] = [[]]; permutar (x:xs) = concatMap (posicoes x)
      (permutar xs). Para quatro ocorrências, há 4×3×2×1=24 resultados.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      permutar [] = [] elimina todas as possibilidades nas chamadas anteriores.
      O tipo sem Eq não pode identificar valores iguais para os deduplicar.
    </div>
  </div>
</Exercise>

<Exercise
  id="to-bits"
  revision={1}
  title="Definir o domínio da conversão binária"
  explanation="/cadeiras/pfl/listas-recursao/#converter-inteiro-para-bits"
  answer={{
    kind: 'self',
    checklist: [
      'Rejeito negativos com Nothing.',
      'Represento zero por Just [0].',
      'Inverto os restos para obter o bit mais significativo primeiro.',
    ],
  }}
>
  <div>
    Implementa toBits com o contrato da lição. Para -3, 0 e 12, pede-se Nothing,
    Just [0] e Just [1,1,0,0].
  </div>
  <div slot="work">
    <CodePlayground
      language="haskell"
      title="Completa a conversão total"
      code={
        'toBits :: Integer -> Maybe [Integer]\ntoBits n = undefined\nmain :: IO ()\nmain = mapM_ (print . toBits) [-3,0,12]'
      }
    />
  </div>
  <div slot="hint">
    <p>Os restos de 12 são 0,0,1,1.</p>
  </div>
  <div slot="hint-more">
    <div>
      Trata os casos negativo e zero antes da função auxiliar que divide
      positivos.
    </div>
  </div>
  <div slot="solution">
    <div>
      Usa as três guardas da lição e reverse (restos n), com restos 0=[] e
      restos k = k `mod` 2 : restos (k `div` 2). O resultado lê os bits da
      esquerda para a direita.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      A divisão inteira de -1 por 2 dá -1; aplicar a recursão a negativos pode
      não terminar.
    </div>
  </div>
</Exercise>

<Exercise
  id="insercao"
  revision={1}
  title="Conservar uma lista ordenada"
  explanation="/cadeiras/pfl/listas-recursao/#ordenação-por-inserção"
  answer={{
    kind: 'self',
    checklist: [
      'Trato a lista vazia.',
      'Conservo a cabeça quando ainda não cheguei à posição de x.',
      'Conservo duplicados.',
    ],
  }}
>
  <div>
    Implementa inserir numa lista já ordenada. Os testes devem dar [2], [1,2,3]
    e [1,2,2,3].
  </div>
  <div slot="work">
    <CodePlayground
      language="haskell"
      title="Completa e compara com os resultados pedidos"
      code={
        'inserir :: Ord a => a -> [a] -> [a]\ninserir x xs = undefined\nmain :: IO ()\nmain = do\n  print (inserir 2 ([] :: [Int]))\n  print (inserir 2 [1,3::Int])\n  print (inserir 2 [1,2,3::Int])'
      }
    />
  </div>
  <div slot="hint">
    <p>Compara x com a primeira posição disponível.</p>
  </div>
  <div slot="hint-more">
    <div>
      Se x &lt;= y, produz x:y:ys; caso contrário, conserva y e continua em ys.
    </div>
  </div>
  <div slot="solution">
    <div>
      inserir x [] = [x]; inserir x (y:ys) | x &lt;= y = x:y:ys | otherwise =
      y:inserir x ys. O contrato pressupõe a lista de entrada ordenada.
    </div>
  </div>
  <div slot="mistakes">
    <p>Não voltes a inserir a cabeça y nem apagues uma ocorrência igual.</p>
  </div>
</Exercise>

      'Obtenho [0,2,4] para indices \'r\' "rarar".',

    ],
  }}
>
  <div>
    Calcula `indices 'r' "rarar"` com a função da lição. Por que termina apesar
    de usar `[0..]`?
  </div>
  <div slot="hint">
    <p>Segue os pares que `zip` produz.</p>
  </div>
  <div slot="hint-more">

  </div>
  <div slot="solution">
    O resultado é `[0,2,4]`. `zip` para ao terminar a string finita, sem

  </div>

  </div>
