    Ao juntar [2,5] e [1,5], depois de escolher 1, quais são as duas listas

  </p>
  <div slot="hint">

  </div>

<Exercise
  id="bits"
  title="Interpretar um prefixo binário"
  explanation="/cadeiras/pfl/listas-recursao/#acumular-uma-representação-binária"
  answer={{ kind: 'number', value: 26, tolerance: 0 }}
>
  <p>Quanto vale foldl (\n b -&gt; 2*n+b) 0 [1,1,0,1,0]?</p>
  <div slot="hint">
    <p>Cada bit duplica o prefixo anterior e soma o bit.</p>
  </div>
  <div slot="hint-more">
    <p>Os acumuladores começam em 0,1,3,6.</p>
  </div>
  <div slot="solution">
    <p>A sequência completa é 0,1,3,6,13,26. O resultado é 26.</p>
  </div>
  <div slot="mistakes">
    <p>
      Não confundas a ordem dos bits com a ordem dos restos numa conversão por
      divisão.
    </p>
  </div>
</Exercise>

<Exercise
  id="insercao"
  title="Conservar uma lista ordenada"
  explanation="/cadeiras/pfl/listas-recursao/#ordenação-por-inserção"
  answer={{
    kind: 'self',
    checklist: [
      'Trato a lista vazia.',
      'Conservo a cabeça quando ainda não cheguei à posição de x.',
      'Conservo duplicados.',
    ],
  }}
>
  <p>
    Implementa inserir numa lista já ordenada. Os testes devem dar [2], [1,2,3]
    e [1,2,2,3].
  </p>
  <div slot="work">
    <CodePlayground
      language="haskell"
      title="Completa e compara com os resultados pedidos"
      code={
        'inserir :: Ord a => a -> [a] -> [a]\ninserir x xs = undefined\nmain :: IO ()\nmain = do\n  print (inserir 2 ([] :: [Int]))\n  print (inserir 2 [1,3::Int])\n  print (inserir 2 [1,2,3::Int])'
      }
    />
  </div>
  <div slot="hint">
    <p>Compara x com a primeira posição disponível.</p>
  </div>
  <div slot="hint-more">
    <p>
      Se x &lt;= y, produz x:y:ys; caso contrário, conserva y e continua em ys.
    </p>
  </div>
  <div slot="solution">
    <p>
      inserir x [] = [x]; inserir x (y:ys) | x &lt;= y = x:y:ys | otherwise =
      y:inserir x ys. O contrato pressupõe a lista de entrada ordenada.
    </p>
  </div>
  <div slot="mistakes">
    <p>Não voltes a inserir a cabeça y nem apagues uma ocorrência igual.</p>
  </div>
</Exercise>
