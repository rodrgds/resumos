<Exercise
  id="compreensao"
  revision={2}
  title="Ordem e dependência dos geradores"
  explanation="/cadeiras/pfl/listas-recursao/#geradores-e-condições"
  answer={{ kind: 'self', checklist: ['Enumero os pares na ordem dos geradores.', 'Mostro a ordem alterada quando troco geradores independentes.', 'Explico por que um gerador dependente não pode passar para a frente.'] }}
>
  <div>
Escreve o resultado de `[(x,y) | x <- [2,3], y <- [7,8], x+y>=10]`. Repete com os dois geradores trocados e a condição no fim. Depois explica por que não podemos fazer a mesma troca em `[(x,y) | x <- [1..3], y <- [x..3]]`.
  </div>
  <div slot="hint">Lista candidatos antes de aplicar a condição.</div>
  <div slot="solution">
Com `x` exterior, os candidatos são `(2,7)`, `(2,8)`, `(3,7)` e `(3,8)`. Depois do filtro ficam `[(2,8),(3,7),(3,8)]`.

Com `y` exterior, a ordem é `(2,7)`, `(3,7)`, `(2,8)`, `(3,8)`. Ficam `[(3,7),(2,8),(3,8)]`. Os pares são os mesmos, mas a sequência mudou.

No último caso, `[x..3]` precisa do `x` ligado pelo gerador anterior. Trocá-los deixa `x` fora do âmbito e produz um erro antes da avaliação.

  </div>
  <div slot="mistakes">Uma compreensão constrói uma lista ordenada por geração, não um conjunto.</div>
</Exercise>

<Exercise
  id="to-bits"
  revision={1}
  title="Definir o domínio da conversão binária"
  explanation="/cadeiras/pfl/listas-recursao/#converter-inteiro-para-bits"
  answer={{
    kind: 'self',
    checklist: [
      'Rejeito negativos com Nothing.',
      'Represento zero por Just [0].',
      'Inverto os restos para obter o bit mais significativo primeiro.',
    ],
  }}
>
  <div>
    Implementa toBits com o contrato da lição. Para -3, 0 e 12, pede-se Nothing,
    Just <code>{'[0]'}</code> e Just <code>{'[1,1,0,0]'}</code>.
  </div>
  <div slot="work">
    <CodePlayground
      autoRun={false}
      language="haskell"
      title="Completa a conversão total"
      code={
        'toBits :: Integer -> Maybe [Integer]\ntoBits n = undefined\nmain :: IO ()\nmain = mapM_ (print . toBits) [-3,0,12]'
      }
    />
  </div>
  <div slot="hint">
    <p>Os restos de 12 são 0,0,1,1.</p>
  </div>
  <div slot="hint-more">
    <div>
      Trata os casos negativo e zero antes da função auxiliar que divide
      positivos.
    </div>
  </div>
  <div slot="solution">
```haskell
toBits :: Integer -> Maybe [Integer]
toBits n
  | n < 0 = Nothing
  | n == 0 = Just [0]
  | otherwise = Just (reverse (restos n))
  where
    restos 0 = []
    restos k = k `mod` 2 : restos (k `div` 2)
```

Para `12`, os quocientes são `6`, `3`, `1`, `0` e os restos são `0`, `0`, `1`, `1`. A lista de restos nasce do bit menos significativo para o mais significativo. `reverse` dá `Just [1,1,0,0]`. As guardas tratam negativos e zero antes de chamar `restos`.

  </div>
  <div slot="mistakes">
    <div>
      A divisão inteira de -1 por 2 dá -1; aplicar a recursão a negativos pode
      não terminar.
    </div>
  </div>
</Exercise>

<Exercise
  id="derivacao-myindex"
  revision={2}
  title="Índice, domínio e ausência"
  explanation="/cadeiras/pfl/listas-recursao/#derivar-myindex-por-casos"
  answer={{ kind: 'self', checklist: ['Escrevo equações que reduzem índice e cauda.', 'Declaro o domínio da versão parcial.', 'Trato negativos e fim de lista numa versão Maybe.'] }}
>
  <div>
Define `myindex :: [a] -> Int -> a` por padrões, para índices válidos a partir de zero. Segue `myindex [7,9,11] 2` e declara o domínio. Define depois `indexSeguro :: [a] -> Int -> Maybe a`, que dá `Nothing` para um índice negativo ou além do fim.
  </div>
  <div slot="hint">Separa índice zero, índice positivo e ausência de um elemento.</div>
  <div slot="solution">
Na versão parcial:

```haskell
myindex (x:_) 0 = x
myindex (_:xs) n = myindex xs (n-1)
```

O domínio é uma lista finita com `0 <= n < length xs`. A chamada passa por `myindex [9,11] 1` e `myindex [11] 0`, que dá `11`. A cauda e o índice diminuem em conjunto.

```haskell
indexSeguro :: [a] -> Int -> Maybe a
indexSeguro _ n | n < 0 = Nothing
indexSeguro [] _ = Nothing
indexSeguro (x:_) 0 = Just x
indexSeguro (_:xs) n = indexSeguro xs (n-1)
```

A guarda negativa vem antes da recursão. O fim da lista é ausência de resposta, não uma exceção. Os índices `-1`, `2` e `3` em `[7,9,11]` dão `Nothing`, `Just 11` e `Nothing`.

  </div>
  <div slot="mistakes">A assinatura da versão parcial permite índices inválidos; o domínio precisa de ser declarado.</div>
</Exercise>
