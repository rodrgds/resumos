<Exercise
  id="gerador-valido"
  revision={2}
  title="Testar uma ordenação contra implementações erradas"
  explanation="/cadeiras/pfl/testes-quickcheck/#contrato-da-ordenação"
  answer={{ kind: 'self', checklist: ['Gero listas de Int no intervalo dado.', 'Testo ordem e multiplicidades da saída de f.', 'Dou contraexemplos distintos para perda e falta de ordenação.'] }}
>
  <div>
Escreve `prop_ordena :: ([Int] -> [Int]) -> Property`. Gera listas com valores entre `-10` e `10`, incluindo a possibilidade de lista vazia. A propriedade deve exigir saída ordenada e os mesmos elementos com as mesmas multiplicidades.

Mostra um contraexemplo para `f xs = []` e outro para `f xs = xs`. Compara com `sort`. Se o gerador for usado com `forAll`, há redução automática dos contraexemplos?

  </div>
  <div slot="hint">Testa a função recebida, não apenas a função de referência.</div>
  <div slot="solution">
Podemos comparar multiplicidades com uma referência independente e comparar vizinhos para a ordem:

```haskell
import Data.List (sort)
import Test.QuickCheck

ordenada :: [Int] -> Bool
ordenada xs = and (zipWith (<=) xs (drop 1 xs))

prop_ordena :: ([Int] -> [Int]) -> Property
prop_ordena f = forAll genLista $ \xs ->
  let ys = f xs
  in ordenada ys && sort ys == sort xs
  where
    genLista :: Gen [Int]
    genLista = listOf (choose (-10,10))
```

`sort ys == sort xs` compara todas as ocorrências, incluindo valores fora do intervalo que uma implementação errada pudesse inventar. A função constante falha para `[0]`: `[]` perde esse elemento. A identidade falha para `[1,0]`: conserva os dados, mas a saída não está ordenada. `sort` satisfaz ambas as partes nos casos gerados.

`forAll` não aplica automaticamente um redutor ao gerador próprio. Para reduzir estas listas, usa `forAllShrink genLista shrink`; verifica sempre que o redutor conserva as condições exigidas pelo problema. Nenhuma das duas formas prova a lei para todas as listas.

  </div>
  <div slot="mistakes">Idempotência passa nas duas funções erradas. Contar só valores do gerador pode ignorar uma saída inventada.</div>
</Exercise>
