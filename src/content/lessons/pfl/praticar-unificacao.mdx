<Exercise
  id="substituicao"
  revision={1}
  title="Propagar uma substituição"
  explanation="/cadeiras/pfl/logica-unificacao-prolog/#termos-e-variáveis-de-cada-cláusula"
  answer={{
    kind: 'self',
    checklist: [
      'Ligo X a a.',
      'Propago a ligação à segunda posição.',
      'Ligo Y a f(a) sem alterar constantes.',
    ],
  }}
>
  <p>
    Unifica <code>{'t(X,g(X),Y)'}</code> com <code>{'t(a,g(a),f(a))'}</code>.
  </p>
  <div slot="hint">
    <p>Compara os argumentos do mesmo functor um por um.</p>
  </div>
  <div slot="hint-more">
    <p>
      A segunda posição já concorda depois de <code>{'X=a'}</code>.
    </p>
  </div>
  <div slot="solution">
    <div>
      A substituição é <code>{'X=a'}</code>,Y=<code>{'f(a)'}</code>. As duas
      ocorrências de X recebem a mesma ligação.
    </div>
  </div>
  <div slot="mistakes">
    <p>Não cries uma substituição independente para cada ocorrência de X.</p>
  </div>
</Exercise>

<Exercise
  id="occurs"
  revision={1}
  title="Unificação de termos finitos"
  explanation="/cadeiras/pfl/logica-unificacao-prolog/#ocorre-a-variável-dentro-do-termo"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'Não; falha no occurs check.',
        correct: true,
        explanation: 'A ligação criaria um termo que contém a si próprio.',
      },
      {
        text: 'Sim; basta substituir X por f(X).',
        correct: false,
        explanation: 'A substituição volta a conter X indefinidamente.',
      },
      {
        text: 'Só se f tiver um argumento.',
        correct: false,
        explanation: 'A aridade não elimina o ciclo.',
      },
    ],
  }}
>
  <div>
    Em unificação de Herbrand sobre termos finitos, X pode unificar com{' '}
    <code>{'f(X)'}</code>?
  </div>
  <div slot="hint">
    <p>Procura X dentro do termo proposto para X.</p>
  </div>
  <div slot="hint-more">
    <p>A nova estrutura teria de conter a estrutura completa outra vez.</p>
  </div>
  <div slot="solution">
    <div>
      Falha no modelo de termos finitos. O = de algumas implementações aceita
      rational trees, um contrato diferente.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Não uses o comportamento de uma implementação sem occurs check como prova
      do exercício teórico.
    </div>
  </div>
</Exercise>

<Exercise
  id="negacao"
  revision={1}
  title="Negar sem gerar candidatos"
  explanation="/cadeiras/pfl/logica-unificacao-prolog/#negação-por-falha"
  answer={{
    kind: 'choice',
    options: [
      {
        text: 'Falha sem devolver uma lista de não pais.',
        correct: true,
        explanation: 'Encontrar uma prova positiva faz falhar a negação.',
      },
      {
        text: 'Devolve todas as pessoas exceto ana.',
        correct: false,
        explanation: 'A negação não enumera o domínio.',
      },
      {
        text: 'Liga X a ana e tem sucesso.',
        correct: false,
        explanation: 'Essa prova é precisamente o motivo da falha.',
      },
    ],
  }}
>
  <p>
    Existe o facto <code>{'pai(ana,leo)'}</code>. Que sucede com a consulta \+{' '}
    <code>{'pai(X,leo)'}</code>?
  </p>
  <div slot="hint">
    <p>Tenta provar o objetivo interior.</p>
  </div>
  <div slot="hint-more">
    <p>
      <code>{'pai(ana,leo)'}</code> satisfaz o objetivo.
    </p>
  </div>
  <div slot="solution">
    <div>
      A consulta falha. Para procurar não pais, enumera primeiro pessoas e nega
      o objetivo com cada pessoa instanciada.
    </div>
  </div>
  <div slot="mistakes">
    <div>
      Não leias negação por falha como complemento de um conjunto já conhecido.
    </div>
  </div>
</Exercise>

<Exercise
  id="sld-completa"
  revision={1}
  title="Resolução SLD com retrocesso"
  explanation="/cadeiras/pfl/logica-unificacao-prolog/#árvore-sld-com-falha-e-alternativa"
  answer={{
    kind: 'self',
    checklist: [
      'Renomeio variáveis da cláusula copiada.',
      'Escolho o objetivo mais à esquerda.',
      'Mostro um ramo falhado e a alternativa com sucesso.',
    ],
  }}
>
  <div>Resolve avo(tomas, N) com resolventes e substituições até N = leo.</div>
  <div slot="hint">
    <p>Começa por avo(X1, Z1) :- pai(X1, Y1), pai(Y1, Z1).</p>
  </div>
  <div slot="hint-more">
    <p>Propaga Y1 = ana ao segundo objetivo.</p>
  </div>
  <div slot="solution">
    <div>
      Resolvente pai(tomas, Y1), pai(Y1, N); depois pai(ana, N); depois N = leo.
    </div>
  </div>
  <div slot="mistakes">
    <div>Não reutilizes nomes sem renomear.</div>
  </div>
</Exercise>
