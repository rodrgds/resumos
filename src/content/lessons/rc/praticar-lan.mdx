  <p>
    {

    }
  </p>
  <p slot="hint">{'Inunda todas exceto a entrada.'}</p>
  <p slot="hint-more">{'A origem é aprendida, mas o destino ainda não.'}</p>

  </p>

</Exercise>

<Exercise

  answer={{
    kind: 'choice',
    options: [
      {
        text: 'IP de B; MAC da interface de saída de R.',
        correct: true,
        explanation:
          'IP identifica a origem do pacote; MAC identifica o emissor no salto local.',
      },
      {
        text: 'IP de R; MAC de B.',
        correct: false,
        explanation: 'O router não substitui o IP de origem neste cenário.',
      },
      {
        text: 'IP de B; MAC do comutador intermédio.',
        correct: false,
        explanation: 'O comutador mantém a origem da trama.',
      },
    ],
  }}
>
  <p>
    {
      'B enviou um pacote a A através de um router R, sem NAT. Na trama que chega a A, quais as origens IP e MAC?'
    }
  </p>
  <p slot="hint">{'Distingue extremo do pacote e extremo da trama.'}</p>
  <p slot="hint-more">{'O router constrói uma trama nova ao sair.'}</p>
  <p slot="solution">
    {'IP de Be MAC da interface de R que envia para a rede de A.'}
  </p>
  <p slot="mistakes">{'Atribuir o MAC de origem ao comutador.'}</p>
</Exercise>
