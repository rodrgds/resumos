<Exercise
  id="so-maximo-validado"
  revision={1}
  title="Escrever um comando de máximo"
  explanation="/cadeiras/so/c-avancado/#argumentos-e-conversão"
  answer={{kind: 'self', checklist: [
    'Rejeitei falta de números, texto inválido e valores fora de int.',
    'Obtive -2 para -8 -2 -11 e 0 para 0.',
    'Só apresentei o máximo depois de validar todos os argumentos.',
  ]}}
>
  <div>

Escreve em C um comando `maximo` que recebe um ou mais inteiros decimais representáveis por `int`. Deve escrever o máximo, ou terminar com erro sem imprimir um resultado se algum argumento for inválido. Verifica `./maximo -8 -2 -11`, `./maximo 0`, `./maximo`, `./maximo 12x` e um número maior do que `INT_MAX`. O executor C do navegador não passa estes argumentos; usa o terminal UNIX.

  </div>
  <div slot="hint">Valida cada string com `strtol` antes de a comparar.</div>
  <div slot="hint-more">O primeiro número válido inicializa o máximo. Um zero devolvido por `strtol` só é válido se houve conversão completa e não houve erro.</div>
  <div slot="solution">

Guarda este programa em `maximo.c` e compila com `cc -std=c17 -Wall -Wextra -Wpedantic maximo.c -o maximo`.

```c
#include <errno.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {
    if (argc < 2) {
        fprintf(stderr, "uso: %s inteiro [inteiros]\n", argv[0]);
        return 1;
    }
    int maximo = 0;
    for (int i = 1; i < argc; i++) {
        errno = 0;
        char *fim;
        long valor = strtol(argv[i], &fim, 10);
        if (errno == ERANGE || fim == argv[i] || *fim != '\0' ||
            valor < INT_MIN || valor > INT_MAX) {
            fprintf(stderr, "inteiro invalido: %s\n", argv[i]);
            return 1;
        }
        if (i == 1 || valor > maximo) maximo = (int)valor;
    }
    if (printf("%d\n", maximo) < 0 || fflush(stdout) == EOF) return 1;
    return 0;
}
```

A atribuição com `i == 1` substitui o zero inicial antes de qualquer comparação. Os dois primeiros comandos escrevem `-2` e `0`; os restantes terminam com estado 1. Uma entrada inválida posterior, como `./maximo 7 12x`, também rejeita todo o pedido.

  </div>
  <div slot="mistakes">Aceitar só o prefixo numérico de `12x`, converter para `int` antes de testar os limites ou imprimir um máximo parcial antes de detetar o erro.</div>
</Exercise>
