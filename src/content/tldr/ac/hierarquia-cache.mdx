## Organização

| Organização       | Bloco entra em               |
| ----------------- | ---------------------------- |
| Direta            | Uma linha, dada pelo índice  |
| $A$ vias          | Qualquer via do seu conjunto |
| Totalmente assoc. | Qualquer linha               |

- Hit exige entrada **válida** com a etiqueta pedida. Com $C$ bytes de dados, $B$ por linha e $A$ vias: $S=C/(BA)$ conjuntos.
- Registos/SRAM rápidos e caros; DRAM maior; armazenamento conserva sem alimentação.

## Endereço de byte

$$q=E//B,\quad o=E\bmod B,\quad i=q\bmod S,\quad t=q//S.$$

- Só o deslocamento muda dentro da linha. Endereço em palavras: multiplica por 4.
- Bits físicos: linhas × (dados + etiqueta + validade + dirty + política).

## Substituição e faltas

- Usa primeiro via inválida. Acerto atualiza LRU, não FIFO.
- **Compulsória:** primeira referência. **Capacidade:** persistiria totalmente associativa. **Conflito:** só pelo mapeamento.
- Mais vias ou linhas maiores não garantem melhor desempenho.

## Matrizes

Ordem por linhas: variar o índice interno percorre vizinhos; variar o externo salta linhas. Percurso por colunas com linhas curtas multiplica faltas.
