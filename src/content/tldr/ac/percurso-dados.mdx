| Instrução | ALUSrc | MemtoReg | RegWrite | MemRead | MemWrite | Branch | ALUOp |
| --------- | ------ | -------- | -------- | ------- | -------- | ------ | ----- |
| R         | 0      | 0        | 1        | 0       | 0        | 0      | 10    |
| `lw`      | 1      | 1        | 1        | 1       | 0        | 0      | 00    |
| `sw`      | 1      | X        | 0        | 0       | 1        | 0      | 00    |
| `beq`     | 0      | X        | 0        | 0       | 0        | 1      | 01    |

- X é indiferente porque a instrução não escreve registos. ALUOp 00 soma, 01 subtrai para igualdade, 10 descodifica.
- Salto tomado usa o PC da instrução mais o deslocamento B; senão, `PC+4`.

## Organizações

- **Ciclo único:** período acomoda o caminho combinacional mais lento. Soma séries, não paralelos.
- **Multiciclo:** R 4 ciclos, load 5, store 4, branch 3. $CPI=\sum_i p_iCPI_i$. Compara **CPI × período**.
- **Pipeline:** `rd`, `RegWrite` e seleção do retorno atravessam registos até WB. Bolha desativa escritas sem apagar dados antigos.
