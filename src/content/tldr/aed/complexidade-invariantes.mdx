Invariante: `melhor` é a primeira posição do máximo em `[0,i)`. Fecha com `i=n`. Usa `>` para conservar o primeiro; `>=` daria o último. São `n-1` comparações.

## Contar sem adivinhar

| Padrão                                         | Total                            | Ordem            |
| ---------------------------------------------- | -------------------------------- | ---------------- |
| Seguidos de `n`                                | `2n`                             | $\Theta(n)$      |
| Encaixados de `n`, `n` interiores por exterior | $n^2$                            | $\Theta(n^2)$    |
| `1+…+n`                                        | $n(n+1)/2$                       | $\Theta(n^2)$    |
| Duplicar de `i=1` enquanto `i<n`, `n>=1`       | $\lceil\log_2 n\rceil$ iterações | $\Theta(\log n)$ |
| Duplicar com interior `i`                      | $<2n$                            | $\Theta(n)$      |

Ciclos seguidos somam os custos; ciclos encaixados com interior independente multiplicam as contagens, e o caso triangular soma `1+…+n`. Copiar `n` posições custa $\Theta(n)$. Percorrer uma string de comprimento `L` custa $\Theta(L)$ por passagem; juntar com `+=` repetido recopia o acumulado em cada passo, por isso fixa a operação antes de contar.

## Limites e recorrências

- $O$ limita por cima, $\Omega$ por baixo, $\Theta$ pede os dois. Indica sempre o caso: $O$ não significa pior caso.
- $3n^2+7n+4$ cabe entre $3n^2$ e $14n^2$ para $n\ge1$: $\Theta(n^2)$.
- Ordem usual: $1\prec\log n\prec n\prec n\log n\prec n^2\prec2^n\prec n!$.

| Recorrência         | Resultado         |
| ------------------- | ----------------- |
| $2T(n/2)+\Theta(n)$ | $\Theta(n\log n)$ |
| $2T(n/2)+\Theta(1)$ | $\Theta(n)$       |
| $T(n/2)+\Theta(1)$  | $\Theta(\log n)$  |
| $T(n-1)+\Theta(n)$  | $\Theta(n^2)$     |

Pilha recursiva ocupa $O(h)$. Média exige distribuição; amortizado limita sequências sem sorteio. Vetor que duplica dá $O(1)$ amortizado por inserção.

## Somas rápidas
