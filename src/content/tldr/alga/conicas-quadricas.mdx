## Matriz da forma quadrática

$$
ax^2+2bxy+cy^2=X^TAX,\qquad
A=\begin{bmatrix}a&b\\b&c\end{bmatrix},\qquad X=(x,y)^T.
$$

A entrada fora da diagonal é **metade** do coeficiente cruzado. Em três variáveis, faz o mesmo para $xy,xz,yz$.

## Retirar termos cruzados e lineares

Para $q(X)=X^TAX+\ell^TX+k$, com $A$ real simétrica:

1. Resolve $2Ah+\ell=0$ para encontrar um centro. Se $A$ for invertível, $h=-\frac12A^{-1}\ell$; se for singular, pode não haver solução ou haver uma família.
2. Usa $X=h+Y$. Quando existe centro, fica $q(h+Y)=Y^TAY+q(h)$.
3. Escolhe uma base ortonormada de vetores próprios e põe-os nas colunas de $Q$. Com $Y=QU$, $Q^TAQ=D$ retira os termos cruzados.
4. Normaliza a equação final e identifica a curva ou superfície, incluindo casos degenerados.

Uma substituição numa forma quadrática produz $P^TAP$. Não podes trocar isso por $P^{-1}AP$ numa base arbitrária. A base ortonormada conserva comprimentos e permite ler semieixos nas mesmas unidades.

Para $2x^2+2xy+2y^2-6x-6y+3=0$, o centro é $(1,1)$ e $q(h)=-3$. Com

$$
u=\frac{x+y-2}{\sqrt2},\qquad v=\frac{x-y}{\sqrt2},
$$

fica $3u^2+v^2=3$, uma elipse com semieixos $1,\sqrt3$. O eixo maior segue $(1,-1)$.

## Cónicas

Depois de retirar termos cruzados e completar quadrados, compara a equação final. Assume $a,b>0$ e $p\ne0$.

| Forma               | Curva                   |
| ------------------- | ----------------------- |
| $u^2/a^2+v^2/b^2=1$ | Elipse                  |
| $u^2/a^2-v^2/b^2=1$ | Hipérbole               |
| $v^2=4pu$           | Parábola                |
| $u^2/a^2+v^2/b^2=0$ | Um ponto                |
| $u^2/a^2-v^2/b^2=0$ | Duas retas concorrentes |
| $u^2=a^2$           | Duas retas paralelas    |
| $u^2=0$             | Reta dupla              |
| $u^2+v^2=-1$        | Conjunto vazio          |

Os sinais próprios não decidem tudo. Com dois valores positivos, a constante distingue elipse, ponto e vazio. Um valor próprio zero não prova que seja parábola: $x^2-2y=0$ é parábola, mas $x^2-1=0$ dá duas retas.

## Quádricas

Com $a,b,c>0$:

| Forma                        | Superfície                      |
| ---------------------------- | ------------------------------- |
| $u^2/a^2+v^2/b^2+w^2/c^2=1$  | Elipsoide                       |
| $u^2/a^2+v^2/b^2-w^2/c^2=1$  | Hiperboloide de uma folha       |
| $-u^2/a^2-v^2/b^2+w^2/c^2=1$ | Hiperboloide de duas folhas     |
| $u^2/a^2+v^2/b^2-w^2/c^2=0$  | Cone elíptico                   |
| $u^2/a^2+v^2/b^2=1$          | Cilindro elíptico, livre em $w$ |
| $w=u^2/a^2+v^2/b^2$          | Paraboloide elíptico            |
| $w=u^2/a^2-v^2/b^2$          | Paraboloide hiperbólico         |

Uma variável ausente fica livre. Confere os casos degenerados pela equação final.

Para distinguir folhas, corta em $w=t$: $u^2+v^2-w^2=1$ dá circunferências para todo $t$; $-u^2-v^2+w^2=1$ exige $|t|\ge1$, ficando duas partes separadas.
