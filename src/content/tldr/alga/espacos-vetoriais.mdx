## Subespaços e espaço gerado

Um espaço vetorial real tem soma e produto por escalar com as regras usuais. Um subconjunto é **subespaço** se contém o zero e é fechado para soma e multiplicação por qualquer escalar real.

- Equações lineares homogéneas definem subespaços. Um plano deslocado que não contém a origem falha logo o teste do zero.
- $\operatorname{span}(v_1,\ldots,v_k)$ é o conjunto de todas as combinações $\sum_i a_iv_i$, com $a_i\in\mathbb R$.
- A interseção de subespaços é subespaço. A união pode falhar o fecho para soma: os eixos contêm $(1,0)$ e $(0,1)$, mas não $(1,1)$.

## Independência, bases e dimensão

Os vetores $v_1,\ldots,v_k$ são independentes se

$$
\sum_{i=1}^k a_iv_i=0\quad\Longrightarrow\quad a_1=\cdots=a_k=0.
$$

Uma **base** gera o espaço e é independente. Cada vetor tem uma escrita única nessa base. A dimensão é o número de vetores de qualquer base de um espaço de dimensão finita.

- Coloca os vetores em colunas. São independentes se houver um pivô por coluna. Para $n$ vetores de $\mathbb R^n$, equivale a determinante não nulo.
- Mais vetores do que a dimensão, ou uma família que contenha zero, implicam dependência.
- Numa dimensão $n$, uma família de $n$ vetores é base se for independente, ou se gerar o espaço.
- $\{0\}$ tem dimensão 0 e base vazia.

## Obter e completar bases

| Descrição do subespaço             | Método                                                                                                         |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Geradores                          | Elimina a matriz das colunas. Escolhe as **colunas originais** nas posições dos pivôs                          |
| Equações homogéneas $Ax=0$         | Parametriza pelas variáveis livres e recolhe os vetores dos parâmetros; a dimensão é $n-\operatorname{car}(A)$ |
| Testar pertença de $w$ a geradores | Resolve $\sum_i a_iv_i=w$                                                                                      |
| Completar uma base                 | Acrescenta vetores fora do espaço já gerado até atingir a dimensão pretendida                                  |

Para $v_1=(1,0,1)$, $v_2=(0,1,1)$, $v_3=(1,1,2)$, temos $v_3=v_1+v_2$. Uma base é $(v_1,v_2)$, a dimensão é 2 e o espaço é $z=x+y$. Assim, $(2,-1,1)$ pertence ao espaço; $(2,-1,0)$ não pertence. Acrescentar $(0,0,1)$ completa a base a $\mathbb R^3$.

## Soma e interseção

Para subespaços de dimensão finita:

$$
U+V=\{u+v:u\in U,v\in V\},\qquad
\dim(U+V)=\dim U+\dim V-\dim(U\cap V).
$$

- Para a soma, junta os geradores e extrai uma base.
- Para a interseção, junta as equações. Se tens geradores, resolve $\sum_i a_i u_i=\sum_j b_jv_j$ e reconstrói os vetores comuns.
- A soma é direta, $U\oplus V$, exatamente quando $U\cap V=\{0\}$. Cada vetor da soma tem então uma decomposição única.

## Coordenadas e outros espaços

Numa base ordenada $B=(b_1,\ldots,b_n)$, as coordenadas de $v=\sum_i a_ib_i$ são $[v]_B=(a_1,\ldots,a_n)^T$. A ordem e a base fazem parte do significado.

- Em $B=((1,1),(1,-1))$, $(3,1)=2(1,1)+(1,-1)$, logo $[v]_B=(2,1)^T$.
- $P_2(\mathbb R)$ contém polinómios de grau **no máximo** 2 e tem base $(1,t,t^2)$, dimensão 3. Grau exatamente 2 não define um subespaço.
- As matrizes reais $2\times2$ formam um espaço de dimensão 4, com uma base de matrizes que têm um único 1.
