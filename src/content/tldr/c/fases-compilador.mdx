## Artefactos e responsabilidades

| Fase              | Recebe e produz                                                   |
| ----------------- | ----------------------------------------------------------------- |
| Léxico            | Caracteres → tokens com categoria, lexema e posição               |
| Sintaxe           | Tokens → árvore segundo a gramática                               |
| Semântica         | Árvore → nomes resolvidos e tipos verificados                     |
| Código intermédio | Árvore validada → operações e controlo explícitos                 |
| Otimização        | Representação válida → outra com o mesmo comportamento observável |
| Geração           | Representação intermédia → instruções e armazenamento do alvo     |

A tabela de símbolos guarda declarações e tipos; as fases conservam posições para erros úteis. O léxico não resolve a declaração de cada nome nem calcula expressões.

## Uma tradução

Em `x = a + b * 2`, os tokens classificam nomes, operadores e o literal. A AST tem atribuição a x, soma na expressão e produto no ramo direito. Com nomes inteiros declarados:

```text
t1 = b * 2
t2 = a + t1
x = t2
```

Com `a = 3` e `b = 4`, o resultado é 11. O compilador gera operações sem conhecer esses valores; o cálculo confere a tradução.

O front-end valida a linguagem; o back-end traduz para o alvo. Bytecode pode depois ser interpretado ou compilado por um JIT. A fronteira é a tarefa executada, não uma classificação fixa da linguagem. [Percurso completo](/cadeiras/c/fases-compilador/#tokens-árvore-e-código-intermédio).
