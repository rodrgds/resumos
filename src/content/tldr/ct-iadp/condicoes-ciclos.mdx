## Decisões

- Uma cadeia `if`/`elif`/`else` executa o primeiro ramo verdadeiro. Dois `if` independentes podem executar ambos.
- A indentação define o bloco. `and` e `or` usam curto-circuito: `b != 0 and a / b > 2` só divide se `b` não for zero.
- Zero, coleções vazias e `None` são falsos; a string `"False"` é verdadeira. Testa ausência com `is None`.

## Ciclos e limites

| Operação                    | Condição de execução                                    |
| --------------------------- | ------------------------------------------------------- |
| `while condicao`            | Testa antes de cada iteração; pode não executar nenhuma |
| `for x in valores`          | Percorre os elementos do iterável                       |
| `range(inicio, fim, passo)` | Inclui início, exclui fim; passo não pode ser zero      |
| `break`                     | Termina o ciclo mais próximo                            |
| `continue`                  | Avança para a próxima iteração                          |
| `else` de um ciclo          | Executa na terminação normal, sem `break`               |

`range(2, 9, 2)` dá 2, 4, 6 e 8; `range(5, 0, -2)` dá 5, 3 e 1. Para incluir `n`, usa `range(1, n + 1)`. Num `while`, identifica a atualização que torna a condição falsa.

## Acumuladores e casos limite

<CodePlayground
  language="python"
  title="Média dos positivos"
  code={
    'valores = [3, -1, 4, 0, 2]\ntotal = 0\nn = 0\nfor x in valores:\n    if x > 0:\n        total += x\n        n += 1\nprint(total / n if n else None)'
  }
/>

A soma é 9 e o denominador é 3 positivos, por isso a média é 3. Sem positivos, não existe essa média. Uma soma começa em zero e um produto em um; o máximo de uma sequência não vazia começa num elemento existente, para funcionar com negativos.

Ao guardar a posição do máximo, `>` conserva o primeiro empate e `>=` o último. Para os dois maiores valores distintos, inicializa pelos dois primeiros, exigindo pelo menos dois valores distintos; ao aparecer um novo máximo, o antigo passa a segundo.

## Parar com uma justificação

- Um inteiro primo é pelo menos 2. Encontrar um divisor entre 2 e `n - 1` basta para rejeitar a primalidade; terminar sem divisor permite aceitá-la.
- Para o MDC de inteiros positivos, procura divisores comuns do menor para baixo. O primeiro encontrado é o maior: em 18 e 12, é 6; em 7 e 5, é 1.
