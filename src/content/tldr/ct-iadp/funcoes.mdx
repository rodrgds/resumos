A chamada devolve 6,75 euros: 90% de 7,50. Os nomes na definição são **parâmetros** e os valores da chamada são **argumentos**.

- `return` termina a chamada e entrega um valor. `print` apresenta-o; uma função sem retorno explícito devolve `None`.
- Argumentos posicionais precedem argumentos por nome. Não forneças o mesmo parâmetro duas vezes.
- `*args` recolhe posicionais num tuplo; `**kwargs` recolhe argumentos por nome num dicionário. Na chamada, `f(*lista)` expande os elementos e `f(**dicionario)` expande pelas chaves.
- `lambda x: x * x` devolve uma expressão. `map` devolve um iterador; `list(map(...))` materializa os resultados.

## Âmbito e mutabilidade

Uma atribuição na função cria normalmente um nome local. `global` permite alterar um nome do módulo; passar parâmetros e devolver resultados torna essa dependência explícita.

Uma lista recebida continua partilhada com o chamador: `valores.append(0)` altera-a. `return valores + [0]` cria outra lista exterior.

```python
def juntar(valor, valores=None):
    if valores is None:
        valores = []
    valores.append(valor)
    return valores
```

Os valores por defeito são criados na definição. Usar `valores=[]` partilharia a lista entre chamadas; o padrão com `None` cria uma lista em cada chamada que omite o argumento.

## Contrato e composição

- Define entradas válidas, retorno e alterações permitidas. Uma média exige números e pelo menos uma observação; rejeita o vazio com `raise ValueError`, sem inventar zero.
- Testa casos normais e limites. `assert` confere expectativas, mas pode ser desativado; valida entradas com condições e `raise`.
- Compõe funções pequenas depois de as conferir isoladamente. Para testar uma letra e os dois vizinhos dentro de uma palavra, percorre `range(1, len(palavra) - 1)` e reinicia em cada palavra.
- `import math` usa `math.sqrt`; `from math import sqrt` usa `sqrt`. Evita nomes de ficheiros como `pandas.py`, que podem esconder o módulo.
