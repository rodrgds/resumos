## Texto literal e padrões

- `serie.str.strip().str.lower()` normaliza espaços nos extremos e caixa, mantendo ausências. A equivalência entre textos tem de ser justificada pelo problema.
- `str.contains(".", regex=False, na=False)` procura um ponto literal e exclui valores ausentes. Sem `regex=False`, o ponto é normalmente qualquer carácter numa expressão regular.
- `str.extract(r"^PT-(\d{3})$", expand=False)` captura três algarismos de um código como `PT-001`, conservando `001` como texto. As âncoras exigem correspondência com toda a string; códigos inválidos ficam ausentes.

## Categorias e ordem

```python
import pandas as pd
tipo = pd.CategoricalDtype(["baixo", "médio", "alto"], ordered=True)
s = pd.Series(["alto", "baixo", "médio"], dtype=tipo)
print(s.sort_values().to_list())  # ['baixo', 'médio', 'alto']
```

A ordem declarada permite comparar prioridades, sem usar a ordem alfabética. `.cat.categories` lista categorias possíveis; `.cat.codes` dá códigos internos, sem os transformar em medidas.

Converter para categorias não corrige grafias. Valores fora das categorias podem tornar-se ausentes. Nos agrupamentos, `observed=True` usa combinações observadas; `observed=False` inclui também categorias definidas sem observações.
