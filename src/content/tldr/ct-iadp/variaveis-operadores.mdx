## Atribuição e tipos

- `x = x + 2` calcula com o valor atual e associa o resultado a `x`. `=` atribui; `==` compara.
- `int` representa inteiros, `float` números aproximados, `str` texto, `bool` valores lógicos e `None` ausência de valor definido.
- `input()` devolve texto. Converte com `int` ou `float` antes de calcular; `int(2.9)` trunca para 2, sem arredondar.
- Nomes distinguem maiúsculas de minúsculas. A indentação define blocos e `#` inicia um comentário fora de strings.

## Operadores e precedência

| Expressão     | Resultado | Regra                                                                   |
| ------------- | --------- | ----------------------------------------------------------------------- |
| `7 / 2`       | `3.5`     | Divisão                                                                 |
| `-7 // 2`     | `-4`      | Divisão arredondada para menos infinito                                 |
| `-7 % 2`      | `1`       | Resto, com `a == (a // b) * b + a % b` para inteiros e divisor não nulo |
| `-2 ** 2`     | `-4`      | Potência antes do sinal                                                 |
| `(-2) ** 2`   | `4`       | Parênteses primeiro                                                     |
| `2 ** 3 ** 2` | `512`     | Potências agrupam pela direita                                          |
| `"ab" * 2`    | `"abab"`  | Repetição de texto                                                      |

Potências precedem multiplicações e divisões, que precedem somas e subtrações. `1.2e3` vale `1200.0`; `2 + 3j` é um complexo com parte imaginária 3.

A saída é `Total: 7.50 euros`. `:.2f` formata duas casas decimais, sem alterar o valor calculado. `print(a, b, sep=";")` muda o separador; `end=""` evita a mudança de linha.

Os `float` têm precisão finita: `0.1 + 0.2 == 0.3` é falso. Usa `math.isclose` com tolerância adequada às unidades. Para quantias exatas em cêntimos, usa inteiros de cêntimos; não arredondes cada passo sem necessidade.
