## Módulos

`import math` permite `math.sqrt`; `from math import sqrt` introduz `sqrt` no âmbito atual. Instruções no nível do módulo executam ao importar. Guarda a interface de entrada/saída em `if __name__ == "__main__":` para correr apenas na execução direta.

## Ficheiros de texto e CSV

`open(caminho, modo, encoding="utf-8")` abre texto. Caminhos relativos partem da pasta de trabalho do processo.

| Modo  | Efeito                            |
| ----- | --------------------------------- |
| `"r"` | Lê; falha se faltar               |
| `"w"` | Cria ou substitui todo o conteúdo |
| `"a"` | Acrescenta no fim; cria se faltar |
| `"x"` | Cria; falha se já existir         |

- `with` fecha o recurso mesmo quando há uma exceção. `read()` lê tudo; `for linha in ficheiro` percorre linhas.
- `readline()` devolve `""` no fim do ficheiro; uma linha em branco pode ser `"\n"`. Não são o mesmo caso.
- `write` recebe texto, não acrescenta uma mudança de linha e devolve o número de caracteres escritos.
- Para CSV, usa `csv.reader`, `DictReader` ou `writer`, com `newline=""`. Campos podem conter vírgulas e aspas; `split(",")` não chega. Os campos lidos são strings; converte os números.

## Exceções

| Bloco         | Quando executa                                                                       |
| ------------- | ------------------------------------------------------------------------------------ |
| `try`         | Tenta a operação                                                                     |
| `except Tipo` | Trata uma exceção compatível do corpo de `try`                                       |
| `else`        | Só quando `try` termina normalmente, sem exceção nem `return`, `break` ou `continue` |
| `finally`     | Ao sair, mesmo com exceção ou retorno                                                |

Uma falha em `else` não volta ao `except` associado. Trata o erro esperado, como `ValueError` numa conversão, sem esconder falhas diferentes. `raise` comunica uma violação do contrato. Decide se uma falha pede novos dados, ignora uma linha ou termina, em vez de inventar um resultado válido.

## Asserções e testes

- `assert` verifica uma hipótese interna, mas pode ser desativado com otimizações. Valida entradas explicitamente.
- Calcula expectativas independentemente. Inclui um caso normal, fronteiras e entradas inválidas previstas; testes finitos não demonstram correção geral.
- Para aproximações numéricas, usa uma tolerância adequada, por exemplo com `math.isclose`. Para depurar, reproduz a menor entrada útil e encontra o primeiro estado diferente do esperado.
