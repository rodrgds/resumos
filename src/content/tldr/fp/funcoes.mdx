## Definição e contrato

- `def quadrado(x):` define uma função com parâmetro `x`. Em `quadrado(5)`, o argumento é 5. Definir não executa o corpo; chamar executa-o.
- O **contrato** indica entradas, pré-condições e resultado, incluindo casos limite. Uma docstring documenta esse contrato, mas não o valida.
- `return` termina a chamada e entrega um valor. `print` escreve e devolve `None`. Chegar ao fim sem retorno explícito também devolve `None`.

## Âmbito e argumentos

- Cada chamada tem os seus nomes locais. A procura de nomes segue o âmbito **léxico**: local, funções envolventes, módulo e nomes predefinidos. Não procura nas variáveis locais do chamador.
- Atribuir a um nome no corpo torna-o normalmente local. Lê-lo antes da atribuição causa `UnboundLocalError`. `global` permite reassociar um nome do módulo; parâmetros e retorno evitam essa dependência.
- O parâmetro refere o objeto recebido, sem cópia automática. Reatribuir o parâmetro só muda o nome local; `xs.append(9)` altera a lista partilhada com o chamador.
- Uma função interior pode conservar acesso ao contexto envolvente depois do retorno: uma [closure](/cadeiras/fp/programacao-funcional/#devolver-funções-e-âmbito-léxico).

```python
valor = 10

def dobrar(valor):
    return 2 * valor

print(dobrar(4), valor)  # 8 10
```

## Valores por defeito

`def potencia(base, expoente=2):` admite `potencia(3)` e `potencia(base=3, expoente=4)`. Os valores por defeito são calculados quando `def` executa. Uma lista por defeito fica partilhada entre chamadas.

```python
def juntar(valor, valores=None):
    if valores is None:
        valores = []
    return valores + [valor]

print(juntar(1), juntar(2))  # [1] [2]
```

`None` sinaliza que não foi fornecida uma lista. O corpo cria uma nova; a concatenação também conserva qualquer lista recebida.
