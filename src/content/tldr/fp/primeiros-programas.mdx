## Contrato, valores e atribuição

- Um **algoritmo** dá passos precisos para uma classe de problemas. Define a entrada válida e a saída antes de programar.
- `int` representa inteiros, `float` aproximações numéricas, `str` texto e `bool` condições. `None` representa ausência de um resultado útil.
- `12 + 3` vale `15`; `"12" + "3"` vale `"123"`. O tipo determina a operação.
- `total = total + 1` calcula o lado direito com o valor antigo e reassocia o nome. `=` atribui; `==` compara. Os nomes distinguem maiúsculas de minúsculas.

## Operadores

| Expressão | Resultado | Regra                                                 |
| --------- | --------- | ----------------------------------------------------- |
| `7 / 2`   | `3.5`     | Divisão                                               |
| `7 // 2`  | `3`       | Quociente arredondado para baixo                      |
| `7 % 2`   | `1`       | Resto                                                 |
| `-7 // 2` | `-4`      | Arredondar para baixo não é truncar                   |
| `-7 % 2`  | `1`       | `a == (a // b) * b + a % b`, para inteiros e `b != 0` |
| `2 ** 3`  | `8`       | Potência                                              |

- A potência precede multiplicação/divisão, que precedem soma/subtração. `(2 + 3) * 4` dá 20; `2 + 3 * 4` dá 14.
- `-2 ** 2` dá -4; `(-2) ** 2` dá 4. `2 ** 3 ** 2` associa à direita e dá 512.
- `float` é aproximado: `0.1 + 0.2 == 0.3` dá `False`. Formatar com duas casas decimais muda a apresentação, não o valor.

## Entrada, cálculo e saída

`input()` devolve uma string sem a mudança de linha final. `int(input())` converte-a, assumindo texto inteiro válido. `float("3.5")` usa ponto decimal. `print(a, b)` separa valores por espaços; `f"{12.5:.2f}"` produz `"12.50"`.

Para uma duração inteira não negativa, divide por 3600 e depois divide o resto por 60:

A saída é `1 1 1`. Horas podem ultrapassar 23; minutos e segundos ficam entre 0 e 59. Confere por `horas * 3600 + minutos * 60 + segundos == total`.

## Diagnosticar erros

Sintaxe inválida impede interpretar; uma operação inválida falha em execução; um erro lógico dá uma resposta errada. Lê o tipo e a linha da exceção. Para uma resposta errada, segue os valores num caso pequeno conhecido.
