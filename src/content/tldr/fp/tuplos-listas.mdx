## Sequências e mutação

- Listas, tuplos e strings têm ordem e suportam `len`, índices, fatias e `in`. A lista é mutável; o recipiente tuplo é imutável.
- A vírgula cria o tuplo: `(12,)` tem um elemento, `(12)` é um inteiro. `x, y = (3, 4)` desempacota; o número de nomes tem de coincidir com o de elementos.
- `a, b = b, a` usa os valores antigos no lado direito. Um tuplo pode conter uma lista que continua mutável.

| Operação          | Efeito                                         |
| ----------------- | ---------------------------------------------- |
| `xs.append(x)`    | Acrescenta `x` como um elemento                |
| `xs.extend(ys)`   | Acrescenta cada elemento de `ys`               |
| `xs.insert(i, x)` | Insere antes de `i`                            |
| `xs.pop(i)`       | Retira e devolve o elemento                    |
| `xs.remove(x)`    | Retira a primeira ocorrência; falha se faltar  |
| `del xs[i]`       | Retira sem devolver                            |
| `xs[a:b] = ys`    | Substitui a fatia, podendo mudar o comprimento |

`append`, `extend`, `insert`, `remove`, `sort` e `reverse` devolvem `None`. `xs = xs.append(4)` perde a referência à lista. Evita alterar o comprimento da lista durante o próprio percurso sem uma estratégia explícita.

## Alias e cópia superficial

- `b = a` cria outro nome para o mesmo objeto, um **alias**. `==` compara conteúdo; `is` compara identidade.
- `a.copy()` e `a[:]` criam outra lista exterior, mantendo referências aos elementos. A cópia é **superficial**.

## Percorrer, combinar e ordenar

- `enumerate(xs)` fornece índice e valor. `zip(u, v)` fornece pares correspondentes e termina na sequência mais curta. Valida comprimentos iguais se o contrato o exigir.
- O produto interno de `[2, 3]` e `[4, 5]` é $2\times4+3\times5=23$; para vetores vazios, a soma é zero.
- `sorted(xs)` devolve uma lista nova; `xs.sort()` altera a existente e devolve `None`. `reverse=True` pede ordem decrescente; `key` escolhe o valor usado na comparação.
