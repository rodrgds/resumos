## Pertença e operações

- $x\in A$ significa que $x$ é elemento; $A\subseteq B$ significa $\forall x(x\in A\to x\in B)$. A inclusão estrita $A\subset B$ exige também $A\ne B$.
- $\emptyset\subseteq A$ para qualquer $A$. $\emptyset$ tem zero elementos; $\{\emptyset\}$ tem um.
- Em $\{f(x):P(x)\}$, um elemento $y$ exige uma testemunha: $\exists x(f(x)=y\land P(x))$.
- Aqui, $\mathbb N=\{0,1,2,\ldots\}$ e $\mathbb N^+=\{1,2,\ldots\}$.

Fixado o universo $U$:

| Conjunto            | Condição para $x$ pertencer                |
| ------------------- | ------------------------------------------ |
| $A\cup B$           | $x\in A\lor x\in B$                        |
| $A\cap B$           | $x\in A\land x\in B$                       |
| $A\setminus B$      | $x\in A\land x\notin B$                    |
| $A^c$               | $x\in U\land x\notin A$                    |
| $A\mathbin\Delta B$ | $x$ pertence exatamente a um dos conjuntos |

União e interseção são comutativas, associativas e distributivas. A diferença não é comutativa nem associativa.

$$
(A\cup B)^c=A^c\cap B^c,\qquad (A\cap B)^c=A^c\cup B^c.
$$

Para provar $A=B$, mostra as duas inclusões ou transforma a pertença de um elemento arbitrário por equivalências. Para refutar uma inclusão, basta um elemento do primeiro conjunto ausente no segundo.

## Partes, cardinalidade e produtos

- $\mathcal P(A)=\{X:X\subseteq A\}$. Logo, $X\in\mathcal P(A)$ equivale a $X\subseteq A$.
- $A\times B$ contém pares ordenados $(a,b)$, com $a\in A,b\in B$. Se um fator é vazio, o produto é vazio.
- Para conjuntos **finitos**:

$$
|\mathcal P(A)|=2^{|A|},\quad |A\times B|=|A||B|,\quad
|A\cup B|=|A|+|B|-|A\cap B|.
$$

$\mathcal P(A)\cap\mathcal P(B)=\mathcal P(A\cap B)$, mas a união não dá a identidade análoga. Com $A=\{a\},B=\{b\}$, $\{a,b\}$ pertence a $\mathcal P(A\cup B)$ e a nenhuma das duas partes separadas.

## Relações e equivalências

Uma relação $R$ de $A$ para $B$ é um subconjunto de $A\times B$. Escrevemos $aRb$ para $(a,b)\in R$. Para uma relação sobre $A$, todos os quantificadores seguintes percorrem $A$:

| Propriedade    | Condição                                |
| -------------- | --------------------------------------- |
| Reflexiva      | $\forall a,\ aRa$                       |
| Irreflexiva    | $\forall a,\ \neg aRa$                  |
| Simétrica      | $\forall a,b,\ aRb\to bRa$              |
| Antissimétrica | $\forall a,b,\ (aRb\land bRa)\to a=b$   |
| Transitiva     | $\forall a,b,c,\ (aRb\land bRc)\to aRc$ |

Simetria e antissimetria podem coexistir. Não ser reflexiva não significa ser irreflexiva. Para refutar transitividade, apresenta $aRb,bRc$ e a ausência de $aRc$.

Uma **equivalência** é reflexiva, simétrica e transitiva. A classe $[a]_R=\{b\in A:aRb\}$ contém $a$. As classes são iguais ou disjuntas e formam uma partição de $A$. Reciprocamente, cada partição define a equivalência de pertencer ao mesmo bloco.

O quociente $A/R$ tem as classes como elementos. Na paridade sobre $\{0,1,2,3\}$, é $\{\{0,2\},\{1,3\}\}$, com dois elementos.
