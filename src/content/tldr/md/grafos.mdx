## Arestas e graus

Um grafo não dirigido simples $G=(V,E)$ tem pares não ordenados de vértices distintos, sem laços nem arestas repetidas. Um dígrafo usa pares ordenados, podendo ter laços. Neste tópico os grafos são finitos.

Um subgrafo escolhe vértices e arestas conservando os seus extremos. O subgrafo induzido por $U$ mantém **todas** as arestas entre vértices de $U$. O complemento simples, no mesmo $V$, contém os pares distintos ausentes.

| Família        | Arestas e convenção                             |
| -------------- | ----------------------------------------------- |
| $K_n$          | $n(n-1)/2$                                      |
| $P_n$          | $n-1$                                           |
| $C_n$, $n\ge3$ | $n$                                             |
| $K_{m,n}$      | $mn$                                            |
| $S_n$          | $n$ vértices, $n-1$ arestas                     |
| $W_n$          | Ciclo de $n$ vértices mais centro; $2n$ arestas |

Para grafos simples não dirigidos:

$$
\sum_{v\in V}\deg(v)=2|E|.
$$

Há um número par de vértices de grau ímpar; cada grau é no máximo $|V|-1$. Estas condições não bastam para realizar qualquer sequência de graus. Num dígrafo, a soma dos graus de entrada e a soma dos de saída valem ambas $|E|$.

Na matriz de adjacência, linhas são origens e colunas destinos. No caso não dirigido simples, é simétrica, com diagonal zero; a soma de cada linha dá o grau.

## Percursos e conectividade

| Percurso | Repetições                                        |
| -------- | ------------------------------------------------- |
| Passeio  | Pode repetir arestas e vértices                   |
| Trilho   | Não repete arestas                                |
| Caminho  | Não repete vértices                               |
| Circuito | Trilho fechado                                    |
| Ciclo    | Caminho fechado, repetindo apenas a origem no fim |

O comprimento conta arestas. No dígrafo, cada passo respeita a direção. Euler exige arestas distintas, mesmo quando um enunciado lhe chama "caminho".

Um grafo não dirigido é conexo se há caminho entre quaisquer vértices. Componentes conexas são maximais; um isolado também é componente. Um dígrafo é fortemente conexo se há caminho dirigido para cada par ordenado; é fracamente conexo se fica conexo ignorando direções.

## Árvores e distâncias

- Uma árvore é conexa e sem ciclos. Há exatamente um caminho entre cada par de vértices.
- Uma árvore com $n\ge1$ vértices tem $n-1$ arestas. Uma floresta com $n$ vértices e $c$ componentes tem $n-c$ arestas.
- Retirar uma aresta da árvore desconecta-a; acrescentar uma aresta entre vértices existentes cria um ciclo.
- Uma árvore abrangente mantém todos os vértices de um grafo conexo e escolhe $n-1$ arestas sem ciclos.

A distância é o comprimento mínimo, com $d(u,u)=0$ e $d(u,v)=\infty$ quando não há caminho. É simétrica no caso não dirigido e satisfaz a desigualdade triangular.

Com pesos não negativos, **Dijkstra** inicializa origem a 0 e restantes a infinito, fixa a menor distância provisória e melhora os vizinhos por $d(v)\gets\min(d(v),d(u)+w(u,v))$. A hipótese impede um caminho posterior menor para um vértice fixado. Menos arestas não implica menor peso.

## Isomorfismos

Uma bijeção $f:V\to V'$ é isomorfismo se preserva adjacência **nos dois sentidos**:

$$
\{u,v\}\in E\Longleftrightarrow\{f(u),f(v)\}\in E'.
$$
