## Onde está a definição?

O cabeçalho declara a função. O ficheiro `.cpp` define-a. A ligação junta
os objetos.

```cpp
// dobro.hpp, com guarda:
double dobro(double valor);

// dobro.cpp:
#include "dobro.hpp"
double dobro(double valor) { return 2.0 * valor; }
```

<Dot
  source={compilacaoSeparada}
  alt="O cabeçalho entra nas duas fontes. Cada fonte compila num objeto; a ligação junta os dois no executável."
/>

- Cada `.cpp` com includes é uma unidade. Compila sozinho, liga junto.
- Sem `dobro.cpp`, a ligação falha com `undefined reference`.
- `dobro(int)` em vez de `dobro(double)` cria outra sobrecarga. A esperada continua em falta.
- Não incluas `.cpp`. Acrescenta ao alvo.

## Como compilo?

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp dobro.cpp -o exemplo
./exemplo
```

```cmake
add_executable(exemplo main.cpp dobro.cpp)
target_compile_features(exemplo PRIVATE cxx_std_17)
```

`cmake -S . -B build` configura. `cmake --build build` compila. Não edites `build`.

## Que fase falhou?

| Sintoma                | Fase       | Verifica primeiro               |
| ---------------------- | ---------- | ------------------------------- |
| Nome desconhecido      | Compilação | Include, declaração, assinatura |
| Referência por definir | Ligação    | `.cpp` no alvo, definição igual |
| Símbolo repetido       | Ligação    | Definições em cabeçalhos        |
| Valor errado           | Execução   | Contrato, entrada, estado       |
| Falha de memória       | Execução   | Limites, vida, dono             |

Depurar:

1. Reduz a entrada com resultado conhecido.
2. Compila Debug, para antes da divergência.
3. Compara estado com o contrato.
4. Corrige, repete, acrescenta teste. Só depois alarga fronteiras.

Com `{-1, -2}`, `erase` devolve iterador para `-2`. Avançar outra vez salta-o por engano.
