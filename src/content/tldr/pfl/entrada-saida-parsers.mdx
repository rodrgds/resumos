## Ações e valores em IO

- `getLine :: IO String` é uma ação, não a string lida. `putStrLn :: String -> IO ()` cria uma ação de impressão.
- `IO ()` devolve `()`; pode imprimir ou nem produzir interação observável, como `pure ()`.

```haskell
main :: IO ()
main = do
  nome <- getLine
  let cumprimento = "Ola, " ++ nome ++ "!"
  putStrLn cumprimento
```

`<-` corre a ação e nomeia o resultado; `let` nomeia um cálculo puro. As ações correm por ordem. `return n` cria uma ação que devolve `n`; não interrompe o bloco como um `return` imperativo. `length getLine` é um erro de tipo: uma ação não é o valor que produz.

## Parsers como funções

```haskell
newtype Parser a = P (String -> [(a,String)])
```

Um parser lê um prefixo e devolve o valor com o resto. Nesta lição, `[]` é falha e `[(v,resto)]` é o único sucesso; o tipo permite vários pares, mas os combinadores apresentados **pressupõem determinismo**.

| Operação            | Comportamento                                                           |
| ------------------- | ----------------------------------------------------------------------- |
| `item`              | Lê um caráter: `"abc"` dá `[('a',"bc")]`; entrada vazia falha.          |
| `pure v`            | Devolve `v` sem consumir entrada.                                       |
| `fmap f p`          | Transforma o valor, conservando o resto.                                |
| `p >>= f`           | Usa o valor para escolher o parser seguinte, corrido no resto.          |
| `p +++ q`           | Se `p` falhar, tenta `q` na entrada original; prefere o sucesso de `p`. |
| `many p`, `many1 p` | Zero ou mais, ou uma ou mais ocorrências.                               |
| `token p`           | Ignora espaços à volta de `p`.                                          |

`parse nat "42x"` lê `4`, depois `2`, e dá `[(42,"x")]`. `nat :: Parser Int` pressupõe que o valor cabe em `Int`; para naturais arbitrariamente grandes, muda o resultado para `Integer`.

## Precedência, associatividade e progresso

A gramática é `expr = term '+' expr | term`, `term = factor '*' term | factor`, `factor = '(' expr ')' | nat`.

- `term` agrupa produtos antes de `expr` os somar: `2+3*4` dá `14`; `(2+3)*4` dá `20`.
- A recursão à direita associa à direita. Com subtração em vez de adição, `8-3-1` daria `8-(3-1)=6`; acumular à esquerda daria `4`. Prioridade e associatividade são escolhas separadas.
- Recursão à esquerda direta (`expr = expr '+' term`) chama o parser sem consumir nada e pode divergir.
- `many p` exige que **cada sucesso consuma entrada**. `many (pure 1)` repete sem avançar.

## Validar a entrada inteira
