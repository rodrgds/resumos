## Compilar e ligar

`gcc -E`, `-S`, `-c` param no pré-processamento, assembly e objeto. Só a ligação produz o executável.

| Erro                   | Fase       | Falta                               |
| ---------------------- | ---------- | ----------------------------------- |
| `implicit declaration` | compilação | declaração visível (incluir o `.h`) |
| `undefined reference`  | ligação    | definição (objeto ou `-lX`)         |

- Cabeçalho declara; implementação define. `-L.` diz onde procurar, `-lvetor` o quê; a biblioteca estática entra **depois** dos objetos que a usam.
- Partilhada: compilar com `-fPIC`, ligar com `-shared`; o carregador tem de encontrar a `.so` em execução (`LD_LIBRARY_PATH`).
- `-g` é depuração, `-Wall` não é todos os avisos. Lê e corrige cada aviso.

## Apontadores

C passa tudo por valor. A cópia de um endereço permite alterar o objeto, não o apontador do chamador.

```c
int x = 5, y = 3, *p = &x, *q = p;
p = &y;   /* q continua em x */
*q = 9;   /* x passa a 9, y continua 3 */
```

- `p+1` avança um elemento; `a[i]` é `*(a+i)` com índice válido. O fim do array serve de limite, não de leitura.
- `sizeof a / sizeof a[0]` só conta elementos no âmbito do array; em `int a[]` como parâmetro, passa o comprimento.
- `void *` guarda endereços sem tipo: sem desreferência nem aritmética em C17.

## Tempo de vida

- Automático morre no fim do âmbito. Devolver `&local` é comportamento indefinido, com ou sem falha visível.
- `malloc` não inicializa; `calloc` zera. Confere `NULL`, define quem liberta.
- Em `realloc`, guarda o retorno num temporário. Com tamanho pedido maior que zero, a falha conserva o bloco antigo e o sucesso invalida o endereço antigo. `realloc(p, 0)` tem contrato que varia por edição e implementação, por isso não assumas libertação nem bloco válido.
- Depois de `free`, o bloco morreu; pôr um alias a `NULL` não salva os outros.

## Strings, argumentos e listas

- `"ola"` ocupa 4 bytes. `strlen` conta até `\0` numa string válida; não mede a capacidade do buffer. `strcmp` só garante o sinal.
- `strcpy(dst, src)` exige `strlen(src)+1` bytes no destino; `src` tem de ser uma string válida e as regiões não se podem sobrepor.
- `strcat(dst, src)` exige `strlen(dst)+strlen(src)+1` bytes; `dst` já tem de ser uma string válida e as regiões não se podem sobrepor. Não medir `strlen` de um destino ainda não inicializado.
- `strtok` altera o buffer e trata delimitadores como conjunto; `strsep` pode dar tokens vazios.
- `argc` inclui o nome; `argv` são strings. Valida com `strtol` (`ERANGE`, sem dígitos, resto) e confirma `INT_MIN`/`INT_MAX` quando precisas de `int`.
- Para um máximo de números que podem ser negativos, inicializa com o primeiro valor validado, não com zero.
- Lista vazia: cabeça `NULL`. Quem muda a cabeça recebe `struct no **`; guarda `seguinte` **antes** de `free`.
